# 麻枝准 前半の技術（“好きにさせる”工学）

泣きは後半だが、**威力は前半で仕込む**。読者が対象を本気で好きになっていないと、どんな喪失も刺さらない。このファイルは最小公式の「①好きにさせる／②意味を仕込む」の実装方法（`maeda-casebook.md` の前段）。本人インタビューの実務を反映。

---

## 1. 原則：落差は“緩み”の質で決まる
- 麻枝の基本手口は「**最初はギャグシナリオだと思わせて楽しく盛り上げ、最後にシリアスにまとめる**」。
- だから前半の笑い・日常は手抜き厳禁。**緩みが甘いと落差が出ない**＝泣けない。
- シリアスを書く前に、必ず一枚“笑い／ぬくもり”を噛ませる（`maeda-style.md`§2-1）。

## 2. 日常にリアリティを与える（“生活している”感）
本人いわく、キャラが本当にそこで生活しているように描く。具体策：
- **一貫した行動パターン**: 「毎回同じベンチに座る」のように、各キャラに定位置・口癖・儀式を1つ持たせる。反復が“生活”を立ち上げ、後でモチーフ反転（casebook CARD 1）の弾にもなる。
- **小さな固有名詞**: そのキャラだけの呼び方・あだ名・手癖。固有性が愛着を生む。
- **無目的な会話**: 物語を進めない雑談を少し許す。目的のない時間こそ“日常の尊さ”の正体。
- **MINA応用**: ミナの口癖（「わたくし」＋固有の言い回し）、少年の手癖、各ボスの定位置／儀式を1つずつ決めて道中で反復。`Stage*.cs` の `Intro` 配列にぬくもりの一往復を仕込む。

## 3. 掛け合い／ギャグの書き方
- **ボケ役とツッコミ役を固定**し、リズムを作る。誰がボケるか＝キャラ設計（「何をするかでなく、誰がやるか」で笑いは決まる）。
- **三段**: 振り（前提）→ボケ（ズレ）→ツッコミ（回収）。短文で畳みかける。
- **テンポを台詞尺で作る**: 1行を短く、間（…）を効かせる。長台詞でボケない。
- **シリアスの直前ほど明るく**: 落とす直前のシーンを一番楽しくする（落差の最大化）。
- **MINA応用**: `who=0`(少年) と `who=1`(ミナ) でボケ/ツッコミを固定。弾幕の合間（道中 Intro/Clear）に三段の掛け合いを置く。汚染が深まる局面ほど、直前の掛け合いを明るく書いて落差を作る。

## 4. プレイヤー自身の記憶を借りる（普遍的ノスタルジー）
- 本人の手口:「お客様の学生時代の、帰り道で見た**夕日の記憶**と結びつくビジュアルを散りばめる」。
- 固有の物語に、**誰もが持つ普遍的な感覚**（夕暮れ・雨・放課後・別れ際）を重ねると、読者は自分の記憶で勝手に泣く。
- **MINA応用**: 汚染／雨／起動／名前といった本作のモチーフを、普遍的な原風景（雨上がり・誰かに名前を呼ばれた記憶）に接続する地の文(`who=3`)を一行差す。

## 5. インタラクティブ性・選択肢（ゲームだけの武器）
- 麻枝はゲームの本質を「**インタラクティブ性＝“自分が物語を進めている”体験**」と断言。
- **選択肢は“言い訳”にしない**: 「一応遊ばせている感」を排除し、選択でキャラの反応が**実際に変わる**設計にする。
- インターフェース自体（選択肢の有無・タップの反応）で感情を操作する。決定打の場面で**あえて選ばせる／あえて選ばせない**。
- **MINA応用**: 本作 `Epilogue.cs` の `PwChoices[]`（名前/パスワード選択）はまさにこれ。最終局面で「名前を選ぶ／呼ぶ」行為をプレイヤーの手に委ね、選択で結末の手触りを変える。クライマックスの一行は、読ませるより**押させる**。

## 6. 音楽同期の実務（テキスト側でできること）
- 本人は**BGM開始タイミングに極度にこだわる**:「ひとつ前のセリフからBGMをスタートしてほしい」と指示するレベル。
- 決定打の**直前で無音**、その一行の**手前**から主題を入れる、という前のめりの同期で感情を先回りさせる。
- **MINA応用**: 台詞配列に演出ト書きコメントを添える運用（`maeda-style.md`§5）。
  - 例: `// ここで無音`／`// 一行前からBGM:主題`／`// 記憶フラッシュ(who=3と同期)`
  - クライマックスの一行は、曲の入りに合わせて**改行・尺**を調整する前提で書く。

## 前半チェック（“好きにさせ”られたか）
- [ ] 各キャラに定位置・口癖・儀式を1つ与えた
- [ ] 物語を進めない雑談を少し許した（無目的な時間）
- [ ] ボケ/ツッコミ役が固定され、三段のリズムがある
- [ ] 落とす直前のシーンを一番明るくした
- [ ] 普遍的原風景（夕暮れ・雨・別れ際）に接続する一行がある
- [ ] 選択／タップを“言い訳”でなく結末に効く形で使った
- [ ] クライマックスに音・無音のト書きを添えた
