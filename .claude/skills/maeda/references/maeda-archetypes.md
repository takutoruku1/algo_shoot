# 麻枝准 喪失アーキタイプ集（キャラ造形の引き出し）

麻枝ヒロイン／キャラの「喪失の型」を抽象化したカタログ。レイ／あかり／こはる／ミナの造形に、**型をかぶせて固有化する**ために使う。各型は `核となる痛み → 効かせ方 → MINA応用`。
1キャラに1型を主にし、混ぜすぎない（一点を深く＝`maeda-style.md`§7）。

---

## TYPE A — 既に喪われている者（あゆ／Angel Beats型）
- **核**: 出会った時点で、その人はもう“いない／死んでいる”。あるいは留まれない存在。物語の途中でその事実が明かされる。
- **効かせ方**: 読者が好きになってから「実は最初からいなかった」を撃つ。日常の全シーンが追想に変わる。
- **MINA応用**: あるボスを「もう失われた存在の残響／記憶の投影」にする。倒す＝消す、ではなく“見送る”。

## TYPE B — 生きながら失われていく者（真琴／風子／ひな型）★最も残酷
- **核**: 死ではなく、**記憶・自我・存在そのものが、生きたまま薄れていく**。周囲が忘れていく／本人が本人でなくなる。隣にいるのに失われる。
- **効かせ方**: 「死」より重い。看取る側の無力と、最後まで残る一片（口癖・約束）を描く。
- **MINA応用**: 汚染＝記憶/存在の侵食、と接続。あるキャラが「名前を忘れていく／呼ばれなくなる」過程を描き、最後に一度だけ名前を取り戻す。本作の**名前モチーフと最強の相性**。

## TYPE C — 宿命に定められた死（観鈴／渚型）
- **核**: 生まれ・血・病によって、愛するほど失われると決まっている。それでも関係を結ぶ。
- **効かせ方**: 回避不能を早めに予感させ、日常を切なくする。救いは「死を覆す」ではなく「最後まで生ききった肯定」（"がんばった"型）。
- **MINA応用**: あるボスを「穢れを宿す宿命」に。倒さず“届ける”ことで、運命は変えられなくても**肯定して送る**結末に。

## TYPE D — 自己を差し出す者（Charlotte／恭介型）
- **核**: 記憶・自我・命を代償に、他者／世界を救う。救った相手は、救われたことすら覚えていない。
- **効かせ方**: 報われなさ＝無償。当人だけが代償を背負い、世界はそれを知らない。
- **MINA応用**: ミナ or 少年が、皆を救うために**自分の名前/記憶を差し出す**選択。Epilogueの選択（`PwChoices[]`）に代償を絡める。

## TYPE E — 未練を抱えて留まる者（Angel Beats型）
- **核**: 心残りがあって“あいだの世界”に留まる。未練が果たされ／受け入れられた瞬間に消える＝救われる。
- **効かせ方**: 救い＝消失という痛みを伴う解放。送り出す側との疑似家族。
- **MINA応用**: 各ボス＝それぞれの未練を抱えた穢れ。倒さず未練を「届けて」解く＝穢れが晴れて去る。**本作の「倒さず救う」構図の直接の設計図**。

## TYPE F — 遺していく者の側（智也／After Story型）
- **核**: 失う側ではなく、**残されて生き続ける側**の物語。悲しみを抱えて日常を回す重さ。
- **効かせ方**: 喪失そのものより“その後”を描く。立ち直りに時間と代償を要する。
- **MINA応用**: 少年（プレイヤーの分身）を「残される側」に置く。Epilogueで、救った後も残る欠落と、それでも続く日常を短く描く。

---

## 組み合わせの指針（MINA 3ボス＋ミナ）
- **3ボスは別々の型**にして反復を避ける（例: レイ=E未練／あかり=B生きながら／こはる=C宿命）。型が被ると「同じ話」に見える。
- **ミナ本人**は A〜D のどれか“一段重い型”を隠し持ち、終盤で開示（casebook CARD 4「世界の秘密」と接続）。
- **少年**は F（遺される側）に置くと、プレイヤーの感情の受け皿になる。
- ⚠️ どの型を誰に割るかは設計書／ユーザーの意図で確定する（叩き台が要るなら設計書を読んで提案する）。

## 型ごとの“決定打”の方向（詳細は `maeda-lines.md`）
- A: 不在の確定（「もう、いないんだね」）／B: 名前を取り戻す一瞬／C: 生ききった肯定（"がんばった"）／D: 覚えていない相手への無言／E: 「いってらっしゃい」型の送り／F: 「それでも生きる」の小さな再起。
