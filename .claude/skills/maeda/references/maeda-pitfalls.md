# 麻枝准 失敗パターン研究（負の空間／滑る条件）

成功手口の裏返し。麻枝作品が**実際に批判された点**（特に『神様になった日』）を、再利用できる「避けるべき型」に抽象化したもの。`/maeda` は**ドラフトを書いた後の自己レビュー**でこれを通す。`maeda-style.md`§7（線引き）の実証編。
※ 批判の研究＝麻枝の否定ではない。神様も含め信者/批判双方の指摘から「滑る条件」を学ぶ。

---

## P1 — 構造が透けて「シナリオ感」が出る（ワンパターンの露呈）
- **症状**: 同じ型の使い回し・過去作セルフオマージュが目立つと、キャラが「作者の都合で動かされている」感（シナリオ感）になり、自発性が死ぬ。
- **回避**: 構造（beatsheet）は骨であって見せ物にしない。3ボスは**別アーキタイプ**にし、退行/喪失の同型反復を避ける（archetypes 指針）。「このパターン前も見た」を作らない。

## P2 — 主人公が受動的で空虚（“等身大”の罠）
- **症状**: トラウマも夢も主体性もない主人公が、強い存在（神/ヒロイン）に振り回されるだけで退屈。読者の感情の受け皿になり損ねる。
- **回避**: 少年に**賭けるもの・能動の選択**を1つ持たせる。受け皿(TYPE F)に置くのは可だが、「ただ巻き込まれる」だけにしない。弾幕を撃つ＝意志の表明、として行動と感情を一致させる。

## P3 — リアリティラインの混乱（設定で煽って描写で裏切る）
- **症状**: 学術用語/SF設定（量子コンピュータ・難病名）で期待値を上げるが描写が曖昧。能力と状態の矛盾（歩けるのに数字が読めない等）、根拠なき離れ業。
- **回避**: 汚染/穢れ/名前の**ルールを決めたら破らない**。説明できない超展開で泣かせない。提示した設定は必ず描写で裏打ちする。煽り設定を“雰囲気”で使わない。

## P4 — 倫理的無神経さ（最大の批判点）★最重要ガード
- **症状**: ヒロインの意思・尊厳を軽視し、**「主人公の郷愁の器」**にしてしまう。退行/喪失したキャラへの一方的な感情を“感動”として処理。「あの夏」への懐古を本人の現在の意思より優先。所有願望に見える構図。
- **回避**: 救う相手は**人格であって器ではない**。本人の意思・尊厳・現在を描く。「救い」を主人公（プレイヤー）側の満足にしない。MINAでボスを“救う/届ける”時、**相手が何を望むか**を必ず一拍描く。代償も相手の側に閉じない。

## P5 — 泣きの押し付け（感情の強制）
- **症状**: 「ここで泣け」が透ける演出・説明的な感謝/決意・地の文での感情要求。現代の読者ほど興醒めする。
- **回避**: `maeda-lines.md` アンチパターン厳守。感情語直書き禁止、トドメ連発禁止、地の文で泣きを要求しない。**間と日常で泣かせ、押さない**。

## P6 — 尺・テンポ不足（仕込み切れずに転ぶ）
- **症状**: 本来2クール必要な情を1クールに圧縮し、テーマが中盤まで不明瞭、関係構築不足のまま喪失だけ来て空転。
- **回避**: 弾幕ゲームは尺が限られる前提で、**1ボス＝1完結の小さな情**に圧縮し切る（beatsheet）。広げた風呂敷は畳む。建てた伏線は必ず回収。回収できない要素は最初から建てない。

## P7 — 媒体特性の無視（テキストの強みを捨てる）
- **症状**: 麻枝のギャグ/間は「全提示要素を自分が制御できるテキスト」で最も効く。他者の手を経ると崩れる、と本人も認める。
- **活かす**: 本作は**テキスト＝こちらが完全制御**。だから間・改行・無音ト書きを攻めて使える（強み）。逆に、ボイス/作画/秒単位演出に依存しないと成立しない泣きは、エンジンで再現できる範囲に設計する。
