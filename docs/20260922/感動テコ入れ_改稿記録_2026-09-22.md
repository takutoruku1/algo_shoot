## 2. 改稿ビート一覧（ファイル:行 ／ before → after ／ 狙い）

### ビート1 — F4 の手前に「心拍の途切れ」を置く
- `src/Final.cs:105-110`（`_Ready` の `T(...)` 列）
- 追加: `T("ミナ", "……心拍の集計が、途切れています。……回線が、細いので。");`（「三人が、待っていてくださいます」と「まだ、いらっしゃいますか」の間）

### ビート2 — 【初】が届いた後に、認識の一行と心拍の回収
- `src/Final.cs:149-172`（`ApplyFinalChoice` の `after` リスト。`List` 初期化子を分割し、条件付き `Add` に変更）
- 追加①: `"……最初の日に、散った言葉ですね。"`（`_game.FirstScattered` が空＝フォールバック語のときは出さない）
- 追加②: `"……心拍、七十二。——あの日と、同じです。"`
- 位置: `CueResolveLine`（「届きました」）の直後、軽口「{n}文字」の前。
- 狙い: ①【初】が「最初の日に散った言葉」だとミナが**観測として**認識する。なぜ戻ったかは言わない（08 の指定は守る）が、どの言葉かは言う＝回収の最低条件。②「途切れた」心拍が「七十二」に戻る＝「まだ、いらっしゃいますか」の答えを数字で返す。何の心拍かは言わない（ミナのでも、回線の向こうのでも読める＝遅延した理解）。直後の軽口「相変わらず、短いですね」が「あの日と、同じ」を受けて余白になる。
- 実装注意: `CueSilenceLine` / `CueResolveLine` / `DropLine` は**本文一致**で音楽・演出が同期するので変更していない。行の挿入は index 非依存で安全。

### ビート3 — E6 END に空の問いの最終回収
- `src/Epilogue.cs:265-272`（`ApplyE6Choice` の `after`）
- 追加: `"……今日の空は、聞きません。——ご自分の目で、どうぞ。"`（命名の一行の後、「いってらっしゃいませ」の前）
- 狙い: S1-11「返事は、いりません」→ S2-9 無言 → S3-9「もう、聞きません。三度、聞きました。」→ F4「戻ったら、空の話を」→ E5b「わたくしの目で、見た空です」と来た問いを、同じ「聞きません」で閉じる。意味だけが「諦め」から「見てきてください」へ反転し、次行「いってらっしゃいませ」の宛先が「外」になる。
- 実装注意: `ShowingGoodbye`（`_line >= _end.Count - 2`）と END 表示（`_line >= _end.Count - 1`）は末尾からの相対なので、挿入位置に影響なし。

### ビート4 — 結び手（あなた）の返しを「下書き」の声に戻す
