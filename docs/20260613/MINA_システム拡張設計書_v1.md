## §0 統合メモ（分野横断の整合・確定事項）

新システム群は既存シナリオ設計書 v2 の3つの背骨——**(a) 一本道構成、(b) 汚染ゲージ、(c)「撃って解決しない／倒さず届ける」原則**——を一切壊さない。以下は4分野の設計を突き合わせて確定した横断ルール。各章はこの§0に従属する。

### 0-1. テーマ衝突の解消（最重要・全章共通の指針）

「インプレッション＝承認欲求」「フォロワーで強くなる」「炎上」という現代Xの喧噪は、本作の核（"声にならない声を静かに救う"）と衝突しうる。これを**欠陥ではなく主題へ昇華**する。

- **インプレッション／フォロワー＝「届けた証」**。承認の戦利品ではなく、ミナが誰かへ何かを確かに届けた痕跡・繋がりの蓄積。「有名になると強くなる」は「**多くの人に届けたぶん、次に届ける力が増す**」と読み替える。
- **数字に踊らされる世界の中で、ミナと少年だけは"届ける"ことを見失わない**——この対比で主題を彫る。炎上（最大の数字）すら誰の心にも触れていない、という形で「数字 ≠ 届いたか」を体感させる。
- **EPILOGUE 既存伏線②への収束**：救った3人（レイ／あかり／こはる）は救済のたびにミナのフォロワーに加わる。賑やかな数字の海は、実は少年が大切な人だけを潜った名簿だった——とEPILOGUEで反転回収する。フォロワー機能はこの反転のために存在する。

### 0-2. 汚染ゲージ × 経済成長の二律（同じ行為の裏表）

汚染ゲージ（祓うほど濁る）と経済成長（祓うほど豊かになる）は**対立ではなく同一行為の裏表**として同居させる。

- 「届ける」一つの行為が、外向きには **フォロワー＝信頼（豊かさ）** を増やし、内向きには **ミナ自身へ穢れ（汚染）** を溜める。**強くなるほどミナは自分を削っている**——この引き裂きが FINAL 暴走（汚染の必然的到達）への静かな代償として効く。
- **確定ルール**：経済的成功は汚染を帳消しにしない。強化項目「汚染耐性／浄化耐性」は上昇カーブを**緩めるだけ**で、ステージ後の段階的な濁り（v2 §4-b）と FINAL 暴走は**必ず到達する**。
- **確定ルール**：汚染ゲージは**物語進行でのみ動く**。戦闘の勝敗・被弾・難易度・炎上では一切動かさない（一本道の演出を全プレイヤー共通に保つ）。

### 0-3. 強化の恒久化（確定）

**強化は最初から常時恒久（被弾・ミス・リトライで溶けない）をデフォルトとする。**「溶けない」を購入オプションにはしない。

- 理由：本作の要件（最大強化のための周回、フォロワーという永続第2ステータス、ルナ解禁の積み上げ）は**恒久メタ進行型**であり、ローグライト的に溶ける仕様と二重進行軸が衝突する。
- ♥（ライフ）＝「そのランの生存資源」、強化＝「恒久資産」と役割を明快に分離。
- テーマ整合：「届けたものは、なかったことにはならない／いなくならない」を、強化が**消えない**というメカニクスで反映する。
- 緊張は「失う恐怖」ではなく **①ノーダメ/コンボ係数（稼ぎ効率）②難易度ボーナス③ステージ内ノーミス目標** で作る。

| 層 | 場所 | トーン | UI |

# ① メタ進行・経済システム設計（インプレッション経済 / 強化 / フォロワー）

> **要約**：戦闘で得た「インプレッション」をステージ間の**タイムライン・ハブ**で消費し、自機ミナを恒久強化していく Marfusha 型の周回ループを定義する。第2の恒久ステータス「フォロワー」が火力とインプレ倍率に効き、十分な強化でルナティック（最高難度）が解禁・クリア可能になる。承認欲求の数値化という現代Xの皮肉は、本作では「届けた証＝信頼」として物語的に反転させ、汚染ゲージ（祓うほど濁る）と経済成長（祓うほど豊かになる）の二律を**同じコインの裏表**として同居させる（§0-1, §0-2）。

## ①-1. 設計の前提と本章の責務

- 本作は**一本道**（分岐・マルチED なし）。メタ進行は「物語の進行」ではなく「自機性能と周回密度」のみを変化させる。物語フロー・伏線回収は既存シナリオ設計書 v2 が管轄し、本章は介入しない。
- 自機＝ミナ。穢れは「倒す」のではなく「届けて」解決する。本章の数値設計はこの禁則を破らない（後述の「無双」は弾幕制圧であって、ボス＝救う対象を撃ち倒すことではない）。
- 数値はすべて**初期バランス目安**であり、プレイテストで再調整する前提。

## ①-2. 全体ループ（経済の一巡）

```
            ┌─────────────────────────────────────────────┐
            │  ① 戦闘（ステージ／道中＋ボス＝救済）         │
            │     → インプレッション獲得（Imp）            │
            │     → 浄化100%でフォロワー獲得（Fol）        │
            └───────────────┬─────────────────────────────┘
                            ▼
            ┌─────────────────────────────────────────────┐
            │  ② ステージ後：MINAの自動投稿               │
            │     → 投稿に時間経過でImpが入る（放置収入）  │
            │     → プレイヤーがコメント返信でImpブースト  │
            └───────────────┬─────────────────────────────┘
                            ▼
            ┌─────────────────────────────────────────────┐
            │  ③ タイムライン・ハブ（ステージ間ショップ）  │
            │     → Impで強化購入（恒久）                  │
            │     → Folが火力・Imp倍率に常時上乗せ         │
            └───────────────┬─────────────────────────────┘
                            ▼
            ┌─────────────────────────────────────────────┐
            │  ④ 強化された状態で次ステージ／同ステージ周回 │
            │     → 楽になる→無双→より速く深く稼げる       │
            │     → 高難度ほどImp/Fol倍率が高い            │
            └───────────────┬─────────────────────────────┘

```

**インプレッション（Imp）の獲得元一覧**

| 獲得元 | 概要 | 目安 |
|---|---|---|
| 言葉弾の祓い（撃破） | 道中で言葉弾を祓うたび加算。連続でコンボ係数 | 1祓い＝1〜3 Imp ×コンボ |
| 浄化進捗 | ボス浄化の%到達ごとにマイルストーン報酬 | 浄化100%で大口ボーナス |
| ノーダメ／被弾少 | ステージ被弾0でリーチ係数。♥減で逓減 | ノーダメ ×1.5〜2.0 |
| インプレ獲得倍率（強化） | ショップで買う恒久倍率 | 後述（段階制） |
| コメント返信（②導線） | クリア投稿へミナがコメント→伸び | 1返信で投稿Impの+10〜30% |
| 自動投稿の放置収入 | ステージ後の自動投稿に時間/周回で加算 | 小額×回数（チリツモ） |

| フォロワー倍率 | Folが多いほど全Impに常時上乗せ | 後述の式 |

> 設計意図：**「祓う＝届ける」行為そのものが経済の源泉**。撃ち込み快感（『艦砲射撃！甲改』参照）は道中コンボに、報酬の山場はボス浄化100%に置く。スコアではなく「届けた量」が通貨になる構図を保つ。

## ①-3. タイムライン・ハブ（ステージ間ショップ）

- ステージに入る前、Xのタイムラインが川のように流れるハブ画面を表示（既存世界観：ミナはここにのみ存在）。
- ここで Imp を消費して**恒久強化**を購入する。Marfusha のウェーブ間ショップの直接の翻案だが、「ウェーブ間」ではなく「ステージ間（＝物語の節目）」に置く。
- 同ステージへの**再ダイブ（周回）**もこの画面から選択（①-8）。
- 強化はカテゴリ別の浅いツリー（前提購入で上位解禁）。1画面で全体像が見える設計（迷子にさせない）。

## ①-5. フォロワー数とパワーの関係（第2の恒久ステータス）

フォロワー（Fol）は Imp と別軸の**消費されない永続ステータス**。Imp が「使うと減る通貨」なのに対し、Fol は「貯まり続け、常時バフを生む信頼度」。

**増え方**
- 主な獲得：各ステージの**浄化100%（救済達成）**で大口加算。
- 副次：高難度クリア、ノーダメ達成、コメント返信・自動投稿のエンゲージメント、周回ボーナス。
- 性質：基本的に**減らない（届けた証は消えない＝テーマと一致）**。

**パワーへの効き方（定式・目安）**
```
火力倍率      = 1.0 + min(0.50, Fol × 0.00010)      … Fol 5000 で +50% に漸近（天井あり）
Imp獲得倍率   = 1.0 + min(0.50, Fol × 0.00008)      … 同じく天井あり
ルナ解禁判定  = Fol ≥ FOL_LUNATIC かつ 強化主要項目が一定段階
```
- **対数的／天井付き**にして「フォロワーが青天井で無限インフレ」を防ぐ（ルナでも油断させないため）。
- Fol は「広く薄く全体を底上げ」、ショップ強化は「狭く深く尖らせる」——2軸の性格を分けることで、稼ぎ方の好み（周回でFol盛り型／集中投資で尖らせ型）に幅を出す。

## ①-6. 無双の作り方（カタルシス）と最高難度での抑制

**無双の作り方**
- 火力系（#2拡散・#14オプション子機・#3連射）が重なると、画面下半分の言葉弾を**面で祓える**ようになり、道中が「避ける」から「制圧する」へ反転する。これがカタルシスの核。
- ボム（#6/#7）の所持・範囲が増えると、ピンチを能動的に**浄化チャンス**へ変換できる（ボムで一掃→コンボ継続→Imp激増）。
- Fol 火力倍率が乗ることで「有名になるほど弾が分厚くなる」体感を与える。

**ただしルナティックでは無双しても油断できない調整**（②難易度へ接続）：
- 火力・Fol倍率には**天井**があるため、ルナの弾密度・速度には性能だけでは追いつかない領域を残す。
- ルナ限定で「祓っても即補充される言葉弾」「制圧前提の高密度配置」を置き、**操作精度（避け・グレイズ）が依然として要求される**設計を②難易度に依頼。
- すなわち、Normal〜Hard は「強化で無双できる達成感」、Lunatic は「最大強化を**入場資格**とし、その上で腕を試す」二層構造。

## ①-7. 周回（同ステージ再プレイ）の動機と報酬設計

- **再ダイブ**をハブから選択可能に。物語進行には影響せず、稼ぎ・強化のための周回として機能。
- **動機**：①最大強化に必要な Imp を稼ぐ ②Fol を盛る ③高難度クリアでルナ解禁を積む ④無双の気持ちよさの反復。

**報酬カーブ（目安）**

| 軸 | 設計 |
|---|---|
| 最大強化までの所要 | 通常プレイ＋数周（目安：全ステージ1周＋同ステージ計5〜8周程度）で主要項目が揃う |
| 逓減 | 同一ステージの周回は2周目以降 Imp ×0.8 → ×0.6… と逓減（同じ場所の連打を抑制） |
| 天井（リフレッシュ） | 難易度を上げる／別ステージへ移ると逓減がリセット。**「より難しく」「より広く」回す**よう誘導 |
| 難易度別Imp倍率 | Normal 1.0 / Hard 1.5 / Lunatic 2.5〜3.0（①-2 と一致） |
| 周回ボーナス | 同ステージ規定周回ごとに一括Fol／実績報酬（チリツモの目標感） |

> 設計意図：**「同じステージを楽に何度も」だけでは飽きと作業化を招く**ため、逓減で横移動（別ステージ）と縦移動（難易度上げ）に誘導し、結果として「広く・高く」プレイさせる。Marfusha 的な単調反復を、難易度×ステージのマトリクスで回避する。

## ①-8. コメント返信／自動投稿の経済ループ（②導線の数値定義）

文面・トーンは③ナラティブ管轄。本節は**経済としての数値ループ**のみ定義。

| 要素 | 仕様（目安） | 経済的役割 |
|---|---|---|
| 自動投稿 | ステージクリア後、ミナが結果を自動投稿。時間経過／次プレイ開始時に少額Impが自動加算 | **放置収入**。プレイの隙間を埋める小口の安定収入 |
| コメント返信 | 自動投稿（または救済したツイート）にプレイヤーがミナのコメントを選んで返す | **能動ブースト**。返信で当該投稿のImpを+10〜30%、Folを少量加算 |
| エンゲージ係数 | 高難度クリアの投稿ほど、伸び（Imp係数）が大きい | 高難度プレイへの追加報酬 |
| 上限 | 1投稿あたりの累計Imp・返信回数に上限。複利暴走を防止 | インフレ防止の安全弁 |

ループ：**クリア→自動投稿（放置収入）→返信（能動ブースト）→Imp/Fol増→次の強化**。返信は「数手で完了する軽いミニ操作」とし、稼ぎの最大化を狙うプレイヤーへのご褒美に留める（必須化しない＝静かなトーンを壊さない）。

## ①-9. ルナティック解禁の接続（②難易度への受け渡し）

本章は「**強化によってルナが解禁／クリア可能になる**」接続のみを定義。ルナ自体の弾幕・配置・速度設計は②難易度が管轄。

**解禁条件（目安・本章提案）**：次のいずれか／組み合わせを満たすとルナ解禁。
- フォロワー `Fol ≥ FOL_LUNATIC`（目安：火力倍率天井に近い水準）
- 主要火力強化（#2拡散・#14オプション）が一定段階以上
- 当該ステージを Hard で規定回数クリア

**②難易度への受け渡し事項**
1. 本章が保証する「ルナ入場時の自機性能レンジ」（最大火力・最大Fol倍率・ボム数の上限）を共有。②はこのレンジを前提に**性能だけでは突破できない弾密度**を設計。
2. ルナのImp/Fol倍率（2.5〜3.0想定）が経済を壊さない範囲か、①-7 の逓減・天井と合わせて要すり合わせ。
3. 「無双しても油断できない」具体パラメータ（即補充弾・高密度配置の量）は②へ委譲。本章は「天井のある倍率」という制約のみ提供。

## ①-10. メタ進行・経済：未確定・要協議項目

- ルナ解禁を「ステージ単位」か「全体一括」か（②難易度・進行担当と協議）。

- 自動投稿の放置収入が「時間経過」か「次プレイ開始時一括」か（プレイ形態に合わせ確定）。
- 恒久化（§0-3）がローグライト期待層と乖離しないか、初回プレイテストで検証。

# ② 難易度・戦闘バランス設計（難易度選択 / ルナティック / 炎上デバフ）

> **要約**: 戦闘難易度を「ステージ入場時に選ぶ4〜5段ティア」として定義し、調整の主軸を一貫して**敵弾（玉）の数＝弾密度**に置く。最高難度ルナティックは**メタ強化が乗らないと現実的にクリア不能、乗れば無双気味に攻略可能**という曲線で設計し、炎上を**そのステージ限定の一時的戦闘デバフ**として接続する。鉄則「撃って解決しない／全員が結末に到達する」を壊さないため、低難度には結末到達を保証する救済を必ず用意する。すべての数値は**目安**。

## ②-1. 基本方針（設計の前提）
- **調整の主軸は「弾数（玉数）」**。弾速・敵HP・出現量は副次パラメータとし、ティア間の体感差はまず**画面上の同時弾数**で作る。弾幕パターンは1本作って**密度係数で派生**させる工数集約方式。
- **二層構造を死守**：低〜中難度は基本操作だけで完走でき、高難度は強化前提でも気を抜けない。クリア可否の天井をメタ強化側で押し上げる。
- **戦闘は物語を止めない**：戦闘の勝敗で汚染ゲージは動かさない（§0-2）。
- **本作ルールとの整合**：道中の敵＝言葉弾を撃って祓う、ボス＝弾幕を抜けて奥の本人へ光を届ける（倒さない）。難易度は「届ける」までの**到達難度**の調整であり、「より強く倒す」ゲームには絶対にしない。

## ②-2. 難易度ティア表
入場時に選択。推奨は4段（＋任意で「とてもやさしい」）。

| 項目 | とてもやさしい（任意） | やさしい | ふつう | むずかしい | ルナティック |
|---|---|---|---|---|---|
| 想定プレイヤー | 物語だけ見たい層 | STG苦手 | 標準 | STG経験者 | 強化済みの上級者／やりこみ |
| **同時弾数（玉数）係数** ★主軸 | ×0.4 | ×0.6 | ×1.0 | ×1.5 | ×2.2〜2.6 |
| 弾速 | ×0.7 | ×0.85 | ×1.0 | ×1.1 | ×1.25 |
| 敵HP | ×0.7 | ×0.85 | ×1.0 | ×1.2 | ×1.4 |
| 敵出現量（ウェーブ密度） | ×0.7 | ×0.85 | ×1.0 | ×1.2 | ×1.5 |
| ボス弾幕パターン | 基本のみ・間引き | 基本 | 基本＋怒り | 基本＋怒り＋断末魔 | 全段＋ルナ限定弾幕 |
| インプレ倍率 | ×0.5 | ×0.7 | ×1.0 | ×1.4 | ×2.0〜2.5 |
| ルナ限定弾幕/ギミック | なし | なし | なし | なし | あり（②-4） |
| ♥（ライフ）初期 | 5 | 4 | 3 | 3 | 3（強化で増加） |
| コンティニュー | 無制限 | 無制限 | 回数制 | 回数制（少） | なし（②-4） |

- **★主軸の読み方**：ティア差はまず「同時弾数係数」で作る。弾速・HP・出現量は体感の角を整える微調整であり上げすぎない（理不尽化の主因）。
- **インプレ倍率**は経済へ渡す係数。高難度ほどバズるが炎上リスクも上がる綱引きの入口。
- **「とてもやさしい」**は弾密度を大きく間引き、被弾救済も最大化（誰でも結末に到達できることを最優先）。

## ②-3. 「無双」と難易度の両立
- **低〜中難度 × 強化 = 弾幕制圧の爽快感**：強化が乗ると言葉弾を**まとめて浄化**できる。画面が言葉弾で埋まっても一掃して光に塗り替わる「無双」を意図的に作る（『艦砲射撃！甲改』の撃ち込み快感）。ただし**ボスは倒れない**ため、無双は道中に限定し、ボスは常に「抜けて届ける」緊張を残す。
- **高難度 = 強化前提でも気が抜けない**：火力が上がっても弾密度がそれを上回るよう設計。強化＝「クリアの土俵に上がる券」であって「無敵」ではない。火力インフレに対しては**弾密度（玉数）で必ず追い越す**（火力で殴り勝つゲームにしない）。
- **火力インフレ vs 弾密度の指針**：強化1段の火力上昇は「同難度の弾密度を1段下げて感じる」程度に抑制。ルナのみ、強化天井で弾密度を火力がわずかに上回る地点を作り、ここで初めて「無双気味のクリア」が成立（②-4 の曲線）。

## ②-4. ルナティック（最高難度）の位置づけ
- **コンセプト**：「強化なしでは現実的にクリア不能、強化が乗れば無双気味に攻略可能」。攻略曲線を強化量に強く依存させ、**メタ強化の成長を戦闘の前提に組み込む唯一のティア**（Marfusha の物量増 × 恒久強化の綱引きに相当）。

| 強化段階 | ルナの体感 |
|---|---|
| 無強化 | クリア不能（弾密度×2.2が火力を大きく上回る） |
| 中強化 | 道中は捌けるがボスで力尽きる。挑戦が成立し始める |
| 高強化 | 道中を無双で抜け、ボスは紙一重で「届く」 |
| 天井強化 | 火力が密度をわずかに上回り、無双気味に安定クリア |

- **解禁条件**：ルナは初見では選べない。解禁トリガーは①メタ進行が確定し、②はフラグ `IsLunaticUnlocked(stageId)` を受けるだけ（§0-4, ①-9）。
- **コンティニューなし**：やりこみティアのため無制限復活を与えない。代わりに**強化の累積が事実上のコンティニュー資源**（負けても強化は溶けず次回が楽になる＝マルフーシャ型の前進感、§0-3）。
- **ルナ専用の弾幕/ギミック案**（ステージのナラティブに沿わせる。倒さず届ける原則は維持）：
  - **STAGE1 レイ（順位掲示板）**：「２位」の数字弾が外周から内側へ収束する**順位収束弾**。火力で数字を浄化すると一時的に隙間が開く＝火力が密度を割る快感。
  - **STAGE2 あかり（雨の教室）**：言いかけて弾ける白い吹き出しが、ルナでは**弾ける瞬間に二次弾を撒く**（「す——」が破裂して拡散）。抑制トーンを壊さない静かな高密度。
  - **STAGE3 こはる（台所）**：冷めていく料理＝**減速しながら戻ってくる回帰弾**。画面に居座る弾が密度を底上げ。届けた瞬間に全消し（カタルシス）。
  - 共通：ルナのみ**「奥の本人の光」が明滅して届ける窓が狭い**（タイミング要求）。ただし強化が乗ると窓が広がる調整にし、強化＝救済の関係を保つ。

## ②-5. 炎上デバフの仕様
炎上の**発生条件は①メタ進行／③ナラティブが確定**する（フォロワー・インプレ・ミナの投稿に連動）。戦闘側は「炎上中フラグを受け取り、その回の戦闘を弱体化する」ルールのみ定義（§0-4）。

- **発生トリガー（戦闘側はフックのみ）**：入場時に `IsBurning(stageId)`＋強度（0.0〜1.0）を受け取る。炎上は**入場時点で確定**し、戦闘中に新規発火しない（途中で理不尽に弱くならない）。
- **効果（推奨：ショット弱体を主、移動低下を従）**：

| 候補効果 | 採否 | 内容（目安） | 理由 |
|---|---|---|---|
| **ショット弱体** | ◎主効果 | 火力 −20〜30%（強度比例） | 「届けるのに手間取る」緊張を作るが回避は阻害しない |
| **移動速度低下** | ○従効果 | 移動 −10%（軽め） | 「動揺で操作が鈍る」表現。下げすぎると回避不能 |
| インプレ倍率低下 | ○ | 当該ステージのインプレ ×0.6 | ナラ整合（炎上中は伸びにくい）。経済と要調整 |
| 被弾判定拡大 | ✕不採用 | — | 回避そのものを難しくするのは理不尽 |
| ♥減 | △限定 | 初期♥ −1（強度最大時のみ／下限2） | 採るなら最強度時だけ。下限を割らせない |

  - **基本推奨**：「ショット弱体（主）＋移動わずか低下（従）＋インプレ低下」。**回避能力（弾を避ける力）は削らない**のが鉄則。
- **解除条件**：**そのステージ限定**。クリア（または離脱）で**自動解除**。次ステージに持ち越さない。
- **視覚/聴覚フィードバック**：自機周囲に赤い通知ノイズ/燃える微発光を薄く（汚染の濁りとは別系統の赤系で区別）。HUDに小さく「炎上中」アイコン＋火力ダウン表示。SEは入場時に一度だけ低い通知音（戦闘中は鳴らし続けない）。ミナの軽口を1行差せる枠を③に用意。
- **難易度ティアとの相互作用（救済方針）**：**高難度＋炎上は救済**。炎上強度に上限を設け、**ルナ × 炎上は弱体率を半減**（例 −30%→−15%）。低難度＋炎上は通常適用。とてもやさしいでは炎上の♥減を無効化。

## ②-6. 被弾・汚染ゲージ・♥（ライフ）の関係
- **♥（ライフ）= 戦闘リソース**：被弾で減り、尽きるとミス。**その回の戦闘の中だけ**で完結し物語に干渉しない。
- **汚染ゲージ = 物語の背骨**：物語進行でのみ進む。**戦闘の勝敗・被弾・難易度・炎上では一切動かさない**（§0-2）。
- **恒久強化は♥が削れても溶けない**（§0-3）：被弾・ミスで強化資産は失わない。
- **ライフ管理とリスタート**：ミス時は原則**その場復帰**（任意でショット段階1ダウン程度の軽い罰）。全ロストはしない。♥全消費＝失敗時は強化を保持したまま**当該ステージ頭から再挑戦**。ルナのみコンティニューなし＝失敗で即ステージ頭へ（強化は保持）。汚染ゲージはリスタートで巻き戻さない。

## ②-7. 難易度とストーリー体験の両立（完走保証）
一本道作品として、**全プレイヤーが結末（EPILOGUE）に到達できる**ことを絶対要件とする。
- **やさしい以下は完走を保証**：コンティニュー無制限＋その場復帰で、戦闘が原因で物語が止まらない。
- **FINALは戦闘なし**：難易度に関わらず到達後は同じ体験。難易度の壁は STAGE1〜3 のみ。
- **ボム/救済での担保**：低難度では緊急回避（全弾消し＋短時間無敵）を多めに付与。
- **難度はいつでも下げられる**：失敗が続いた場合により低い難度を提案するアシスト導線。難度を下げても汚染ゲージ＝物語状態は不変。

## ②-8. 難易度・戦闘：未確定・要協議項目
- 「とてもやさしい」を正式採用するか（4段か5段か）。
- 各ティアの弾数係数の確定値（特にルナ ×2.2〜2.6 の上限。実機の可読性テスト必須）。
- ルナ解禁トリガーの最終仕様（①メタ進行）。
- 炎上効果の最終構成（弱体率／移動低下の有無／♥減）と強度算出式（①③と）。炎上 × ルナの弱体半減の具体数値。
- インプレ倍率の確定値、炎上中インプレ低下の採否。
- グレイズ/接近報酬を入れるか。ミス時ショット段階ダウンの有無。

## ③-4. 道中ザコの葛藤"声"（言葉弾に載せる短文）
- 道中のザコ＝救う相手の心を侵す「言葉」そのもの（本人ではない／撃って祓っていい）。そこへ**短い"声"を載せる**。弾の出現〜接近時に薄く小さな文字が浮かび、撃って消すと声も消える＝「声を鎮める」。倒す快感ではなく**沈めてあげる**感触。SEは「砕く」音でなく「ふっと消える」音。

| ステージ | 言葉弾の"声"（短文） |
|---|---|
| STAGE1 レイ | 「どうせ二番」「届かない」「努力は天才に勝てない」「私を見て」「もう、走れない」「一番だけが、ぜんぶ」 |
| STAGE2 あかり | 「言えない」「ごめんね」「す——（弾けて消える）」「あの——」「すきになって、ごめん」「会いたかった」 |
| STAGE3 こはる | 「むだだよ」「なにをつくっても」「もう帰ってこない」「ひとりになる」「いってきます、が言えない」「あかりのせいだ」 |

**頻度と分量の指針（重さ／テンポを壊さない）**
- **声付き弾は全体の2〜3割まで**。残りは無地の弾（テンポ用）。
- 1つの声は**最長6〜8文字**。完文より断片を優先（「届かない」＞「私の努力は届かない」）。
- 同一フレーズの連続反復は最大3回まで。掲示板の「２位」無限は背景で担い、弾文は単調にしない。
- 道中前半は声を薄く、ボス手前で密度を上げる（感情のピークへ）。
- **ボス（本人）の弾には声を載せない**。撃って祓う対象と光を届ける対象を弾の質感で無言で区別する。

## ④-8. 帰還〜自動投稿の演出シーケンス
