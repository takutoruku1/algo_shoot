# algo ― やさしさは、ひろがる。 統合企画メモ（再設計v2）

> SNSの悪意で歪んだ世界／悪魔のようなコメントをする人々を、algoが浄化して優しい人に戻す——をテーマにした再設計。
> 旧版は [GAME_DESIGN.md](GAME_DESIGN.md)。本書がコンセプトの最新版（v2）。

## 採用/不採用の判断（先に結論）

|---|---|---|---|

中核思想: **「敵にHPはない。死なない。貼りついた黒い吹き出し（ヘイト・パネル）を剥がし、その人を救い、救った人が次の救済を助ける」** を一本化の柱にする。Clean Timelineの重いグリッドは捨て、あいことばのパネル剥がし＋他案の"連鎖/味方化/二軸"だけを最小コストで足す。

## 2. ワンライン・コンセプト

> 撃って"消す"んじゃない。人に貼りついた黒い暴言を1枚ずつ剥がして本当のことばを取り戻し、救ったその人が次の誰かを救う――やさしさが連鎖していく横スクロール浄化シューティング。

## 3. 世界観（SNSで歪んだ世界）

舞台は **SNSの悪意ある投稿で歪んでしまった世界**。誹謗中傷・暴言・炎上・スパムが「黒い汚れ／ノイズ」となってタイムライン・街・人々を侵食している。

- **敵＝モンスターではなく人間**。元は普通の人が、SNSの悪意に当てられて"悪魔化"し、黒い吹き出しの暴言弾を撒く存在になっている。
- **algoは殺さない・壊さない**。取り憑いた悪意・暴言の汚れだけを浄化して、本来の穏やかな表情・あたたかい言葉の人間に戻す。
- メッセージの着地: 「ことばで傷つけ合う世界を、algoがやさしいことばで塗り替える」希望の物語。

**重いテーマをalgoのかわいさで優しく昇華する三層方針（厳守）:**
1. **罵倒語そのものは出さない。** 暴言は黒い記号・形（黒ハート／黒い渦／ドクロ吹き出し／棘の輪郭／「・・・」）でのみ抽象表現する。出しても「は？」「で？」程度の軽い短文まで。
2. **言語化は救済後だけ。** 浄化後に初めて「ありがとう」「だいじょうぶ」「きみは悪くないよ」等のやさしい言葉を見せ、必ず前向きに締める。
3. **感情の着地は"倒した"でなく"助けた"。** 敵は消えず、笑顔の味方／背景の花として画面に残り、救済を視認させる。誰も死なない非致死。

## 4. なぜ前案より強いか（浄化＝本物のメカニクスの実現／弱点解消）

**旧コンセプトの致命弱点:** 「撃つ→敵が消える」で普通のSTGと同じ＝浄化が"言葉だけのリスキン"だった。

**本案の解決（三層を貫く核動詞）:**
- **弾幕密度の層:** 敵のHPを「剥がせる黒い吹き出しパネル配列」に置換。各パネルは①暴言弾の発生源②algoの弾を遮る盾、を兼ねる。1枚剥がすごとに飛んでくる弾が実際に減り、盤面が物理的に軽くなる＝"自分の手できれいにしている"手応えがデータで保証される。
- **攻略順序の層:** 1人を剥がし切って浄化すると、その人から**やさしさの波紋**が同心円に広がり、近隣の敵パネルを半減／連鎖浄化させる。"最初の誰をどこで救うか"の配置パズルがSTGに同居。
- **スコア／快感の層:** スコアは撃墜数でなく「救った人数×連鎖長×残こころ」。さらに**救った人がオプション編隊（やさしいフォロワー）化**し、次の浄化を加速する正のフィードバックと、**雑に祓えば灰色／踏み込んで救えば極彩色**の二軸やり込みを統合。

→ 浄化が見た目リスキンでなく、弾幕・攻略・スコア・難易度・結末すべてを駆動する。**5案の最良要素（パネル剥がし＋連鎖＋味方化＋二軸価値）を、Clean Timelineの重グリッドを捨てることで実装可能なスコープに収めた**点が前案群より強い。

## 5. コアメカニクス（浄化の動詞・操作・盤面/タイムラインの変化）

### 5-1. 敵の構造（最重要の作り直し）
各「悪魔化した人」は **不滅の本体（人間・消えない）＋本体に旋回する3〜6枚の黒い吹き出しパネル** で構成。`Enemy.Hp` 単一値を **パネル配列** に置換する。

### 5-2. 浄化の動詞＝パネル剥がし（基礎ループ）
- algoの光弾（2way流用）をパネルに当てる → インクが減る → ヒビ → パリンと砕けて**光の粒「やさしさ」**（回収アイテム）に。
- パネルが減るほど、そのパネルが撃っていた暴言弾の手数が減る＝盤面が軽くなる。

### 5-3. 浄化完了＝人が戻る（撃破ではない）
- 全パネルを剥がし切ると本体が一瞬虹色フラッシュ → 穏やかな人間スプライトに切替 → 頭上に白い吹き出しでやさしい言葉。
- その人は enemy グループから外れる。

### 5-4. 救った人の二択（フォロワー化＋傾聴を統合・簡略化）
浄化完了の瞬間に **自動で**（"近づいて拾う"二段アクションは廃し負荷を下げる）：
- **やさしさの波紋**を発生（同心円リング）。波紋に触れた近隣敵パネルはインク半減、残1枚なら自動剥離＝**連鎖浄化**。
- 救った人は画面に残り、ゆっくり左へ流れる**味方コメント**になる。味方の周囲では敵弾がゆっくり**減速**（"場を鎮める声"）。
- さらに、画面内の味方が一定数たまると、近い順に最大4体が **algoの周囲を回るフォロワー（オプション）** に昇格し、algoのショットに同期してハート弾を撃つ＝**手数が増え、次の浄化が速くなる正のループ**。

### 5-5. 二軸の価値（"祓い vs 救い"を密度で表現）
精密な三重リング滞在は工数過大なので**簡略化**して取り込む：
- **雑に流す:** パネルを全部は剥がさず通り過ぎる／祓い弾で黙らせるだけ → 速いが連鎖もフォロワーも発生せず、汚染バーは下がらず背景は灰色のまま、低スコア。
- **きちんと救う:** パネルを剥がし切って浄化 → 連鎖・味方化・汚染バー低下・背景が極彩色化、高スコア。
- 「速くクリアしたいなら流す／世界を救いたいなら救う」のやり込み二軸が成立。

### 5-6. 世界の変化（重グリッドを捨てた軽量版）
- 画面上部に **タイムライン汚染バー**。剥がしたインク量で下がる。放置すると敵が再暗化し微増（ゆるいプレッシャー）。
- バーが閾値を下回ると **トレンド浄化**発動 → 4層パララックス背景が暗→明＆極彩色にトランジション（既存背景をそのまま色替え）。
- → 「世界が自分の手で塗り替わる」を**float配列グリッドなしで**達成。可読性・処理負荷リスクを根本回避。

### 5-7. 操作まとめ（W0流用）
- 移動: 8方向。低速(Shift): パネルをピンポイントで狙う精密モード。
- ショット(2way光弾): パネル剥がし。フォロワーが同期射撃。
- ボム「ぜんぶに、おはよう」: 全画面へやさしい一斉投稿。全パネルのインクを一段階洗い流す＋飛来中の暴言弾を花びらに変換（全消しでなく"きっかけ作り"）。
- グレイズ＝「既読スルー」: 暴言弾をかすって受け流すと小加点＋光が少し戻る。

## 6. 敵＝悪魔コメント民のデザイン

共通: 浄化前＝寒色・うつむき・棘のある吹き出し形状／浄化後＝暖色・顔を上げる・丸い柔らかい吹き出し＋花・光のハート。非致死でかわいい。

- **アンチくん（直進ザコ／GlyphMote改）**: うつむいた人。黒い「↓低評価」吹き出しを3枚旋回。浄化後→にっこり「ありがとう」、低評価がピンクのいいね♡に反転。
- **エンジョー（炎上型・中ボス／PageShard系）**: 頭から黒い炎、6枚の渦巻き吹き出しを高速旋回。剥がすほど鎮火 → 浄化で炎が桜の花びらに変わり舞いながら退場。子分（同調アカ）を従え、本体浄化で子分も連鎖浄化。
- **スパムロボ（連投型・群れ）**: 同じ黒吹き出しを機械的に量産。減速場（味方の声）に誘い込んでまとめて剥がすのが上手い立ち回り。浄化で「コピペ」が花束の連投に。改心後は通知ドロップ（残機/ボム）を落とす得点源。
- **かげぐち（潜伏型）**: 背景に紛れ半透明。光を当てると実体化。浄化で「だいじょうぶだよ」。
- **ボス「バズの主（ぬし）」**: 巨大な炎上の渦＋黒い引用吹き出しの王。元は注目されたかった寂しい人間。多層の吹き出しを順に剥がすフェーズ制。最終浄化で渦が大きな花の樹になり「ごめんね、言い過ぎた」とうなだれて素の人に戻り、静かにログアウトする余韻。タイムライン全体が虹色に。

暴言はすべて記号・形・トーンで表現し、実在の中傷文は書かない。

## 7. SNS表現（UI/演出/メカへの織り込み）

- **背景＝タイムライン**: 4層パララックス最奥を流れる投稿カード層に。汚染時は黒帯、浄化進行で明るい投稿カードへ。画面上下に流れる「タイムライン帯」が世界回復率の常時インジケータも兼ねる。
- **敵弾**: 角丸の黒い吹き出し小弾（中身は「・・・」やドクロ・黒ハート）。浄化で花びら／光ハートに変換。
- **自機・フォロワー弾**: 薄紫のハート・「♡」の小吹き出し。
- **HUD**: スコア＝「インプレッション」、コンボ＝「やさしさが◯人にひろがった！」のリツイート風吹き出し、味方化＝画面隅「Followers: N」、汚染バー＝「タイムライン汚染度」、こころ＝既存HeartsBar。
- **通知トースト**: 浄化完了で「◯◯さんが本当のきもちを取り戻しました」、フォロー成立で「◯◯さんがフォローしました」（既存 Hud.ShowBanner/ShowMessage 流用）。
- **ボム/グレイズ**: ボム＝「ぜんぶに、おはよう」（一斉やさしい投稿）、グレイズ＝「既読スルー」。
- **報酬通貨は"いいね"より"だいじょうぶ"**: 承認欲求でなく安心のサインを主軸に。

## 8. コアループ（数十秒）

1. 右から悪魔化した人々が黒い吹き出し弾を撒きながら流れてくる。
2. 低速(Shift)で弾を避けつつ、各人の黒パネルを光弾で1枚ずつ剥がす → 手数が減り盤面が軽くなる。
3. 誰か1人を剥がし切って浄化 → **やさしさの波紋**が広がり、近くの人が連鎖浄化。
4. 「やさしさが◯人にひろがった！」。救った人は味方コメント化し敵弾を減速、たまるとフォロワー（オプション）に昇格して手数が増える。
5. 落ちた光の粒（やさしさ）を集めて汚染バーを下げる → 閾値で背景＝世界が明るく極彩色に塗り替わる。
6. 増えた手数と安全地帯を足場に、次の敵へより深く踏み込む → 高連鎖。

→ 約20〜40秒で「剥がす→救う→連鎖→増える→世界が明るくなる」が一巡する上り調子ループ。

## 9. 勝利/失敗・スコア/ランクの意味

- **勝利**: ステージのタイムライン汚染バーを閾値以下まで下げ、ボス「バズの主」を浄化（大炎上を鎮火）してエリアをきれいにする。
- **失敗**: algoのこころ（hearts）が尽きると"しょんぼり"して一時退場＝「くじけそう…もう一度」のリトライ表現（非致死・破壊でない）。チュートリアルは死なない学習空間。
- **スコア（インプレッション）** ＝ 救った人数 × 連鎖長 × 残こころ。
- **ランク（PURITY%）** ＝ そのステージで救った割合。S＝ほぼ全員を救った高彩度クリア（真エンド・虹のタイムライン）、A〜C＝流し（祓い）多めの速攻。
- 意味の中心: 撃墜数でなく **「どれだけ広くやさしさを広げたか＝連鎖と救済をどう設計できたか」** の上手さを評価する。

## 10. 普通のSTGとの決定的な差別化

1. **敵が死なず、味方／背景の花として画面に残る** ＝破壊の逆ベクトルが報酬。
2. **HPの代わりに"剥がせる悪意パネル"** ＝弾を当てる行為が弾源と盾を物理的に減らす盤面操作になっている（リスキンでない）。
3. **"最初の一人をどこで救うか"の配置パズル** がシューティングに同居＝撃つ場所の意味が違う。
4. **倒した相手が次の戦力になる正のフィードバック**（撃つほど手駒が減る通常STGと真逆）。
5. **雑に流す（灰色）vs 救う（極彩色）の二軸** で、最適行動が殲滅でなく救済効率になる。
6. **スコアが撃墜数でなく救済・連鎖・残したやさしさ**。

- Hud.ShowMessage/ShowBanner/Flash（通知トースト・大技フラッシュに流用）。

2. **`Die()` を「QueueFree」→「人間スプライトへ切替＋味方コメント化＋波紋発生」へ変更。** 既存Purify()の浄化フラッシュ演出を改心ポップに拡張。

5. **汚染バー＆背景カラートランジションの軽量Manager**（float配列グリッドなし）。
6. **2way光弾の調整**（パネルをピンポイントで狙えるよう貫通/拡散の微調整）。
7. char/algo.png はそのまま使用。敵・吹き出し・人間化スプライトは新規素材（暫定は _Draw プレースホルダで先行検証可）。

## 12. 主要リスクと対策

- **【最大リスク】スコープ膨張**（パネル配列＋波紋連鎖＋味方化＋フォロワー＋汚染バー＋背景遷移の同時実装）。
  - 対策: **段階実装を宣言で固定**。MVPは「パネル剥がし＋2人連鎖」だけ（§13）。フォロワー編隊・汚染バー・4敵種・ボスは後回し。
- **【連鎖が運任せに退行】** 配置パズルの意図が伝わらず"ただの全消しゲー"化。
  - 対策: 浄化完了直前のパネルに **波紋射程プレビュー**（剥がし切ると波紋が届く範囲を薄いリングで予告表示）を必ず入れる。配置パズル成立の最重要対策。
- **【正のフィードバック効きすぎ】** フォロワー火力増で後半が作業化。
  - 対策: フォロワー上限4・被弾で離脱・視認上限で負荷管理。
- **【二軸が片寄り崩壊】** 流す一択 or 救う一択になる。
  - 対策: 流すは"速いがスコア・ランク・背景回復ゼロ"、救うは"遅いが全報酬"と価値を直交させ、時間制限（汚染再増）でテンポ管理。MVPで早期体感検証。
- **【可読性】** 薄紫トーン上で黒弾が埋没。
  - 対策: 敵弾は黒だが**縁取り・高彩度の差し色**を付け、浄化済み帯を明るくして弾を浮かせる。
- **【炎上テーマの繊細な扱い】**
  - 対策: §3の三層方針を厳守（罵倒語は記号化／言語化は救済後のみ／着地は"助けた"）。敵は必ず救えて二度と敵にならず、誰も死なない。報酬通貨を"いいね（承認）"でなく"だいじょうぶ（安心）"に寄せる。

## 13. まず作る最小プロト（次の一歩）

**MVPゴール: 「剥がす→救う→2人連鎖」だけが気持ちよく回ることを検証する。** それ以外は全部後回し。

1. **`Enemy` をパネル配列化**: HP単一値を撤廃し、本体（不滅）＋3枚の黒パネル（旋回・各々が弾源兼盾）に。光弾ヒットでパネルのインク減→砕けて光の粒。プレースホルダは `_Draw` の円/四角でよい。
2. **浄化完了処理**: 全パネル剥離で本体を虹色フラッシュ→「ありがとう」吹き出し→enemyグループ離脱（QueueFreeしない）。
3. **やさしさの波紋＋プレビュー**: 浄化完了でArea2Dリングを発生、触れた近隣パネルを半減/自動剥離。**剥がし切る直前に波紋射程プレビューを表示**（配置パズル成立の生命線）。
4. **最小スコア表示**: 「やさしさが◯人にひろがった！」のコンボ表示（既存Combo流用）。

この4点で **"パネル剥がしで弾幕が実際に減る"＋"連鎖が狙って起こせる"** の2点が検証できれば、本コンセプトの核は成立。フォロワー編隊・汚染バー＆背景遷移・4敵種・ボス・二軸スコアは、この検証後に順次追加する。

### 統合の要点
土台「あいことば」のパネル剥がし＋波紋連鎖を幹に、「フォロワーたち」の味方化・正フィードバック、「傾聴」の二軸価値＋減速場、「Refrain」のグレイズ/ボムの軽量形を枝として接ぎ木し、「Clean Timeline」の重い汚染グリッドのみ切除して汚染バー＋背景遷移という軽量版に置換した。これにより5案の魅力を保ちつつ、最大の共通弱点だった"スコープ膨張・可読性・連鎖の運任せ化"を、MVP絞り込みと波紋射程プレビューで構造的に解消している。
