# 主人公 弾・ショット強化システム 設計書 v2

> 対象：自機（少年／MINA戦時は役割反転）のショット周りの強化（パワーアップ）システム
> 関連実装：`src/Player.cs` / `src/Bullet.cs` / `src/BulletPool.cs` / `src/Follower.cs` / `src/GameManager.cs` / `src/Shop.cs`
> 通貨：**インプレッション**（`GameManager.Impression`）
>
> **v2 追記**：戦闘中にボタンで切り替える「ショットモード（連射／拡散／ホーミング）」を新規追加（→ [§3](#3-ショットモード切替システムnew)）。

---

## 1. 目的とコンセプト

- プレイヤーが稼いだ**インプレッション**を恒久強化に投資し、周回ごとに自機ショットを育てるメタプログレッション。
- 強化は `user://save.json` に永続保存され、リトライ・難易度変更・汚染状態をまたいで維持される。
- ショット強化は「火力（damage）」「手数（連射）」「面制圧（拡散／フォロワー）」の3軸で構成し、プレイスタイルに応じた伸ばし方を許容する。
- **ショットの“撃ち味”自体を3モード（連射／拡散／ホーミング）から選び、戦闘中にボタンで切り替えられる**（→ [§3](#3-ショットモード切替システムnew)）。連射は初期解放、拡散・ホーミングはショップ購入で解放。強化レベル（火力・連射速度等）は全モード共通で乗る。

## 2. 現状のショット仕様（強化が掛かるベース値）

`src/Player.cs` `Fire()` を起点とした基本パラメータ。**強化システムはこの基底値に乗数／加算で作用する。**

| 項目 | フィールド/値 | 既定値 | 備考 |
|---|---|---|---|
| 発射間隔 | `FireInterval` | `0.11s`（約9発/秒） | 過熱(Overload)時 `0.07s` |
| 弾速 | `Fire()` 内 `vel` | `360 px/s`（右方向） | 固定 |
| 弾半径 | `Bullet.Radius` | `3.0 px` | 固定 |
| 基礎ダメージ | `1 + ShotDamageBonus` | `1` | `shot_power` で加算 |
| 弾数 | 2-way（上下） | 2 | `muzzle ±4px` |
| マズル位置 | `GlobalPosition + (20,0)` | — | 自機の右20px |

```csharp
// src/Player.cs  Fire()
Vector2 muzzle = GlobalPosition + new Vector2(20f, 0f);
Vector2 vel    = new Vector2(360f, 0f);
int dmg        = 1 + (_game?.ShotDamageBonus ?? 0);
_pool.Spawn(muzzle + new Vector2(0f, -4f), vel, isEnemy:false, 3f, dmg); // 上
_pool.Spawn(muzzle + new Vector2(0f,  4f), vel, isEnemy:false, 3f, dmg); // 下
```

### フォロワー（拡散／オプション）
ショット火力に直結する補助ユニット。`src/Follower.cs`。

| 種別 | 弾速 | 弾半径 | ダメージ | 発射頻度 |
|---|---|---|---|---|
| 通常フォロワー | `300 px/s` | `2.5 px` | `1` | 2発に1回（過熱時は毎回） |
| ヒカゲ（昇格） | `380 px/s` | `3.6 px` | `2`×2way | 毎回 |

- 敵を3体浄化するごとに1体獲得。最大4体（うち1体をヒカゲ化可能）。
- フォロワー累計数に応じた恒久ボーナスあり（`GameManager`）：
  - `FollowerImpressionMul = 1 + min(0.50, Followers × 0.00008)`（インプレ獲得、上限1.5x）
  - `FollowerPowerMul = 1 + min(0.50, Followers × 0.00010)`（火力、上限1.5x）

## 3. ショットモード切替システム（NEW）

> **v2 の主機能。** 自機のメインショットを3つの「モード」から選び、**戦闘中にボタンで即時切替**できる。
> 連射は最初から使用可能。拡散・ホーミングは**ショップで購入すると解放**される（→ [§5-0](#5-0-ショットモード解放ショップ)）。
> §2 の強化（`shot_power` / `fire_rate` 等）は全モードに共通で乗算・加算される。

### 3-1. 3モードの概要

| モード | 解放条件 | 一言で | 得意 | 弾形/色 |
|---|---|---|---|---|
| **連射**（Rapid） | 初期解放 | 右へ直線の高速ストリーム（段数で複線化） | 単体DPS・正面の硬い敵 | ガラス円弾（浄化の水色） |
| **拡散**（Spread） | ショップ購入 | 右方向へ扇状に展開 | 雑魚処理・面制圧・道中 | ガラス円弾（水色・小粒） |
| **ホーミング**（Homing） | ショップ購入 | 右側のマゼンタの穢れ標的へ吸い寄せられて曲射 | 動く敵・避けながらの削り | ガラス円弾（軌跡を引く） |

- 3モードは**同じ弾プール（`BulletPool` / `Bullet`）**を使い、生成パラメータ（弾数・角度・速度・追尾フラグ）だけが異なる。
- いずれも `isEnemy:false`・自機弾レイヤー（layer=2 / mask=4）で生成し、ダメージは `1 + ShotDamageBonus` を基準にモード係数を掛ける。

### 3-2. 各モードの弾仕様（提案値）

#### ① 連射（Rapid）— 右へ直線の高速ストリーム
- 現行ショット（§2）を継承。**「段数」レベルで複線化**する：
  - 段数1：2-way（±4px）／段数2：3-way（±6px・中央）／段数3：4-way（±4/±10px）…
  - 段数は `shot_power` レベル（または専用レベル `rapid_line`）に連動させる案。`段数 = 2 + floor(Lv/2)`。
- 弾速 `360 px/s`、半径 `3.0px`、直線（`Velocity` 固定）。
- 発射間隔は §2 通り（`FireInterval × FireIntervalMul`、過熱時 `0.07s`）。
- 1発あたりダメージ最大＝**正面集中型**。横の取りこぼしは大きい。

#### ② 拡散（Spread）— 右方向へ扇状に展開
- 銃口から**右向き扇状に n-way**（既定 `n=5`）。
  - 角度：上下 `±28°`（`t = i/(n-1) - 0.5` → `ang = t × deg2rad(56)`）。基準方向は `+X`。
  - ※ ヒカゲ専用スキル `TryHikageSpecial()`（±32°の15-way）と同方式。常用メインなので本数・威力は控えめ。
- 弾速 `320 px/s`、半径 `3.0px`。
- 1発ダメージは連射より低め（係数 `×0.8` 目安）＝**手数で面を取る**。
- 段数レベルで `n` を増やす案（n=5 → 7 → 9）。

#### ③ ホーミング（Homing）— マゼンタの穢れ標的へ曲射
- 毎ショット2発を斜め前方へ放ち、**最寄りの穢れ標的へ吸い寄せられて曲がる**。
- **標的選定**：`GetTree().GetNodesInGroup("enemies")` のうち `IsPurified == false` かつ `GlobalPosition.X > Player.X`（＝右側）から、各弾が最寄りを選ぶ。
  - 敵弾（マゼンタ）ではなく**敵本体（穢れの発生源）**を標的にする。標的が無ければ直進。
- **曲射の挙動**（`Bullet` に追尾を追加）：
  - 初速 `260 px/s`、半径 `3.0px`。
  - 毎フレーム、速度ベクトルを標的方向へ**最大旋回角 `≈180°/s`** で寄せる（急旋回しすぎない＝“吸い寄せ”感）。
  - 速度の**大きさは一定**に保つ（向きだけ補間）。
- 連射より発射間隔をやや長く（`×1.15` 目安）、1発ダメージは連射と同等＝**当て易さと引き換え**。
- 弾形は `Needle`/`Rice` 系で進行方向に伸ばすと曲射が映える（`Bullet._Draw` は `Velocity.Angle()` 追従済み）。

### 3-3. モード別バランス早見

| モード | 弾速 | 本数/発 | ダメージ係数 | 間隔係数 | 性格 |
|---|---|---|---|---|---|
| 連射 | 360 | 2〜（段数） | ×1.0 | ×1.0 | 単体最大DPS・正面特化 |
| 拡散 | 320 | 5〜（段数） | ×0.8 | ×1.0 | 面制圧・取りこぼし減 |
| ホーミング | 260 | 2 | ×1.0 | ×1.15 | 自動追尾・避け重視で安定 |

> 数値は提案初期値。`fire_rate`・`shot_power`・`FollowerPowerMul` は全モードに共通で乗るため、最終DPSは強化レベルで底上げされる。

### 3-4. 切替（入力）UX

- **切替ボタン**（新規割当）：
  - キーボード：`V`（ショット `Z` / ボム `X` / スキル `C` と隣接、押し間違いしにくい配置）
  - ゲームパッド：`B` ボタン（現状 A=ショット・X=ボム・Y=スキル・L1/R1=低速 で空き）
- 押すたびに**解放済みモードのみ**を循環（連射 → 拡散 → ホーミング → 連射 …）。未解放はスキップ。
- **エッジ検出**（`_modeHeld` でホールド中の連続切替を防止）。`Hud.BubblePaused`（会話中）は不可＝他入力と同じ規約。
- 切替時：HUD に現在モード名を短時間トースト表示＋軽い SE／フラッシュ。クールダウンは無し（または 0.15s デバウンス）。
- 選択中モードは**ラン継続中保持**し、`Save()` で「最後に選んだモード」を記録 → 次回も同モードで開始。

### 3-5. HUD 表示

- 残機・ボム表示の近くに**現在ショットモードのアイコン＋名称**を常時表示（`Hud.SetShotMode(mode)`）。
- 未解放モードは選択循環に出さない（ショップ未購入が一目で分かる必要は薄いので HUD では非表示でよい）。

### 3-6. データモデル & 永続化（`GameManager`）

```text
enum ShotMode { Rapid, Spread, Homing }

// 解放フラグ（ショップ購入で true、Save 対象）
bool HasSpread   // shot_spread Lv≥1
bool HasHoming   // shot_homing Lv≥1
// Rapid は常に解放

// 現在選択（Save 対象。起動時に復元）
ShotMode SelectedShotMode

// 解放済みモードの循環ヘルパ
ShotMode NextUnlockedMode(ShotMode cur)
bool IsModeUnlocked(ShotMode m)
```

- 解放は §5 のショップ強化 `shot_spread` / `shot_homing`（Lv1=解放）に対応。`Deferred` からは外す（購入可能にする）。
- 既存セーブ（モード情報なし）からのロード時は `Rapid` 固定＝後方互換。

| 入手元 | 量 |
|---|---|

| ステージクリア | `120`（基礎） |

総合乗数（`GameManager.TotalImpressionMul`）：
```
TotalImpressionMul = 難易度倍率 × フォロワー倍率 × 強化倍率 × (今回バーニング ? 0.6 : 1.0)
```
- 難易度倍率：Easy 0.7 / Normal 1.0 / Hard 1.4 / Lunatic 2.2
- 周回ペナルティ：同ステージ反復 `ReplayMul = 0.8^反復回数`（下限0.4）
- バーニング（炎上）デバフ：次ステージのインプレ ×0.6

## 5. 強化カタログ（ショット関連を中心に）

`src/GameManager.cs` の `UpgradeDef[]` に定義。コスト式は共通：

```

```

購入処理（`GameManager.TryPurchase`）：所持インプレから減算し、レベルを+1して `Save()`。

## 6. データフロー（強化＋モード → ショットへの反映）

```
[Shop UI]  購入操作（強化 / モード解放）
   │  GameManager.TryPurchase(id)
   ▼
[GameManager]  _upgrades[id]++  →  Save() → user://save.json
   │  各種派生プロパティを再計算
   │   ・ShotDamageBonus   = GetUpgradeLevel("shot_power")
   │   ・FireIntervalMul   = max(0.4, 1 - 0.08×Lv("fire_rate"))
   │   ・HasSpread/HasHoming = (shot_spread/shot_homing Lv≥1)
   │   ・MoveSpeedMul / HitRadiusMul / TotalImpressionMul ...
   ▼
[Player]  _PhysicsProcess
   │   ・切替ボタン(V/Pad B) → SelectedShotMode を解放済みモードで循環 → Hud.SetShotMode
   │   Fire():
   │     switch SelectedShotMode
   │       Rapid   : 段数分の直線2way+ を vel=(360,0) で発射
   │       Spread  : ±28°のn-way を vel=320 で発射（dmg ×0.8）
   │       Homing  : 2発を Homing=true で発射（vel=260, 間隔 ×1.15）
   │     dmg          = (1 + ShotDamageBonus) × モード係数
   │     _fireCooldown = FireInterval × FireIntervalMul × モード間隔係数（過熱時0.07s）
   ▼
[BulletPool.Spawn → Bullet.Activate]  弾を生成（vel, radius, damage, Homing 反映）
   └ Homing弾は _PhysicsProcess で最寄りの穢れ標的へ最大旋回角つきで曲射
```

ポイント：
- ショットの**ダメージ**は弾生成時に `Bullet.Damage` へ焼き込み、敵側（`Enemy`）で消費される。モード係数も生成時に確定。
- ショットの**連射速度**は乗数で `FireInterval` に作用。過熱（やさしさオーバーロード）時は強化・モードと独立に `0.07s` 固定で上書き。
- **モード切替はラン中いつでも可・無料**。強化レベルは全モード共通で乗る（モードを変えても育てた火力は無駄にならない）。
- 強化・解放はすべて恒久。`SelectedShotMode` も保存し次回に引き継ぐ。

## 7. バランス指針

- **早期の伸ばし先**：`fire_rate`（350〜）か `imp_mult`（300〜）が安価。手数か資金循環で立ち上げる。
- **火力の本命**：`shot_power` は最大Lv5・総額約5275で、終盤の DPS を大きく押し上げる主軸。
- **面制圧**：`fol_gain` でフォロワー獲得を加速 → `FollowerPowerMul`（上限1.5x）の恒久火力も育つ二重効果。
- **モード解放の位置づけ**：`shot_spread`（500〜）/ `shot_homing`（700〜）は“火力”ではなく“状況対応の選択肢”を買う枠。連射1本でもクリア可能なバランスを崩さないよう、各モードは一長一短（拡散は1発威力↓・ホーミングは弾速↓/間隔↑）に留める。
- **モードと敵配置**：道中（散開する雑魚）＝拡散、ボス（単体・正面）＝連射、動き回る中型＝ホーミング、という住み分けを意識した敵配置だと切替が活きる。
- **コスト倍率設計**：いずれも 1.4〜1.55x の指数で、レベルが上がるほど割高。低レベルを広く取るか1軸を尖らせるかの選択を作る。
- **難易度との関係**：高難易度ほどインプレ倍率が高い（Lunatic 2.2x）ため、強化資金は「リスクを取るほど早く貯まる」設計。
