# ルナティック 純粋STG化（2026-09-26）

作者指示（原文）:

> ルナティックモードは回想シーンとエンディングシーン、選択肢等のギミックはカットで、常に敵がでつづけて、ボス戦では戦闘が止まらないようにして

判定は `GameManager.IsLunatic`（= `Difficulty == Diff.Lunatic`。難易度選択の「底まで」）の1本。静的な入口として `GameManager.LunaticActive`（`Instance?.IsLunatic == true`）も置き、Stage/Boss/CameoBoss/BossPostSequence がこれだけを見る。**Easy/Normal/Hard は判定が false のまま従来の分岐をそのまま通る**（挙動は変えていない。後述の Normal 走行で確認）。

## 判断したこと（指示に無かった点）

- **ボス投稿の割り込み（BossPost）も切った。** 指示の列挙（回想・エンディング・選択肢）には無いが、ボスが隠れて札を撃たせ「読む間」（`BossPost.MinimumReadTime`=3.2 秒〜）を置く仕組みで、5 回分の割り込み＋最後の一枚絵が「ボス戦が止まる」時間になるため、優先順位①（止まらない）で切った。戻すなら `BossPostSequence.Attach` と `BossAkari._Ready` の各1行（`BossDraftScene` だけ切る形にもできる）。
- 中ボスの捨て台詞は 1 行目だけ字幕（止めない）で残し、本ボスの改心の台詞は丸ごと省いた（1 行だけ残しても文脈が無く意味を成さないため）。
- ステージクリア後は 3 秒のリザルト表示（TIME/SCORE/BEST）を置いた。会話ではなく数字を読む間なので「待ち」には数えていない。FINAL も他の面と同じ様式で `FINAL CLEAR` を出してからタイトルへ。

## 残したもの

- 道中の波（Spawner A/B/C・あかりの肩慣らし0）、中ボス（CameoBoss。登場の第一声・RECLOSE・捨て台詞はもともと `ShowBossLine`＝止めない）、本ボスのスペル・宣告カード・カットイン・BREAK/RECLOSE の字幕、投稿弾（PostBullets）、レイ面の「引用の嵐」（step 18。射撃ギミック）、あかりの「雨の帰り道」、こはるの「五徳の十字火」、レイの安置リレー、ミナ戦の段ごとの武装（`MinaPhaseAttacks.BeginPhase`）と衣装替え。
- 【激情】メーター（`FuryDial` の背景演出）。選択が無いので `RecordChoice` は呼ばれず、初期値は 0（`FuryMeter.cs` は触っていない）。
- `STAGE n START`／`STAGE n CLEAR`（TIME/SCORE/BEST）バナー、FINAL のタイトルカード。クリア後は `LunaticClearHold`=3 秒だけリザルトを置いてハブへ（会話が閉じるのを待つ step は無い）。
- ハブ・ショップ・プロローグ・チュートリアル（Stage0）は戦闘外なので対象外＝無変更。

## QA（`tools/LunaticQa.cs` + `tools/qa_lunatic.tscn`）

自動操縦（QaPilot の --assist と同じ作法をツール内に持つ。QaPilot は起動しない）で 4 面を順に走らせ、面ごとに

- (b) `StoryFilm/ChoiceOverlay/MinaPhaseScene/BossDraftScene/CommentInput/BossPost/EndingFilm` が `SceneTree.NodeAdded` で一度も観測されない
