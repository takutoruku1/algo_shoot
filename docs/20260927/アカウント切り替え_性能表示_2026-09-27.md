# アカウント切り替え 性能表示（2026-09-27）

作者指示「アカウント切り替えに火力とかの記載を追加してほしい／乗ってない情報があれば記載」への対応記録。
あわせて指揮官指示の数値振り直し（レイ ♥+1、4人の移動・回避距離）も反映している。

## 何が足りなかったか

改修前の `Hub.JobStats` は 1 行だけを返していた。

```
♥+2／移動×0.88／回避距離×0.9
```

`JobTuning` が持っている情報のうち、**撃ち方（Mode）・火力（PowerMul）・溜め打ち（Charge*）・
密着クリティカル・遠距離ボーナス・浄化ドレイン・BREAK ボム・祈りの帳・被弾無敵・踏みとどまり**が
一切画面に出ていなかった。アカウントを選ぶ手がかりとして、選択理由の本体（どう撃つ人か）が欠けていた。

## 表示項目（フィールド → 文言）

### 段（行）の 1 行要約 — `Hub.JobStats`

| 出典 | 文言 | 例 |
|---|---|---|
| `JobTuning.Mode` | `Jobs.ModeName` | `連射` / `加速` / `追尾` / `拡散` |
| `JobTuning.PowerMul` | `Jobs.PowerLabel` | `火力 標準` / `火力 低い ×0.8` |

合わせて `連射／火力 標準` のように出す。行の右端に寄せ、名前とハンドルの高さを食わない。

### 詳細パネル（選択中の 1 人ぶん） — `Hub.DrawJobPanel`

**上段：撃ち方**

| 出典 | 文言 |
|---|---|
| `Mode` | チップ（`Jobs.ModeName`）＋ `Jobs.ModeNote` の一言 |
| | 連射「素直な直射。手数で押す」／加速「伸びるほど速い。一点突破」／追尾「勝手に追う。狙いが楽」／拡散「扇状に広く。面の制圧」 |

**中段：火力と溜め**

| ラベル | 出典 | 文言 |
|---|---|---|
| 火力 | `PowerMul` | `標準`（1.0）／`高い ×n`／`低い ×n`。1.0 超は Light、未満は Text3 で色分け |
| 溜め | `ChargeDescription` `ChargePower` `ChargeWays` | `3発の追尾弾（威力4×3発）` / `直線を貫く高速弾（威力12）` |

**中段：体の目安（4 列・`Hub.JobVitals`）**
★この 4 項目は基準値と同じでも落とさない。並べたとき 4 人の序列が読めることが目的。

| ラベル | 出典 | 書式 | 色 |
|---|---|---|---|
| ♥ | `MaxLifeDelta` | `+2` / `±0` / `-1` | 正=Ok / 負=Hp / 0=Text2 |
| 移動 | `MoveMul` | `×0.88` 形式（`0.00` 固定） | 1.0 超=Ok / 未満=Hp |
| 回避距離 | `DodgeDistMul` | 同上 | 同上 |
| 回避の戻り | `DodgeCdMul` | 同上 | **小さいほど良い**ので符号は逆読み |

倍率は `0.00` 固定。`×1` と `×0.96` が並ぶと桁が揃わず、序列が目で追えないため。

**回避距離の一言（`Jobs.DodgeDistNote`）** — 4 列の下に細い区切り線を引き、`回避距離：…` を 1 行だけ添える。
4 人で 0.55〜1.50（約 2.7 倍）と開きが大きく、倍率だけでは「踏み込む足」なのか
「その場でやり過ごす無敵」なのかが読めないため。

| `DodgeDistMul` | 文言 | 該当 |
|---|---|---|
| ≥1.35 | `踏み込みも離脱も速い` | あかり 1.50 |
| ≥1.05 | `標準よりわずかに伸びる` | こはる 1.10 |
| ≥0.75 | `ほぼその場。耐えて捌く` | ミナ 0.80 |
| それ未満 | `ほとんど動かない。無敵だけもらう` | レイ 0.55 |

回避の無敵（`Player.DodgeIFrame` 0.45 秒）は 4 人共通なので、短い側でも「その場で弾をすり抜ける」ことは
言い落とさない文言にしてある。

**下段：強み／弱み（`Hub.JobPros` / `Hub.JobCons`）**
上の 4 項目と重複しないよう、「その人しか持っていない性質」だけを拾う。

| 条件（出典） | 文言 | 側 |
|---|---|---|
| `HitInvulSec > 1.2` | `被弾後の無敵が長い 1.8秒` | 強み |
| `NoHitKnockback` | `被弾でのけぞらない` | 強み |
| `CloseDodgeCdMul < 1.0` | `密着中は回避が軽い ×0.75` | 強み |
| `CritEnabled && CritMult > 1.25` | `密着クリティカル ×2（上限8）` | 強み |
| `FarMult > 1.0` | `120px より遠い敵に ×1.3`（距離は `Jobs.FarRange`） | 強み |
| `DrainPerLife > 0` | `24体 浄化するごとに♥+1` | 強み |
| `BombOnBreak` | `BREAK ごとにボム+1` | 強み |
| `VeilFloorRadius > 0` | `祈りの帳を常時 14px／0.4秒` | 強み |
| `!CritEnabled` | `密着クリティカルなし` | 弱み |
| `HitInvulSec < 1.2` | `被弾後の無敵が短い n 秒` | 弱み |

空のときは「特になし」ではなく **`上の数値のとおり`**。♥-1 を抱えたあかりに「弱み 特になし」と
書くと、すぐ上の赤い `-1` と矛盾するため。

### 出さないことにした項目

| フィールド | 理由 |
|---|---|
| `ChargeSpeed` / `ChargeRadius` / `ChargePierce` / `ChargeSpreadDegrees` | 溜め打ちの一言（`ChargeDescription`）で性質は伝わる。px・度・貫通数まで並べると数値の羅列になり、選ぶ手がかりが薄まる |
| `CritMult` / `CritCap`（基準 ×1.25・上限5 のまま） | 3 人が同値＝差にならない。基準から離れている あかりだけ出す |
| `PlayerTexturePath` / `CharacterId` / `UnlockStageId` | 内部識別子・アセットパス。画面に出す情報ではない |
| `SpreadPowerMul` / `HomingPowerMul`（`GameManager` 側） | ショットモード内部の係数で `JobTuning` の外。`PowerMul` と二重に見えて誤読を招く |
| `ChargeTier`（2 段チャージ） | ショップ `n_charge` の購入状態に依存し、アカウント固有の性能ではない |

### 未解放キャラの扱い

**一覧に出さない**（従来どおり）。`OpenJob` の `_jobChoices` が `IsJobUnlocked` で絞っており、
ハブ全体の作法「押せないものを見せない」（`Hub.cs` 冒頭の解禁ゲート節）と揃えた。
解放条件は `GameManager.JobUnlockHint` が別の導線で文として出すので、この画面に伏字行は増やさない。

## レイアウト

`JobBox()` を縦に広げ、段を詰めて詳細パネルを足した。

```
height = 68（見出し）+ n × JobRowH(62) + JobPanelGap(10) + JobPanelH(246) + 74（確定ボタン帯）
```

4 人で 646px（旧 542px）、上端 y=58。スマホ列（`PhoneX`, `PhoneW=480`）の内側に収まる。

- 段（`JobHitRect`）: 62px。アバター + 名前 + ハンドル、右端に「撃ち方／火力」の 1 行。
- 詳細パネル（`JobPanelRect`）: 段の直下、ジョブ色の薄い塗り + 縁。内側 pad=14。
- 確定ボタン（`JobConfirmRect`）: 従来どおり枠の最下段。パネルとの間に 16px。

フォントは `UiKit.ZenBold`（チップ・値・見出し）／`UiKit.Zen`（本文・ラベル）／`UiKit.Mono`（ハンドル）。
色は既存トークン（`White` / `Text2` / `Text3` / `Text4` / `Ok` / `Hp` / `Light`）とジョブ色 `JobColor`。

## 数値の振り直し（指揮官決定）

| キャラ | ♥ | 移動 | 回避距離 | 回避の戻り |
|---|---|---|---|---|
| ミナ | +2 | ×0.88 | **×0.80**（旧0.90） | ×1.00 |
| あかり | -1 | **×1.12**（旧1.00） | **×1.50**（旧1.00） | ×1.00（密着中 ×0.75） |
| こはる | ±0 | **×0.96**（旧1.00） | **×1.10**（旧1.00） | ×1.00 |
| レイ | **+1**（旧±0） | **×0.92**（旧1.00） | **×0.55**（旧1.00） | ×1.15 |

- 機動（移動）の序列 あかり > こはる > レイ > ミナ
- 耐久（♥）の序列 ミナ > レイ > こはる > あかり
- 回避距離の序列 あかり > こはる > ミナ > レイ。最長と最短で約 2.7 倍（作者指示「すこし極端に」）

レイは ♥+1 で寿命を担保する代わり、回避距離が 4 人中最短＝「逃げるな、離れて撃て」を値で言う。
回避の無敵は 4 人共通なので、レイでも「その場で弾をすり抜ける」ことはできる。
**動いて避けるのが あかり、その場で耐えるのが ミナとレイ** という差が距離だけで出る。
