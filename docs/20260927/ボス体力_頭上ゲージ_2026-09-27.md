# ボス／中ボスの体力を頭上の簡略ゲージへ（2026-09-27）

作者指示（原文）:

> ボス／中ボスの体力ゲージを画面上部じゃなくて、簡略化して、実際に動いてるボスの上部に表示するようにしてほしい

## 決めたこと

- 画面上端のボスカード（`Hud.DrawBossCard`＝Xアイコン・名前・ハンドル・リプ数・穢れバー・pip・残/総）は**描かない**。メソッドは残してあるが `DrawAll` から呼ばない。
- 代わりに **ボス本体の子ノード** `BossGauge`（`src/BossGauge.cs`）が頭上に描く：
  - いまの1本ぶんのバー（幅はボスの体格から `Enemy.GaugeWidth`＝26〜56 world px、高さ 2.6 px、色はスペル色＝`SetBossBarTint`、未設定なら穢れ色）
  - 残り本数の点（`Total > 1` のときだけ。左から残本数ぶんを満たす）
  - バー1本割れの白フラッシュ（`FlashBossBarBreak`）、改心の見送り（`HideBossBar` → 穢れ色→浄化色に抜けて薄れる）は従来の状態機械をそのまま読む
  - Z は絶対 11（自機 10・弾 0 より手前）。ボスの子なので、位置・表示／非表示（投稿で隠れる等）・Modulate のフェードはボスに追従し、ボスが消えれば一緒に消える
- 状態は従来どおり `Hud` が持つ（`UpdateBossBar / SetBossBarTint / FlashBossBarBreak / HideBossBar`）。各ボスの呼び出しは `ShowBossBar(name, handle, this)` に **owner を1つ足しただけ**。
- 名前・ハンドル・リプ数・顔アイコンの表示は落とした（簡略化）。誰と戦っているかは宣告カード・字幕・立ち絵が担う。

## 変更ファイル

- `src/BossGauge.cs`（新規）／`src/Enemy.cs`（`GaugeTop`・`GaugeWidth`）／`src/Hud.cs`（`GaugeState`・`ShowBossBar(owner)`・`DrawBossCard` 呼び出し撤去）
- `src/BossAkari.cs` `src/BossHikage.cs` `src/BossKoharu.cs` `src/BossMina.cs` `src/BossRei.cs` `src/CameoBoss.cs`（`this` を渡す）

## 追記：無敵＝灰＋斜線／BREAK＝金（2026-09-27）

作者指示（原文）:

> ボスのHPバーだけど無敵のタイミングと、BREAK時のHPバー色分けしたい

- バーの**塗り**だけを状態で分ける。1本ぶんの割合（`GaugeState.Frac`）の意味は変えない。
  - **無敵**（`Shielded`／`Reclose`＝本体に弾が通らない）: 灰 `(0.60, 0.63, 0.68)` α0.55 ＋ 45° の斜線ハッチ（暗色 α0.6・太さ 0.8px・間隔 3px。塗りの矩形の中だけに線分を計算して引く）。
  - **BREAK**（`Break`／`Exposed`＝殴れる）: 金 `#f0c85a`（本体まわりの無防備窓タイマーバー `#e9d28b` より少し暖かく濃い）。割れた瞬間は白へ寄せて一拍光り（`Enemy.GaugeBreakFresh`＝0.35 秒で 1→0）、あとは 1.5Hz の脈で α0.85〜1.0。
  - **改心の見送り中**（`Purify > 0`）は従来どおり浄化色へ抜ける（上の2色より優先）。
- 残本数の点・台座・上端のハイライト・割れフラッシュは据え置き。フェーズ（スペル）色は点に残る。
- 殴れるかどうかは `Hud.GaugeState` ではなくボス本体から読む：`Enemy.GaugeVulnerable`／`GaugeBreakFresh`／`GaugeWindowLeft`（無防備窓の残り割合。Break 中 1、無敵中 0）。中ボス（`CameoBoss`）は同じ状態機械なのでそのまま同じ扱い。
- 検証: `tools/BossGaugeQa.cs` ⑦（反射で Shielded→Break→Exposed→Reclose を切り替え、`BossGauge.LastFillKind` が invuln／break／break／invuln）。スクショ `build/shots_gauge_qa/gauge_invuln.png`・`gauge_break.png`、3倍拡大 `gauge_zoom_invuln.png`・`gauge_zoom_break.png`。
- 色味: ゲージは盤面側（世界の `CanvasModulate`＝夜の冷色 Tint が掛かる層）に居るので、BubbleLayer と同じく Tint の逆数を `SelfModulate` に置いて打ち消し、塗り・台座・点・斜線を本来の色で描く（Tint が無い面では補正なし）。本体まわりのタイマーバーは従来どおり Tint が掛かる。
