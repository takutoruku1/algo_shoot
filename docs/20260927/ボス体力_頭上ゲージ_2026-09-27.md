# ボス／中ボスの体力を頭上の簡略ゲージへ（2026-09-27）

作者指示（原文）:

> ボス／中ボスの体力ゲージを画面上部じゃなくて、簡略化して、実際に動いてるボスの上部に表示するようにしてほしい

## 決めたこと

- 画面上端のボスカード（`Hud.DrawBossCard`＝Xアイコン・名前・ハンドル・リプ数・穢れバー・pip・残/総）は**描かない**。メソッドは残してあるが `DrawAll` から呼ばない。
- 代わりに **ボス本体の子ノード** `BossGauge`（`src/BossGauge.cs`）が頭上に描く：
  - いまの1本ぶんのバー（幅はボスの体格から `Enemy.GaugeWidth`＝26〜56 world px、高さ 2.6 px、色はスペル色＝`SetBossBarTint`、未設定なら穢れ色）
  - 残り本数の点（`Total > 1` のときだけ。左から残本数ぶんを満たす）
  - バー1本割れの白フラッシュ（`FlashBossBarBreak`）、改心の見送り（`HideBossBar` → 穢れ色→浄化色に抜けて薄れる）は従来の状態機械をそのまま読む
  - Z は絶対 11（自機 10・弾 0 より手前）。ボスの子なので、位置・表示／非表示（投稿で隠れる等）・Modulate のフェードはボスに追従し、ボスが消えれば一緒に消える
- 状態は従来どおり `Hud` が持つ（`UpdateBossBar / SetBossBarTint / FlashBossBarBreak / HideBossBar`）。各ボスの呼び出しは `ShowBossBar(name, handle, this)` に **owner を1つ足しただけ**。
- 名前・ハンドル・リプ数・顔アイコンの表示は落とした（簡略化）。誰と戦っているかは宣告カード・字幕・立ち絵が担う。

## 変更ファイル

- `src/BossGauge.cs`（新規）／`src/Enemy.cs`（`GaugeTop`・`GaugeWidth`）／`src/Hud.cs`（`GaugeState`・`ShowBossBar(owner)`・`DrawBossCard` 呼び出し撤去）
- `src/BossAkari.cs` `src/BossHikage.cs` `src/BossKoharu.cs` `src/BossMina.cs` `src/BossRei.cs` `src/CameoBoss.cs`（`this` を渡す）
