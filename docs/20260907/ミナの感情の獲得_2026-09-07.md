# ミナの感情の獲得（2026-09-07 ユーザー確定）

ユーザー原文:

> 冒頭での MINA は寂しいとか悲しいとかつらいとか、そういった感情はなくて、実際に悲しい心に触れて、徐々に泣くことができる、笑うことのできる表情が増えていく、そんなキャラクターにしたい。

> 「——放っておけません。潜ります。」のセリフは最初のオープニングの MINA のイメージと合わない。

## 何が決まったか

**ミナは感情を持って生まれない。三人の心に触れることで、少しずつ獲得していく。** これが冒頭から結末までを貫くミナ自身の線になる。

- **冒頭のミナに感情語は無い**。寂しい・悲しい・つらい・放っておけない、は言わない。あるのは**観測と、処理の判断**だけ。
- 「放っておけません」は**感情による動機**なので冒頭に置けない。潜る理由は、**観測した事実の処理**として言う（例: 消えていない言葉がある。拾えるのは自分だけ。だから行く）。
- 三人の面を経るごとに、**使える表情が増える**。笑う・泣くは後半で初めて成立する。
- 終盤（FINAL・エピローグ）では感情を持った状態で喋れる。E5b の「拾えるところにいたい、と思います」は**願望＝感情**なので、そこまで来て初めて言える台詞になる。この順序は既に正しい。

## 実装との照らし合わせ（要調査）

- ミナの表情素材は `mina_face` / `mina_smile` / `mina_worried` / `mina_tears` / `mina_doubt` 等。**現状は冒頭から全部使えてしまう**。冒頭で `mina_smile` や `mina_tears` が出ていないかを洗い、出ていれば差し替える。
- 「使える表情が増える」を**仕組みとして持たせるか**（面のクリア数で解禁）、**台本側の運用だけで守るか**は判断が要る。仕組みにすると、台本の書き手が間違えても破綻しない。
- 冒頭の台詞から感情語を洗い出して置換する（`src/Prologue.cs` と `wiki/08_仮台本/04_冒頭台本_案C.md`）。
