## 0. 結論（先に）

- そのうち **12 画面が `bgm_menu_mina.ogg`（「巡る思い出」）1 本の使い回し**。

  新規に要るのは最大 11 スロット。ただし **優先度 S の 4 本で体感の大半が変わる**。

## 2. 新規に要る曲のリスト（優先順位つき）

判断軸は **①その画面に居る時間 ②他画面との情緒の落差 ③実装コスト**。
`/mitsuda` §12「投資対効果」と §1「一つの主題、多くの顔」に沿い、**全部を別曲にするのではなく
"意味のある差"がある所から割る**。12 画面すべてをバラバラの曲にすると主題の統一が壊れるので、
**記録・設定・遊び方は同系のままで良い**という判断を含む。

## 3. 実装メモ（調達後にやること・今回は未実施）

新規スロットは既存と同じ作法で足せる。**コードは今回触っていない**。

- 配置規約: `BGM/` にマスター（export 除外）→ ffmpeg で加工 → `audio/bgm_<役割>.ogg`（import `loop=true`）。
- ローダー: `src/Audio.cs` の `LoadBgmMenu()`（:971）と同型の関数を 1 本足し、失敗時は既存の `BgmMenu` へフォールバック。
- 呼び出し: 各画面の `_Ready` にある `Music(Audio.Instance.BgmMenu)` の引数を差し替えるだけ（§1-A の file:line がそのまま作業点）。
- 音量: 実音源は `MusicTargetDb()`（`src/Audio.cs:310-322`）で自動的に `StageBgmRealDb = -10dB` が乗る。
  ただし `BgmMenu` と `BgmFinalResolve` は 0dB 例外（:317-320）なので、**メニュー系の新規曲も 0dB 側に入れるか要判断**（現行曲との段差を作らないため）。
- クレジット: 表記義務のあるサイト（MusMus / PeriTune の 2026-02 以前の曲 / 魔王魂 / incompetech / OtoLogic）を使ったら
  `config/credits.ini` の `[音楽]` に追記が必須。
- E5b は**ループ不要**の曲なので、`Music()`（クロスフェード＋鳴らしっぱなし）ではなく
  **1 周で終わって無音になる**扱いが要る（台本の指定＝「…………。」で完全停止 → 残り 2 行は無音）。
  既存の `Music()` 経路はループ前提なので、**ここだけ再生制御の追加が要る**（未実装・要設計）。
