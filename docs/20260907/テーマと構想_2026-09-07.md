# テーマの確定と新しい構想（2026-09-07）

ユーザーの発言をそのまま記録し、指揮官の解釈と、これから決めることを添える。

## 1. 作品の一律テーマ（確定・全シナリオに適用）

ユーザー原文:

> ミナの能力は SNS やコメント等の下書きを読めること。このゲームでは書いて消してしまった下書きは本人の本音とする。三人の主人公＋プレイヤーには、書いて消してしまって埋もれてしまった本音をミナによって掘り起こしてもらい、悩みを解消することをテーマとする。このテーマは全シナリオを通して一律のテーマとしたい。

指揮官の解釈:

- **ミナの能力＝下書きを読むこと**。これが唯一の能力であり、ミナが観測できる範囲の定義そのもの。送られた投稿は誰でも読めるが、消された下書きはミナだけが読める。
- **下書き＝本音、投稿＝仮初の自分**。この対比が全編の芯。
- **救済の型は一つ**。埋もれた本音をミナが掘り起こし、本人に返す。これがあかり・こはる・レイの三人と、**プレイヤー自身**にも起きる。四人目はプレイヤーである。
- これは既存の実装と矛盾しない。三人の改心はいずれも「消した一行を返す→決定打」の二段で、FINAL は「あなたが最初に散らした言葉」が戻る。**すでにこの型になっている**ので、テーマの確定は既存を壊さず、今後の判断基準になる。

適用のしかた:

- 新しい場面・台詞・仕掛けを足すとき、**「これは埋もれた本音を掘り起こしているか」**で採否を決める。
- ミナに新しい能力を足さない。読めるのは下書きだけ。それ以外は「観測できません」と言う。

## 2. エンディングの映像（新規・未実装）

ユーザー原文:

> エンディングはオルゴールで、三人のキャラクターたちのデフォルメした姿が一人ずつ前に歩いていくシーンにして、最終的にミナ含めて仲良く四人で歩いていく映像を作りたい。

指揮官のメモ:

- 音はオルゴール。既存の曲のオルゴール編曲か新規かは未決。
- 絵は戦闘用のデフォルメ（`char/v3/boss_*_body_*` 系ではなく、自機ミナと同じ頭身の小さい姿）。**歩く動きが要る**ので、横向きの歩行が描ける素材が新規に要る可能性が高い。
- 順番は あかり→こはる→レイ→ミナ が自然（面の順）。最後に四人が並んで歩く。
- 置き場所は E7 スタッフロールの前後。**星空（E5b）との重複に注意** — 星空は「まだ拾われていない無数の他人」、この歩行は「拾われた四人」。役割が違うので両立できるが、続けて置くと長い。

## 3. ボスの第二形態（構想・未実装）

ユーザー原文:

> 構想として、ボス戦は第二形態に変わるようにしたい。

現状の実装:

- ボスは HP バーが複数本あり、割れるごとに弾幕が切り替わる（`PatternThresholds`）。**形態変化に相当する仕組みは既にある**が、見た目は変わらない（本体の絵は待機・攻撃・被弾・改心の4枚のみ）。
- レイだけは例外で、改心の決定打でガワが割れて中の人が出る＝実質の形態変化がある。

決めることの候補:

- 第二形態を**見た目の変化**として作るのか（本体の絵をもう1枚ずつ）、**弾幕の質の変化**として作るのか（既存の閾値の演出強化）、**両方**か。
- あかり・こはるにも「ガワが割れる」に相当する見せ場を作るのか。テーマ（本音が掘り起こされる）に沿うなら、**第二形態＝本音が露出した姿**が筋。仮初の自分（投稿）で戦い、割れて本音（下書き）が出る、という読み替えができる。
- 絵の追加量は三人×1〜2枚。既存の発注方針（本体とエフェクトの分離）に従う。

**2026-09-07 ユーザー決定**: 「ボスの第二形態、見た目と BOSS の周囲を回っているアイテムを派手にする」。＝本体の絵を差し替え、かつ部品（公転している吹き出し等）を第二形態で増やす・大きくする・動きを強める。弾幕だけの変化では足りない。

## 4. 歩行と星空は一続き（2026-09-07 ユーザー決定）

ユーザー原文:

> 歩行は拾われた四人が昼から夕方、夜にかけて歩いて、最後見上げ星空のシーンにしたい。

これで **E5b（星空）と歩行の順番が決まった**。別々の場面ではなく、**一続きの一場面**にする。

- 時間が昼 → 夕方 → 夜へ流れ、そのまま星空へ着地する。歩行が星空の前振りになり、星空が歩行の結論になる。
- 四人が一人ずつ加わる（あかり→こはる→レイ→ミナ）のと、空の色が変わるのを同じ進行に乗せる。加わるたびに時間が進む形が自然。
- 最後は四人が立ち止まって見上げる。そこでミナの台詞（E5b の10行）が乗る。**星空を見上げているのは四人**であって、ミナ一人ではない。
- 既存の暁（夜→明け方）の演出と衝突する点は E5b の節に書いたとおり。**歩行が昼から始まるなら、E5 の「明け方」との整合を取り直す必要がある**（昼→夕→夜と進むので、その前が明け方でよいか）。
