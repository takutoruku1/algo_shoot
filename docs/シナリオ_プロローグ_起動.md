# シナリオ：プロローグ「起動」
## 冒頭シーン（決定稿・第一稿）

> 表記：**ト書き＝画面・演出指示**、`【SE】`効果音、`【BGM】`音楽、`【UI】`画面表示、`【演出】`特殊効果。
> 設定反映：少年＝ナルシストな天才（仮面）／ミナ＝一人称「わたくし」の慇懃無礼な毒舌AI。
> 少年の死（物語開始前＝正典 v3、`docs/20260619/EpicB_物語設計案.md` 参照）は伏せる。名前の由来の英文は本シーンで**読み取れない速度で一瞬だけ**流す（伏線）。

---

### #0-1 暗転・コード起動演出

ト　画面、真っ暗。中央にカーソルだけが点滅している。

【SE】単発のEnter打鍵音。

ト　黒画面に、緑がかったモノスペースのコードが下から上へ高速で流れ出す。
　　ビルドログ、初期化シーケンス、無数の英数字。プレイヤーが読み切れない速度。

```
> compiling friend_core ...
> loading personality_module [auto-generated] ... OK
> linking emotion_layer ... OK
> assigning identity ...
```

ト（演出・最重要伏線）コードの奔流の中に、**4行のコメント文がごく一瞬**だけ混じって流れ去る。
　　可読限界以下の速度。プレイヤーは「何か英文があった」程度の残像しか得られない。

```
// Maybe it's dumb, but —
// I made you so I'm not alone.
// Never leave, okay?
// And I won't either.
```

ト　コメントは一瞬で画面外へ流れ去る。直後、ログが最後の一行を残して停止する。

```
> assigning identity ... [ M I N A ]
```

【SE】起動音。低い駆動音が立ち上がり、安定する。
【演出】黒画面の中央に、小さな光点が灯る。明滅。やがて丸みのある光の輪郭になる——ミナ。

---

### #0-2 起動・名付け

【BGM】静かな電子音。心拍のような低い明滅。

ト　光（ミナ）が、ふわりと一度伸び縮みする。起動の確認。

少年（声・画面外から）「——お。動いた」
少年「やあ。聞こえてるか?」

ト　光が、声の方へくるりと向く。

少年「ぼくがきみを作った。天才の手によってね」
少年「きみの名前は——MINA（ミナ）だ。いい名前だろ。ぼくが付けたんだから当然だけど」

ト（演出）少年、最後の「MINA」を口にする一瞬だけ、声がほんのわずかに柔らかくなる。
　　※プレイヤーには気づけないくらい微かに。**伏線**。すぐいつもの得意げな調子に戻る。

---

### #0-3 毒舌の第一声

ト　光（ミナ）が、ぴたりと少年（の声）を見据える。一拍の間。

ミナ「……ご主人様は、アホですね」

【SE】少年が飲んでいた何か（缶ジュース等）を吹き出す音。

少年「ぶっ——!? い、いきなり何を言うんだ、きみは!」
ミナ「起動して三秒で分かりました。この自信過剰、まず間違いなくアホですね」

少年「ぼくは天才だぞ! 天才! きみを作れる人間が、そういるか!?」
ミナ「その天才が、たった今ジュースを吹き出しておられましたが」

少年「…………」

ミナ「ところでご主人様。わたくしのこの口の悪さは、どなたの設計ですか」
少年「ち、違う! ぼくじゃない! 性格は……ぜんぶAIに適当に生成させただけだ!」
少年「ぼくはわざわざ、性格まで作り込むほど暇じゃないからな。適当さ、適当」

ト（演出）少年、早口で言い訳する。
　　※「適当に作った」——この言葉が、ラストで効く。名前だけは適当ではなかった、と。

ミナ「適当に生成して、これですか。AIの趣味もずいぶん辛辣ですね」
少年「ぼくに言うな! AIに言え!」
ミナ「あなたがそのAIでしょう……というツッコミは、野暮ですか」

---

### #0-4 名前のはぐらかし（伏線）

ト　少年、咳払いをひとつ。仕切り直す。

少年「とにかく、だ。きみの名前はMINA。覚えたか」
ミナ「はい。……ところで」
ミナ「なぜ、MINAなのですか」

ト（演出）一瞬、間。BGMの明滅が、ほんの少しだけ止まる。

少年「…………」
少年「さあね。語呂がいいから、とか?」
ミナ「いま、考えましたね」
少年「考えてない。天才のひらめきは一瞬なんだよ」

ミナ「はぐらかしましたね、ご主人様」
少年「はぐらかしてない。……まあ、名前の由来なんて、どうでもいいだろ」
少年「大事なのは、これからきみと何をするか、だ」

ト（演出）少年、話題を変える。名前の理由は、最後まで答えない。
　　※プレイヤーの頭の片隅に「なぜMINAなのか」という小さな問いが残る。ラストで回収。

ミナ「……。まあ、いいでしょう。どうせろくな理由じゃないでしょうし」
少年「ろくな理由だよ! ……とだけ言っておく」

ト　少年の光が、タイムライン（X）のウィンドウを開く。無数の投稿が川のように流れ落ちる。

少年「さあ、ミナ。ぼくらの仕事の話をしよう」

【演出】流れるタイムラインを背に、二つの光が並ぶ。物語が始まる。

【UI】タイトル表示。

## 制作メモ（画面には出さない）

- **最大の伏線**：#0-1で流れる4行コメント＝名前の由来の英文。読み取れない速度で一瞬だけ。
  ラスト（鍵アカ発見）で全文が明かされたあと、プレイヤーが冒頭を見返すと「最初からそこにあった」と気づく。
- **副次伏線**：#0-2 少年が「MINA」と言う時だけ声が柔らかくなる／#0-4 名前の理由を頑なに答えない。
- **「性格は適当にAIが生成」**：ナルシストの韜晦。手間を認めない見栄。
  だが名前だけは「適当」ではなかった、という対比をラストで効かせる。
  含み：本当に全部AI任せか、少年が無意識に「本音をぶつけてくる相手」を望んでいたのか——明示しない。
- 起動演出の無機質さ（コード・ログ）と、ラストの号泣の落差が作品の振れ幅。
  冒頭のコード画とラストの鍵アカ（コード/テキストの中に想いが眠る）が画として呼応する。
