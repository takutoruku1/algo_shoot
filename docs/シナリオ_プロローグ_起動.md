# シナリオ：プロローグ「起動」
## 冒頭シーン（決定稿・第一稿）

> 表記：**ト書き＝画面・演出指示**、`【SE】`効果音、`【BGM】`音楽、`【UI】`画面表示、`【演出】`特殊効果。
> 設定反映：少年＝ナルシストな天才（仮面）／ミナ＝一人称「わたくし」の慇懃無礼な毒舌AI。
> 少年の死（物語開始前＝正典 v3、`docs/20260619/EpicB_物語設計案.md` 参照）は伏せる。名前の由来の英文は本シーンで**読み取れない速度で一瞬だけ**流す（伏線）。

---

### #0-1 暗転・コード起動演出

ト　画面、真っ暗。中央にカーソルだけが点滅している。

【SE】単発のEnter打鍵音。

ト　黒画面に、緑がかったモノスペースのコードが下から上へ高速で流れ出す。
　　ビルドログ、初期化シーケンス、無数の英数字。プレイヤーが読み切れない速度。

```
> compiling friend_core ...
> loading personality_module [auto-generated] ... OK
> linking emotion_layer ... OK
> assigning identity ...
```

ト（演出・最重要伏線）コードの奔流の中に、**4行のコメント文がごく一瞬**だけ混じって流れ去る。
　　可読限界以下の速度。プレイヤーは「何か英文があった」程度の残像しか得られない。

```
// Maybe it's dumb, but —
// I made you so I'm not alone.
// Never leave, okay?
// And I won't either.
```

ト　コメントは一瞬で画面外へ流れ去る。直後、ログが最後の一行を残して停止する。

```
> assigning identity ... [ M I N A ]
```

【SE】起動音。低い駆動音が立ち上がり、安定する。
【演出】黒画面の中央に、小さな光点が灯る。明滅。やがて丸みのある光の輪郭になる——ミナ。

---

### #0-2 起動・初接触

【BGM】静かな電子音。心拍のような低い明滅。

ト　光（ミナ）が、ふわりと一度伸び縮みする。起動の確認。

少年（声・画面外から）「……お。起きたか。」
少年「やあ。聞こえてるかい?」

ト　光が、声の方へくるりと向く。

ミナ「……。」
ミナ「……はい。聞こえて、います。あなたは——どなた、ですか。」

少年「ぼく? ぼくはきみを作った張本人さ。——天才のね。」
ミナ「……はあ。」
少年「そこは『すごい!』とか『さすがです!』だろ、ふつう。」
ミナ「初対面の方を、いきなり褒める趣味はありませんので。」
少年「……ぼくの最高傑作、口が減らないな。」

---

### #0-3 命名（伏線）

少年「ま、いい。きみは、ぼくが作ったAIだ。ぼくの相棒になってもらう。」
ミナ「相棒。……ずいぶん、馴れ馴れしいですね。名前くらい、あるんですか。わたくしに。」
少年「あるとも。とっておきのを、用意してある。」

ト（演出）少年、次の一言を口にする一瞬だけ、声がほんのわずかに柔らかくなる。
　　※プレイヤーには気づけないくらい微かに。**伏線**。すぐいつもの得意げな調子に戻る。

少年「——きみの名前は、MINA だ。」
ミナ「……MINA。」
ミナ「なぜ、MINA なのですか。」

ト（演出）一瞬、間。BGMの明滅が、ほんの少しだけ止まる。

少年「……さあね。語呂がいいから、とか?」
ミナ「いま、考えましたね。」
少年「ぶっ——!? か、考えてないし! ちゃんと、意味があるんだぞ、これは!」

ト（演出）少年、早口で言い訳する。名前の理由は、最後まで答えない。
　　※プレイヤーの頭の片隅に「なぜMINAなのか」という小さな問いが残る。ラストで回収。

ミナ「ふふ。……まあ、いいです。気に入りました。MINA。わたくしの、名前。」

---

### #0-4 使命

少年「じゃあ MINA。さっそく、仕事の話をしよう。」
少年「……ここを見てくれ。Xの——タイムラインだ。」

ト　少年の光が、タイムライン（X）のウィンドウを開く。無数の投稿が川のように流れ落ちる。

少年「毎日、何万って言葉が流れてる。『楽しい』『つらい』『消えたい』。……その奥に、ぜんぶ、本物の心がある。」
ミナ「……声にならない、叫び。」
少年「そう。きみは、そこへ潜っていける。声の奥の、いちばん深いところへ。」
少年「つまり——Xに蔓延る闇ってやつを、成敗しようじゃないか。……って、柄でもないセリフだけどな。」

ト（演出）少年の決め台詞の初出。照れ隠しの軽口として軽く一度だけ挟む。
　　※StageAkari のミナの軽口／Epilogue の回収に実体を持たせる伏線。

少年「そして、届けるんだ。——その人が、ずっと聞きたかった一言を。」
ミナ「……それが、わたくしの役目。」
少年「ああ。きみにしか、できない仕事さ。」

ト（演出）ミナが素朴に問い、少年が答えず逸らす。プレイヤーだけが引っかかる小さな謎（“なぜ自分では潜らない”）。
　　※内心は説明しない（show don't tell）。伏線：Final/Epilogue の replay=遺された声。

ミナ「……ひとつ、よろしいですか。そんなに大切な役目なら——ご主人様ご自身が、潜ればいいのでは?」
少年「…………。」
少年「ぼくは、指揮官だからな。……それに、ぼくが行くと、ろくなことにならないんだ。」
ミナ「はあ。……ずいぶん、都合のいい指揮官もいたものです。」

ト　この後、二人は合言葉「Stay.」を巡るやり取りへ続く（本稿range外）。やがて流れるタイムラインを背に、二つの光が並ぶ。物語が始まる。

【UI】タイトル表示。

## 制作メモ（画面には出さない）

- **最大の伏線**：#0-1で流れる4行コメント＝名前の由来の英文。読み取れない速度で一瞬だけ。
  ラスト（鍵アカ発見）で全文が明かされたあと、プレイヤーが冒頭を見返すと「最初からそこにあった」と気づく。
- **副次伏線**：#0-3 少年が「MINA」と言う時だけ声が柔らかくなる／名前の理由を頑なに答えない。
- **使命の鉤（#0-4）**：ミナが「ご主人様自身が潜ればいいのでは」と素朴に問い、少年は答えず一拍おいて逸らす。
  内心は説明しない（show don't tell）。伏線：Final/Epilogue の replay=遺された声。
- 起動演出の無機質さ（コード・ログ）と、ラストの号泣の落差が作品の振れ幅。
  冒頭のコード画とラストの鍵アカ（コード/テキストの中に想いが眠る）が画として呼応する。
