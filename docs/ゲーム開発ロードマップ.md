## M0 — 意思決定ゲート【最初の1日】

Epic C全体をブロックしている唯一の未決事項を最初に片付ける。

- [x] **シールド方針の決定**（#7/8/24）→ **(c)で確定（2026-07-02）**: 固定シンボル式は不採用。既存パネルサイクルを「シールド制導入済み」と再定義し、HP+1本＋フェーズ色演出＋ボス別弾幕ギミック＋テレグラフ横展開で磨く（査定・実装スケッチは `タスク管理.md` 参照）。検討した選択肢:
  - **(a) 固定シンボル破壊式を全ボスに導入** — 攻略に「順序」が生まれるが実装・調整が最重。
  - **(b) 一部キャラのみ導入**（例: あかり=承認の殻、こはる=祈りの障壁など、キャラの主張(#12)と紐づけ） — 物語との整合が取りやすく、ステージごとの手触りの差別化にもなる。**推奨検討**。
  - **(c) 導入しない**（現行構造のまま#25/#26/#16の磨きに集中） — 最短。リリース優先ならこれも正解。
  - 決め方: game-designer(sakurai) にリスクとリターン・テンポ観点の査定を出させ、その提案で確定する。
