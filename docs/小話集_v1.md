# 小話集 v1（本筋以外の日常会話）

> 2026-08-13 作成。ユーザー要望「ストーリーとの闘い以外での小話的な会話を増やしたい」に対する文面集。
> 場所：ハブ／道中／ショップ／トレーニング／タイトル。色の比率は **日常5：軽口3：情緒2**。
>
> **この小話の戦略的な意味**：本作はエピローグで「何でもない日常が最初から失われていた」（少年＝archive replay）と判明する。
> だから**何でもない会話ほど2周目で刃になる**。1周目は微笑ましく、2周目で痛い。伏線は明示しない。
>
> **二周目に効く仕掛け（明示しないこと）**：少年の返答をすべて「はぐらかし・一般論・過去形」で統一してある。
> ミナの具体的な問い（今日の献立／何時／天気）に対し、少年は**一度も具体で答えていない**。
> 1周目は「だらしない人」、2周目は「答えられない人」に読める。「そのうち」「いつか」を口癖として反復。

## 実装状況メモ（調査済み）

| 場所 | 器の有無 | 備考 |
|---|---|---|
| ハブ | あり（要拡張） | `Hub.cs:945-1011` `ReturnDialog(id)` は id ごと固定1パターン、`Hub.cs:103-116` でクリア直後1回のみ再生。複数パターン化には抽選＋既読管理が要る |
| 道中 | あり | 各 `Stage*.cs` の `Mid` 配列と同型。`Step_Lines` で合間に挟む |
| ショップ | **なし** | `Shop.cs` に会話配列なし（説明は別シーン `ShopTutorial.cs`）。トースト表示の新設が要る（`Hub.cs:900-903` に同型あり） |
| トレーニング | **なし** | `TrainingRoot.cs` は会話系皆無。`DrawUi` の空き帯に描く器が要る |
| タイトル | **なし**（投稿のみあり） | `TitleMenu.cs:22-27` の `Ticker` は投稿形式3件。ミナのひとことは別配列＋描画が要る |

**話者の制約**：ハブの `(string, string)[]` は `SpeakerFace`（`Hub.cs:908-916`）が解釈できる話者のみ（`少年` / `ミナ` 始まり / `rei` `akari` `koharu` を含む文字列）。
道中は `(int who, string text, string face)[]`、who は `Hud.LineKind`（0=少年 / 1=ミナ）。face 定数（`SGentle`/`SCocky`/`SAfraid`）は**ファイルごとに存在を確認してから使うこと**。

**出し分け方針**：
1. 現行の初回クリア直後の分岐（`Hub.cs:103-116`）は温存＝正典パターン。
2. `JustClearedStageId == null` かつクリア済ステージがあるとき、`IdleDialogs(最後にクリアしたid)` ＋ `SmallTalks` のバンクから抽選。
3. `GameManager` に既読インデックス（`HashSet<int>`）を持たせ**未再生を優先**、全部見たらリセット。セーブに含める。
4. 毎回出るとうるさいので**ハブ入場2回に1回程度**。
