## (a) 前提（✅ 実機検証済み）

- 本プロジェクトは **Godot 4.x の .NET（C#）版** と **.NET 8 SDK** が必要。
- **検証済み環境**: Godot **4.6.3-stable Mono**（winget: `GodotEngine.GodotEngine.Mono`）＋ **.NET SDK 8.0**（winget: `Microsoft.DotNet.SDK.8`）。
  - この組み合わせで **C#ビルド成功（0エラー / 0警告）**、**ヘッドレス実行で実行時エラーなし（exit 0）**、**ウィンドウ実行で描画確認済み**（淡い緑背景・HUD・`algo.png` のプレイヤー表示・日本語表示OK）。
- `csproj` は現在 `Godot.NET.Sdk/4.6.3` ＋ `TargetFramework=net8.0`（Godot 4.6 の要件）。**別バージョンの Godot を使う場合はこの2つを合わせて調整**すること（例: Godot 4.3 なら `Godot.NET.Sdk/4.3.0` + `net6.0`）。
- Godot 4.6 は C# に **.NET 8 SDK** を要求する（.NET 7 SDK ではビルド不可。ランタイムだけでは不足）。

## (b) セットアップ手順

### 一番かんたん（GUI）
1. **Godot を起動**（インストール済み。新しいターミナルなら `godot` エイリアスでも起動可）。
2. プロジェクトマネージャから **「インポート」→ `d:/dev/algo_shoot/project.godot`** を開く。
   - 初回オープンで `char/algo.png` が自動インポートされ `.godot/` が生成される（生成済み）。
3. エディタ右上の **「Build」ボタン（ハンマー）** で C# をビルド。
4. **F5**（または再生ボタン）でメインシーン `res://Main.tscn` を起動。

### コマンドライン（検証で使用した手順）
```powershell
# インポート（初回のみ。.godot 生成・画像インポート）
godot --headless --path d:\dev\algo_shoot --import --quit

# C# ビルド
dotnet build d:\dev\algo_shoot\algo_shoot.csproj -c Debug

# 実行（ウィンドウ）
godot --path d:\dev\algo_shoot
#   ※ エラー検出だけなら: godot --headless --path d:\dev\algo_shoot --quit-after 300
```
- `godot` が見つからない場合は実体: `…\WinGet\Packages\GodotEngine.GodotEngine.Mono_*\Godot_v4.6.3-stable_mono_win64.exe`（CLI出力が欲しい時は同フォルダの `..._console.exe`）。winget導入直後はPATH反映のため新しいターミナルを開くこと。
- 内部解像度 384x216、stretch=viewport / aspect=keep。

## (d) W0 で実装した内容と既知の制限

### 実装した内容
- **固定画面 STG の土台**: 内部解像度 384x216、stretch=viewport / aspect=keep。
- **Main**: 背景（淡い緑）・World ノード・Player・Hud・StageW0 を生成して参照を配線。
- **BulletPool（Autoload `/root/Pool`）**: 512 発の事前生成プール。枯渇時は追加生成。`Spawn` / `Despawn`。
- **Bullet**: Area2D。自機弾／敵弾で layer/mask と見た目を切替。画面外（余白16px）で自動 Despawn。当たり処理は弾側で行わず、敵側・自機側で検出。
- **Player**: 移動（通常150 / 集中65 px/s）、約0.11s 間隔の上下2way連射（弾速360）、被弾無敵点滅、`algo.png` 表示（読込失敗時は白円＋紫十字フォールバック）。※手触り検証後に調整した値。
- **Enemy 基底**: 自機弾被弾でダメージ→弾 Despawn、Hp0 で浄化演出（白→紫フラッシュ＋パーティクル風の点）後 QueueFree。画面左外で QueueFree。
- **GlyphMote（E1）**: Hp2、左進（64px/s）、約1.6s 毎にプレイヤー狙い弾（弾速95＝W0向けに穏やか）。
- **PageShard（E5）**: Hp3、左へ漂流＋上下揺れ、無攻撃の破壊可能オブジェ。
- **Hud（CanvasLayer）**: 下中央メッセージ、中央バナー、左上残機表示（日本語＋英語併記）。
- **StageW0**: 経過時間ベースの簡易ステップ機械で 移動説明 → ショット説明+PageShard → GlyphMote ウェーブ → STAGE CLEAR バナー。

### 衝突レイヤー/マスク（仕様準拠で確認済み）
| 種別 | layer | mask | 検出対象 |
|------|-------|------|----------|
| Player | 1 | 12 | 敵(4)・敵弾(8) |
| PlayerBullet | 2 | 4 | 敵(4) |
| Enemy | 4 | 2 | 自機弾(2) |
| EnemyBullet | 8 | 1 | 自機(1) |

### 既知の制限
- **手触りは数値検証のみ**: ビルド・起動・描画は実機確認済みだが、実際にプレイしての主観的な手触り（移動感・弾速・難度）は未確定。値はコードベースで妥当化した初期値であり、実プレイでの微調整が前提。
- **ウィンドウサイズ**: CLI起動時にウィンドウが小さめで開く場合あり（`window_width_override` が効きにくいケース）。エディタ実行/リサイズで対応可。
- **ボム（X）未実装**: 入力想定のみ。効果なし。
- **残機減少なし**: W0 は練習扱いで `TakeHit` は無敵化のみ。`Lives--` は意図的に未実装（コメントに切替ポイントを明記）。
- **`algo.png` の表示はエディタでの初回インポート後に有効**。未インポート時はプレースホルダ描画になる。
- **敵が左に抜けても撃破扱い**: GlyphMote が画面左外へ抜けると QueueFree され、ステップ進行上は「全滅」と同義になる（チュートリアルでは許容）。
- **サウンド・スコア・複数ステージ・ポーズ未実装。**
- 浄化演出は簡易（_Draw ベース）。本格的なパーティクル（GpuParticles2D 等）は未使用。

## (e) 次の一歩

1. **実プレイでの手触り調整**: 実際に遊んで移動速度・連射・弾速・敵スポーン間隔・難度を微調整（ビルド〜起動は検証済み）。
2. **ボム（X）実装**: 画面消去＋短時間無敵などの基本効果。
3. **残機・ゲームオーバー導線**: W0 以降の本編ステージ向けに `TakeHit` で `Lives--` と GameOver 演出を有効化。
4. **スコア／コンボ**: 浄化（撃破）でスコア加算、Hud に表示。
5. **サウンド**: ショット・被弾・浄化・BGM。
6. **敵バリエーション拡充**: 弾幕パターン、編隊スポーン、ボス。
7. **演出強化**: GpuParticles2D による浄化、ヒットストップ、画面シェイク。
8. **入力の堅牢化**: ゲームパッド対応、キーコンフィグ。
9. **日本語フォント**: Hud に日本語フォントを theme で設定し、英語併記を整理。
