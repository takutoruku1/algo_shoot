# ハブと難易度画面の案（2026-09-06、game-designer 査定）

> ユーザーの所感「ステージ選択メニューが業務メニューっぽくて面白みがない」「難易度選べるところとかつまらない」への回答。提案のみ。決定はユーザー。

## 1. 何が「業務メニュー」に見せているか

### 1-1. 選ぶ理由が画面に無い（選択ではなく確認になっている）
- 現状: 解放は線形（`GameManager.cs:302` `IsStageUnlocked = cleared || next`）。1周目はどの時点でも潜れるカードが1枚しかなく、カーソルは最初からそこに置かれる（`Hub.cs:319-326` `DefaultSelection`）。
- 問題: ↑↓「えらぶ」（`Hub.cs:960`）は儀式で、やることは「置かれたカーソルで Z」だけ。直後の難易度画面も `_sel` が前回値（`DiffSelect.cs:85`）なので、確認画面が2枚続く。

### 1-2. 均等なカードの並び＋画面の3分の2が空
- `Hub.cs:676-682` `CardMetrics` は等間隔。初回は NEW 1枚＋伏字バー付き LOCKED 2枚で、可視情報は1行の投稿と「ロック中 — まだダイブできません」（`Hub.cs:781`）。管理画面の一覧表そのもの。

### 1-3. ラベルの語彙がパッチノート
- ピル「NEW／✓ CLEAR／LOCKED／FINAL」（`Hub.cs:768`）、「BEST --」、フッタ「えらぶ／ダイブ／強化／記録」（`Hub.cs:956-967`）、トースト「投稿が届いた Imp +40 フォロワー +8」（`Hub.cs:445`）、炎上トースト（`Hub.cs:451`）。難易度側は「標準的な弾幕。」「難易度で「弾の数」が変わります」「報酬 ×1.0」（`DiffSelect.cs:25/291/367`）。
- 世界観は「投稿の下の声を聞く」なのに、画面の言葉は英語ステータスと倍率表。対象読者が昼間に見ている業務ツールの語彙と同じ。

### 1-4. 偽の UI と意味の無い数字
- タブ「おすすめ｜フォロー中」は切替不能（`Hub.cs:660-673`）。エンゲージ数と相対時刻は定数（`Hub.cs:204`, `:908`）。押せないタブと動かない数字がハリボテのダッシュボードに見える。

### 1-5. 動きが無い
- 動くのは流入 0.28s、選択グロウの呼吸、NEW ピルの明滅の3つ。背景の夜景は静止。タイムラインなのに流れない。

### 1-6. ミナが居ない
- カードモードのミナは 28px のアバターのみ。声が出るのは H0 一回、クリア帰還、再訪小話の抽選だけ。「ミナにだけ声が聞こえる」根拠がカード上に描かれていない。

### 1-7. 難易度画面は「表」であり、決め手が数値
- 同寸の行4本に名前／説明／密度ピップ／報酬倍率／♥ボム。右のミナの立ち絵と一言は添え物。残機 6→2、ボス HP バー 2→6 本の差が読めない。

## 2. ハブの案

### 2-a. 小: 語彙と動きだけ（規模 S）
- ピルを世界の言葉に。NEW→「声」、✓ CLEAR→「届いた」、LOCKED→ピル無し、FINAL→「限界」。
- ロック文言を削除。ロックカードは本文を薄く表示し、Z でミナが一言「……まだ、聞こえません。」。
- 伏字バーの用途を反転。声の聞こえるカードの本文の下に薄く明滅する伏字＝「消された一行」がそこにある印。
- 偽タブを削除。フッタ「えらぶ」削除、「ダイブ」→「潜る」。
- トーストを X の通知文に（「@mina_ai_ の投稿が 8 人に届いた」、炎上「炎上中。次に潜るとき、光が薄い。」）。
- 動き: 夜景の極低速ドリフトと、選択カードの左バーの 60bpm の脈。
- 1周目の体験: 3枚の投稿のうち1枚だけ縁が脈打ち、消された行のような伏字がちらつく。Z で潜る。
- リスク: 「選ぶ理由」の構造問題は残る。

### 2-b. 中: 「今夜どこへ潜るか」の画（規模 M）
- タイムラインを本物の feed にする。三人の投稿の間に日常層／病みサイン層の投稿を 6〜10 本混ぜる（`PostPool` と 09_投稿文集の資産で足りる）。潜れるのは「声が聞こえる」投稿だけ。
- 選ぶ行為＝「病んでいる人を見つける」。声のある投稿にカーソルが乗ると左バーが脈打ち、ミナの一行が出る。他は無言。
- Z でカードがその場で開く（投稿詳細）。本文／消された行の伏字／ミナの一言／潜り方（難易度）を1枚に。難易度画面への遷移を吸収。
- ミナの最新投稿を feed 最上段に固定ポストとして置く。
- 既定カーソルは次の声のある投稿。2押しで潜れる導線は守る。
- 1周目の体験: 「今日も残業〜」の中に「すき、すき、すき」がある。合わせるとミナが「……聞こえます」。
- リスク: 埋め草の文面が要る。読む時間が増える。1画面 5〜6 本まで。

### 2-c. 大: 選択そのものにリスクとリターンを足す（規模 L）
- 面の順は物語で固定なので、賭け金は「潜る前に何をするか」に置く。「露出」: 返信・自動投稿で上がり、高い状態で潜ると引用リプ型の敵の比率とインプレ倍率が上がる。
- 「返信してから潜るか、潜ってから返信するか」を毎晩考える。
- リスク: 敵圧の査定が未決のまま足すと手応えが出ない。炎上の一回性と混線しないよう「騒がしさ」として別扱い。

## 3. 難易度選択の案（数値の実装は不変）

### 3-1. 「今夜の潜り方」を言葉と絵で選ばせる（規模 S〜M）
- 見出しを選んだ投稿カードそのものにする。4段の名前を 浅く／いつも通り／深く／底まで に。
- 説明と一言を統合してミナの観測1行だけに（例: 浅く「光は六つ。……ゆっくりで、いいんですよ。」／底まで「光は二つ。……覚悟は、できていますか。」）。
- 密度ピップを、ミナの背後に流れる実弾のプレビューに置き換える。
- 隠れた賭け金（ボス HP バー本数 2/4/5/6）を小さく添える。「報酬 ×1.0」の文字は消す。

### 3-2. 初回は選ばせず、ミナが決める（規模 M）
- 各面の初回は難易度画面を出さず、ミナが「では、いつも通りに。」で潜る。難易度はフッタから任意に開け、再訪では自動で出す。
- FINAL は選ばせず、三人を救ったときの深さで固定。
- 被弾が多いランの帰還でミナが一度だけ「次は、浅く潜りますか。」と聞く。
- リスク: Easy の入口を見失う。選択カードに「潜り方: いつも通り」チップを常時表示。

## 4. 推奨と質問
- 今すぐ: 2-a（S）＋ 3-1（S）。次: 2-b（M）、3-2 は 2-b のカード展開に吸収して一緒に検討。保留: 2-c（L）、敵圧の査定後。
- ユーザーへの質問: タイムラインに三人以外の日常の投稿を流し、その中から「声のする投稿」を探して潜る形（2-b）にしてよいか。3枚固定のまま見せ方だけ直す（2-a）ならそこで止める。
