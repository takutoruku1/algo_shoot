# 激情メーター — 台詞と選択肢（あかり／こはる／レイ）

2026-09-25 / シナリオ稿（**文書のみ。実装なし**）

---

## 0. この文書の前提

### メーターの目盛り（作者決定・2026-09-25 訂正版）

```
  +100 ┃ 激情エンド ── 荒れた発言で分かる
       ┃
     0 ┃ ← プレイヤーはここを保つ（理想）
       ┃
  -100 ┃ 無感情エンド ── 空っぽな発言で分かる
```

- **中央は 0**。上に振れる＝プラス方向＝激情、下に振れる＝マイナス方向＝無感情。
- 放置すると**プラス方向へ上がっていく**（＝何もしなければ荒れる）。
- ボスが台詞を言った直後に選択肢が出る。選択中は弾幕が止まる。
- 選んだ言葉をチャージショットに込め、当てるとメーターが動く。込めた言葉は一定時間で消えて再装填（＝選び直せる）。
- **選択肢に正解／不正解はない。あるのは向きと強さだけ。** 正しさはそのときのメーター位置で決まる（プラス側に居るなら「下げる言葉」が正しく、マイナス側に居るなら「上げる言葉」が正しい）。
- 終了時の値で結末が分岐：**+90 以上＝激情エンド／-90 以下（実質 -100 到達）＝無感情エンド／それ以外＝通常エンド**。
- プレイヤーは数字ではなく**ボスの発言**で危険を察する（§2 の危険信号）。

### 表記上の注意

本文中の数値は**すべて新目盛り**（-100 〜 +100、中央 0）。旧仕様の「50%を保つ」「0%＝無感情」という表記はこの文書には存在しない。**0 は常に「理想の中央値」の意味**で、無感情側の端は必ず **-100** と書く。

### 書式

- 各セットは「ボスの台詞（＝問い）」→「選択肢3つ（込める言葉）」→「当てたときの返し」。
- 選択肢の効果は `↑大／↑中／↑小／↓小／↓中／↓大` で表記。↑＝プラス（激情）方向、↓＝マイナス（無感情）方向。
- 実装フォーマットは `(int who, string text, string face)[]`、who = `Hud.LineKind`（0=少年 / 1=ミナ / 2=相手ボス / 3=ナレ / 4=投稿 / 5=中継 / 6=潜行キャラ本人）。本機能で使うのは **2（ボス）と 1（ミナ＝込めた言葉を放つ声）** のみ。**ナレ（3）は使わない**。
- 選択肢の文言は、**ミナが実際に口にして弾に込める言葉**として書いてある（そのまま who=1 の行になる）。

### 選択肢の設計原則（読む人への申し送り）

3つとも「正しそう」に見えること。具体的には各セットで次の3枚を置いた：

1. **寄り添い**（受け止める・許す） … たいてい ↓ 方向
2. **問い直し**（事実を突く・確認する） … たいてい ↑ 方向
3. **並走**（一緒に居る・肯定する） … 中間、あるいはそのボスの傷の形によって符号が反転する

3 番目が曲者で、ボスによって「並走」が慰めになる場合と燃料になる場合がある。あかりは「一緒に居る」が執着を焚き、こはるは「一緒に見る」が救いになり、レイは「見ている」が最も強く燃える。**言葉の善悪ではなくその人の傷の形で符号が決まる**、が本機能の芯。

# STAGE1 — あかり（@akari_ame / 「あふれるわたし」）

**傷の形**：返事が来ないことに耐えられない。「おめでとう ほんとだよ 元気でね」を送れずに十二回取り消した。既読と返事への執着。
**上げるもの**：宛先・返事・確認を思い出させる言葉（＝待つ相手が居ることを刺激する）。
**下げるもの**：もう返さなくていい・送らなくていいと**許す**言葉（＝待つ理由そのものを抜く）。

> 既存正典との整合：スペル名「ねえ、こっち見て／すきって言って／ずっと一緒／離さない」、RECLOSE「返して。読んだなら、返してよ。」、改心台詞「……返事がほしかった。おめでとう、より先に。」、下書き「おめでとう　ほんとだよ　元気でね／……好きだよ。いまも。」（`src/BossAkari.cs:59-65, 99-108, 489-494`／`src/BossPostStory.cs:13-37`）

# STAGE2 — こはる（@koharu_light / 「我に返るわたし」）

**傷の形**：「ちゃんとしなきゃ、みんな見てるもん」と言いながら、誰も見ていない。止まると我に返る。本音は「もう疲れた、休みたい」。消えたペンライト。

# STAGE3 — レイ（@星逢レイ / ボスはガワ）

**傷の形**：登録者2000、同接は一桁。「切り抜かれない」ことへの執着。好きな作品の話をしたいのに、数字を見て告知を消す。中の人に誰も気づかない。
**上げるもの**：数字・見られている・気づかれる——**「見ている」がこのボスでは最強の燃料**（気づいてほしい／気づかれるのが怖い、の両方を同時に突く）。
**下げるもの**：見なくていい・数えなくていい・いつも通りでいい——**「いつも通り」が最も深く抜く**。

> 既存正典との整合：スペル名「初見さんいらっしゃい／登録者２０００／同接８／切り抜かれない」、挑発「初見さん、いらっしゃい!」「戦ってよ。わたしを、ちゃんと見てよ。」、RECLOSE「……逃げるの? また。——いいわ。切り抜かれないんだから、わたし。」、改心台詞「だから……だからなんで、だれも、中にいるわたしに、気づいてくれないのよ!」、下書き「好きな作品の話がしたい。／わたしの声を、聞いてほしい。」（`src/BossRei.cs:73-88, 125-135, 482-487`／`src/BossPostStory.cs:63-87`）
> **注意**：戦闘中のレイは**ガワ**（笑顔固定）。返しは笑顔のまま声だけが動くように書いてある。ガワを割るのは改心の決定打の専有なので、戦闘中の台詞で割らない。

# 2. 危険信号の台詞（最重要）

メーターが端に近づいたとき、ボスが自発的に喋る。**プレイヤーはこれで危険を察する。** 数字は読まなくていい。

発話条件の想定（実装側で決める値）：
- **上振れ**：+55 を超えたら第1行、+75 で第2行、+88 で第3行以降（順に、または重み付きランダム）
- **下振れ**：-55 を下回ったら第1行、-75 で第2行、-88 で第3行以降
- どちらも**弾幕は止めない**（`Hud.ShowBossLine` の既存経路で足りる想定）。選択肢の「問い」とは別枠で、割り込みとして出す。

方向性：
- **上振れ**＝荒れていく。文が壊れる、反復が増える、相手が見えなくなり、二人称が消えて独り言になる。
- **下振れ**＝空っぽになっていく。**静かに怖い方向**。返事が短くなる、同じ言葉を繰り返す、疑問符が消える、そして「もういい」に落ちる。

# 3. エンディング3分岐

戦闘終了（浄化成立）時のメーター値で、改心シーンが分岐する。

**通常エンド（-90 < 値 < +90）は既存の改心シーンをそのまま使う。**
- あかり：`src/BossAkari.cs:99-108`（`Lines`）
- こはる：`src/BossKoharu.cs:148-166`（`Lines`）
- レイ：`src/BossRei.cs:125-135`（`Lines`）
- BGM 停止行・ガワ割れ行（`BgmStopLine` / `SilenceAtLine` / `BreakAtLine`）も既存のまま。**通常エンドは一切書き換えない。**

激情エンド・無感情エンドのみ新規。いずれも既存の「二段で抜く」構造（① ミナが下書きを返す ② ミナ自身の言葉で決定打）を**崩れた形で**なぞる。
- **激情エンド**＝①も②も届くが、**相手が受け取れる状態にない**。言葉は正しいのに、聞く耳が焼き切れている。
- **無感情エンド**＝①も②も届く。**届いたのに、動かない**。受け取った本人が、受け取ったことを感じられない。

> **共通の設計ルール**
> - ナレーションは使わない（who=3 は出さない）。語り手はミナ。
> - ミナの内心を説明しない。表情（face）と短い発話で見せる。
> - 「救いに代償を残す」。激情も無感情も**浄化そのものは成立する**（Finished は立つ）が、残るものが違う。
> - **どちらのエンドでも、最後の一行はボスが喋る。** ミナが締めない＝プレイヤーの選択の結果を、本人の口から受け取らせる。

# 5. 自己レビュー（maeda-pitfalls ゲート）

- **P1 構造が透ける** — 3ボスで選択肢の符号の付き方を変えた。あかりは「一緒に居る」が燃料、こはるは「一緒に見る」が救い、レイは「見ている」が最大の燃料。同じ言葉が違う向きに効く。
- **P2 主人公の能動** — 本機能そのものがプレイヤーの能動（言葉を選んで撃つ）。少年は案Cに居ないため登場させていない。
- **P3 ルール破り** — スペル名・RECLOSE・改心台詞・下書き（`BossPostStory`）はすべて実装から引いて矛盾させていない。レイのガワは戦闘中に割っていない。
- **P4 救う相手を“器”にしない** ★ — 着地用セット（A-8 / K-8 / R-8）に**効果ゼロの選択肢**を置き、「それは、あなたが決めることです」で本人の決定権を残した。無感情エンドの最後の一行は3人とも**本人の問い**で終わり、ミナが締めない。
- **P5 泣きの押し付け** — 地の文（who=3）を一切使っていない。感情語の直書きなし。決定打は既存のものを流用し、新しいトドメを増やしていない（連発回避）。
- **P6 尺** — 1ボス6〜8セット＋危険信号＋エンド3本で完結。新しい伏線は建てていない（下書きの回収のみ）。
- **P7 エンジン再現性** — 全て既存の吹き出し・`ShowBossLine`・`_lines` 差し替えで表現できる範囲に収めた。秒単位演出・ボイス依存の泣きは入れていない。
