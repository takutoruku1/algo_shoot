# ボタン配置 資料（現状）

algo_shoot の現在の入力割り当て一覧。コードからの実測（2026-06-21 時点）。

> **実装メモ**: Godot の InputMap（`project.godot` の `[input]`）は**未使用**。移動とメニューの十字／決定だけが既定アクション（`ui_left/right/up/down`・`ui_accept`）に乗っており、それ以外は各ファイルで `Input.IsKeyPressed(Key.*)` / `Pad.Pressed(JoyButton.*)` を**直読み**している。したがって「設定でキー変更」は現状不可（リバインドUIなし）。
>
> **操作表示モード（2026-06-21 追加）**: ヒント/ボタン表記を `キーボード / コントローラ(PS) / コントローラ(Xbox)` の3択で**固定**できる（[Pad.cs](../src/Pad.cs) `enum DisplayMode { Auto, Keyboard, PadPlayStation, PadXbox }` / `Pad.Display`）。入力自体はどのデバイスも常に有効で、これは表記だけの話。タイトル「はじめから」で**毎回必ず**選ばせ、設定（操作カテゴリ「操作表示」）でも変更可。永続キーは `inputdisplay`(0=KB/1=PS/2=Xbox)。旧 `padstyle`(0=Xbox/1=PS) は Auto 時のパッド表記として後方互換で読む（`Display` 導入後、`Pad.Style` は `Display` から導出）。未選択（旧データ）は `Auto`＝直近デバイスで自動判定（従来挙動）。

## 1. ゲームプレイ操作（自機）

実装: [Player.cs](../src/Player.cs) ほか。パッドは物理配置 Xbox 基準、PS 表記は設定切替時の見た目。

| 操作 | キーボード | パッド（Xbox） | パッド（PS） | 実装 |
|---|---|---|---|---|
| 移動 | 矢印キー / WASD | 左スティック | 左スティック | [Player.cs:248-254](../src/Player.cs#L248-L254) |
| 低速（集中・Focus） | Shift | LB または RB（肩） | L1 / R1 | [Player.cs:258](../src/Player.cs#L258) |
| ショット | Z / Space / Enter | A | 〇 | [Player.cs:301](../src/Player.cs#L301) |
| ボム | X | X | □ | [Player.cs:312](../src/Player.cs#L312) |
| ショットモード切替 | V | B | × | [Player.cs:289](../src/Player.cs#L289) |
| ヒカゲ専用スキル | C | Y | △ | [Player.cs:320](../src/Player.cs#L320) |
| やさしさ全開（手動発動） | Ctrl（左右どちらも） | R3（右スティック押込） | R3 | [Player.cs:329](../src/Player.cs#L329) |
| ポーズ | Esc | （なし） | （なし） | [PauseMenu.cs:64](../src/PauseMenu.cs#L64) |

- 移動の WASD は、安価なキーボードで「矢印＋Z」同時押しがゴースト（入力消失）するための代替。
- ショットの Space/Enter は `ui_accept` 由来（Z と併用可）。
- 低速は Shift と肩ボタン（L1/R1 どちらでも）。
- ショットは会話中（吹き出し表示中 `Hud.BubblePaused`）は不可。ボム・モード切替・スキル・全開も同様。
- やさしさ全開はかつて Space → B と変遷。Space は `ui_accept`（＝ショット）と重複、B はパッド B（モード切替）と紛らわしいため、**Ctrl（左右どちらも拾う）/ R3** に変更（2026-06-21・論点①②を解消）。

## 3. HUD 操作ヒントのトークン表記

**操作表示モード**（[Pad.cs](../src/Pad.cs) `Pad.Display`）で KB / PS / Xbox を**固定**して出す。`Auto` のときだけ直近デバイスで自動判定（[Pad.cs](../src/Pad.cs) `PollDevice`）。

- **単体チップ**（BOMB 残数横・ショットモード切替・スキル）は代表1表記（[Hud.cs](../src/Hud.cs) `TokShot/TokFocus/TokBomb/TokMode/TokSkill/TokMove`）。
- **プレイ中の操作ヒント**（[Hud.cs](../src/Hud.cs) `DrawControls`）は、選択中モードに属する**割り当てを全部**列挙（`AllShot/AllMove/AllFocus/AllBomb/AllMode/AllSkill/AllKind`）。横幅が画面に収まらない場合は自動で複数行に折り返す（はみ出し防止）。

| 機能 | KB（全割り当て） | パッド表記（Xbox→PS） |
|---|---|---|
| 移動 | 矢印 / WASD | L（左スティック） |
| ショット | Z / Space / Enter | A → 〇 |
| 低速 | Shift | LB/RB → L1/R1（両方表記） |
| ボム | X | X → □ |
| モード切替 | V | B → × |
| スキル | C | Y → △ |
| やさしさ全開 | Ctrl | R3 |

## 4. 操作表示モードとパッド表記（Keyboard / PlayStation / Xbox）

[Pad.cs](../src/Pad.cs) の `Pad.Display`（`Auto/Keyboard/PadPlayStation/PadXbox`）が表記を固定する。`Pad.Face()` は物理 JoyButton → 表記文字列に変換（物理配置は Xbox 固定で**表記のみ**切替）。`Pad.Style` は `Display` から導出（PadPlayStation⇔PlayStation / その他⇔Xbox。`Auto` のみ旧 `padstyle` 由来の `_autoStyle`）。

- **選び方**: タイトル「はじめから」で必ず3択（[TitleMenu.cs](../src/TitleMenu.cs) `DrawDisplayPicker`）。設定の操作カテゴリ「操作表示」セグメント（[Settings.cs](../src/Settings.cs)）でも変更可。
- **永続化**: `user://settings.json` の `inputdisplay`(0=KB/1=PS/2=Xbox)。タイトル決定時は [Pad.cs](../src/Pad.cs) `SetDisplayAndSave` がマージ書き込み、設定では `Settings.Save`。起動時 [Pad.cs](../src/Pad.cs) `ApplySaved`（`Audio._Ready` から）で復元。旧 `padstyle` は Auto 時のパッド表記として後方互換に読む。

| 物理（JoyButton） | Xbox | PlayStation |
|---|---|---|
| A | A | 〇 |
| B | B | × |
| X | X | □ |
| Y | Y | △ |
| LeftShoulder | LB | L1 |
| RightShoulder | RB | R1 |
| RightStick(R3) | R3 | R3 |

## 5. 見直し時に気づいた論点（解消状況）

1. ~~**キーボード B とパッド B の役割がちぐはぐ**~~ → **解消（2026-06-21）**: キーボードのやさしさ全開を `B → Ctrl` に変更。B はパッドのモード切替専用に。
2. **キー密集**: `Z X C V` が一列に並び、ボム(X)／モード切替(V)／スキル(C) の押し間違いの懸念は残る（全開は Ctrl へ離した）。要観察。
3. **やさしさ全開が R3（右スティック押込）**: パッド側は据え置き（タスク指定）。押下感の論点は継続。
4. **ポーズがパッド非対応**: Esc のみ。未対応のまま（今回スコープ外）。
5. **InputMap 未使用**: 入力は全ファイル直読みのまま。表記だけ `Pad.Display` で集約したが、リバインドUIは未対応（将来 InputMap へ集約推奨）。
