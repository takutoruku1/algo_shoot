# ボタン配置 資料（現状）

algo_shoot の現在の入力割り当て一覧。コードからの実測（2026-06-21 時点）。

> **⚠ この資料は 2026-06-21 時点で止まっている**（低速移動・ショットモード切替・ヒカゲ専用スキル・やさしさ全開は、その後いずれも機能ごと撤去済み）。
> **現行の正典は実装**＝[Player.cs](../src/Player.cs) の入力判定と、[HowToPlay.cs](../src/HowToPlay.cs) `DrawPageControls` の3タブ表。
> 直近の変更: **2026-09-17 ロックオン解除を `G`（KB）/ `R3`（パッド）へ新設**。R3 は旧「やさしさ全開」の枠を再利用（同機能は撤去済みで読み手ゼロだった）＝**以後 R3 は空きではない**。

> **実装メモ**: Godot の InputMap（`project.godot` の `[input]`）は**未使用**。移動とメニューの十字／決定だけが既定アクション（`ui_left/right/up/down`・`ui_accept`）に乗っており、それ以外は各ファイルで `Input.IsKeyPressed(Key.*)` / `Pad.Pressed(JoyButton.*)` を**直読み**している。したがって「設定でキー変更」は現状不可（リバインドUIなし）。
>
> **操作表示モード（2026-06-21 追加）**: ヒント/ボタン表記を `キーボード / コントローラ(PS) / コントローラ(Xbox)` の3択で**固定**できる（[Pad.cs](../src/Pad.cs) `enum DisplayMode { Auto, Keyboard, PadPlayStation, PadXbox }` / `Pad.Display`）。入力自体はどのデバイスも常に有効で、これは表記だけの話。タイトル「はじめから」で**毎回必ず**選ばせ、設定（操作カテゴリ「操作表示」）でも変更可。永続キーは `inputdisplay`(0=KB/1=PS/2=Xbox)。旧 `padstyle`(0=Xbox/1=PS) は Auto 時のパッド表記として後方互換で読む（`Display` 導入後、`Pad.Style` は `Display` から導出）。未選択（旧データ）は `Auto`＝直近デバイスで自動判定（従来挙動）。

## 4. 操作表示モードとパッド表記（Keyboard / PlayStation / Xbox）

[Pad.cs](../src/Pad.cs) の `Pad.Display`（`Auto/Keyboard/PadPlayStation/PadXbox`）が表記を固定する。`Pad.Face()` は物理 JoyButton → 表記文字列に変換（物理配置は Xbox 固定で**表記のみ**切替）。`Pad.Style` は `Display` から導出（PadPlayStation⇔PlayStation / その他⇔Xbox。`Auto` のみ旧 `padstyle` 由来の `_autoStyle`）。

- **選び方**: タイトル「はじめから」で必ず3択（[TitleMenu.cs](../src/TitleMenu.cs) `DrawDisplayPicker`）。設定の操作カテゴリ「操作表示」セグメント（[Settings.cs](../src/Settings.cs)）でも変更可。
- **永続化**: `user://settings.json` の `inputdisplay`(0=KB/1=PS/2=Xbox)。タイトル決定時は [Pad.cs](../src/Pad.cs) `SetDisplayAndSave` がマージ書き込み、設定では `Settings.Save`。起動時 [Pad.cs](../src/Pad.cs) `ApplySaved`（`Audio._Ready` から）で復元。旧 `padstyle` は Auto 時のパッド表記として後方互換に読む。

| 物理（JoyButton） | Xbox | PlayStation |
|---|---|---|
| A | A | 〇 |
| B | B | × |
| X | X | □ |
| Y | Y | △ |
| LeftShoulder | LB | L1 |
| RightShoulder | RB | R1 |
| RightStick(R3) | R3 | R3 |

## 5. 見直し時に気づいた論点（解消状況）

1. ~~**キーボード B とパッド B の役割がちぐはぐ**~~ → **解消（2026-06-21）**: キーボードのやさしさ全開を `B → Ctrl` に変更。B はパッドのモード切替専用に。
2. **キー密集**: `Z X C V` が一列に並び、ボム(X)／モード切替(V)／スキル(C) の押し間違いの懸念は残る（全開は Ctrl へ離した）。要観察。
3. **やさしさ全開が R3（右スティック押込）**: パッド側は据え置き（タスク指定）。押下感の論点は継続。
4. **ポーズがパッド非対応**: Esc のみ。未対応のまま（今回スコープ外）。
5. **InputMap 未使用**: 入力は全ファイル直読みのまま。表記だけ `Pad.Display` で集約したが、リバインドUIは未対応（将来 InputMap へ集約推奨）。

## 2026-09-26 追記（ロックオンは「モード」として保持する）

作者指示「画面から敵が消えてもロックオン解除しないで。ステータス欄でロックオンモードかを分かるように」。

- `Player._lockArmed`（狙う意思）を `_locked`（今この敵を掴んでいる）と分けた。対象が倒れた・画面外へ出た・ウェーブの合間で敵が一体も居ない、のどれでもモードは落ちず、次に現れた最寄りの敵へ**自動で付く**（音なし）。
- 落ちるのは解除入力だけ：**Shift を離す／モード中の左クリック／R3**。敵の居ない盤面で Shift・左クリック・S・RB を押すと「待機」に入る。
- サイドパネル TIME の下に **LOCK-ON 行**を足した（`Hud.DrawLockOn`）。`OFF`（灰）／`待機`（青緑・明滅＝モードは立っているが画面に敵が居ない）／`追尾中`（ジョブ色）。COMBO 576→606・集中 649→660 に詰めた。
- 会話で戦闘が止まっているあいだは自機を吹き出しの奥（Z -8）へ回す（`Player.TickBubbleDepth`。作者指摘「吹き出しの上に乗っていたら、動かせないのに読めなくなる」）。弾は触らない。
- 検証：`tools/qa_lock_mode.tscn`（`LockModeQa`。窓ありで `-- --lm-shot --lm-out <dir>` を付けるとサイドパネルの3状態と奥回しのスクショを撮る）。

## 2026-09-27 追記（会話ボックスのボタン列）

作者指示「テキストボックスの上に AUTO／SKIP／LOG／MENU のボタンが出てキーボードでも選択できるように」。ノベルゲーム定番の「テキスト枠の上辺・右寄せに小さなボタンが横一列」を会話ボックスに付けた。実装は `src/DialogToolbar.cs`（Hud の partial）。

| ボタン | 動作 | キーボード | パッド | マウス |
|---|---|---|---|---|
| AUTO | 自動送りの切替（設定の「オート会話送り」と同じ値。`user://settings.json` の `auto` へ保存） | **A** | **Y** | クリック |
| SKIP | 既読スキップのラッチ（ON の間は Ctrl／RB 押しっぱなしと同じ） | **S** | **RB 押し離し**（長押しは従来どおり押しっぱなしスキップ） | クリック |
| LOG | 会話ログを開く | L（Tab） | View | クリック |
| MENU | ポーズメニューを開く | M | Menu(≡) | クリック |

- 出る場所：Hud が描く会話ボックス全部＝戦闘中の会話バー・ナレーション枠・カットシーン（StoryFilm の回想／アフター、BossDraftScene、MinaPhaseScene）。ボックスの上辺右寄せに 10px 食い込む。高さ 24px・間隔 8px。各ボタンは `[キー] ラベル`、キー名は直近デバイスに追従（マウス時は KB 表記）。
- **対象外**：Prologue／Final／Epilogue／Hub は会話枠を自前で描いていて Hud を通らないので、ボタン列は出ない（キー割り当ては各画面の従来どおり）。
- 戦闘の会話バーは弾の奥（BubbleLayer）に沈んでいるが、ボタン列は最前面（HudCanvas）に描く＝弾に隠れずクリックできる。
- 反応するのはボックス表示中だけ。出た直後 0.3 秒はキーを無視する（戦闘中に A／S を叩いている最中に会話が割り込んでもトグルしない）。
- 点灯：AUTO＝自動送り ON、SKIP＝ラッチ ON または押しっぱなしで早送り中（旧「▶▶」チップはこれに置き換えて撤去）。マウスホバーで少し明るくなる。

- 検証：`tools/qa_dialog_toolbar.tscn`（`DialogToolbarQa`。窓ありで `-- --dt-shot [--dt-out <dir>]` を付けると戦闘会話・ナレーション・カットシーンの3枚を `build/shots_toolbar/` に撮る）。

## 2026-09-27 追記（Esc でメニュー／Shift ロックの会話またぎ／ヒント削除／アカウント切り替えのキー導線／終了時のセーブ確認）

作者指示5件。

- **Esc でもポーズメニューが開く**（「シューティング中は ESC でポーズ。スマホの選択画面以外は同様。オープニングやエンディングも」）。開いた後の Esc は従来どおり「一段もどる」（確認→スロット→設定→トップ→閉じる）。
  - Esc で開く画面：ステージ（戦闘中・会話中も）と Prologue／Final／Epilogue（`PauseMenu.EscOpensHere`）。
  - スマホ系（ハブ／ショップ／難易度選択／記録／カスタマイズ）と**トレーニング**は Esc の意味を変えない＝各画面の「もどる」（ハブのホームでは何もしない）。M／Start ではそこでも従来どおり開く。トレーニングは Esc＝ショップへもどる（2026-09-26 指示）を優先した。
  - カットシーン（Prologue／Final／Epilogue）は M／Esc で開く。**パッドの Start はカットシーンでは開かない**（そこでは「長押しでさいしょから」に使われている）。メニューの行は「離脱」を落とした6行（リスタート＝そのシーンの最初から）。オープニング／エンディングのムービー再生中は開かない（ムービーが入力を握る＝絵が BGM に同期しているので止めない。Esc 長押しはムービーのスキップのまま）。
  - Credits（スタッフロール）・タイトル・設定は対象外のまま。
- **Shift ロックは Shift の状態（レベル）で解除**（「キーボードでロックオンしたまま会話に入ると、会話終わったあとシフト放してもロックしたまま」）。Shift で武装した（または武装中に Shift を押し直した）ロックは、Shift が上がっていれば会話中でも会話明けでもその場で外れる（`Player._lockByShift`）。会話中に外れたときは音を鳴らさない。S／A／RB／左クリックで付けたロックは Shift と無関係で、会話を挟んでも保つ。
- **戦闘画面の「M メニュー」ヒントを削除**（「シューティング中の ESC メニューの表示は削除して」）。右下の常駐ヒントはハブ／ショップ／難易度選択／記録／カスタマイズだけに出す（`PauseMenu.ShowHint`）。ステージ・トレーニング・カットシーンでは描かない。
- **アカウント切り替えにキーボード／パッドで届く**（「キーボード操作でアカウントを開くを選択できない」）。原因は SNS のフッタがマウス専用で、キー導線 J／RB が画面のどこにも表示されていなかったこと（`FooterItems` のキー表記を `DrawFooter` が捨てていた）。
  - SNS で **←／→**（どのカードからでも）または**最後のカードで ↓** → フッタへ降りる（着地は「アカウント」）。フッタ上は ←→ で項目を巡り、**Z／Enter／パッド A** で押す。↑ でカードへ戻る。パッドは十字キーで同じ。
  - フッタの各ラベルの右にキー表記（X／C／J、パッドは B／Y／RB）を小さく添えた。J／RB で直接開く導線は従来どおり。
- **タイトルへ戻る／ウィンドウを閉じるときに「セーブしますか？」**（`PauseMenu` の QuitAsk）。
  - メニューの「タイトルへ」→「タイトルへ戻る前に、セーブしますか？」＝**セーブする**（→ スロット選択 → 保存したらそのままタイトルへ。スロットをキャンセルするとこの問いへ戻る）／**セーブしない**（→ そのままタイトルへ）／**キャンセル**（→ メニューへ）。
  - ウィンドウの ×／Alt+F4 → ツリーをポーズして同じ問いを「セーブして終了／セーブせずに終了／キャンセル」で出す（`GetTree().AutoAcceptQuit=false` ＋ `NotificationWMCloseRequest`）。メニュー表示中ならメニューの上に重ね、キャンセルでメニューへ。メニューを開いていない状態からならキャンセルでそのままゲームへ戻る。タイトル／設定／スタッフロールでは確認せず即終了。トレーニング（セーブ不可）は「セーブせずに終了／キャンセル」の2択。あそびかた／会話ログが開いている間の × は、それを閉じた時点で問いを出す。
  - 操作：←→ または ↑↓ で選ぶ、Z／Enter／パッド A で決定、Esc／X／パッド B／右クリックでキャンセル。既定は「セーブする」。タイトルへ・終了のどちらも従来どおり離脱時オートセーブ（スロット0）は打つ（手動スロットとは別枠）。
