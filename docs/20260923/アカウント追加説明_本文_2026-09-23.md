### 本文と事実の対応（行ごとの注記）

- **1 行目**「ご報告。アカウントが、ひとつ、増えています。……名義は、わたくしではありません。あの方です。」
  - 「ご報告。」＝ミナの事務連絡の定型（`Hub.cs:3166`「ご報告。この騒ぎで…」、`Hub.cs:3004`、`StageRei.cs:299`）。
  - 「名義は、わたくしではありません」＝同じ会話の 2 行目「名義は M・I・N・A、わたくしですので」（`Hub.cs:3125`）の反復。同じ言葉で「今度は自分の名義ではない」とだけ言い、「隣に立つ」の意味付けはトーストに任せる（感情の直書きをしない）。
  - 「あの方」＝ミナがあかりを指す既存の呼び方（強化アイテム説明・アンチャー紹介と同じ）。
  - B は「いま潜っていた場所の、あの方」に置き換え＝誰の解禁でも成立する。
- **2 行目**「SNSの下、「アカウント」から、切り替えられます。切り替えた回は、あの方が潜ります。足取りは、ご主人様のままで。」
  - 「SNS」＝ホームのアプリ名（`HomeApps[0]`）でミナの既出語（SNS 導入「SNSでは、投稿に埋もれた…」`Hub.cs:150`）。帰還会話のあとプレイヤーは**ホーム**に居る（`returnMode: Mode.Home`）ので、「タイムラインの下」ではなく「SNSの下」と場所を先に言う。
  - 「アカウント」＝フッタの語そのまま（`Hub.cs:2450`）。キー名（J／RB）は言わない。
  - 「切り替えた回は、あの方が潜ります」＝ `CharacterStory.DiveActive`（そのランは彼女の話になる）。「回」＝ランの単位（ラン中は変えられない）。
  - 「足取りは、ご主人様のままで」＝操作はプレイヤーのまま。初回切り替え時の掛け合い「足取りはご主人様に、返事は、あなたに。」（`CompanionDialogue.cs:214`）と同じ言い方に揃えた＝あとで流れる Select 会話と噛み合う。
- **3 行目**「光の形も、そこで語られる話も、あの方のものになります。……戻すのも、同じ場所からです。」
  - 「光の形」＝撃ち方（連射→加速球）。ミナは弾を「光」と呼ぶ（チュートリアル「光は、自動で放ちます」）。「加速球」「撃ち方」の語は使わない。
  - 「そこで語られる話」＝キャラ別ストーリー（ミナ本編の差し替え）。ミナ不在・記憶なしの規約には触れず「話があの方のものになる」とだけ。
  - 「戻すのも、同じ場所からです」＝次に潜る前なら同じ画面から選び直せる（合わない相手で詰ませない設計）。
  - ♥−1・密着クリ・移動速度の差は言わない（数値・段の説明は選択画面の 1 行が持つ）。

### 口調・表情
- 一人称「わたくし」、プレイヤー呼称「ご主人様」。感情語なし（あかり後に解禁されているのは「困る」だけ。ここでは使わない）。
- face は `mina_face` のみ（ハブでは固定なので指定は形式上）。

## 判断に迷った点（engineer / 指揮官へ）

1. **置き場所（2 案）**
   - **(a) H1 の中に差す（推奨・読み味）**：`ReturnDialog("akari")` の「被弾は{n}回でした」（`Hub.cs:3137`）の**直後**、「……お疲れさまでした。」（`3138`）の**前**。集計→ご報告→お疲れさま→次の声、の順で、締めの「次の声も、もう、聞こえています。」が最後に残る。ただし `ReturnDialog` は静的で再クリア時も流れるので、初回だけにするなら `Hub.cs:345` で組み立てる側の**実行時スプライス**が要る。
   - **(b) 帰還会話の後ろに Concat（最も単純）**：`Hub.cs:345` の `lines` に、`freed != null && !_game.IsIdleDialogSeen("once_account_intro")` のとき 3 行を足して `MarkIdleDialogSeen`。締めの一行の後に事務連絡が来る形になる。
   - どちらでも HomeReveal → ShopTutorial の順は変わらない（会話終了後に発火する）。
2. **初回のみ／毎回**：ユーザー指示どおり**あかり追加時だけ**を推奨（A）。こはる後は炎上、レイ後は FINAL 予告が続くので、そこに説明を挟むと閉じの行がぼやける。2 人目以降にも出したければ B を同じキーの別値（`once_account_intro_{id}`）で。
3. **「SNSの下」の指し方**：会話が終わった時点ではホーム画面で、フッタ「アカウント」は SNS を開かないと見えない。ホームからは開けないので「SNSの下」と場所を先に言った。ホーム下段の使用中アカウント表示（`Hub.cs:1516-1520`）を押せるようにするかは engineer / game-designer の判断（本文はどちらでも成立する）。
4. **wiki との食い違い（参考）**：`wiki/05_ゲーム仕様/12_ジョブ.md` §解禁は「未解禁の行は選択画面から消えず、灰色で残る」と書くが、現行の `OpenJob` は解禁済みだけを一覧にする（`Hub.cs:2723-2724`）。本文はどちらにも依存しない。
