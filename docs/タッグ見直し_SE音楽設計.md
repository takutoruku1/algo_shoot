# タッグ見直し：SE/音楽設計（シナリオ × ゲームUI）

光田康典エージェント（サウンド本体）× 桜井政博エージェント（UI/ゲームプレイの音）× 麻枝准エージェント（シナリオの音）の**三人タッグ**による、SE・音楽設計の見直し統合版。
各自が自分の思想/作風ドキュメントと実装値を読み込んで独立に設計し、互いのフック（`sound-map.md`）を参照し合った上で収束させた。
**この文書は設計・提案のみ。コードは未変更。** 実音源は本環境で生成できないため、設計と結線を確定し「音源を差し替えれば成立する状態」を作る方針（「作曲した」とは偽らない）。

前提（実装で確認した事実）:
- 音声ファイル **0件**、`AudioStreamPlayer` 使用 **0件**、配線は **Master バスのみ**（`Settings.cs:153-156`）。`bgm/se/voice/amb` の4スライダー（`Settings.cs:58-62`）は受け皿バスが無く動かしても無音＝**完全無音**。
- 視覚フィードバックは厚い（`FxLayer` の `Muzzle/Shatter/Graze/PlayerHit/PurifyBurst/Bomb/KindnessMote`、被弾はシェイク＋ヒットストップ0.09＋赤フラッシュ）。**音という情報チャンネルだけが丸ごと欠落**している。

## 0. 三人が独立に到達した「一つの背骨」

別々に走った三者が、同じ主題構造に収束した。

- **メインモチーフ ＝ 「M.I.N.A.／いなくならない」**。`Prologue.cs:32-38` の Acrostic（"I made you so I'm not alone / Never leave, okay? / And I won't…"）を旋律化。**M→I→N→A の4音**動機にし、`Epilogue.cs:36-42`・`:169-192` の解錠で **一行＝一音で鳴らし、4音目で和音として完成**＝名前の回収を音で。Prologue仕込み→Final/Epilogue回収の対構造。
- **言葉のライトモチーフ「ご主人様は、アホですね」が3回**（`Prologue.cs:82` 軽口／`Final.cs:56` 命綱／`Epilogue.cs:65` 喪失）。光田・麻枝が独立に「音でも同じ動機を帰す」と指定。各回で温度が違う（軽口→命綱→喪失）ので編成・密度の変奏で応える。
- **制作順の合意**：全員が「**バス整備＋コアSE4種が最初の一手**」で一致（桜井§15「磨きは新規より先」＝光田の制作順＝麻枝の優先発注）。

## 1. シナリオ側の音（麻枝主導）

### 1-1. 中核主題「いなくならない」＝少年＝MINAのモチーフ
少年がMINAを作った理由「ひとりになりたくない」が旋律。**この歌が誰のものかが最後に反転する**のが肝。
- **Prologue**：電子・グリッチで断片的に無害に。`boot[]` の `not_alone=1`（`Prologue.cs:71`）で主題の最初の2音だけ刺す。
- **Final**：同じ旋律が汚染で**濁って**聞こえる。「少年が自分のために歌っていた」へ意味が傾く（`Final.cs:53`「臆病者だから何回も死んでる」）。
- **Epilogue**：少年はもう歌えない。**ミナの声部が主題を引き継いで歌い切る**（`Epilogue.cs:66`「いなくならないって、書いたくせに」の直後、伴奏が消えミナのモチーフが少年のモチーフと同じ旋律に溶ける）。**P4ガード**＝主題の主体をミナに渡し、器化を回避。「どこにも行きませんよ」（`:69`）はミナ自身の意志として鳴らす。

### 1-2. 各ボスの固有モチーフ＝「未完→完」（型を3つとも変える＝P1回避）
浄化＝倒すでなく届ける。戦闘中は不協和、改心の決定打行で解決和音に変わる＝相手の人格が満ちる音（少年の満足音ではない＝P4）。

| キャラ | モチーフの核（未完の形） | 浄化（改心Lines）で完 |
|---|---|---|
| レイ（順位） | 主音直前で落ちる（半音で届かない） | `BossRei.cs:55`「ちゃんと、ライバルだった…?」で初めて主音に到達 |
| あかり（雨） | フレーズが途中で切れる（"す——"） | `BossAkari.cs:64`「すき、だったの」で初めて最後まで歌われる |
| こはる（台所） | 温かい旋律が冷えて減衰 | `BossKoharu.cs:61`「ちゃんと、食べてくれるかな」で温かい残響が戻る |

**3ボスの解決音は主題の構成音に内包**。「救った三人が全員、少年の知り合いだった」（`Epilogue.cs:56`）と判明する瞬間、**三人のモチーフが主題の中に同時に響く**＝長距離伏線の音版回収。

### 1-3. 挿入歌の一点投入と無音（本編で一度だけ＝希少性）
**Final、ミナの最後の軽口の直前**に落とす（`Final.cs:55-57`）。
- `:55`「光が、いつもよりずっと薄かった」の行で **`// BGM停止（汚染の濁りごと音を抜く）`**
- `:56`「……ご主人様は、アホですね。」の頭から **`// 無音のまま。ミナの声だけ。SE無し`**（最も感情が高い行ほど鳴らさない）
- `:57`「——最後の軽口になりました」の一行前から **`// 挿入歌 IN（本編唯一）`**
- 歌詞＝主題のフルボーカル版。**サビの各行頭文字を M/I/N/A** で組み、Epilogueの縦読み解錠と対に（遅延した理解）。
- Epilogueには挿入歌を置かず**無音と語りで静かに落とす**（押し付け回避＝P5）。
- Prologue既存の「間」（`Prologue.cs:115` `minHold=1.2`、名前の由来をはぐらかす行）に**主題の断片を一瞬止める**＝隠している証。Epilogue回収後に見返すと意味が分かる長距離回収。

### 1-4. 会話・記憶フラッシュ・Acrosticとの同期
- **記憶フラッシュ**（`StageImagery.cs:27` `_flashT=2.4`、`BossAkari.cs:257` who=3で一回限り発火）：0.0s 雨音＋遠い街へ切替（戦闘BGMダッキング）→ 約1.2s クラクション一発（画の "クラクション" と同フレーム）→ 直後あかりモチーフが途中で切れる → 2.4s 戦闘BGMがわずかにキー高く戻る（記憶を通過した感）。
- **Acrostic解錠**（`Epilogue.cs:180-188` 4行が0.7s刻みで浮かぶ）：M・I・N・A の各頭文字が立つ瞬間に主題の構成音を一音ずつ → **4音目で和音として鳴り直す＝主題完成**。ゲーム全体の音の回収点。**PW不正解時（`Epilogue.cs:110`）は和音を鳴らさず鈍い不一致音**だけ（正解の和音を貴重に）。
- **タイプライター送り音**（`Hud.cs:84-85` `CharsPerSec=48`）：話者で音色を変える。少年=温（木）／ミナ=澄（ガラス）／ボス=くぐもり／**ナレ（who=3 地）＝音なし**（語りとセリフを耳で区別）。`Settings` の `msg`/`auto` を尊重、会話中はSE抑制。

### 1-5. 汚染の濁りに物語的意味
ただのホラー演出にしない。濁りの素材を **「3ボスモチーフの歪み＝ミナが抱えた三人の想いの重さ」** にする。`Final.cs:47-48`「穢れを祓うたび、それはわたくしの中に溜まっていた／三人ぶんの、悲しみと、怒りと、届かなかった想い」で**恐怖が想いの重さに意味反転**。視覚の濁りティント（`Player.cs:118-121` `CleanTint→MurkTint`）と同一曲線で音も濁す。

## 2. ゲームUI/ゲームプレイ側の音（桜井主導）

「画は完成、音という情報チャンネルが丸ごと欠落」。重要度順。各件は `FxLayer` フックに同フレーム相乗りが原則。

| # | 重要度 | 指摘 | 同期先（実コード） | 音のキャラクター/方針 |
|---|---|---|---|---|
| ① | **高** | **被弾音が無い** → 高密度で「今食らった」が分からない | `Player.cs:520-523` `PlayerHit`＋Shake＋Hitstop0.09 | **Alertバス＋ダッキング**。ヒットストップ `TimeScale=0.06`（`GameCamera.cs:45`）に引きずられない**実時間再生**。ガラスにヒビ／光が欠ける鋭い高域＋短い余韻。全SE最優先 |
| ② | **高** | **発射音が無い** → 手触りの土台が抜けている | `Player.cs:359` `Muzzle` | 短く・減衰早く・**ピッチ±数%ゆらぎ・ボイス上限**。全開（`Player.cs:284` 0.07s）でピッチ上げ。ショットモードで音色変え（V切替の手応え） |
| ③ | **高** | **ボムの解放カタルシスが無音** | `Player.cs:441` `Bomb`＋Hitstop0.05 | 一拍の溜め→開放の二段（魔法陣立ち上がりに溜め、`BombRing` 拡大で開放）。破壊音でなく「鎮める/光が満ちる」 |

| ⑥ | 中 | **全開（Overload）発動が無告知** ＝ピークなのに気づかない | `GameManager.cs:358` `JustOverloaded`（1フレーム） | 発動ジングル（上昇音＋光が満ちる）。発動中はBGMレイヤー1枚 or ハイパス開で持続提示。終了で静かに戻す |
| ⑦ | 中 | **会話開始の弾消去がテンポを殺す沈黙** | `Hud.cs:95` `ClearEnemyBullets` | 「鎮まる音」（`BulletToPetal` 系の質感）。同時にBGMを一段静める。事故に見せない転換演出に |
| ⑧ | 中 | **メニューUIが全画面無音** | 各画面の `_navHeld`/`Confirm`/`back` エッジ（`TitleMenu`/`Shop`/`DiffSelect`/`Hub`） | 共通UI SEセット。カーソル「ティッ」/決定=芯/キャンセル=下降。**購入成功**（`Shop.cs` `_buyFxT=0.7`）=達成音／**失敗**（`Shop.cs:128` Toast）=拒否音。決定/キャンセル音は全画面で同一（一貫性） |
| ⑨ | 中 | **死んでいる音量スライダー4本** ＝設定UIが嘘 | `Settings.cs:58-62`/`149` | バス整備が前提。結線まではスライダーを無効表示で「準備中」明示 |
| ⑩ | 低 | **ボス段階移行・スペル宣言が無音** | `Hud.cs:163` `AnnounceSpell`／各 `OnHpChanged` | 短い宣言音・警告音。優先度は被弾の下・グレイズの上。弾幕変化を耳で予告（初見殺し回避） |

### ミックス優先度（聴覚版の視認性）
高→低：**①被弾（Alert・ダッキング）→ ②ボム/全開発動 → ③浄化/スペル宣言・段階移行 → ④グレイズ → ⑤発射（土台・ボイス上限＋短い減衰）→ ⑥UI操作音（プレイ中は鳴らない）**。
発射・グレイズは秒間10発以上鳴りうる → **ボイス上限＋古い音の打ち切り＋ピッチ微ゆらぎ**必須。被弾だけは上限の影響を受けない専用枠に隔離。

## 3. 音アーキテクチャ（光田）

### 3-1. バス構成（最初の一仕事）
```
Master
├─ Music   … BGM。後段に AudioEffectLowPassFilter を1枚（汚染で濁す枠）
├─ SE      … 効果音
├─ Voice   … テキスト送り音・ボイス
├─ Amb     … 環境音・心象ノイズ（濁りパッド常駐）
└─ Alert   … 被弾・残機・段階移行の最優先音だけを逃がす（埋もれ防止）
```
`Settings.Apply`（`Settings.cs:149-160`）を現状 `case "master"` だけ→全バスへ一般化（`SetBusDb(bus,f)`）。これで4スライダーが生きる＝**投資対効果No.1**。

### 3-2. SE基盤
`Audio` オートロードを `FxLayer` と同じ流儀（静的 `Instance`、Mainがworldに1個追加）で常駐。SEプール（同時発音制限＝弾幕で飽和しても破綻しない）、`Muted`（QA用）。**SEトリガは `FxLayer.*` 呼び出しの隣に挿入**＝画音同フレーム。

### 3-3. アダプティブ（連続=フィルタ／離散=レイヤー・分岐）
- **Contamination**（`GameManager.cs:74`、Finalで1.0）→ Music の LowPass を `Lerp(800,16000,1-汚染)`。自機の濁りティント（`Player.cs:118-121`）と**同一曲線**。`Amb` の濁りパッドを汚染で音量up。濁りの素材は**3ボスモチーフの歪み**（麻枝の意味づけと素材共有）。
- **Warmth**（`GameManager.cs:70` 浄化進捗）→ 晴らす方向（LowPass開・濁りパッド下げ）。
- **離散＝ボス段階**：同尺・同BPMのレイヤーを**同時Playして音量で抜き差し**（後からPlayしない＝位相を揃える）。`BossRei.OnHpChanged()`（`BossRei.cs:169-183`、`_finale`）で発火。

### 3-4. シーン遷移
クロスフェード（Tweenで旧→-80db / 新→0db、共通主題で橋）。ブツ切り禁止。Prologue/Final/Epilogue は独自レンダラのフェーズ遷移に合わせる。

## 4. 推奨制作順（投資対効果）

1. **【最初の一手】バス構成＋`Settings`配線＋`Audio`オートロード**（死んだ4つまみを生かす・QAはMuted）← 三人のイチオシ。
2. **コアSE 4種**：①発射（`Player.cs:359`）②グレイズ（`:429`）③被弾（`:520`・Alert）④浄化（`Enemy.cs:210`）を `FxLayer` フックに相乗り。**ここで手触りが跳ねる**。暫定は合成音で結線し体験を先に通す。
3. **道中/ボスBGM**（主題＋1変奏）＋シーン遷移クロスフェード。
4. **アダプティブ**（汚染LowPass・濁りパッド・ボス段階レイヤー）。
5. **無音→挿入歌（Final）＋会話同期**、残SE（ボム・パネル・段階移行・全開）。

各段階で `play-game`/`demo-video` で**実際に聴いて**確かめる（机上で音を語らない）。

## 5. 三者の連携・発注（要約）

- **光田→桜井**：被弾音を最優先で（実時間再生＋ダッキング）。会話開始の弾消去の「鎮まる音」長の上限（テンポを殺さないms）を桜井基準で。`msg`速度とテキスト送り音の間引き率。
- **光田→麻枝**：挿入歌の歌詞をM.I.N.A.主題と共有（サビ＝Acrostic 4行の意訳）。Finalの無音位置を行単位で確定。「アホですね」3回の温度指定。
- **桜井→光田**：被弾SE・発射4点セット・浄化二層・バス整備とスライダー結線を早めに。アダプティブより先に離散イベントSEを揃える（手触りへの寄与大）。
- **麻枝→光田**：主題を1曲5アレンジ（Prologue断片／道中／Final濁り／Final挿入歌／Epilogue回収）、①と⑤が同旋律と分かる編曲。3ボスモチーフの構成音を主題に内包。
- **麻枝→桜井**：会話送り音を話者4色（ナレは無音）。汚染の濁りは「三人の想いの重さ」（Player Tintと同一曲線、素材は3ボスモチーフの歪み）。
