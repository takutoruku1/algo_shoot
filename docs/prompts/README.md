## 使い方
1. 今から作るフェーズのファイルを開く。
2. ファイル冒頭の **「共通スタイルプロンプト（接頭辞）」を毎回コピーして先頭に貼る**。
3. 「このフェーズで作るアセット一覧」のチェックリスト順に、1キャラずつ「基準画像確定 → ポーズ個別生成 → 手作業整列」。
4. 仕上げ・アトラス化・命名は [../CHARACTER_ASSETS.md 第8章](../CHARACTER_ASSETS.md#8-命名規則--ファイル構成まとめ) に従う。
