# キャラクター設定書 ④：レイ（ライバル／STAGE1 救う対象）

> 少年の好敵手の女の子。技術・プログラミングで少年と競い続けてきた努力型の才媛。
> 表向きは「あんたにだけは負けない」。本心は、誰よりも少年の才能を認め、認められたい。
> 少年が本気で戦ってくれなくなったことに気づき、「勝負の宙吊り」で病む。
> 救う順番は1人目（レイ → あかり → 妹）。

---

## 1. 基本

| 項目 | 内容 |
|------|------|
| 名前 | レイ（怜／玲 想定。表記は今後確定） |
| 関係 | 少年の好敵手。**恋愛感情はない**、対等にぶつかる関係（あかりと明確に描き分ける） |
| 土俵 | 技術・プログラミング（競技プログラミング、コンテスト等で競ってきた） |
| タイプ | 努力型の才媛。血の滲む努力で天才の少年に食らいつく。プライドが高い |
| 立ち位置 | STAGE1で救う対象。物語の入り（チュートリアル兼用）を担う |

### 二人の関係の形（病む前）
- コンテストで負けるたび、レイが「次は、私が勝つから」と宣戦布告するのが恒例。
- 少年は「待ってるよ」と尊大に受けて立つ。それが二人の儀式であり、絆だった。
- 建前は「あんたを認めたことは一度もない」。実際は誰よりも少年の才能を認めている。
- 少年も内心レイを認めている（唯一対等に楯突ける相手）。だが尊大だから言わない。
- **お互い素直になれない仮面同士**（少年のナルシスト仮面と対になる構図）。

---

## 2. 口癖（変化で描く）

- 本来：**「次は、私が勝つから」**
  （敗北宣言であり、次も戦うという約束。二人の関係そのもの）
- 病んだ後：**「……次なんて、ないんでしょ」「なんで、戦ってくれないのよ」**
  （「次」が来ない予感。口癖が言えなくなる）
- 浄化後：「次は、私が勝つから」が戻る。
- **ラストへの射程**：少年の死後、この言葉は永遠に宙に浮く。
  だが「次」を言い続ける限り、彼女の中で勝負は終わらない＝少年が生き続ける、とも読める。
  エピローグの含みに使用可。

---

## 3. 穢れ（病んだ理由）＝「勝負の宙吊り」

- 少年の様子がおかしくなる：弱る、休みがち、**勝負に応じなくなる**。
- レイは気づいてしまう——あいつ、本気で戦ってくれなくなった。
- 理由は知らない（病気を知らされていない／薄々感じて否認している）。
- 混ざり合う感情：
  - 怒り：「勝ち逃げする気?」
  - 承認の渇き：「私はあいつにとって、本気で戦う価値もなかったの?」
  - 言葉にできない喪失の予感。
- これらが絡んで穢れになる。**あかりの「告白の宙吊り」と対になる「勝負の宙吊り」**。

### 穢れの方向＝「認められなさの裏返し」
- ライバル視は憧れの裏返し。本当はずっと認められたかった。
- 少年がいなくなる予感は、「もう永遠に認めてもらえない」恐怖でもある。

---

## 4. 解決の核（少年が伝えること）

- 少年は正体を隠して（記憶が残らないルール下で）、レイの心象に潜る。
- レイに届くべき真実：**少年はレイを認めていた**。本気で戦う価値のある、唯一の好敵手だと思っていた。
  勝負に応じなくなったのは、レイに価値がないからではない。
- 正体を隠したまま普遍化して伝える形（詳細はステージ本書きで）。
- 皮肉な構造：少年は「認めている」と本人の口から言えなかった（尊大の仮面）。
  正体を隠した今だからこそ、初めて素直にレイへの敬意を言葉にできる。
  **仮面を被ったときだけ本音が言える**——少年の英語（本音の隠れ蓑）と同じ構造。

---

## 5. ミナとの関係（掛け合い上の役割）

- ミナは事情を知らない。1人目なので疑いも持たない（「初仕事で張り切ってる」程度）。
- レイの心象で語られる「あいつ」「あの天才」が少年のことだと、ミナは気づかない。
  プレイヤーには「これ、ご主人様では?」と微かに引っかかる手がかりを置く（伏線の最初の一滴）。
- ただし1人目では確信させない。手がかりは薄く（例：心象に出る「好敵手」の輪郭・口調の既視感）。

## 6. 心象世界（STAGE1）案

- モチーフ候補：**終わらないコンテスト会場／順位掲示板の海**。
  巨大なランキングボードに「2位 レイ」が無限に刻まれる。1位の名前は空白（または白飛ばし＝少年の伏線）。
- 道中の言葉弾：「どうせ二番」「届かない」「努力は天才に勝てない」「私を見て」
- 穢れの核：「二番のわたし」——順位に縛られたレイの形をした穢れ。胸に本当のレイの光。
- 投稿文（導線の〔仮〕確定）：**「どうせ私は二番手。一番には、もうなれない。」**
