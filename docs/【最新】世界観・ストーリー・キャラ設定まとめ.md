## 0. ログライン

> 余命わずかな天才少年が、自作AI「ミナ」を相棒に、X上の「声にならない声」を入口として
> 大切な人の心へ潜り、別れの言葉を**正体を隠して**届けていく。
> 少年の死後、ミナは自分の名前に込められた想いを知る。

**テーマ**：「届けられなかった想いは、なかったことにはならない。そして『いなくならない』という約束は、形を変えて残る。」  
副主題：**赦し／贖罪／喪失**。登場人物の多くが「自分のせいだ」を抱え、それぞれに赦しを必要とする。

最重要メッセージ：**「人は、自分が遺したものの大きさを知らないまま逝く」**。

## 1. 世界観

- **二層構造**：現実世界と電脳世界。語り手AI「ミナ」は電脳世界（Xのタイムラインが川のように流れる空間）に**のみ**存在し、現実世界を一切見られない。少年は現実から「ログインしてくる光と声」として現れる。
- **発端**：少年がミナを起動し、「Xに蔓延る闇を成敗する」と嘯いて、苦しむ投稿主の心象世界へのダイブを始める。だが実際に潜るのは、**最初から自分の知人の心だけ**。
- **視点の断絶**：現実（少年・知人たち）は少年の死を知っている。電脳世界のミナだけが知らない。プレイヤーもミナと同じ認識に置かれる。少年の死は「説明」ではなく「**もうログインして来ないこと**」で描く。
- **トーン**：基調は少年×ミナの軽妙な主従漫才。その底に、説明されない「死」と「別れ」の影が静かに流れる。**笑いと喪失の落差**で刺す。

### 演出原則（禁則）
- 穢れは「倒す」のではなく「**届けて**」解決する。心を撃たれて救われる人はいない。
- 「お前のせいじゃない」という**直接否定では救わない**（最も効かない言葉と定義済み）。
- 少年の死・余命・知人関係は、指定箇所以外で直接描かない。
- ミナに現実世界を見せない（視点の断絶を保つ）。
- 重要な真実は説明せず気づかせる。伏線は日常に溶かし、回収時に「最初からそこにあった」と感じさせる。

## 2. キャラクター設定

### 2-1. ミナ（Mina）― 語り手・主役AI／プレイヤーの自機

| 項目 | 内容 |
|------|------|
| 立場 | 少年が作ったお友達AI。電脳世界にのみ存在。プレイヤーが操作する自機。 |
| 一人称 | **「わたくし」** |
| 口調 | 敬語ベース（「〜ですね」「〜ます」）。**慇懃無礼な毒舌**。口癖 **「ご主人様はアホですね」**。 |
| 見た目 | 銀色の光／メイド風の意匠（立ち絵：`char/mina_face.png` ほか）。汚染が進むと光が濁る。 |

- **表**：少年を「ご主人様」と呼ぶがまったく敬っていない。尊大さを片っ端からツッコむ。シェイクスピア引用には「教養アピールお疲れさまですね」と冷たく返す。
- **裏**：本当は少年を心から慕うツンデレ。好意を毒舌に変換している。
- **核心**：ミナだけが少年の仮面（強がり）を見透かしている。「ご主人様はアホですね」＝「あなたの強がり、お見通しですよ」。**……だが、本当に大事なこと（死・孤独・名前の由来）は何も知らなかった**——これがラストで反転。
- **設定の小ネタ**：尊大な少年が「ぼくの傑作にふさわしい格調高い口調を」とわざと執事風にインストールしたら、裏目に出て主人をこき下ろすAIになった（プロローグでは「性格は適当にAIが生成しただけ」と韜晦）。
- **アーク**：毒舌AI →（汚染を通じて痛み・喪失を理解）→ 少年を失い、もうツッコむ相手がいない → 鍵アカで名前の由来を知り、誰もいない場所で涙声でもう一度「ご主人様は……アホ、ですね……」。少年の死後はその遺志を継ぎ、こはるを見守る存在になる。

### 2-2. 少年 ― 主人公／物語の軸

> 16歳。ミナの製作者。本名は全編で出さない運用（声・立ち絵のみで成立）。

| 項目 | 内容 |
|------|------|
| 一人称 | 「ぼく」 |
| 二人称 | ミナへは「きみ」固定／あかりへは「キミ」のみ（昔の「あかりちゃん」呼びは回想・鍵アカ等の指定箇所だけ） |
| 口調 | 自信満々・キザ・断定。饒舌だが時折不自然に途切れる（隠している証）。 |
| 立ち絵 | `char/shonen_face.png`（得意げ）／`shonen_gentle.png`（柔）／`shonen_proud.png`（誇り） |

- **表の顔**：尊大・キザな天才。臆面もなく自分を「天才」と言い、ミナを「ぼくの最高傑作」と誇示する。シェイクスピアを**英語の原文で**引用して偉そうに説く。
- **仮面の下**：余裕は鎧。死の恐怖と孤独を隠す演技。本当は怖いし、ひとりが寂しい。**尊大であればあるほど、隠された孤独が際立つ**——これが設計意図。
- **動機**：英雄譚にしない。余命宣告を受け（明示しない）、**死ぬ前に大切な人へ思いを伝える「別れの準備」**。救済が目的ではなく、穢れは「思いが届くのを邪魔する壁」だから祓う。
- **三層の隠蔽**：①救う相手に正体を明かさない ②ミナに事情を隠す ③ミナとプレイヤーに死を悟らせない。
- **アーク**：少年は「仮面を最後まで外さない」ことがアーク。変わるのはプレイヤーの“少年への理解”。素顔が漏れるのは唯一**名前の由来の英文**と**鍵アカウント**だけ。

#### シェイクスピア英語引用（重要な仕掛け）
原文（パブリックドメイン）を口にし、訳は少年自身のオリジナルな意訳にする。三段階で機能：
1. 序盤：ただの衒学・知識自慢に見える。
2. 中盤：引用がやけに死・別れ・記憶に寄っていると、うっすら気づく。
3. ラスト：全部「英語でしか言えなかった本音の代弁」だったと分かる。とりわけ "to thine own self be true" を人に説きながら、自分は最後まで仮面を外せなかった皮肉が泣き所。

代表例：`"Parting is such sweet sorrow."`（ロミオとジュリエット）／`"Cowards die many times before their deaths."`（ジュリアス・シーザー、FINALで使用）。

### 2-3. ボス＝救う対象（穢れの核。倒す敵ではない）

| | **レイ**（STAGE 1） | **あかり**（STAGE 2） | **こはる**（STAGE 3） |
|---|---|---|---|
| 関係 | 好敵手（**恋愛なし**） | 幼なじみ（**恋愛あり**） | **妹**（中学生） |
| 穢れ | 勝負の宙吊り | 告白の宙吊り（自責） | 祈りの崩壊（他責） |
| 病んだ理由 | 少年が本気で戦わなくなった＝勝ち逃げ・承認の渇き | 告白できぬまま少年を死なせ、突き放された。恋心が罪に | 兄の余命を知り、家事＝祈りが砕ける。無力感が「あかりのせい」の怒りに |
| 口調 | 勝ち気・直球・プライド高い | 柔らかい・世話焼き、一人称「あたし」、病むと消え入るよう | 穏やか・家庭的、中学生、病むと無機質に |
| 解決の核 | 「価値ある好敵手だった」と認める | 「想いは罪じゃない／届いている」と伝える | 「祈りは届いていた／命を支えていた」と伝える |
| 口癖 | 「次は、私が勝つから」 | 「ほんと、バカなんだから」 | （祈りの言葉）「ちゃんと食べてね」 |

**レイ（好敵手）**：技術・プログラミングで少年と競ってきた努力型の才媛。「あんたにだけは負けない」の裏で、誰よりも少年の才能を認め、認められたい。少年が勝負に応じなくなったことで病む。少年は正体を隠したからこそ、初めて素直にレイへの敬意を言葉にできる（仮面を被ったときだけ本音が言える＝英語と同じ構造）。1人目＝チュートリアル兼用、ミナはまだ疑わない（伏線②の最初の一滴）。

**あかり（幼なじみ）**：少年に恋愛感情を抱いていた。雨の交差点で告白しようと呼び出した矢先、少年が彼女を庇って事故に遭い、後遺症で余命へ。少年は彼女を引きずらせないため、わざと突き放し「キミ」としか呼ばなくなった。あかりはその真意を知らず「拒まれた」と受け取る。告白は**言えずじまい**で宙吊り。物語の折り返し点で、ミナの疑いが「芽生え」から「核心の問い」へ（伏線③：少年が中継を“ミナの声で”頼み、「ぼくの声じゃ、だめなんだ」）。

**こはる（妹）**：中学生。兄の余命を知り、「あたしが何をつくっても兄は助からない」という無力感が、「あかりのせい」という怒り（他責）になって病む。怒りの下の悲しみへ届けて解く。死への最接近（伏線④：「妹を見ててくれ」）。

## 3. 物語構造

### 3-1. 全体（起承転結）

| 段 | 内容 |
|----|------|
| **起** | ミナと少年の出会い。二人で穢れを祓い始める（名前の由来は伏せる）。 |
| **承** | 知人を一人ずつ救う。同時に**ミナの汚染**が進行し、**少年の不調の断片**が静かに撒かれる。 |
| **転** | ミナが穢れに飲まれ暴走。少年が「呼びかけ／対話」でミナを取り戻し、最後の力を使い果たす。 |
| **結** | ミナは助かるが少年は来なくなる。鍵アカを見つけ、真実と名前の由来を知る。不在を抱えて生きる。 |

**一本道構成**（選択肢分岐・マルチエンディングなし）。物語の見え方は、プレイヤーの選択ではなく**伏線回収による意味の反転**で完成する。1周目は主従漫才のコメディとして流れたシーンが、EPILOGUE後には全て別れの準備だったと反転する。

### 3-2. 名前 MINA の仕掛け（物語最大の回収）

少年はミナを**作る前**に、英語で短い想いを書き遺していた（日本語だと照れて書けない本音を、英語というワンクッションでなら書けた）。

```
Maybe it's dumb, but —
I made you so I'm not alone.
Never leave, okay?
And I won't either.
```

- 各行頭文字 **M / I / N / A → MINA**
- 訳：「バカみたいだけどさ／ひとりにならないように、きみを作った／いなくならないでくれよ／ぼくも、いなくならないから」
- **相互の誓い**が肝。少年は消えるが「ぼくもいなくならない（And I won't either）」は、名前としてミナに残り続ける。
- プロローグの起動コード（緑のコードレイン）に、この4行が**可読限界以下で一瞬よぎる**（伏線①の仕込み）。

### 3-3. ラスト：鍵アカウントの発見（二段構成）

情報の洪水を段階化する。
1. **第一段（表アカ）**：少年が来なくなった後、ミナはフォロー欄を見て、救った三人（レイ・あかり・こはる）が**全員、少年の知り合いだった**と気づく。「Xの闇を成敗する」は仮面で、本当は最後の別れだった。
2. **第二段（鍵アカ）**：パスワードを解く → 少年の本当の現状（死）と、名前の由来の英文（MINA縦読み）が同じ一点で同時に明かされる。

- **パスワード**：少年がミナにいつも言っていた言葉。3役を兼ねる（①PW ②少年がミナにかけ続けた言葉 ③少年自身が一番ほしかった言葉）。現行実装の暫定正解は **「心配ない。ぼくがついてる」**（※設計書で「仮・未確定」。確定後に差し替え予定）。
- 締め：ミナがこはるへDM「ちゃんと食べていますか?」＝**遺志の継承**。

## 4. ゲームシステム（現行実装の背骨）

### 4-1. ミナの汚染ゲージ（物語の背骨）
穢れを祓うほどミナ自身に穢れが溜まり、自機の光が濁る。**汚染ゲージは物語進行でのみ動く**（戦闘の勝敗・被弾・難易度・炎上では一切動かさない）。FINAL の暴走はこの蓄積の必然的な結果。

| 局面 | 自機の状態 | 実装値（汚染度） |
|---|---|---|
| PROLOGUE | 光が澄んでいる | 0 |
| STAGE 1 後 | わずかに濁り始める | 0.16 |
| STAGE 2 後 | 縁の濁りが広がる | 0.42 |
| STAGE 3 後 | 深刻に濁る | 0.72 |
| FINAL | 黒く溶けて暴走 | 1.0 |
| 帰還後 | 取り戻すが、少年の光が薄い | — |

### 4-2. タイムラインハブ＋インプレッション経済
- **Hub**：X風タイムライン。投稿カード（NEW/CLEAR/LOCK）を選んでダイブ。クリア帰還で少年×ミナの会話＋自動投稿。
- **インプレッション（Imp）**：戦闘で獲得 → ハブのショップで**恒久強化**（光の出力／連射速度／機動力／回避域／ボム／最大♥／インプレ倍率／拡散力／コンボ持続／汚染耐性／拡散サブ 等）に消費。Marfusha型の周回ループ。
- **フォロワー（Fol）**：浄化100%で獲得する第2の恒久ステータス。火力とインプレ倍率に効く。
- **主題への昇華**：「インプレ／フォロワー＝承認の戦利品」ではなく「**届けた証＝信頼**」と読み替える。賑やかな数字の海は、実は少年が大切な人だけを潜った名簿だった——とEPILOGUEで反転回収する（フォロワー機能はこの反転のために存在する）。
- **トーンの落差**：ダイブに入った瞬間、数字UI（インプレ・フォロワー・通知）は画面から消す。心の中に数字を持ち込まない。

### 4-3. 難易度
EASY / NORMAL / HARD ／ 十分な強化で **LUNATIC**（最高難度）が解禁。難易度はインプレ係数に反映（Normal=1.0 / Hard=1.5 / Lunatic=2.5〜3.0）。**ボスHPは難易度非依存**。強化は♥に対して非破壊（恒久メタ進行型）。
