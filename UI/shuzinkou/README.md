# algo: Refrain of Light（MINA）— 主人公の弾 UI（HTML）

主人公ミナのショット（弾）周りで作成した UI 一式です。各 `.dc.html` はブラウザで直接開けます（同梱の `support.js` が必要なため、**フォルダ構成を保ったまま**開いてください）。ネット接続時は Google Fonts（Zen Kaku Gothic New / JetBrains Mono）を読み込みます。

## 収録ファイル
| ファイル | 内容 |
|---|---|
| `Refrain Mina Shots.dc.html` | ミナの攻撃3パターン（拡散／ホーミング／連射）。左→右に発射。強化レベル（Lv.1〜3）で挙動が変化。各パターンにXスペル宣言ツイート風演出＋スペック表。 |
| `Refrain Shot Upgrades.dc.html` | 弾・ショット強化システム（インタラクティブ）。3モード切替（V循環）＋解放（拡散◈500／誘導◈700）＋共通強化（光の出力／連射速度／拡散力）。演出：弾トレイル・チャージリング・購入バースト・モードスウィープ・**過熱オーバーロード全画面フラッシュ**・**レベルアップのダイヤル充填**。 |

## 3モードの要点（設計書 v2 準拠）
- **連射（Rapid）** — 右へ直線の高速ストリーム。段数＝2+⌊光の出力Lv/2⌋。初期解放。単体DPS・正面特化。
- **拡散（Spread）** — 右方向へ扇状（5→7→9way）。ショップ解放。面制圧（1発威力×0.8）。
- **ホーミング（Homing）** — 右側のマゼンタの穢れへ吸い寄せられて曲射（追尾2→3→4体）。ショップ解放（弾速↓・間隔×1.15）。
- 共通強化（火力・連射速度・拡散力）は**全モードに乗算**。コスト式＝基礎×倍率^Lv。
