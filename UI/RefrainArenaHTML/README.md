# algo: Refrain of Light — 予測攻撃アリーナ / テレグラフ UI（HTML）

敵の攻撃予測（テレグラフ）まわりの UI 一式です。各 `.dc.html` はブラウザで直接開けます（同梱の `support.js` が必要なため、**フォルダ構成を保ったまま**開いてください）。ネット接続時は Google Fonts（Zen Kaku Gothic New / JetBrains Mono）を読み込みます。

## 収録ファイル
| ファイル | 内容 |
|---|---|
| `Refrain Telegraph Arena.dc.html` | 予測攻撃アリーナ（インタラクティブ）。左起点のプレイヤーが、エリアに出る予測攻撃を避ける。キャラ別演出＋技名＆Xツイート風の技発動通知。技名→予測エリア→攻撃判定の順で発生。**難易度＝弾数（弱2／中4／強7）**。マウス操作⇄自動回避・被弾カウンター。 |
| `Refrain Telegraphs.dc.html` | テレグラフ・カタログ（参照用）。キャラ別の予測線／予測エリアの種類と、心象に応じた着弾色（レイ＝金の白飛び／あかり＝蒼／こはる＝加熱／ミナ＝濁りグリッチ）。 |

## アリーナの仕様
- プレイヤー（ミナ）は**左側のHOMEゾーン**起点。点線の内側＝攻撃範囲。
- 予兆（点線で範囲を囲う）→着弾（範囲内が発光、このフレームのみ判定）。
- キャラ別プロファイル：弾形・色・予兆時間・技セット・背景が切替。
  - レイ＝横ビーム/矩形・金菫／あかり＝縦カラム/円・雨青／こはる＝円/矩形・琥珀深紅／ミナ＝全形・濁色。
- 技発動：技名バナー＋Xツイート風通知（@ハンドル・認証・技名・宣言セリフ・いいね/リプ）。
- 難易度（弱/中/強）で同時に出る攻撃数が増加。

## デザイントークン（SnsTowerDefense デザインシステム準拠）
- ミナ＝`#9a72d9`（--primary）／浄化・光＝`#6cbcd8`（--info）／穢れ・敵＝`#e072ac`（--accent）。
- 見出し・本文＝Zen Kaku Gothic New ／ 数値・ラベル＝JetBrains Mono。
- 内部解像度 384×216 を整数倍した 16:9（1920×1080 相当）で設計。

> 実装の当て所（参考）：`StageBase.cs`／各 `BossXxx.cs` の弾幕パターン、テレグラフ（予兆）→着弾の判定タイミング、難易度パラメータ（同時弾数）。
