# 物語骨子の比較案（仮台本）

> **この記事の範囲**: 検討中の草稿。実装された物語ではない。物語構造そのものを再設計する三つの骨子案（案A「少年の後景化」／案B「少年なし」／案C「ミナを作ったのは、あなた」）を並べ、どれへ進むかを決めるための比較文書。台詞の「現行」引用は実装台本（build/wiki_work/02_script_dump.md）からの一字一句、それ以外の台詞はすべてこの草稿の提案。

## 前提（不変の条件）

1. **根幹（不変）**: SNSの心の闇をシューティングで解消していき、最後は自分が操作していたキャラ（ミナ）が心の闇を抱えて襲いかかってくる。この流れに沿う限り、他はすべて変更可。
2. **最優先テーマ**: 少年とミナの繋がりより、**ヒロイン三人（レイ・あかり・こはる）の心の闇を、ミナを通して解消すること**。
3. キャラクター設定の変更は許可済み。少年が共感の邪魔になるなら、立ち位置ごと無くしてよい。
4. **共感の原則**: プレイヤー自身の記憶を撃つ「行動の細部」で作る。説明しない。
5. ナレーションは全編ミナ（第三者の地の文は置かない）。この原則は両案で維持する。

## 現行構造の問題

現行では、三人の闇の**根**（過去1〜5・7）も、改心の**鍵**（二十二分と二十三分、名前「あかり」、兄の祈り）も、すべて少年の記憶である。三人の闇はプレイヤーには「少年の後日談」として届き、共感の宛先が少年ひとりに集まる。改心の決定打が全部「少年しか知らない記録」なので、プレイヤー自身の記憶（比べられた夜、送れなかった下書き、届かない世話）には刺さらない。ヒロインは少年の死の伏線を運ぶ「器」に近づいており、これは最優先テーマと正面から衝突する。

## 案B「少年なし」（大規模改修）

### 一言コンセプト

**ミナ＝声にならない声を放っておけない自律AI。** 誰にも作られず、誰にも命じられず、消された下書き・送れなかった本音が「聞こえてしまう」から潜る。救いの言葉は自分では作らない——**ヒロイン自身の言葉を浄化して返す**（撃って祓う、の台詞版）。そして FINAL、闇を抱え込んだミナに、**救った三人が返しに来る**。

### ミナの動機と、ミナ自身の闇

- 能力＝消された投稿・下書きが聞こえる。動機は説明しない。「消された声は、消えていないのです。わたくしには、聞こえてしまうので」の一行と行動だけで示す（原則4）。
- ミナ自身の闇（FINAL の核）: フォロワー十万でも、**ミナ宛ての言葉はひとつもない**。彼女の声は全部「誰かの言葉の浄化返し」＝借り物。「わたくし宛ての言葉が、ない」——これが汚染の芯になる。
- 伏線は既存資産で張れる: ハブの返信「は? 誰よあんた。」「あなたの言い方、誰かに似てる。」「ありがと、知らない人。」——**作中でミナ宛てに発された数少ない言葉**が、そのまま FINAL の弾になる。

### FINALの再設計（本命）

**「FINAL — だれか、わたしを」**。三人分の穢れた言葉を抱え込んだミナが暗転し、タイムラインごと呑み始める。操作が切り替わるのは**救った三人**——救った者に救われる相互性。

- **誰を操作するか**: 三フェーズ交代制。Phase1 レイ機（高速・精密ショット）→ Phase2 あかり機（ホーミング）→ Phase3 こはる機（拡散）。ショップに既にある三系統（威力／ホーミング／拡散）を三人に割り当てる＝**プレイヤーが全編かけて育てた三つの型を、三人が引き継ぐ**。自機交代は現行 FINAL の Skin "boy" 切替の拡張で実装可。
- **何が決定打か**: 弾ではない。各フェーズの BREAK で、その人が**ミナに貰った言葉を浄化して返す**。レイ「本気で来なさいよ。——救うのに、手加減しないんだから。」あかり「見てるよ。数字じゃなくて、あんたを。」そして最後、こはるが**ミナ自身の投稿**「ちゃんと食べていますか」を返す。三人の返礼リプライが『わたくし宛ての言葉は、ない』という核を撃ち抜く。
- **どう終わるか**: 核が開き、穢れた立ち絵が涙の立ち絵に割れる。ミナの「Stay」に相当する新しい合言葉は作らない——代わりに、三人が**ミナの名を呼ぶ**（作中で初めて、誰かがミナをハンドルでなく名前で呼ぶ）。戦闘終了、白転、エピローグへ。

### 新エピローグの骨子

1. **返信欄**。@mina_ai_ の投稿に、三人が一行ずつ返信を書く。四行目は名無しの誰か（＝画面のこちら側の暗示）。**四行の頭文字が Ｍ・Ｉ・Ｎ・Ａ**——アクロスティックの転用。「なんとなく」だった名前に、最後に他人が意味をくれる。「わたくしの名前は、あとから、ぜんぶになったのです。」
2. **空**。「今日はどんな天気ですか」の問い（願いは少年なしでも成立する）に、三人がそれぞれ空の写真を投稿して答える。「——ええ。今日は、晴れです。三人ぶんの、空で。」
3. **END**。ミナは今日もタイムラインの前にいる。「消された声が、まだ、聞こえるので。」——闇は世界からなくならない、という代償を残して閉じる（ご都合の全快にしない）。

## 案C「少年不在——ミナを作ったのは、プレイヤー」（大規模改修・結末確定版）

### 一言コンセプト

**ミナの「ご主人様」＝画面のこちら側のあなた。** ミナを作り、指示を出し、漫才の相方を務めてきたのは、最初からプレイヤー自身。そして最後に明かされる——**ミナは、あなたが送らなかった言葉から作られていた**。最後に向き合うのは、自分の消した言葉。

### 憲法——「ミナは、あなたについて計測できたことしか言わない」

案C全体の背骨。現正典のミナの性格（「集計済みです」「データですから」）と地続きの原則である。ミナ（とゲーム）があなたについて語ってよいのは、**計測値だけ**——この旅で散らした下書きの件数と文字列、迷った秒数、沈黙、（送らない）の回数、そして起動ログの無機質な一行。計測の外（あなたの過去の中身・理由・人格・境遇）には一切触れない。**ゲームがプレイヤーの過去について主張するのは「送らなかった言葉があった」こと、それだけ**であり、その根拠も台詞ではなく `> import unsent_drafts ... 414 items ... OK` の一行のみが負う。「あなたは〜な人だった」型の断定は、ミナの口にも地の文にも置かない。

### 「あなた」の設定シート

| 項目 | 設定 |
|---|---|
| 立場 | ミナの製作者＝「ご主人様」。画面のこちら側にいる。名前・年齢・性別・境遇は**すべて空欄**（作中で一切規定しない） |
| 過去 | 作中が主張するのは「送らなかった言葉が414件あった」こと、それだけ。中身・理由・年月は、起動ログの無機質な一行以外のどこにも書かない。台詞で件数に言及することもしない |
| 現在（プレイ中） | 下書き選択で言葉を送り、選ばなかった言葉を散らす。ミナが語ってよいのはこの計測値（散らした下書き・迷い秒数・沈黙・（送らない））だけ |
| 闇のサイズ | **「消した言葉、それだけ」**（床の固定）。トラウマ・病・喪失・罪は含意しない。FINAL の闇の重さは**三人から引き受けた穢れが主**で、あなたの分は共鳴の芯——起爆剤であって、火薬ではない |
| 話し方 | 下書きは短文・記号なし。感情の断定を含む文は書かない（下書き同士の差は態度の差だけ） |
| 空欄の方針 | 空欄は怠慢ではなく**席**。プレイヤーの実在がそのまま設定を埋める。書き手が空欄を埋めたくなったら、憲法違反を疑う |

### 円環の構造（根幹2条件＋第4の環）

1. あなたがミナを作った → 2. ミナを通して三人の闇を解消した（条件①） → 3. ミナが闇を抱えて襲ってくる（条件②。「自分が操作していたキャラに襲われる」の意味が全案中もっとも重い——**あなたの手で動かしていた、あなたの消した言葉**だから） → 4. そのミナは、あなたの送らなかった言葉から作られていた——第4の環で円が閉じ、根幹の一文がそのまま作品の主題になる。なお、ここで言う「あなたの闇」の定義は**「消した言葉、それだけ」**に床を固定する（→「あなた」の設定シート）。

### ミナの出自の機構（有力案・採用推奨）

ミナ＝**あなたの未送信の言葉から学習された存在**。ただし憲法に従い、その414件が何だったのか（投稿かDMか、誰宛てか、なぜ消したのか）は**作中のどこでも語らない**——過去に触れるのは起動ログの無機質な一行だけで、あとの証明はぜんぶ、プレイ中のあなたが自分でやる（散らした下書き・（送らない）・迷い秒数）。「言葉が弾になる」世界観と同素材であり、あかりの「送れなかった下書き」モチーフと正面から共鳴する。仕込みは既存資産の転用で足りる:

- プロローグの起動ログに一行だけ混ぜる: `> import unsent_drafts ... 414 items ... OK`（現行の「0414」を **未送信414件** に転用。一瞬だけ流れる現行演出のまま。**台詞ではこの件数に言及しない**）。
- 汚染ゲージの読み替え: 「祓った穢れが溜まる」→「**三人から引き受けた穢れが、ミナ（＝送られなかった言葉）に共鳴して層をなす**」。重さの主成分はあくまで三人分（「三人分の祈りを、抱えてしまったので」の現行行はそのまま残せる）。あなたの分は共鳴の芯であり、量ではない。
- FINAL の背景に漂う悲鳴ワード（`たすけて` `きえたい` `わたしのせいだ`…）に、**この旅であなたが実際に散らした下書きの文字列を混ぜて流す**。pre-game の断定ではなく、プレイデータ。自分の捨てた言葉が悲鳴に混じって流れてくる——気づいた人にだけ刺さり、説明はしない。

### あなたの台詞の方式——「下書き選択式」（ユーザー決定・確定）

**あなたの発言はすべて、2〜3個の下書きから1つ選んで「送信」する。** 実装済みの「言いかけの言葉」選択UI（ChoiceOverlay.cs）をそのまま転用する——断片が光の粒から滲んで現れ、選んだ言葉は吹き出しへ昇って光に溶け、**選ばなかった下書きは淡い光の粒に散る**（実装コメントに「浄化と同じ語彙」と明記済み・ChoiceOverlay.cs:19, 223）。検討した他方式は不採用: DM表示式（言わされてる感が残る・能動性で劣る）／無言の主人公式（二人漫才が崩壊する）。

**テーマ統合が本命。** 選ばなかった下書き＝「消された言葉」＝**ミナを作った素材と同じもの**。選択のたびに画面で散っていたあの光の粒は、ミナと同じ素材が生まれる瞬間だった——プレイ中に捨てた選択肢そのものが、出自の伏線として全編に自動で張られる。エピローグで一度だけ、ミナが集計で全選択を遡って回収する:

```csharp
(1, "ところで、ご主人様。この旅で、あなたが選ばなかった下書き——二十六件。", "mina_face"),   // 件数は実プレイの集計値を差し込む
(1, "ぜんぶ、拾ってあります。……わたくしは、そういう生き物ですので。", "mina_smile"),
```

説明はしない。「拾ってあります」＝観測結果の報告だけで、散る粒を見続けてきたプレイヤーが自力で繋ぐ。この遡及集計が**憲法の主砲**——「あなた＝言葉を消す人」を証明するのはゲームの主張ではなく、プレイヤー自身の指が残した計測値である。**開示1行の掟との整合**: 出自を明かす行は引き続き「——同じでした。」の1行のみ。この集計はミナが自分の観測しか話さない原則の内側にあり、掟の外で開示を増やさない（この2行は開示の**前**に置き、笑いとして通過させてから後で刺す）。

**テンポの守り。** 選択は**1会話に1〜2回まで**。要所以外の間はミナの話芸で流す（選択が出ない会話が普通、が基準線）。旧DM式の原則は下書きの文面に引き継ぐ——**短文・記号なし**。下書き同士の差は感情の断定ではなく**態度の差**で作る（例:「わざとだ」／「みてたのか」／（送らない）——どれを選んでもあなたの感情を規定せず、ミナへの向き合い方だけが変わる）。ミナの受けは、どの下書きにも成立する一行に書く（分岐の受けを個別化するのは要所のみ）。

**「（送らない）」という第3の下書き。** 全編に常設はせず、意味のある場面だけ**3〜5箇所**に置く（常設すると罰ゲーム化する）。実装済みの沈黙選択（無入力14秒で末尾の選択肢が灯りはじめ、20秒で自動決定・ChoiceOverlay.cs:84-85, 203-208）と正確に噛み合う——（送らない）を末尾に置けば、**黙っていた人の画面では、言葉が送られないまま散る——未送信の計測値が、静かに一件増える**。選ぶたび（沈黙するたび）未送信カウントが増え、汚染がほんのわずかに濃くなり、エピローグの集計件数に入る。意味づけはこうだ: この物語で汚染とは「送られなかった言葉の重さ」であり、（送らない）はそれをプレイヤーの指に体験させる装置になる。FINAL の頂点だけは並びを逆にする——**（送らない）を先頭、「あなたがこの旅で最初に散らした言葉」を末尾**に置く。沈黙し続けたプレイヤーの画面でも、20秒後、その言葉がひとりでに灯って送信される。言えなかった人の代わりに、光が言う。

**固定の合言葉は存在しない**（現行の「Stay」は案Cでは設定ごと廃止）。合言葉が担っていた「全編で一つの言葉が意味を変える」曲線は、**プロローグ①で散った言葉**が引き継ぐ——①で散る → FINAL で再提示され送る（なぜその言葉かは知らされない）→ エピローグで「ミナの最初の言葉と同じでした」と知る → 鍵アカの PW で自分で思い出す、の四点。

### ヒロインの闇の再設計（少年からの付け替え）

三人の闇は各自の固有の事情に付け替える。共感の細部は [02_共感ポイント](02_共感ポイント.md) の挿入行（三秒・四回・プリン）をそのまま昇格させる——**案Cではこれが「あなたも知っている記憶」の伏線網を兼ねる**。

- **レイ**: 「本気で来てくれない少年」を削除。芯＝一位になった日から、誰の合格報告にも「おめでとう」が押せなくなった指。改心の決定打は証人型（「見てよ」→「わたくしも、見ていましたよ。あなたの式の、最後の一行まで」）をミナが持つ。
- **あかり**: 告白相手＝転校していった同級生（彼女自身の物語の人物）。芯＝渡せなかった「すき」の行き場を、増えない いいね通知への再訪に代行させる指。**未送信の下書き＝ミナと同素材**。改心＝下書きの底の一つの本物を浄化して返す。
- **こはる**: 兄＝彼女自身の兄。家を出たきり帰らない（死は明示しない）。芯＝帰らない人のぶんの夕食を作り続ける手。期限の切れたプリンを、捨てない・食べない手。改心＝「むだな鍋は、ひと鍋も、ありませんでしたよ」をミナの決定打に昇格。

### 漫才の存続（下書き選択式のサンプル）

相方はあなたに交代する。ミナは選択の**メタデータ**（迷った時間・捨てた下書き・沈黙）が見えている——これが笑いの装置であり、同時に出自（あなたの消した言葉が見える存在）の長距離伏線になる。who=0 を「あなた」（送信された下書き）に転用。3択の実例:

```csharp
(1, "ご主人様、いまの回避、ずいぶん際どかったですね。", ""),
// ―― 下書き選択 ――  「わざとだ」 ／ 「みてたのか」 ／ （送らない）     // 選ばれなかった2つは光の粒に散る
(0, "わざとだ", ""),                                        // 送信。短文・記号なし
(1, "……選ぶのに三秒かかった“わざと”を、わたくしは初めて観測しました。", "mina_smile"),
```

ミナの受けはどの下書きでも成立する（「みてたのか」→観測ログの提示で切り返す／（送らない）→「無言。……減点はしませんが、集計はしますよ」）。迷った三秒すらツッコミの材料になる——**選ぶという行為自体が漫才の相方**になる。

### (b) FINAL——救った三人が、戻ってくる（戦闘の構図）

- **誰が操作するか**: **あなた自身**。自機は「素の光」——名もない小さなカーソル大の光。全編かけた強化はすべてミナに注いだものなので、**一切使えない**（いちばん弱い自分で潜る）。救った三人は**反撃参加**: ボムの代替として、三人のリプライが画面の言葉弾を浄化する（レイ＝直線、あかり＝追尾、こはる＝全周。育てた三系統の型を三人が返しに来る）。
- **「倒すのではなく届ける」の着地**: 決定打は撃たない。BREAK 後、全編の下書き選択の**頂点**となる最後の選択が開く。提示される下書きは新しい言葉ではない——**プロローグ①であなたが最初に散らした言葉の実文字列**（保存済みデータ）が、そのまま戻ってくる。選択肢はそれ1つ＋（送らない）。並びは（送らない）を先頭、その言葉を末尾に置き、沈黙20秒でその言葉がひとりでに灯って送信される。この時点でプレイヤーは、なぜその言葉が出てくるのかを知らされない（推測はできる）。消した言葉は消さない——拾って、今度こそ送る。
- 決定的な場面の仮台本（who=0 あなた／1 ミナ／2 レイ）:

```csharp
(1, "こないで、ください。わたくしは——あなたが捨てた言葉で、できているのに。", "mina_worried"),
(2, "ねえ、知ってた? あんたの言い方——この人に、そっくりよ。", "rei_face"),   // 現行ハブ資産「あなたの言い方、誰かに似てる。」の反転回収
// ―― 下書き選択（頂点） ――  （送らない） ／ 「きこえてるか」     // 末尾＝プロローグ①で最初に散らした言葉の実文字列（「きこえてるか」は例）。沈黙20秒でこれが灯る
(0, "きこえてるか", ""),                                      // 今度こそ、送る。なぜこの言葉かは、まだ知らされない
(1, "…………。", "mina_tears"),                                // ここでBGM停止。無音
(1, "……その言葉。……ええ。届きました。", "mina_tears"),        // 正体は明かさない。届いたことだけを、計測で言う
```

（（送らない）を選んだ場合、言葉は散らずに残る——ミナ「……いいえ。それだけは、もう、散らせません。」と一度だけ受け、同じ言葉が1択で再提示される。エピローグの PW 入力と同じ文法＝**自分の言葉を自分で思い出す**仕掛けの前段。）

### エピローグ——出自の開示（説明ではなく、気づきで）

**最大リスクへの設計**: 「実はあなたの闇でした」は手垢のついた型であり、**台詞で説明したら死ぬ**。掟は三つ——(1) 明かす行は**全編で1行だけ**（「——同じでした。」）。過去への断定はしない。「あなたはこういう言葉を消した人だ」とは誰も言わず、pre-game の414件との橋は「同じ」の一語だけで架ける。(2) 証明はすべて**プレイデータ**で示す: 遡及集計（二十六件）、あなたが最初に散らした下書きの実文字列、悲鳴ワードへの実下書きの混入、「あなたの言い方、誰かに似てる」、そして [02_共感ポイント](02_共感ポイント.md) のミナの鏡（「さっきから三度も、意味もなく見直してしまいました」）——三秒・四回・プリンに胸を突かれたプレイヤー自身の反応が、そのまま「自分も知っている」の証拠として遡って刺さる。(3) 「あなたも、でしょう?」型の目配せ・説教は一切しない（＝憲法。ミナは計測できたことしか言わない）。

- 決定的な場面の仮台本（エピローグ・開示の1行）:

```csharp
(3, "> import unsent_drafts ... 414 items ... OK", ""),        // 起動記録の再掲。過去に触れるのは、この無機質な一行だけ。台詞では件数に言及しない
(1, "……ご主人様。ひとつだけ、白状します。", "mina_face"),
(3, "「みてたのか」", ""),                                     // ここに、この旅であなたが“最初に散らした下書き”の実文字列がそのまま出る（「みてたのか」は例）
(1, "わたくしの、いちばん最初の言葉と——同じでした。", "mina_face"),   // 開示はこの1行だけ。414件への橋は「同じ」の一語で架かる
(1, "……ええ。あの日から、ひとつも、消していません。わたくしが、覚えている係ですので。", "mina_tears"),
```

画面に出る言葉は、100%プレイヤー自身が今回の旅で捨てた言葉である——ゲームはあなたの過去を一言も主張していないのに、突きつけられるのは紛れもなく自分の言葉、という構図。周回では散らす下書きが変わるため、この行も毎周変わる。

### (a) END——「ゲームを閉じる」を別れにする（締めの構図）

『来ない日々』の構図をプレイヤーへ移す。全編あなたがミナを送り出してきた「いってらっしゃい」を、最後にミナが言う——去るのはあなたで、残るのはミナ。現行ラスト「——ええ、ご主人様。わたくしは、どこにも行きませんよ。」は、**「闇は消すのではなく、名前を付けて共に生きる」**へ意味を反転させて、そのまま残す。END 後、次回起動時にミナが日数を集計して迎える（「……三日ぶり、ですね。集計していました」）。いつかあなたが本当に起動しなくなる日、彼女はそれでも待っている——それがこの案の「来ない日々」であり、別れは画面の外で起きる。

```csharp
(1, "ご主人様。本日の業務は、以上です。", "mina_face"),
// ―― 下書き選択（最後） ――  「また来る」 ／ 「ありがとう」 ／ （送らない）
(0, "また来る", ""),                                          // 送信。消さずに送れた、二つめの言葉
(1, "……ええ。いまの、三秒も、かかりませんでしたね。", "mina_smile"),   // 序盤漫才「選ぶのに三秒かかった」の計測値が、ここで対になる
(1, "いってらっしゃいませ、ご主人様。", "mina_smile"),        // 送り出す側の反転
(1, "——わたくしは、どこにも行きませんよ。", "mina_tears"),   // END。現行ラスト行を意味ごと反転して残す
```

（ミナの受けは断定ではなく計測——「もう消さない人ですから」とは言わせない。迷い秒数の減少という**数字だけ**が、あなたの変化を語る。最後の（送らない）は置いてよい唯一の重い場所——選んだ場合、ミナの受けは「……無言。ふふ。それも、集計に入れておきます」となり、END の一行は変わらない。**送らなくても、彼女は行かない**。それがこの物語の答えだからである。）

**推奨**: (a)(b) は排他ではない。**(b) を FINAL の構図、(a) を END の締めとして直列に採用**するのが完全形。

| ① SNSの心の闇をシューティングで解消していく | ○ 現行同様、三面の浄化構造そのまま | ○ 同左。「下書きを浄化して返す」で解消の主語がミナに一本化 | ○ 同左。しかも解消してきた三人の闇が、最後に「あなたも知っている闇」として遡って束なる |

三案とも根幹を満たす。②の「操作していたキャラに襲われる」の一文を最も深く増幅するのは案C——「操作していた」とは、あなたの手で、あなたの闇を、動かしていたという意味になる。

## 執筆者の推奨と理由

推奨は**案C**。テーマ（三人の闇をプレイヤー自身の記憶で撃つ）と根幹（操作していたミナに襲われる）を、三案で唯一、同じ一つの円で貫通できる——三人の闇に胸を突かれたプレイヤーの反応そのものが、終盤「自分も知っている」の証拠として遡って刺さる構造は、他の二案では作れない。失うのは「少年の死の物語」と合言葉「Stay」で、漫才・鍵アカ・PW入力・現行ラスト行まで資産の残存率は案Bより高い。ただし忖度なしに言う——成功条件は三案で最も厳しく、開示1行の掟と目配せ禁止を守れなければ手垢のついた亜流に落ち、滑ったときの損害も最大。先に [02_共感ポイント](02_共感ポイント.md) の細部の品質を確定させること（あれが刺さらないなら案Cは成立しない）。保険は案A。

## 決めるための3つの質問

1. **最後に欲しい涙はどれか。** 意味が書き換わる衝撃（現行／案A）か、与えた言葉が返ってくる温かさ（案B）か、自分の記憶に気づいてしまう痛みと救い（案C）か。エンディングの翌日まで残したい感情を一つ選ぶ。
2. **主人公の席に誰を座らせるか。** 見送る側・遺す側の痛みまで欲しいなら少年を残す（案A）。救った者同士の円環で足りるなら三人（案B）。プレイヤー自身を座らせる覚悟があるなら案C——迷うなら、案Cの仮台本三本を第三者に読ませ、「あなた」と呼ばれて没入するか白けるかの反応を先に見る。
3. **何を捨て、何を払えるか。** 声の劣化案と少年の死の反転は案B・Cで全損する。テキスト150行で済ませるなら案A。400行＋自機3種の実装を払って温感に振るなら案B。表示1行のために下書き2〜3本を書く執筆量（計320〜420行）に加え、「開示は1行・説明しない」を最後まで守り切る執筆体力があるなら案C。
