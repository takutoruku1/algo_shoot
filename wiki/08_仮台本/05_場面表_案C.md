# 場面表 案C

> **この記事の範囲**: 検討中の草稿。実装された物語ではない。[03_物語骨子の比較案](03_物語骨子の比較案.md) の案C（少年不在・ご主人様＝あなた・下書き選択式）について、**粗い全体台本を書く前段**として、場面の順番と、各場面でプレイヤーが何を知り・何を選ぶかを一覧にする。台詞は書かない（書いても1行の例まで）。[04_冒頭台本_案C](04_冒頭台本_案C.md) の冒頭は本表で一部を統合・削除しており（→ 冒頭の圧縮案）、食い違う箇所は本表を優先する。

対象は、20代後半から30代後半の、社会に組み込まれて現実に疲れている人。表記と説明の量はその読者に合わせる（見出しは漢字、説明は最小限）。

物語の順に、場面ごとに、起きること、あなたが知ること、あなたが選ぶことだけを書く。開発用の情報は末尾の実装メモにまとめた。

黄色い枠で囲んだ 13 場面が、読んで判断してほしい場面。枠の最後の「見る点」に、何を見てほしいかを書いた。他の場面は流れの確認だけでよい。

## プロローグ

### P0　タイトル

「はじめから」を選ぶと、操作の説明が三つ出る。

### P1　起動シーケンス

文字の雨が三周する。その中に「未送信の下書き 414件を読み込んだ」という記録が一瞬だけ混じり、四行の英文が光って消える。「名前の割り当て、保留」で止まる。

- 知ること: まだ名前が無いこと。414件の記録は、読めた人だけが気づく。

:::judge
### P2　目覚め、最初の言葉

目覚めた機械に、あなたが最初のひとことを送る。選ばなかった二つは光の粒になって散る。ミナは起動記録からあなたを作り手だと判断し、「ご主人様」と呼ぶことに決める。

- 知ること: ミナには、あなたが迷った秒数が見えている。
- 選ぶこと: 「おはよう」「きこえてる」「うごいた」の三つ。ここだけは、送らない、が無い。
- ==見る点==: 最初の三つが自分の言葉に感じられるか。散った二つを自分が捨てた、と意識できるか。

:::

:::judge
### P3　命名

ミナが名前をねだる。あなたが名付ける。どの選び方でも名前はMINAに落ち着き、ここで初めてロゴが灯る。

- 知ること: 自分が付けた名前、あるいは付けなかった名前が、ロゴになる。
- 選ぶこと: 「ミナ」「超絶最強無敵ハイパーAIちゃんMk-Ⅱ」、または送らない。
- ==見る点==: 名前を自分で付けた実感があるか。ダサい名前を選んで却下される流れが、笑いになっているか。

:::

:::judge
### P4　タイムライン

にぎやかな投稿でひとしきり笑ったあと、三つめの投稿の下から、送られなかった声が聞こえる。「たすけて」と三回書いて、三回消した声。ミナは「放っておけません」と言い、先に、れんしゅうをすることにする。

- 知ること: ミナは、消された下書きが聞こえる体質。「覚えておきます」が初めて出る。
- 選ぶこと: 「きこえるんだ」「そっか」「耳いいね」の三つ。送らない、は無い。
- ==見る点==: たすけてを三回消した投稿で、ミナの聞こえる体質が腑に落ちるか。

:::

## れんしゅう

### T1　練習

操作はボタンの絵と単語だけで覚える。移動、ショット、低速、回避、ボム、浄化。ミナの実況は無い。浄化のところで「倒すのではなく、届ける」、締めで「行く先の光が、灯りました」の2行だけ。

- 知ること: 操作。倒すのではなく、届けること。

### S2-5　道中C

- 知ること: あかりの芯。同じ通知を何度も見にいく指。

### S2-6　ボス出現

「あふれるわたし」。

### S2-7　ボス戦

四つの技と、雨の帰り道の通路。

:::judge

- 知ること: あかりの本物の一通。
- ==見る点==: 「汚れた好きは、ひとつも」がレイの決定打と同じ型に見えて飽きないか。

:::

四つの技と「お残し禁止」。

### F1　導入

ミナの声が壊れ、三人の投稿が変質して戻ってくる。「ぜんぶ、わたくし、の」。自機はあなた自身の素の光になる。無言で潜る。

### F2　ボス戦「穢れたわたし」

- 知ること: 救った三人が返しに来る。

:::judge
### F3　邂逅

ミナ「こないで、ください」。レイ「あんたの言い方、この人に、そっくりよ」。ミナの出自に触れる行は置かない。

- 知ること: ミナの言い方があなたに似ている。
- ==見る点==: 出自に触れずに、レイの「そっくりよ」だけで橋が架かっているか。

:::

:::judge
### F4　頂点

悲鳴の言葉が漂い、その中にあなたが散らした下書きが混じる。ミナの語り「祓うほど、軽くなると思っていました」。最後の選択に、あなたが冒頭で最初に散らした言葉がそのまま戻ってくる。二十秒黙っていると、その言葉がひとりでに灯って送られる。ミナ「届きました」。白転。

- 知ること: なぜこの言葉が出るのかは、まだ知らされない。
- 選ぶこと: 最初に散らした言葉、または送らない。送らないを選ぶとミナが一度だけ受けて、同じ言葉がもう一度、ひとつだけ出る。
- ==見る点==: 最初に散らした言葉が戻ってきたとき、理由が分からないまま送る気になるか。二十秒の沈黙で光が送る演出に納得できるか。

:::

## エピローグ

### E1　タイムライン

フォロー欄に救った三人が並ぶ。「あなたが選ばなかった下書き、七件。ぜんぶ、拾ってあります」。

- 知ること: 散った粒はぜんぶ拾われていた。

### E2　鍵アカ

あなたの下書きフォルダに鍵がかかっている。合言葉の候補は「おはよう」「きこえてる」「うごいた」「ミナ」。正解は、あなたが最後に送った言葉。間違えると「違います。最後に送ったのは、それでは、ありません」。

- 知ること: 自分の言葉を自分で思い出す。
- 選ぶこと: 四つから一つ。

:::judge
### E3　四行

あなたが唯一消さなかった下書きとして、四行の英文が出る。頭文字はM、I、N、A。名前の選び方で一行だけ変わる。

- 知ること: 自由に選んだつもりの名前が、最初から書いてあった。
- ==見る点==: 四行の英文を残すか差し替えるか。ミナが観測しか言わない決まりと、ぶつかっていないか。

:::

:::judge
### E4　開示

起動記録の「未送信の下書き 414件」がもう一度出る。「白状します」。あなたが最初に散らした言葉が画面に出て、「わたくしの、いちばん最初の一件と、同じでした。」「あの日から、ひとつも、消していません。わたくしが、覚えている係ですので。」

- 知ること: ミナの最初の一件は、自分が最初に散らした言葉。
- ==見る点==: 開示の一行で、説明されたと感じないか。

:::

### E5　空とDM

「今日は、晴れているそうです。どなたかの、空の写真で。」ミナからのDM「ちゃんと食べていますか?」

:::judge
### E6　END

「本日の業務は、以上です」。最後の選択。冒頭で迷った秒数との対句「何秒も、かかりませんでしたね」。「いってらっしゃいませ」「わたくしは、どこにも行きませんよ。」END。

- 知ること: 送り出す側が入れ替わった。送らなくても、彼女は行かない。
- 選ぶこと: 「また来る」「ありがとう」、または送らない。
- ==見る点==: 対句と最終行で締まるか。送り出す側が入れ替わった実感があるか。

:::

### E7　スタッフロール

三人のその後の投稿。「そして、ご主人様へ。」の下に、あなたが最後に送った言葉。

## 周回

### R1　次回起動

END後にもう一度起動すると、ミナが空白の日数を数えて迎える。「三日ぶり、ですね。集計していました」。

- 知ること: 来ない日々が、自分の側に移った。

### R2　二周目

- 知ること: 前の周と違う言葉が自分に返ってくる。

### 選択肢の温度（三つに割る）

ぶっきらぼう一色だと、どれを選んでも同じ人に見える。各3択は **ぶっきらぼう／やさしい／ふざけ** の三つの温度で組み、どれを選んでもミナの受けは成立させたまま、選ぶ人の性格だけが出るようにする。（送らない）がある場面は、無言がいちばん冷たい温度を担うので、言葉は二つ（ぶっきらぼう／やさしい）。ミナの受けは温度を評価しない（「やさしいですね」と言わない）。観測だけで返す。

**言い回しの決まり: あなたが男か女か分からない言葉にする。** 命令形（ひろえ、つづけろ）、語尾の「か」「な」「ぞ」「よ」「わ」は使わない。て形（ひろって、つづけて）、言いかけ（きこえてる）、体言止め、「そっか」「ありがとう」のような性別のない口語で組む。

## ヒロイン3人の救済の設計

三人共通のエンジンは一つ。**ミナは「消された言葉が聞こえる」体質（P4）で、道中でその子の言葉（穢れ）を全部浴びて祓った唯一の証人**である。改心はどの面も二段で組む——(1) ミナが拾った「その子が消した一行」を読み上げる（証拠。本人の言葉）→ (2) **ミナ自身の言葉で決定打を撃つ**（証人の判決。02 の「ミナ発の一言の種」を配達人の露払いから決定打へ昇格）。あなたについての断定は一切含めない（憲法）。三面でミナがヒロインの消した言葉を拾って返し、FINAL であなたがミナの消した言葉（【初】）を拾って返す——三面の構造がそのまま FINAL の鏡になる。

### レイ

- 闇の中身: 一位になった日から、誰の合格報告にも「おめでとう」が押せなくなった指。「本気で来てくれない少年」は削除。
- 道中の細部: 一位の隣の空席と掲示板の落書き「カレーうまかった」（S1-2）→ 採点する目・「てっぺんは寒い」（S1-7）→ 投稿「午前二時。三秒だけ見て、閉じた」（S1-8）。
- 中ボス: 現行維持（先出し「逃げたら承知しないんだから」）。捨て台詞は少年を含意しないので無傷。
- 決定打の方向性: **証人型**。(1) 削除済み下書き「——だれか、追いついてよ」を返す（H0 で「寒そうな声」として温存し、S1-4 で「削除済みの一行」とだけ示した一行）。(2) ミナが「見てよ」に「見ていました」を式の語彙で返し、消した一行にだけ点数がついていなかったことを言う。例: 「わたくしが、追いつきました。——最後の一行まで、見ましたので。」
- 救済後の実在感: 投稿「次は、本気のあなたと。——逃げたら、承知しないから。」（宛先がミナに変わっても成立するので現行維持）。返信「は? 誰よあんた」。FINAL の援護1人目、E7 の1行目。

### あかり

- 闇の中身: 渡せなかった「すき」の行き場を、増えない いいね通知への再訪に代行させる指。相手は転校していった同級生（空いた机で示す。名前は出さない）。傘・交差点・「キミ」は削除。
- 道中の細部: 「ねえ見て」「すき」の吹き出し・黒板「あたしのせいだ」（S2-3）→ ノート、書いては消した跡（S2-4。ここに選択 #4）→ 投稿「今日だけで四回も、見にきちゃった」（S2-5）。
- 中ボス: 現行維持（序盤先出し「見て? 見てるよね?」）。
- 決定打の方向性: **返却型＋証人型**。(1) ノートの底にあった、消されていない本物の一通（内容は短く、宛名なし）を浄化して返す。(2) 教室中の「すき」を弾として浴びた自機＝ミナにしか言えない判決。例: 「汚れた“好き”は、ひとつも、ありませんでした。」——あかりの「迷惑なだけ」という自己判決を証人が覆す。名前を呼ぶ決定打（「——あかり。」）は少年の資産なので使わない。
- 救済後の実在感: 黒板「ありがとう」。投稿「ほんと、バカなんだから。……あたしも、だけど。」（現行維持）。返信「あなたの言い方、誰かに似てる」→ F3 でレイが反転回収（あかりの気づきをレイが言う構図は維持）。FINAL の援護2人目——その一言はクリア時の「あったかい声が、した。……知らない声なのに」（S2-9）の返礼。

### こはる

- 闇の中身: 家を出たきり帰らない兄のぶんの夕食を作り続ける手。期限の切れたプリンを、捨てない・食べない手。兄≠少年、死は明示しない。
- 道中の細部: 投稿「すてない。たべない。あたしのじゃ、ないもん」（S3-2）→ 伏せた茶碗・空席の食卓・「むだだ」の声（S3-3・S3-5）→ 中ボスの「ちゃんと、してるのに……どうして——」（S3-4。「あの人のせいだ」は削除し、責める宛先を作らない）→ 割り込みでミナ自身の濁り（S3-7）。
- 決定打の方向性: **証人型（否定の返却）**。(1) 消された一行「たべに、きて」を返す。(2) 道中で「むだだ」を祓い切った唯一の証人として、02 の一行を決定打に昇格。例: 「むだな鍋は、ひと鍋も、ありませんでしたよ。」——兄の声の代弁（「祈りは届いてた」）は削除。ミナは兄を知らないので、知っていること（鍋の数）だけを言う。
- 救済後の実在感: 空席の箸の前で湯気が戻る（現行演出維持）。投稿「ちゃんと食べてね。……あたしも、食べるから。」。返信「ありがと、知らない人」→ F2 の援護3人目で「知らない人じゃ、なかったよ」を返す。ミナの投稿「ちゃんと食べていますか」（H3）が E5 の DM に繋がる。

## 選択と戦闘の結線（案）

一つだけ提案する。**【散】の件数 n を、FINAL 第5スペル『世界中の悲鳴』（HP22%）に混ざる「あなたの下書き弾」の数にする。** 悲鳴ワードの言葉弾に、あなたが散らした下書きの実文字列が n 個だけ混ざり、この弾だけは当たっても被弾にならず「拾う」扱い（残機減なし・ボム扱いの小さな浄化波・【濁】がわずかに薄まる）。自分の捨てた言葉は自分を傷つけない、消した言葉は拾える——F4 で【初】が戻ってくる前に、手で一度体験させる。三人の援護は結線せず、現行の背景巡回の閾値（HP 0.80／0.58／0.36）に固定する（（送）の回数で援護を遅らせる等の罰は置かない）。実装は BossMina のスペル5に文字列プールを差し込む形で、Final.tscn の Screams 混入（F4）と同じデータを使う。

## 冒頭の圧縮案

04 の冒頭は「起動→①→②→③→④→⑤→れんしゅう（選択1）→ハブ初回（選択1）」で、初弾（れんしゅうのショット）までに会話5場面・選択7回あった。本表では初弾までを2場面短くする。

1. **②初対面を①に統合**（P2）。「あなたは——どなたですか」の問いと「作った人だ／天才だ／さあな」の選択を削除。ミナは起動ログの operator 表記（観測）から作り手だと判断し、①の受けの中で「{秒}秒・{文字数}文字」の観測芸と「ご主人様」呼びを済ませる。空欄（名前・職業）は問わないまま席として残す。
2. **⑤送り出しを削除**（P4 の末尾から直接 T1 へ）。「その前に、ひとつだけ」が送り出しを兼ねる。送り出し系の3択は固定枠を持たない方針（04 設計ノート）なので、失うものは無い。

結果: 初弾までの会話は3場面（P2・P3・P4）・選択3回、想定31行（04 の44行から13行減）。迷い秒数の初出は P2 に残るので E6 の対句は生きる。
