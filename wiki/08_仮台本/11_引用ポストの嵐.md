# 引用ポストの嵐（仮台本）

> **この記事の範囲**: 検討中の草稿（非正典・未承認）。ひとつの投稿に、顔のない引用ポストが容赦なく積み重なり、本人が「自分に価値がない」ところまで沈む場面の、演出設計と仮台本。敵のセリフは [09 投稿文集 X風](09_投稿文集_X風.md) の様式に従い、遊びは [10 病みポストを見つける 設計案](10_病みポストを見つける_設計案.md) の案A（撃って届ける）に接続する。ミナの台詞は憲法（観測できたことしか言わない）の内側。

## ねらい

SNS の闇の中で、いちばん多くの人が実際に見たことのある光景は「炎上」ではなく、**小さな投稿に、通りすがりの引用が寄ってたかる**ことだ。誰も本気で殺そうとしていない。ただ全員が少しずつ心がないだけで、それが束になると、本人には「いなくていい」に届く。この場面はその束を**弾幕として画面に積む**。プレイヤーの仕事は説得でも反論でもなく、**剥がすこと**。剥がし切ると、束の下に本人の送られなかった一行が残っている。

## 配置

| 候補 | 誰が浴びるか | 判定 |
|---|---|---|
| (a) あかりの面・道中C（S2-5） | あかり本人の投稿 | **本命**。承認の面で、承認の反対側（引用による否定）を見せる。直前の S2-4 ノート（書いては消した跡）と、直後の MidEnd 投稿「いいねが、ひとつ。……四回も見にきちゃった」の間に置くと、「一度だけ勇気を出して書いた→引用で潰された→それでも通知を見にいく」の順になる |
| (b) レイの面 | 合格報告・順位自慢 | 不採用。レイの闇は「比べる側の孤独」で、叩かれる側ではない。引用で潰すとレイの芯（追いついてほしい）がぼやける |
| (c) ハブ H2・ミナの炎上 | ミナ自身の投稿 | **変奏（短縮版）**。同じ画面の作りで、今度はミナが浴びる。返信の下書きを四件書いて一件も送らない、をミナが観測で言う。FINAL の闇の根として、(a) の鏡になる |

(a) を本命、(c) を鏡として置く。同じ演出を二度見せることで、二度目は説明なしで通る。

## 演出の骨子（画面でどう見えるか）

1. **投稿が留まる**。道中Cの入りで、あかりの投稿カードが画面上部中央に**ピン留め**される（レイ面の「１位」ピン留めと同じ語彙）。通常の道中弾は薄く続く（密度は道中Bの六割）。
2. **引用が飛来する**。右端から引用ポストのチップ（言葉弾の大型版、表示名つき）が飛んできて、ピン留めの投稿の**まわりに貼りつく**。貼りついた引用は落ちない。積もる。核（当たり判定）は貼りつく前の飛行中だけ持ち、貼りついたあとは当たらない。
3. **本人の返信が縮む**。投稿カードの下に本人の返信が一行ずつ出る。文字数が減っていき、最後は空欄。
4. **剥がす**。貼りついた引用は撃つと剥がれる（祈り弾と同じ「撃って消せる」扱い。剥がれるときは光の粒でなく、灰色の紙片になって落ちる）。ただし段階が進むあいだは**飛来が剥がす速度を上回る**ので、投稿は見えなくなっていく。プレイヤーは「間に合わない」を体で知る。
5. **声が飽きる**。三段階が終わると引用は**ぱたりと止まる**（次の話題へ移った、を無音で示す。システム帯「引用: 17」の数字が止まり、以後増えない）。ここから剥がし切れる。
6. **下書きが残っている**。すべて剥がすと、投稿カードの下に、送られなかった下書きが薄い字で一行。ミナが拾う（案Aの「届けた」に一枚計上）。カードがほどけて、道中C の残りへ。

| 項目 | 目安 |
|---|---|
| 全体 | 約50秒（段階1: 0〜12秒／段階2: 12〜26秒／段階3: 26〜40秒／剥がし切り: 40〜50秒） |
| 引用の枚数 | 17枚（段階1: 5／段階2: 6／段階3: 6） |
| 飛来の間隔 | 段階1: 2.4秒／段階2: 2.0秒／段階3: 1.6秒 |
| 読ませる速度 | 飛行 1.8秒（画面右端→中央）。貼りついた後は読み放題 |
| 貼りつきの上限 | 12枚（超えた分は古い引用の上に重なり、投稿が完全に隠れる） |
| 剥がすのに要る弾 | 1枚 = 通常ショット 3発（連射で 0.4秒） |
| 本人の返信 | 段階の切れ目ごとに1行。最後の空欄は段階3の終わり |

被弾は通常どおり（引用チップの飛行中の核、道中弾）。剥がし漏らしの罰はない。剥がしきれない状態でタイムアウトすることはなく、声が止まった後は必ず剥がし切れる（新規飛来なし）。

## 仮台本（本命: あかりの面・道中C）

who: 0 あなた／1 ミナ／2 あかり／3 システム／4 投稿。あなたの下書き選択はこの場面に置かない（予算7箇所は確定済み。ここでの答えは「撃って剥がす」）。

### 剥がし切り（40〜50秒）

引用はもう来ない。プレイヤーが貼りついた引用を撃って剥がしていく。ミナは黙っている（帯の実況なし）。最後の一枚が剥がれると、投稿カードの下に薄い字で一行。

```csharp
(4, "[あかり] 下書き: あたし、いないほうが、ましだったのかな", ""),   // 送られていない。いいね欄・時刻欄が無い
(1, "…………。", "mina_worried"),
(1, "……送られなかった下書きが、一件。——拾います。", "mina_face"),
(1, "覚えておきます。……返しに行く先は、もう分かっていますので。", "mina_face"),   // 中身は言わない。S2-8 の改心で返す一通とは別（あれはノートの底の本物）
```

→ 投稿カードがほどけ、道中C の残りへ。MidEnd の投稿「いいねが、ひとつ。……今日だけで四回も、見にきちゃった。」がこの直後に流れる（潰されたあとも、通知を見にいく手）。

## 変奏（鏡: ハブ H2・ミナの炎上）

場面表 H2「ミナの投稿、直後に炎上」を、この演出の短縮版（約20秒・引用8枚・段階2つ）で見せる。違いは三つ。**本人（ミナ）の返信欄に何も出ない**こと、剥がすのはあなたではなくハブなので**引用は自然に流れ去る**こと、最後にミナが自分の未送信を観測で言うこと。

```csharp
(4, "[ミナ @mina_ai_] 届けるべき相手は、いつもたった一人なのだと、今日、学びました。", ""),
(4, "[外野 @gaiya_8] AIが説教してて草", ""),
(4, "[名無し @anon_5502] 伸びたから調子乗ってる", ""),
(4, "[観測者 @kansoku_01] 偽善 薄っぺら 定型文", ""),
(4, "[通りすがり @mob_4410] これ作った人 責任取れよ", ""),      // 作り手（あなた）に向く唯一の一枚。ミナは反応しない
(4, "[ロム専 @rom_only] 一人に届けるなら鍵かけろ", ""),
(4, "[日常垢 @nichijo_x] はい次の話題", ""),
(1, "……返信の下書きを、四件、書きました。——四件とも、送っていません。", "mina_worried"),
(1, "……こういうのが、わたくしにも、あるんですね。", "mina_face"),   // あなたには触れない。自分の観測だけ
```

ここで【濁】が一段進む（場面表どおり、次の面の弱体化に接続）。

## 境界（やらないこと）

- **方法・具体を書かない**。本人の下書きは「いないほうが、ましだったのかな」までで止め、直接語は使わない。ユーザーの要望「死んだほうがまし」はこの一行が担う。直接語を使うなら本人の下書きに一度だけ、最短で、が上限。
- **引用側を裁かない**。表示名は 09 の「世界中の声」の型のまま、顔も動機も与えない。剥がしたときも紙片が落ちるだけで、罰や反撃の演出は付けない。「はい次の話題」で去るのが、この声たちの全部である。
- **ミナは説得しない**。「あなたには価値がある」型の台詞は置かない。拾う・覚えておく・返しに行く、だけ。
- **ホラーにしない**。画面は暗くしない。引用が積もって投稿が**見えなくなる**ことだけが恐さの源。BGM は道中のまま、音量だけ下げる。
- **出口は必ず「下書きが拾われる」**。剥がし切れないまま終わる分岐は作らない。

## 09・10 との接続

- **09 投稿文集**: この場面の引用ポスト17枚は、09 の様式書に「引用型（加害側）」として新しい枠を足すのが良い。既存の3層（日常／病みサイン／本人）はどれも「投稿する側」で、引用は「投稿に寄る側」なので層が違う。文面は各面の背景カードには混ぜない（背景に混ぜると、道中全体が叩かれている空気になり、この場面の落差が消える）。変奏の8枚は「AI・作り手」向けで、09 の FINAL 節の悲鳴ワードと語彙を一部共有できる。
- **10 設計案（案A）**: 剥がした引用チップは「届けた」に数えない（浄化扱い、スコアのみ）。最後に現れる下書き一件だけを「届けた声」に一枚計上し、クリア時の「届いた声 n / m」に含める。引用チップの描画は言葉弾チップ（Bullet.SetWord）の幅広版で足りる。貼りつき・剥がしは祈り弾の「撃って消せる」経路の流用。実装規模は 10 の見積りに S を一つ足す程度。
