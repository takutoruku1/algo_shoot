# 引用ポストの嵐（仮台本）

> **この記事の範囲**: 検討中の草稿（非正典・未承認）。ひとつの投稿に、顔のない引用ポストが容赦なく積み重なり、本人が「もう、いいかな」まで沈む場面の、演出設計と仮台本。人物は [12_キャラ設定シート](12_キャラ設定シートv2_社会人版.md)（v3）に準拠し、本命はレイ（STAGE3・配信者「星逢レイ」）の面に置く。敵のセリフは [09 投稿文集 X風](09_投稿文集_X風.md) の様式に従い、遊びは [10 病みポストを見つける 設計案](10_病みポストを見つける_設計案.md) の案A（撃って届ける）に接続する。ミナの台詞は憲法（観測できたことしか言わない）の内側。

## ねらい

SNS の闇の中で、いちばん多くの人が実際に見たことのある光景は「炎上」ではなく、**小さな投稿に、通りすがりの引用が寄ってたかる**ことだ。誰も本気で殺そうとしていない。ただ全員が少しずつ心がないだけで、それが束になると、本人には「いなくていい」に届く。この場面はその束を**弾幕として画面に積む**。プレイヤーの仕事は説得でも反論でもなく、**剥がすこと**。剥がし切ると、束の下に本人の送られなかった一行が残っている。

レイの面に置くと、貼りつく先が投稿カードだけでなく、壁の配信画面に立つガワ（ボスの姿）になる。豪華なガワの上に心のない言葉が貼られて、中の人が見えなくなる。「気づいて」の面で、気づかれないことの反対側（顔のない言葉に覆われること）を、絵で見せる。

## 配置

| 候補 | 誰が浴びるか | 判定 |
|---|---|---|
| (a) レイの面・引用の嵐（S3-5b） | 星逢レイの配信後の投稿 | **本命**。直前に流れる本人の投稿「今日のコメント 全部読んだ 読まなきゃよかった」（09 R41。12 道中の細部「この直後にガワの上へ引用が貼られはじめる」）と、直後の MidEnd の同接カウンター「8」→「3」の間に置くと、「配信のあと一言だけ書いた→引用で覆われた→それでも次の枠を立てる」の順になる。叩かれている原因は置かない（12 判断3） |
| (b) あかりの面・道中C | あかりの投稿 | v2 までの本命。v3 で**不採用**。あかりの芯は「返して」（送ったのに返ってこない）で、叩かれる側ではない。引用で潰すと「返事が来ない」が「叩かれた」にすり替わる。あかりの面には引用を一枚も置かない |
| (c) ハブ H2・ミナの炎上（こはるの面のあと） | ミナ自身の投稿 | **変奏（短縮版）**。同じ画面の作りで、今度はミナが浴びる。返信の下書きを四件書いて一件も送らない、をミナが観測で言う。FINAL の闇の根として、(a) の鏡になる |

(c) が先、(a) が後。ミナが自分に貼られた引用を剥がし切れないまま（H2 では引用は流れ去るだけで、剥がしていない）、レイに貼られた引用を剥がしに行く順になる（12 ミナと「あなた」）。一度目は約二十秒で説明なしに通し、二度目に「剥がす」が遊びとして開く。

## 演出の骨子（画面でどう見えるか）

1. **投稿が留まる**。道中Cの入りで、星逢レイの投稿カードが壁の配信画面の上部中央に**ピン留め**される。カードの下には、等身大より大きいガワ（ボスの姿）が笑顔で立っている。通常の道中弾は薄く続く（密度は道中Bの六割）。
2. **引用が飛来する**。右端から引用ポストのチップ（言葉弾の大型版、表示名つき）が飛んできて、ピン留めの投稿の**まわりと、その下のガワの上に貼りつく**。貼りついた引用は落ちない。積もる。核（当たり判定）は貼りつく前の飛行中だけ持ち、貼りついたあとは当たらない。
3. **本人の返信が縮む**。投稿カードの下に本人の返信が一行ずつ出る。配信中と同じ言葉から始まり、文字数が減っていき、最後は空欄。
4. **剥がす**。貼りついた引用は撃つと剥がれる（祈り弾と同じ「撃って消せる」扱い。剥がれるときは光の粒でなく、灰色の紙片になって落ちる）。剥がした下には、まだ同じ笑顔のガワ（12 道中の細部）。ただし段階が進むあいだは**飛来が剥がす速度を上回る**ので、投稿もガワも見えなくなっていく。プレイヤーは「間に合わない」を体で知る。
5. **声が飽きる**。三段階が終わると引用は**ぱたりと止まる**（次の話題へ移った、を無音で示す。システム帯「引用: 17」の数字が止まり、以後増えない）。ここから剥がし切れる。
6. **下書きが残っている**。すべて剥がすと、投稿カードの下に、送られなかった下書きが薄い字で一行。ミナが拾う（案Aの「届けた」に一枚計上）。カードがほどけて、ガワは笑顔のまま道中C の残りへ。

| 項目 | 目安 |
|---|---|
| 全体 | 約50秒（段階1: 0〜12秒／段階2: 12〜26秒／段階3: 26〜40秒／剥がし切り: 40〜50秒） |
| 引用の枚数 | 17枚（段階1: 5／段階2: 6／段階3: 6） |
| 飛来の間隔 | 段階1: 2.4秒／段階2: 2.0秒／段階3: 1.6秒 |
| 読ませる速度 | 飛行 1.8秒（画面右端→中央）。貼りついた後は読み放題 |
| 貼りつきの上限 | 12枚（超えた分は古い引用の上に重なり、投稿とガワが完全に隠れる） |
| 剥がすのに要る弾 | 1枚 = 通常ショット 3発（連射で 0.4秒） |
| 本人の返信 | 段階の切れ目ごとに1行。最後の空欄は段階3の終わり |

被弾は通常どおり（引用チップの飛行中の核、道中弾）。剥がし漏らしの罰はない。剥がしきれない状態でタイムアウトすることはなく、声が止まった後は必ず剥がし切れる（新規飛来なし）。

## 仮台本（本命: レイの面・道中C）

who: 0 あなた／1 ミナ／2 星逢レイ（返信は @rei_____ の本人。画面に出ているのはガワ）／3 システム／4 投稿。あなたの下書き選択はこの場面に置かない（予算7箇所は確定済み。ここでの答えは「撃って剥がす」）。


### 剥がし切り（40〜50秒）

引用はもう来ない。プレイヤーが貼りついた引用を撃って剥がしていく。ミナは黙っている（帯の実況なし）。剥がした下には、まだ同じ笑顔のガワ。最後の一枚が剥がれると、投稿カードの下に薄い字で一行。

```csharp
(4, "[星逢レイ] 下書き: もう、いいかな", ""),                             // 送られていない。いいね欄・時刻欄が無い。何が「いい」のかは書かれていない（09 R46）
(1, "…………。", "mina_worried"),
(1, "……送られなかった下書きが、一件。——拾います。", "mina_face"),
(1, "覚えておきます。……返しに行く先は、もう分かっていますので。", "mina_face"),   // 中身は言わない。S3-8 の改心で返す一行とは別（あれは削除済みの「わたしに、気づいてよ。わたしを、見てよ」。12 の決定打）。この下書きはその一歩手前で、改心では読み上げない
```

→ 投稿カードがほどけ、ガワは笑顔のまま道中C の残りへ。MidEnd で同接カウンターが「8」から「3」へ落ちる（覆われたあとも、次の枠を立てる手）。

## 変奏（鏡: ハブ H2・ミナの炎上）

場面表 H2「ミナの投稿、直後に炎上」（v3 ではこはるの面のあと。レイの面の前に来るので、この短縮版が本命より先に見える）を、この演出の短縮版（約20秒・引用8枚・段階2つ）で見せる。違いは三つ。**本人（ミナ）の返信欄に何も出ない**こと、剥がすのはあなたではなくハブなので**引用は自然に流れ去る**こと、最後にミナが自分の未送信を観測で言うこと。

## 境界（やらないこと）

- **方法・具体を書かない**。本人の下書きは「もう、いいかな」で止め、直接語は使わない。何が「いい」のかは書かず、続きは改心で返す「わたしに、気づいてよ。わたしを、見てよ」が担う。二つの下書きの間に、方法や状態の語は一つも置かない。
- **引用側を裁かない**。表示名は 09 の「世界中の声」の型のまま、顔も動機も与えない。叩かれている原因も置かない（12 判断3。原因を書いた瞬間に「叩かれる側にも理由があった」と読める席ができ、一枚一枚の軽さが消える）。剥がしたときも紙片が落ちるだけで、罰や反撃の演出は付けない。「はい次の話題」で去るのが、この声たちの全部である。
- **ミナは説得しない**。「あなたには価値がある」型の台詞は置かない。拾う・覚えておく・返しに行く、だけ。
- **ガワを壊す言葉を誰も言わない**。引用もミナも、ガワそのものには触れない。割れるのは S3-8 の改心で、「もう隠れなくていい」の意味だけ（12）。
- **ホラーにしない**。画面は暗くしない。引用が積もって投稿とガワが**見えなくなる**ことだけが恐さの源。ガワの笑顔は最後まで崩れない（ガワには泣き顔が無い）。BGM は道中のまま、音量だけ下げる。
- **出口は必ず「下書きが拾われる」**。剥がし切れないまま終わる分岐は作らない。

## 09・10 との接続

- **09 投稿文集**: この場面の引用ポスト17枚は、09 の様式書の「引用型（加害側）」の枠。v3 で配信者向けの語彙（切り抜き、界隈、低評価、企画、ガワ、同接、初見）に書き換えた。既存の3層（日常／病みサイン／本人）はどれも「投稿する側」で、引用は「投稿に寄る側」なので層が違う。文面は各面の背景カードには混ぜない（背景に混ぜると、道中全体が叩かれている空気になり、この場面の落差が消える）。ピン留めの投稿は 09 R42、直前に流れる本人の投稿は R41、剥がし切りの下書きは R46。変奏の8枚は「AI・作り手」向けで、09 の FINAL 節の層1（炎上のリプライ）と語彙を共有できる。
- **10 設計案（案A）**: 剥がした引用チップは「届けた」に数えない（浄化扱い、スコアのみ）。最後に現れる下書き一件だけを「届けた声」に一枚計上し、クリア時の「届いた声 n / m」に含める。引用チップの描画は言葉弾チップ（Bullet.SetWord）の幅広版で足りる。貼りつき・剥がしは祈り弾の「撃って消せる」経路の流用。貼りつき先が投稿カードとガワの二箇所になるので、ボス（星逢レイ）の待機絵を道中で先に出す描画が要る。実装規模は 10 の見積りに S を一つ足す程度。
