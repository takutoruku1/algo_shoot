# 粗い台本 案C（1）冒頭とレイ

> **この記事の範囲**: 検討中の草稿。実装された物語ではない。[05_場面表_案C](05_場面表_案C.md) を仕様として、案C（少年不在・ご主人様＝あなた・下書き選択式）の**粗い全体台本**の第1分冊——P0〜H1r（プロローグ／れんしゅう／ハブ初回／難易度／STAGE1 レイ／帰還・再訪）。要所の台詞だけを置き、各場面の行数は場面表の想定行数を上限とする。磨いていない。STAGE2 以降は別分冊。

## 書式

- 台詞は `(who, "text", "face")`。who: 0 あなた（送信された下書き）／1 ミナ／2 レイ／3 システム表示／4 投稿。who=5（中継）は本分冊では使わない。
- `// ―― 下書き選択 ――` 行に候補を書き、直後に選ばれた例を1行。分岐の受けはフェンスの下に箇条書き。
- 仕掛けの値の拾い箇所は `// 【初】拾` のようにコメントで明示。
- 「現行維持」の場面は行を写さない（転用元は場面表の列を参照）。

```csharp
(1, "ご主人様。投稿の文末、句点を打つ派と打たない派、どちらがお好みで。", "mina_face"),
(1, "……集計しました。ご主人様の下書き、いまのところ句点ゼロです。", "mina_smile"),   // 下書きは短文・記号なしの仕様なので必ず成立
(1, "打つと、そこで話が終わってしまうでしょう。", "mina_face"),
(1, "……ですので、この話も、打たずに置いておきます。", "mina_face"),   // ミナ自身の投稿（H1）は句点を打っているので「今日の投稿」とは言わない
```

- 残りのプール（一人称／フォロワー／埃／好きな食べ物／何も起きない日／外へ／猫背／名前／歌）は後続。
