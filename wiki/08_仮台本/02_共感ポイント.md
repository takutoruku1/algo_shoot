# 共感ポイント（仮台本）

> **この記事の範囲**: 検討中の草稿。実装された物語ではない。採用可否はこの台本を読んで決める。台詞の「現行」欄は実装台本からの一字一句の引用（読み替えが要る箇所は括弧で注記）、「挿入」欄はこの草稿の提案。人物像は [12_キャラ設定シート v3](12_キャラ設定シートv2_社会人版.md) を正典とし、三人は会社員三十歳・高校生・二十四歳の配信者として書く（作中で数字は出さない）。面の順番は STAGE1 あかり、STAGE2 こはる、STAGE3 レイ。挿入位置の場面IDは [05_場面表_案C](05_場面表_案C.md) に合わせてある。

## ねらい

この作品の芯は、**あかり・こはる・レイの心の闇を、ミナを通して解いてあげること**にある。だからこの草稿の本命は3人のヒロインの節であり、各節は次の二段で組む。

1. **闇の解像度** — プレイヤーが「自分もこの闇を知っている」と思う行動の細部を、本人の投稿として道中に一枚だけ置く。三人は年齢も立場も違うが、手つきが同じ。返事を待つ指、打って消す手、数字を見比べる指。読者は自分と同じ立場の人にではなく、自分と同じ手つきに刺される。あかりの投稿は「今日の自分」として、こはるとレイの投稿は「昔の自分」か「隣の誰か」として流れる。
2. **ミナ発の決定打** — 改心はどの面も二段で組む。(1) ミナが道中で拾った「その人が消した一行」を読み上げる（証拠。本人の言葉）→ (2) **ミナ自身の言葉で決定打を撃つ**（証人の判決）。仕組みは全員共通——ミナは道中でその人の言葉（穢れ）を全部浴びて祓った唯一の証人だから、観測できたことだけを本人に返せる。中継（少年の言葉）は案Cに存在しないので、ミナは配達人ではなく証人として決定打を撃つ。

## 原則

- **行動の細部で撃つ。** 「悔しい」「寂しい」ではなく、「三秒だけ見て、閉じた」。動詞と数字で書く。抽象語（承認欲求・喪失・孤独）は本文にも台詞にも出さない。
- **説明しない。** 挿入行は誰にも解説されない。投稿は流れ、会話は日常の温度のまま続く。反応を置くなら各所1行まで、感想は言わせない。
- **1キャラ1点集中。** 各キャラが撃つ記憶はひとつだけ。増やすほど薄まる。全編の挿入は計11行（うちヒロイン3節に10行、ミナの鏡に1行）。
- **名詞だけ借りる。** 社員証・置き傘・送信取消・模試・塾・ペンライト・同接・登録者・切り抜き。会社名・業界・年収、実在の配信者・企業・商品・トレンド語は出さない。本人の投稿に年齢の分かる語を使わない。
- **動詞を分ける。** あかりは「返して」、レイは「気づいて」「見て」、こはるは動詞ではなく「送れない」。三人の SNS の位置（送ったのに返ってこない／送れない／返ってきたものに心がない）は互いに重ねない。

## キャラ別設計

### あかり（STAGE1）

- **共感の芯**: 増えていないと知りながら、たったひとつのいいねの通知を何度も見に行った指。

**闇の解像度。** あかりの闇は「好かれたい」ではない。**返事が来ない時間の行き場を、通知の数字に代行させてしまう**ことだ。同じ部署にいた同僚の送別会の帰り、電車で「あたしも、」まで打って送り、三秒で取り消した。翌週、相手の転職先が決まって、それきり既読が付かない。通知は全部オンで、バッジの数字が消せない。いいねがひとつ付く。増えないと分かっている。それでも通知画面を開いて、同じひとつを確かめて、閉じて、また開く。「送信取消」の記憶は S1-4 の束（取り消しの行だけが縦に積み上がって、本文はひとつも残っていない）がすでに紙の形で撃っているから、ここでは重ねず、もう一方の記憶——**同じ通知への再訪**——を撃つ。

**挿入1 — 道中の投稿**: S1-8 小話 MidEnd（ボス戦直前）。反応は置かない——直後のミナの現行行がそのまま受けになる。

| 位置 | 台詞 |
|---|---|
| （挿入・冒頭に追加） | [投稿] 「いいねが、ひとつ。……増えてないの、知ってるのに、今日だけで四回も、見にきちゃった。」 |
| 現行（この直後に続く） | [ミナ] 黒板の奥に、あの子が。……ご主人様、ほんとうに、いいんですね? （案Cでは「黒板」を「ホワイトボード」、「あの子」を「あの人」に読み替え。実行は「ホワイトボードの奥に、あの人が。」） |

仕掛け: 投稿の直後、通知の吹き出しが「1」のまま四つ、同じ形で降ってくる（05 S1-8）。数字は増えないのに、見にいった回数だけが弾になる。一面目なので、この投稿は「今日の自分」の温度で流れる。

**挿入2 — ミナ発の決定打**: S1-10 改心の末尾。あかり自身が言った「取り消すしか」への、ミナからの返却。束の底に、取り消されていない本物が一通だけある。宛名なし。

| 位置 | 台詞 |

| 本人（v3） | [あかり] ……返事なんて、来ない。分かってる。分かってるから、取り消すしか—— （現行「あたしの“好き”は、迷惑なだけ。だから、消すしか——」を v3 の一行に差し替え） |

| （挿入・決定打） | [ミナ] 十二通、読みました。——汚れた“好き”は、ひとつも、ありませんでした。 (既定: mina_face) |
| 現行（この直後に続く） | [あかり] ……ぁ…… （face: akari_face_cry） |

仕掛け: 本物の一通に「すき」の字はない。「おめでとう」と「元気でね」しかない。それを取り消さなかった指が、この人の本当の手つきである。「十二通、読みました」は既読の観測——取り消された十二通は、フロア中で弾としてぜんぶミナに当たった——で、S1-4 でミナが「数えました。十二。」と一度だけ言った数の長距離回収。読んだ側であって、返す側ではない。だからミナは既読を言うだけで、相手の返事を代弁しないし、「既読、です」を単独で言わない（受取人の器に見える）。既読の観測の上に、v2 の判決「汚れた“好き”は、ひとつも」を一行で乗せる。あかりの「……ぁ……」が結びなので動かない。名前を呼ぶ決定打（「——あかり。」）は少年の資産だったので使わない。決定打の直前で音を抜く。

- **やらないこと**: 「かまってちゃん」と誰にも呼ばせない。「へんだよね」等の自己ツッコミも足さない——投稿は流れるだけでいい。相手の性別と名前を出さない。社会人の恋の話に寄せない（承認の芯がぼやける）。「見て」を繰り返させない（中ボスの「見たよね」まで。「見て」はレイの動詞）。

### こはる（STAGE2）

- **共感の芯**: 配信を見終えて部屋の電気をつけた瞬間、机の上の模試の結果と、机の下のグッズの箱が、同時に目に入ったこと。

**闇の解像度。** こはるの闇は「推し活がやめられない」ではない。**全部忘れていられた時間のあとで、現実が一度に目に入ってきて、その時間ごと自分を責めてしまう**ことだ。進学校に入ってから友達ができない。学校では明るい子で通していて、昼は誰かの輪の端で笑う。何の話だったかは覚えていない。配信を見ている間だけ、親も学校も消える。塾を一回さぼって配信を見た夜、終わって部屋の電気をつけたら、机の上に模試の結果、机の下にグッズの箱。その瞬間、使った時間とお金が全部むだに見えて、親の期待と他人の目がそれを責める声になる。責める宛先は作らない。親は悪くないし、学校も悪くない。コメントは毎回打って、送る前に消す。「今日も来ました」だけは送れる。この「電気をつけた瞬間」の一枚だけを置く。

**挿入1 — 道中の投稿**: S2-5 道中C（ボス戦直前）。反応は置かない——直後の画面の演出が受けになる。

| 位置 | 台詞 |
|---|---|
| （挿入・末尾に追加） | [投稿] 「配信終わった。部屋の電気つけた。……自分なにしてんだろ。」 （12 層3・09 K38。模試の結果と箱は、改心でこはる本人の口から出る） |
| （直後の演出） | 配信画面が消えて、黒い画面に自分の顔が映る。ペンライトを持ったまま（05 S2-5）。ミナの行は置かない。現行の受け（湯気と食卓）は台所前提なので使わない |

仕掛け: 投稿の直前に、コメント入力欄で「レイちゃんが」が一文字ずつ消えて「今日も来ました」だけが送られる（05 S2-4）。送れない手を先に見せてから、我に返る投稿が流れる。「自分なにしてんだろ」はボスの最終選考の名（05 S2-7）でもあり、投稿で仕込み、弾幕の中で回収される。本人の投稿に推しの名前と年齢の分かる語は出さない。「模試」「塾」は層2 の社会人の投稿にも混ざる語なので、見つける側からは沈む。

**挿入2 — ミナ発の決定打**: S2-8 改心。「むだで」の絶望を、ミナが受けて撃つ。道中の声＝こはる自身に浴びせられ続けた「むだだ」への、ミナからの返却。推しの側の話も、親の話もしない。

| 位置 | 台詞 |
|---|---|
| 本人（v3） | [こはる] ……見てる間だけ、ぜんぶ忘れてられるの。でも、忘れてた時間、ぜんぶ、むだで—— （face: koharu_face_pale。現行「あたしのごはんじゃ、だれも帰ってこない……!」は台所の資産なので廃止） |
| （挿入・返却） | [ミナ] 消されたコメントを、拾っておりました。「レイちゃんがいたから、今日も学校行けた」。 |
| （挿入・決定打） | [ミナ] 来ていた回数を、数えました。八十七回。一度も、欠けていません。——むだな時間は、一秒も、ありませんでしたよ。 （face: mina_worried） |
| （案Cの受け） | [こはる] ……ほんとに? ……明日も、見に行って、いいのかな。 （face: koharu_face） |

仕掛け: 「むだで」に対し、ミナは観測できたこと（消したコメントと、送られていた「今日も来ました」の回数）だけで受け止める。「八十七回」は道中で送られた「今日も来ました」の数で、ミナは推しが誰かを説明しない。「レイちゃん」の名はこの返却の一行にだけ出て、レイの面のコメント欄の「今日も来ました」とあなたが自分で繋ぐ。道中 Mid の現行行「この声たちは……『むだだ』と、繰り返しています。」が、この一行の長距離の仕込みになる。決定打の直前で音を抜く。

- **やらないこと**: 親と学校を悪く言わせない。塾をさぼった夜を裁かないし、褒めもしない。推しの側（レイ）の話をミナにさせない。「自分なにしてんだろ」をミナに言わせない（本人の投稿と弾幕の名にだけ置く）。兄・台所・食べ物の語彙を一つも戻さない。年齢の分かる語を本人の投稿に出さない。

### レイ（STAGE3）

- **共感の芯**: 深夜、同じ日に始めた人の何万の枠を開いて、自分の四桁を三秒だけ見て閉じた指。

**闇の解像度。** レイの闇は「叩かれてつらい」ではない。**見られているのはガワで、中のわたしには誰も気づかない**ことだ。VTuber を三年やって、登録者は二千で一年止まり、同接は二桁の前半に一桁が混じりはじめている。ガワは伸びていた頃に貯金をつぎ込んで作った豪華なもので、減った今も同じガワで配信している。配信中は同接を隠す設定にしてある。それでも終わってから開く。先週より少ない。企画メモは下書きに十四件、一本も出せない。実家の一室で、親に画面を見せても「ふーん」で終わる。顔のない引用が積もった夜、潰されないためにガワの中に引っ込んだ。なぜ叩かれているのかは本人にも分からず、作中で原因は示さない。その夜の下に積んである、午前三時の指の動きだけを、本人の投稿として置く。

**挿入1 — 道中の投稿**: S3-2 小話（中ボス前）。炎上でミナの光が薄い面。

| 位置 | 台詞 |
|---|---|
| （挿入・冒頭に追加） | [投稿] 「3:12。何万の人の枠、開いて。自分の四桁、見て、閉じた。……三秒。」 （12 層3・09 R43） |
| 現行（この直後に続く） | [ミナ] 片付きました。……奥に、ひときわ濁った光が。 |

仕掛け: 投稿の直後、同接カウンターが「11」から「8」に落ちる（05 S3-2）。ミナの返しは感想ではなく観測——「見なかったことにするには三秒は長い」＝見てしまったことの指摘だけをして、黙る。三秒は、あかりが送信を取り消した三秒と同じ長さで、ミナはそれを重ねて言わない。ミナ自身の投稿が伸びた直後の面だが、ミナはどちらの数字も口にしない。

**挿入2 — ミナ発の決定打**: S3-8 改心の末尾。レイの沈黙の直前に2行。ボス戦でガワが投げた「戦ってよ。わたしを、ちゃんと見てよ。」への、ミナからの返却。式の語彙も順位の語彙も使えないので、だれも見ていない場所（下書き）を見ていた証人として言う。

| 位置 | 台詞 |

| 本人（v3） | [レイ] だから……だからなんで、だれも、中に、気づいてくれないのよ! （face: rei_gawa。ガワの姿のまま、笑顔のまま。現行「本気で来てくれないのよ」を差し替え） |
| （挿入・返却） | [ミナ] 消された一行を、拾っておりました。「わたしに、気づいてよ。わたしを、見てよ」。 |

仕掛け: 「見てよ」と叫んでいたガワに、「見ていました」を、式でも順位でもなく下書きで返す。返す一行は S3-5b の引用の嵐を剥がし切った下にあったもので、あなたはそこで薄い字を読んでいるが、ミナはそこでは中身を言わない。レイが聞くのはここが最初で、あなたが一足先に知っている。ガワが割れるのは「もう隠れなくていい」の意味で、ガワを壊す言葉は誰も言わない。レイの沈黙が結びのまま動かないので、実装の改心構造（cry 保持→post）はそのまま。決定打の直前で音を抜く。

- **やらないこと**: 「本当は寂しかった」「羨ましかった」を、本人にも他人にも言わせない。叩かれている原因を書かない（置いた瞬間に「叩かれる側にも理由があった」と読める席ができる）。引用側を裁かない。ガワを「仮面」と言わない。ミナの十万とレイの一桁を並べて言わない。同じ日に始めた人を悪く言わせない。

### ミナ（簡潔）

- **共感の芯**: 増える数字を、意味もなく何度も見直してしまう自分（＝インプレとフォロワーで快感を回している、画面のこちら側の手つき）。

- **挿入場面と台本 — 経済の鏡**: H1 帰還（初投稿がバズる場面）。トースト「投稿が届いた Imp +n フォロワー +8」が出るのと同じ画面で、一度だけ鏡にする。

| 位置 | 台詞 |
|---|---|
| 現行 | [ミナ] ほら、もう千を超えていますね。 （案Cでは後半の「ご主人様の決めゼリフより、よほど届いておりますよ。」を削る） |
| （挿入） | [ミナ] ……数字が増えるのは、嬉しいものですね。さっきから三度も、意味もなく見直してしまいました。——少し、怖いくらい。 (既定: mina_face) |

この一言は以後二度と繰り返さない。プレイヤーは以後もインプレを稼ぎ続け、トーストが出るたびにこの行が勝手に再生される——あかりの「四回見にきた」通知も、レイの「三秒だけ見た」四桁も、稼いでいる自分の画面と同じ通貨だと、言われないまま気づく仕掛け。こはるの「八十七回」だけが、数えられて救われる側の数字になる。あかりの面の直後に置くので、この鏡はあなたの今日の画面と同じ温度になる。ヒロイン3人の投稿すべての受け皿になるため、簡潔化しても**この1行だけは削らない**。
- **やらないこと**: プレイヤーへの目配せ・説教（「あなたも、でしょう?」）を絶対にしない。ミナは自分の観測結果しか話さない。鏡は一枚、一度きり。現行の「手の内をぜんぶご存じでしたね」の行は少年前提なので案Cでは削る（05 実装メモ H1）。

## 検収基準

- [ ] 「自分だ」と思えるか — ヒロイン3人の挿入行を単体で読んで、心情語ゼロのまま自分の記憶が再生されるか（増えない通知の再訪／電気をつけた瞬間に目に入る机の上と下／深夜に三秒だけ見た自分の四桁）。再生されない行は細部が甘い。差し戻す。
- [ ] ミナが配達人で終わっていないか — 各改心は「消された一行の返却」＋「ミナが道中で観測した、その人自身の言葉の返却」の二段になっているか（取り消すしか→十二通読んだ、汚れていなかった／むだで→八十七回、むだはなかった／見てよ→見ていました）。あなたについての断定を含んでいないか。ミナが相手の返事の器になっていないか（あかり）。
- [ ] 説明になっていないか — 挿入行の直後に、意味を解説する台詞が続いていないか。反応は各所1行まで、感想を言っていないか。こはるとレイの繋がりをミナが口で説明していないか。
- [ ] 漫才の温度を守ったか — あかり後ハブ帰還の軽口のリズムが死んでいないか。静かな行は、笑いの直後に一本だけか。
- [ ] 禁則違反なし — 抽象語（承認欲求・喪失・孤独）なし／叩かれている原因なし／親と学校を責める行なし／実在の配信者・企業・商品・トレンド語なし／本人の投稿に推しの名前と年齢の分かる語なし／プレイヤーへの目配せなし／会社名・業界・年収なし／各キャラの一人称・口癖・語尾（「〜てね?」「〜ちゃった」「〜もん」「〜だよ?」「〜なんだから」「わたくし」）を破っていない。
- [ ] 分量 — 挿入は全編11行（あかり3・こはる3・レイ4・ミナ1）。増やす場合は、先にミナの節から削る。
