# 共感ポイント（仮台本）

> **この記事の範囲**: 検討中の草稿。実装された物語ではない。採用可否はこの台本を読んで決める。台詞の「現行」欄は実装台本からの一字一句の引用、「挿入」欄はこの草稿の提案。

## ねらい

この作品の芯は、少年とミナの繋がりではなく、**レイ・あかり・こはるの心の闇を、ミナを通して解いてあげること**にある。だからこの草稿の本命は3人のヒロインの節であり、各節は次の二段で組む。

1. **闇の解像度** — プレイヤーが「自分もこの闇を知っている」と思う行動の細部を、本人の投稿として道中に一枚だけ置く。
2. **ミナ発の一言の種** — 現行の改心はどれも少年の言葉の中継が決定打で、ミナは配達人に留まる。そこに追加1行だけ、**ミナにしか言えない救い**を置く。仕組みは全員共通——ミナは道中でその子の言葉（穢れ）を全部浴びて祓った唯一の証人だから、「あなたの言葉は、汚れていなかった」と本人に返せる。決定打（中継）は動かさない。

## 原則

- **行動の細部で撃つ。** 「悔しい」「寂しい」ではなく、「三秒だけ見て、閉じた」。動詞と数字で書く。抽象語（承認欲求・喪失・孤独）は本文にも台詞にも出さない。
- **説明しない。** 挿入行は誰にも解説されない。投稿は流れ、会話は日常の温度のまま続く。反応を置くなら各所1行まで、感想は言わせない。
- **1キャラ1点集中。** 各キャラが撃つ記憶はひとつだけ。増やすほど薄まる。全編の挿入は計11行（うちヒロイン3節に7行）。

## キャラ別設計

### レイ

- **共感の芯**: 深夜、他人の合格報告を三秒だけ見て画面を閉じ、いいねを押さずに寝た夜。

**闇の解像度。** レイの闇は「一位でいたい」ではない。**他人の良い報せを、素直に喜べなくなった自分に、深夜ひとりで気づいてしまう**ことだ。タイムラインをただ眺めていただけなのに、誰かの合格報告が流れてきて、指が止まり、三秒だけ読み、そっと画面を閉じる——おめでとうも、いいねも、押せないまま。翌朝には忘れたふりができる。その夜の指の動きだけを、本人の投稿として置く。

**挿入1 — 道中の投稿**: STAGE1 小話 MidEnd の冒頭（ボス戦直前）。

| 位置 | 台詞 |
|---|---|
| （挿入・冒頭に追加） | [投稿] 「午前二時。おなじ歳の子の、合格報告。三秒だけ見て、閉じた。……いいねは、押してあげないんだから。」 |
| （挿入） | [ミナ] ……三秒。見なかったことにするには、すこし、長いですね。 (既定: mina_face) |
| 現行（この直後に続く） | [ミナ] 片付きました。……奥に、ひときわ濁った光が。 |
| 現行 | [少年] ああ。さっきの子だ。今度こそ、奥まで届かせる。行くぞ。 |

仕掛け: ボス戦・安置リレー完走の実装済み一言「……っ、合格。……なんて、言ってあげないんだから。」と**同じ文法**（合格＋「〜てあげない」）で書いてある。投稿で仕込み、弾幕の中で回収される。ミナの返しは感想ではなく観測——「見なかったことにするには三秒は長い」＝見てしまったことの指摘だけをして、黙る。

**挿入2 — ミナ発の一言の種**: 改心の末尾。中継の決定打（三年前の地区予選）が届いた後、レイの沈黙の直前に1行。ボス戦でレイ自身が投げた「戦ってよ。わたしを、ちゃんと見てよ。」への、ミナからの返却。

| 位置 | 台詞 |
|---|---|
| 現行 | [中継] 強くなってくれ。ぼくが、もう一度挑みたくなるくらい。——挑めなく、なっても。 |
| （挿入） | [ミナ] ……わたくしも、見ていましたよ。あなたの式の、最後の一行まで。——きれいでした。 (既定: mina_face) |
| 現行（この直後に続く） | [レイ] …………。 （face: rei_face_cry） |

仕掛け: 「見てよ」と叫んでいた本人に、「見ていました」を、式の語彙のまま返す。少年の中継が過去（三年前）を証すのに対し、ミナは**たったいまの戦い**の証人になる——ミナにしか言えない一行。レイの沈黙が結びのまま動かないので、実装の改心構造（cry 保持→post）はそのまま。

- **やらないこと**: 「本当は寂しかった」「羨ましかった」を、本人にも他人にも言わせない。嫉妬の解説をした瞬間、この投稿は死ぬ。

### あかり

- **共感の芯**: 増えていないと知りながら、たったひとつのいいねの通知を何度も見に行った指。

**闇の解像度。** あかりの闇は「好かれたい」ではない。**渡せなかった気持ちの行き場を、通知の数字に代行させてしまう**ことだ。いいねがひとつ付く。増えないと分かっている。それでも通知画面を開いて、同じひとつを確かめて、閉じて、また開く。「送信寸前で消した下書き」の記憶は実装済みの MidStory（ノートに「すき」を書いては消す）がすでに紙の形で撃っているから、ここでは重ねず、もう一方の記憶——**同じ通知への再訪**——を撃つ。レイの投稿（いいねを押してあげない側）と対になる。同じ通貨で、押さない者と、ひとつを何度も数える者。

**挿入1 — 道中の投稿**: STAGE2 小話 MidEnd の冒頭（ボス戦直前）。反応は置かない——直後のミナの現行行がそのまま受けになる。

| 位置 | 台詞 |
|---|---|
| （挿入・冒頭に追加） | [投稿] 「いいねが、ひとつ。……増えてないの、知ってるのに、今日だけで四回も、見にきちゃった。」 |
| 現行（この直後に続く） | [ミナ] 黒板の奥に、あの子が。……ご主人様、ほんとうに、いいんですね? |
| 現行 | [少年] ……ぼくが、やらなきゃいけないんだ。 |

**挿入2 — ミナ発の一言の種**: 改心の末尾。名前（中継「——あかり。」）が届いた後に1行。あかり自身が言った「あたしの“好き”は、迷惑なだけ」への、ミナからの返却。

| 位置 | 台詞 |
|---|---|
| 現行 | [ミナ] ……ちゃんと、届きましたよ。 (既定: mina_face) |
| （挿入） | [ミナ] それと——この教室の“好き”を、ぜんぶ浴びて、祓ってきたわたくしが言います。汚れた“好き”は、ひとつも、ありませんでした。 (既定: mina_face) |
| 現行（この直後に続く） | [あかり] ……ぁ…… （face: akari_face_cry） |

仕掛け: 決定打の名前は少年（の頼み）のもの。だがこの一行だけは、教室じゅうの「すき」を弾として浴びた自機＝ミナにしか言う資格がない。「迷惑なだけ」という自己判決を、証人が覆す。あかりの「……ぁ……」が両方への返事になるので、結びは動かない。

- **やらないこと**: 「かまってちゃん」と誰にも呼ばせない。「へんだよね」等の自己ツッコミも足さない——投稿は流れるだけでいい。

### こはる

- **共感の芯**: いなくなった人の物を、捨てることも使うこともできないまま、冷蔵庫に置き続ける手。

**闇の解像度。** こはるの闇は「悲しい」ではない。**日常の物のほうが先に期限を迎えてしまうのに、手がそれを動かせない**ことだ。冷蔵庫のプリンの賞味期限が切れる。捨てられない——捨てたら片付けたことになる。食べられない——自分の物ではないから。だから毎日、扉を開けるたびに視界の隅で確かめて、閉める。喪失を一度でも通った者なら必ず知っている、この「すてない。たべない。」の二連の動詞だけを置く。誰のプリンかは言わない。

**挿入1 — 道中の投稿**: STAGE3 小話 Mid の冒頭（空席の食卓が見える場面の直前）。反応は置かない。

| 位置 | 台詞 |
|---|---|
| （挿入・冒頭に追加） | [投稿] 「プリン、きのうで賞味期限が切れちゃった。すてない。たべない。……だって、あたしのじゃ、ないもん。」 |
| 現行（この直後に続く） | [ミナ] ご主人様、見てください。湯気の向こうに、たくさんの食卓。……どれも、空席です。一つも、埋まっていない。 |
| 現行 | [ミナ] この声たちは……「むだだ」と、繰り返しています。 |

仕掛け: 実装済みの「お茶碗が、伏せてあります。ずっと。」（BossTalk Chat3）と同系の細部だが、あちらは食卓の景色、こちらは**期限が切れても動かせない**という時間の細部で、被らない。

**挿入2 — ミナ発の一言の種**: 改心の中盤。「なんの、意味が……!」の絶望と、少年の決定打（祈りは届いていた）の間に1行。道中の声＝こはる自身に浴びせられ続けた「むだだよ」への、ミナからの返却。

| 位置 | 台詞 |
|---|---|
| 現行 | [こはる] あたしのごはんじゃ、お兄ちゃんは帰ってこない……! じゃあ、なんの、意味が……! （face: koharu_face_pale） |
| （挿入） | [ミナ] ……“むだだよ”という声なら、ここへ来るまでに、わたくしがぜんぶ祓いました。——むだな鍋は、ひと鍋も、ありませんでしたよ。 （face: mina_worried） |
| 現行（この直後に続く） | [少年] ……お兄さんが最後の日まで、あったかいままでいられたのは。きみの食卓が、あったからだよ。 （face: shonen_gentle） |

仕掛け: 「なんの意味が」に対し、まずミナが道中の事実（むだの声を祓い切った）で受け止め、そのうえで少年が本当の答え（食卓の意味）を置く二段構え。決定打はあくまで少年＝兄の声のままで、ミナは露払いに徹する。道中 Mid の現行行「この声たちは……『むだだ』と、繰り返しています。」が、この一行の長距離の仕込みになる。

- **やらないこと**: プリンの持ち主を明かさない。死・不在の直接語に接続しない（この面の禁則。既存の景色描写がすでに全部言っている）。

### 少年（簡潔）

- **共感の芯**: 「そのうち」「今度」で先送りにしたまま、期限が来てしまった約束。
- **挿入場面と台本**: FINAL Intro。ハブの共通小話で実装済みの伏線——「[少年] ……そのうちな。」「[ミナ] 「そのうち」は、ご主人様のいちばんの口癖ですよ。集計済みです。」——を、全編で一度だけ清算する。

| 位置 | 台詞 |
|---|---|
| 現行 | [少年] ……ぼくは、ずっと見てるだけだった。光を、きみに握らせて。 （face: shonen_gentle） |
| （挿入） | [少年] ……ミナ。きみの集計に、ひとつだけ、訂正だ。 （face: shonen_gentle） |
| （挿入） | [少年] ——「そのうち」は、今日だ。 （face: shonen_proud） |
| 現行（この直後に続く） | [少年] 今度は、ぼくが行く番だ。待ってろ、ミナ。 （face: shonen_proud） |

「そのうち」→「今日」→「今度は」と、先送りの語彙そのもので前進する並び。訂正は一度だけ、軽口の文法で二行で切る。
- **やらないこと**: 後悔の独白にしない。「あのとき〜していれば」を言わせない。

### ミナ（簡潔）

- **共感の芯**: 増える数字を、意味もなく何度も見直してしまう自分（＝インプレとフォロワーで快感を回している、画面のこちら側の手つき）。
- **挿入場面と台本 — 経済の鏡**: STAGE1 クリア後、ハブ帰還小話（初投稿がバズる場面）。トースト「投稿が届いた Imp +n フォロワー +8」が出るのと同じ画面で、一度だけ鏡にする。

| 位置 | 台詞 |
|---|---|
| 現行 | [ミナ] ほら、もう千を超えていますね。ご主人様の決めゼリフより、よほど届いておりますよ。 |
| （挿入） | [ミナ] ……数字が増えるのは、嬉しいものですね。さっきから三度も、意味もなく見直してしまいました。——少し、怖いくらい。 (既定: mina_face) |
| 現行（この直後に続く） | [ミナ] それにしても、ご主人様。会ったこともない相手の手の内を、ぜんぶご存じでしたね。……お見事です。 |

この一言は以後二度と繰り返さない。プレイヤーは以後もインプレを稼ぎ続け、トーストが出るたびにこの行が勝手に再生される——レイの「押してあげない」いいねも、あかりの「四回見にきた」通知も、稼いでいる自分の画面と同じ通貨だと、言われないまま気づく仕掛け。ヒロイン3人の投稿すべての受け皿になるため、簡潔化しても**この1行だけは削らない**。
- **やらないこと**: プレイヤーへの目配せ・説教（「あなたも、でしょう?」）を絶対にしない。ミナは自分の観測結果しか話さない。鏡は一枚、一度きり。

## 検収基準

- [ ] 「自分だ」と思えるか — ヒロイン3人の挿入行を単体で読んで、心情語ゼロのまま自分の記憶が再生されるか（深夜の合格報告／増えない通知の再訪／捨てられない期限切れ）。再生されない行は細部が甘い。差し戻す。
- [ ] ミナが配達人で終わっていないか — 各改心の追加1行は「ミナが道中で浴びて祓った、その子自身の言葉」の返却になっているか（見てよ→見ていました／迷惑なだけ→汚れていなかった／むだだよ→むだはなかった）。少年の決定打を上書きしていないか。
- [ ] 説明になっていないか — 挿入行の直後に、意味を解説する台詞が続いていないか。反応は各所1行まで、感想を言っていないか。
- [ ] 漫才の温度を守ったか — レイ後ハブ帰還の軽口のリズムが死んでいないか。静かな行は、笑いの直後に一本だけか。
- [ ] 禁則違反なし — 抽象語（承認欲求・喪失・孤独）なし／死の直接的示唆なし（プリンの持ち主を明かしていない）／プレイヤーへの目配せなし／各キャラの一人称・口癖・語尾（「〜てあげないんだから」「〜ちゃった」「〜もん」「わたくし」「ぼく」）を破っていない。
- [ ] 分量 — 挿入は全編11行（レイ3・あかり2・こはる2・少年2・ミナ2）。増やす場合は、先に少年・ミナの節から削る。
