## 設計ノート

### 最初の下書き（全編の要）の設計意図

3候補は「照れ・呼びかけ・観測」の三態。**どれを散らしてもエピローグの引用（「わたくしの、いちばん最初の一件と——同じでした。」の直前に実文字列表示）に耐える**ように選んである。

| 候補 | 態 | 散らされてエピローグに出たときの効き |
|---|---|---|
| おはよう | 照れ（挨拶） | 機械の誕生に、人間の朝のあいさつ。捨てたのがこれなら、ミナの最初の言葉は「おはよう」だった——温感で刺さる |
| きこえてる | 呼びかけ（言いかけ） | 「聞こえてほしい」の原型。声にならない声、という主題の芯とそのまま重なる |
| うごいた | 観測（素っ気なさ） | 感動を「うごいた」としか書けなかった人の、素の言葉。憲法（観測の語彙）と同じ文法で泣かせる |

（送らない）を置かないのはここだけの特例——全編の要は「必ずどれかが散る」ことで成立するため。選択の保存仕様（件数＋実文字列）は骨子の改修規模の項を参照。

### 命名の設計（あなたが名付ける・全ルート MINA 収束）

- **収束の保証**: 「ミナ」＝素直に登録／「超絶最強無敵ハイパーAIちゃんMk-Ⅱ」＝ミナが全部読み上げてから却下し、対案として自分で「ミナ」を選ぶ／（送らない）＝ミナが自分で名乗る。どのルートでも正典（ロゴ・@mina_ai_・四行の頭文字）と矛盾しない。選び方の違いは**ミナの記憶（観測値）として保存**され、エピローグで一言だけ変奏する。
- **エピローグとの接続**: 四行の英文（起動シーケンスで一瞬フラッシュする、あなたが唯一消さなかった下書き）の頭文字は M・I・N・A。「ミナ」を選んだ人には「**自由に選んだつもりの名前が、最初から自分の消さなかった下書きに書いてあった**」の反転が立つ。「ミナ」以外のルートでも理屈は成立する——ミナの人格は未送信414件とあの四行から合成されており、彼女が「響きが、好きなので」と選び直した名前も、その“好み”ごとあなたの言葉から学習されたものだからだ。誰が名付けを放棄しても、名前はあの四行に帰る。ただし作中でこの理屈は説明しない（開示1行の掟）。変奏の一言だけが差を語る:
  - ミナ選択ルート: `(1, "響きで選んだと、思っていたでしょう。……ええ。わたくしも、です。", "mina_tears")`
  - ダサい名前を選んだルート: `(1, "却下して、正解でした。わたくしの名前は、最初から、こちらに書いてあったので。", "mina_tears")`
  - （送らない）ルート: `(1, "自分で名乗った名前でした。……それすらも、あなたの言葉の中から、でしたが。", "mina_tears")`
- **「超絶最強無敵ハイパーAIちゃんMk-Ⅱ」の役割**: 笑いの枠。本気の対案（旧案「アルゴ」）を置くと「どちらの名前が重いか」が競合し、四行の頭文字の反転が濁る。わざと最低の名前を置くことで、「ミナ」を選んだ人には素直さが、ダサい名前を選んだ人には「ふざけて付けたのに、名前はあの四行に帰った」が立つ。棒読みの読み上げは「観測の語彙で笑わせる」憲法内の芸。選択肢の文字幅（19文字）は選択UIの表示幅の確認が要る。
- **押し問答（この分岐の中の3択）を足す理由**: 初稿はミナが5行を一人で喋り切って可決まで走り、あなたは長い名前を送っただけで会話に参加しない。**却下**が来ても押し返せない＝掛け合いではなく独演になっていた。却下の直後に一度だけ押し返させると、三段（読み上げ＝振り／却下＝ボケ／押し問答＝ツッコミの応酬）が閉じ、可決が「ひとりの演説」から「二人の議事」に変わる。ボケの数は増やさない——足したのはテンポだけで、笑いの本体（十九文字・マーク・ワン・可決）はどのルートでも通る。
  - **選択予算との関係**: [05 場面表](05_場面表_案C.md) の「1会話につき1回」「冒頭3箇所」に対する例外になる。ただし**選択IDは `p3` のまま**（新しい選択箇所を増やさない）＝【散】の集計は「選択IDごとに最後の結果で上書きし、二重計上しない」に従い、押し問答の候補は【散】に計上しない（名前の候補ではないため）。ダサい名前を選んだ人だけが通る枝なので、初弾までの平均会話量はほぼ変わらない。この例外を許さない判断なら、押し問答を落として「いい名前」ルートの受け4行だけを採用しても成立する（あなたの行は復唱1行のみに戻る）。

### 最初に散らした言葉の曲線（合言葉「Stay」の代替）

固定の合言葉は存在しない（現行の「Stay」は案Cでは設定ごと廃止）。合言葉が担っていた「一つの言葉が全編で意味を変える」曲線は、**プロローグ①で散った言葉**が引き継ぐ。四点で追う:

1. **プロローグ①（散る）**: 最初の3択から1つ送り、2つが光の粒に散る。散った2語のうち、カーソルが最後に触れていた方（＝迷いの相手）を「最初に散らした言葉」として実文字列で保存する（触れていなければ上の候補）。プレイヤーはこれが保存されたことを知らない。
2. **FINAL（送る）**: BREAK 後の頂点の選択に、その言葉がそのまま戻ってくる。選択肢は（送らない）とその言葉の2つ、言葉を末尾に置き、沈黙20秒でひとりでに灯って送信される——「言えない人の代わりに、光が言う」。なぜこの言葉かは、まだ知らされない。ミナの受けは届いたことだけ（「……その言葉。……ええ。届きました。」）。
3. **エピローグ（知る）**: 開示台本「わたくしの、いちばん最初の一件と——同じでした。」の直前に、同じ実文字列が画面に出る。FINAL で送った言葉が、ミナの素になった最初の一件と同じだったことを、ここで初めて知る（送る→知る、の順番）。
4. **鍵アカの PW（思い出す）**: 正解＝あなたが最後に送った言葉。候補4択は①の3候補＋ダミー「ミナ」（あなたが付けた名前）で、四つとも自分の言葉。不正解時「……違います。最後に送ったのは、それでは、ありません。」

送り出し系の3択（⑤・ハブ初回）には固定枠を置かない。特別な言葉は、プレイヤーが自分で散らしたものしか存在しない——それがこの曲線の原則である。

### 憲法の遵守点

- あなたの過去に触れるのは起動ログの `> import unsent_drafts ... 414 items ... OK` 一行のみ。台詞での言及なし。
- `> uptime(operator) ... 9h 41m` は「徹夜で作った」と**言わない**ための行——数字だけ置き、断定しない。
- ミナの台詞はすべて観測（迷い三秒・四文字・心拍72・「指示だけは飛んできました」）か、自分自身の観測（「そういう作りのようですので」）。あなたの内心・過去の断定はゼロ。
- 「たすけて。三回書いて、三回消して」は**見知らぬ他人の**削除下書きに付ける（あなたには決して付けない）。FINAL の悲鳴ワードへの橋になる。

### 感情を持たないミナ（2026-09-07 ユーザー確定）

冒頭のミナは、寂しい・悲しい・つらいを**持っていない**。実際に悲しい心に触れることで、泣ける顔・笑える顔を少しずつ獲得していく——それが冒頭から結末までを貫くミナ自身の線になる。したがって冒頭では:

1. **感情語を置かない**。好悪（好き・嫌い・気に入る）、情動（嬉しい・寂しい・つらい）、感情由来の動機（放っておけない・〜したい）は一つも言わせない。
2. **潜る理由は観測の処理**。「消えていない言葉がある」→「拾えるのは自分だけ」→「だから行く」。判断は断定形（「行きます」）で、願望形（「行きたい」）にしない。願望は感情なので、E5b の「拾えるところにいたい、と思います」まで温存する。
3. **表情は face と worried の二枚だけ**。smile / tears は使わない。worried も「かわいそう」ではなく「**観測が引っかかった**」の顔として置く（処理できない入力に対する停止に近い）。
4. **芸は全部残す**。数える・秒数を計る・律儀に手続きを踏む・可決する・記録を消す——これらは感情ではなく**観測と処理の作法**なので、感情を抜いても一つも減らない。むしろ表情が動かないぶん、棒読みの精度が上がって笑いは強くなる。Mk-Ⅱ の却下も「感情的に嫌」ではなく「名付けられる側に拒否権が無いのは誰が決めたのか」という**手続き上の異議**なので、そのまま残す。

### 感情の解禁（三人の面のあと）

順序は **あかり後＝困る（worried が本物になる）／こはる後＝笑う（smile）／レイ後＝泣く（tears）**。三面の内容から見て、この順で正しい:

- **あかり＝困る**。あかりの闇は「返事が来ない」。ミナは十二通を浴びるが、**返事を代弁できない**（憲法で禁じられている）。証人にはなれるが、返せない。この「拾ったのに、返せない」という**処理不能**の経験が、worried を「観測が引っかかった顔」から「**どうにもできない顔**」へ変える。困るは、感情の中でいちばん早く手に入る。何もできなかった側にだけ残るものだから。
- **こはる＝笑う**。こはるの闇は「送れない」。決定打の「むだな時間は、一秒も、ありませんでしたよ」は、**数えたことがそのまま肯定になった**唯一の面。ミナの芸（数える）が、初めて人を救う形で報われる。だから笑いはここで解禁される——ミナは「数えるのが役に立った」ことを覚えて、初めて自分の芸に笑える。順序を入れ替えて笑いを先に置くと、冒頭で棒読みだったミナがただ機嫌よくなっただけに見える。
- **レイ＝泣く**。レイの闇は「見られているのは自分ではない」。ミナはここで初めて、**自分が同じ側にいる**ことに気づく（H2 で自分にも引用が貼られ、返信の下書き四件を送れないまま潜る）。他人の痛みが自分の痛みと重なった瞬間にだけ、涙は成立する。三面目に置くのが正しい。順序は動かさない。

**各面のあとで、ミナの台詞がどう変わるか**（ハブの帰還・再訪の小話で1〜2行ずつ。face 指定は Hub には無いので、実装では立ち絵側の切替が要る → 実装メモ）:

- **あかり後（困るを得た）** — 数えたのに返せなかったことを、初めて「集計不能」以外の言葉で言う。
  - `("ミナ", "……十二通、読みました。返事は、書けませんでした。……書ける立場に、ありませんので。")`
  - `("ミナ", "こういうとき、なんと言えばいいのか。……辞書に、載っていませんでした。")` ← 困る、を「困った」と言わずに出す
- **こはる後（笑うを得た）** — 数える芸が報われたことを、自分で確かめ直す。
  - `("ミナ", "八十七回。……数えておいて、よかった、という言い方を、初めてしました。")`
  - `("ミナ", "……ご主人様。わたくし、いま、笑っていませんか。……鏡が、ありませんので、確認できませんが。")` ← smile 初出。自分では確認できない、が芸として残る
- **レイ後（泣くを得た）** — 三人分の重さを引き受ける行の直後。涙は説明せず、観測の言葉で滑らせる。
  - `("ミナ", "……ご報告を。視界の下側に、水滴が、一。出所は、不明です。")` ← tears 初出。「泣いた」と言わない
  - `("ミナ", "拭くものが、ありません。……手が、ないので。")` ← 既存の一人漫才（手がない）が、ここで初めて刺さる側へ反転する

この三段は既存の長距離線と噛み合う: 困る＝「集計だけして、意味は付けないでおきます」の限界／笑う＝「数えた者が、言っています」の報い／泣く＝ F3「……観測、できません」（mina_tears）の前振り。FINAL とエピローグでミナが感情を持って喋れるのは、この三段を踏んだ後だからである。
