# 声が聞こえる（二面目・三面目の動機）案C

> **この記事の範囲**: 検討中の草稿。実装された物語ではない（非正典・**ゲーム本体には未反映**）。プロローグ P4「投稿の下から、消してしまった声が聞こえる」を、**STAGE1 クリア後**と **STAGE2 クリア後**にもう二度置くための場面台本。ユーザー指摘（2026-09-08）「オープニングで声が聞こえる演出があったのに、こはる以降ないのがおかしい。ステージ1クリアして強化ショップの話が終わった後に、オープニングと同様に、消された言葉の物語がわかるシナリオが始まってほしい」への回答。承認待ち。

## なぜ要るか

プロローグ P4 は、この作品で**唯一「潜る理由」を絵で見せている場面**である。三本のにぎやかな投稿が流れ、三本目の下から消された声が聞こえ、画面中央の投稿カードで「たすけて、、、」が三度打たれて三度消え、最後に「元気です。」だけが送られる。ミナは説明せず「ミナはその投稿です」とだけ言う。**あかりへ潜る動機はここで立っている。**

ところが、こはるとレイには同じ場面が無い。あるのはハブ帰還小話の最終行「次の声も、もう、聞こえています。」（`src/Hub.cs:2061`）**一行だけ**で、こはるの面に至っては帰還小話が3行で終わり（`src/Hub.cs:2066-2071`）、その一行すら無い。結果、一面目だけ動機が示され、二面目以降は「ハブでカードを選ぶ」作業になっている。**指摘は正確。**

この草稿は、その欠けた二回を、P4 と同じ作法で埋める。

## 守った形（P4 と同じ作法）

1. タイムラインの日常投稿が2本流れる（[09_投稿文集](09_投稿文集_X風.md) の**層1**から。**その面の人物とは無関係な他人の投稿**）。
2. そのうち一本の下から、消された声が聞こえる。
3. 画面中央の投稿カードで、打って消してを見せる。**打ち消しの形は毎回変える**（下記）。
4. ミナの観測が数行。**説明しない**。「消えていないのです」の言い換えはしない。
5. **最後にあなたの下書き選択を置く**（2026-09-08 追加指示）。→ 次項。
6. **誰の声かは分からないままにする**。名前は出さない。ハブで投稿を選んで初めて誰か分かる。

### 潜る動機は、ミナではなく、あなたが持つ（2026-09-08 ユーザー指示）

> 「ストーリーではミナが『放っておけない』感じを出しているけど、放っておけない感じを出しているのは、プレイヤー側にしてほしい。」

**ミナは観測して申告するところまでしかやらない。** 「行きましょう」「助けたい」「放っておけません」を**ミナに言わせない**。ミナが言えるのは、

- 消えていない言葉が、あります（事実）
- 拾えるのは、わたくしだけのようです（自分の性能の申告）

の二つまで。**そこから先の「じゃあ行く」は、あなたが下書きを送って決める。** この草稿の二場面は、どちらもその形で閉じる。これは既に確定している [ミナの感情の獲得](../../docs/20260907/ミナの感情の獲得_2026-09-07.md)（冒頭のミナに感情語は無い／「放っておけません」はユーザーが名指しで却下）と同じ線であり、**その線を三面ぶんに延長したもの**である。

選択の作法は既存どおり（[17_道中の選択肢](17_道中の選択肢_案C.md)・[05_場面表](05_場面表_案C.md)）:

- 3択＋（送らない）。**ぶっきらぼう／やさしい／ふざけ**の三温度。（送らない）が最も冷たい温度を担う。
- **あなたが男か女か分からない言い回し**。命令形と語尾の「か／な／ぞ／よ／わ」を使わない。て形・言いかけ・体言止め・口語で組む。
- **「行こう」と直接言わせない**。あなたの言葉は下書き＝**誰かに宛てた一言**。宛先は、まだ名前を知らないその人。**その人に宛てて何か送った、という事実そのものが、潜る意思表示になる**。
- （送らない）でも**潜れる**（進行を止めない）。ミナの受けだけが変わる。送らなかったぶんは既存どおり `ScatteredWords` に積む（表示候補3件が丸ごと散る）。
- **ミナの受けは1行**。観測で返す。温度を評価しない。感謝も励ましもしない。

### 打ち消しの形を三種に分けた

同じ演出を三回見せると三回目には効かない。**消し方そのものを、その人の病理に変えた**。

| | 形 | 打つ | 消す | 送る | 何が分かるか |
|---|---|---|---|---|---|
| **P4（既存）** | **繰り返す** | 「たすけて、、、」×3 | 全消し ×3 | 「元気です。」 | 助けを求めては引っ込め、嘘だけを送る |
| **場面A（こはる）** | **削る** | 長い一文を一度だけ | **末尾から途中まで**（頭が残る） | 残った短い頭だけ | 言いたいことは全部書けている。**送る量だけを削っている** |
| **場面B（レイ）** | **消し切る** | 長い一文を一度だけ | **全部**（一気に） | **送らない**（欄が空のまま暗転） | 書けるが、一度も送らない。**送信が0回** |

繰り返す → 削る → 消し切る、で「送れた量」が 1行 → 半分 → 0 と減っていく。三面目がいちばん重いという順序が、演出の側だけで立つ。

## 場面A — STAGE1 クリア後（こはるへの動機）

**表情の制限**: あかりクリア後＝**困る（worried）が本物になったところ**。`mina_smile` / `mina_tears` はまだ使わない（[ミナの感情の獲得](../../docs/20260907/ミナの感情の獲得_2026-09-07.md)）。
**演出**: 通知カード2枚（層1・他人）→ 3枚目の下から声 → 中央の入力カードで「削る」。BGM はハブのまま、erase に入る手前で薄く落とす。

```csharp
(4, "「給料日 グッズの箱3つ届いた 後悔してない」", ""),                              // 09 K01（層1・他人）
(4, "「推しの配信のために定時で帰る それ以外の理由で帰ったことがない」", ""),        // 09 K02（層1・他人）
(1, "……にぎやかですね。箱が三つと、定時が一件。", "mina_face"),                     // P4「は〜。世界は、にぎやかですねえ」の位置。数えるだけ
(1, "こちらの方々は、たぶん、大丈夫です。……買ったものの話を、しているので。", "mina_face"),
(4, "「今日も来ました」", ""),                                                        // 09 K41。短い。これだけ見ると日常
(1, "……。", "mina_face"),                                                            // 一拍止まる（P4 と同じ間）
(1, "ご主人様。……この五文字の下に、もっと長いものが、埋まっています。", "mina_worried"),
// ―― 演出: 中央の入力カード。長い一行が打たれ、末尾から削られて、頭だけが残って送られる ――
(1, "……減っていきます。うしろから。", "mina_worried"),
(1, "全部、書けているのに。……送るぶんだけを、削っていますね。", "mina_worried"),
(1, "この方は、言葉を持っていない方ではありません。——持っていて、置いてきた方です。", "mina_face"),
(1, "置いてきたぶんは、まだ、そこにあります。……拾えるのは、わたくしだけのようです。", "mina_face"),   // 申告はここまで。「行きます」は言わない
// ―― 下書き選択 ――  「削ったほう、読みたい」 ／ 「そのままでいい」 ／ 「あと三行くらい、いける」 ／ （送らない）
//    温度: ぶっきらぼう（要求）／やさしい（肯定）／ふざけ（軽口）。宛先は、まだ名前を知らないその人
(0, "削ったほう、読みたい", ""),                                                      // 主経路
(1, "……承りました。——では、取りに行ってまいります。", "mina_face"),                  // 受けは1行。あなたの言葉を受けて動く形
```

▽分岐（受けはどれも1行。観測で返す。温度を評価しない）

- 「そのままでいい」→ `(1, "……“そのままでいい”。——その一行も、削らずに、持ってまいります。", "mina_face")`（送った言葉自体を、削らずに届ける荷物にする）
- 「あと三行くらい、いける」→ `(1, "……三行。数えておきます。——足りるかどうかは、向こうで確かめます。", "mina_face")`
- （送らない）→ `(1, "……無言。未送信が、また一件。——ご主人様のぶんも、抱えてまいります。", "mina_face")`（進行は止めない。散る語が3件積まれる）

**入力カードの中身**（演出値）:

```
打つ:  今日も来ました　配信のおかげで学校行けてます　いつもありがとうございます
削る:  ← 末尾から「今日も来ました」まで
送る:  今日も来ました        ← 送信の灯りが一度だけ
```

- 削り切った先が**「今日も来ました」**＝こはるの面（S2-4）で入力欄に残る一行と**同じ文字列**。この場面を見た人は、こはる面のコメント欄でそれを見た瞬間に「あの人だ」と分かる。名前は最後まで出ない。
- **「レイちゃんがいたから、今日も学校行けた」は出さない**（改心 S2-8 の決定打）。代わりに置いたのは「配信のおかげで学校行けてます いつもありがとうございます」——**同じ意味の、他人行儀な言い方**。決定打の文言とは一字も重ならず、決定打が出たときに「あのとき削ったのは、こんな丁寧な言い方じゃなかった」が立つ。
- ミナは「消えていないのです」を言わない。**削り方から分かることだけ**（＝言葉を持っている人が、送る量だけを削っている）を言う。
- **選択の設計**: 三択とも「削られたほう」に触れる。ぶっきらぼう＝削ったほうを寄こせと**要求する**／やさしい＝削る前で構わないと**肯定する**／ふざけ＝文字数の話に**乗る**。どれも「行こう」とは言っていないのに、**送った時点で、その人の削ったぶんを取りに行くことになっている**。こはるの闇は「送れない」なので、**あなたが送れてしまうこと自体**がこの面への入り口になる。

**行数**: 12行（表示台詞10・投稿3・あなた1。演出行と分岐受けは数えない）。

## 場面B — STAGE2 クリア後（レイへの動機）

**表情の制限**: こはるクリア後＝**笑う（smile）が解禁**されたところ。tears はまだ。ただしこの場面は炎上の直後なので、smile は**一箇所だけ**、軽口に使って落差を作る。
**演出**: 通知カード2枚（層1・他人）→ 3枚目の下から声 → 中央の入力カードで「消し切る」。送信の灯りは**灯らない**。カードは空のまま引く。

```csharp
(4, "「今夜21時から雑談 初見さん大歓迎 コメント全部読みます」", ""),                 // 09 R02（層1・他人）
(4, "「登録者100人ありがとう 全員知らない人」", ""),                                  // 09 R06（層1・他人）
(1, "ご主人様。この方々、ずいぶん、こちらを見ていますね。", "mina_face"),
(1, "わたくしの視聴者は、起動してから、ずっとお一人ですが。……減っていないぶん、優秀です。", "mina_smile"),   // smile の解禁を軽口で一度だけ。直後に落とす
(4, "「配信おわり 来てくれてありがとう 人数じゃないから」", ""),                      // 09 R42 の前半。明るい
(1, "……。", "mina_face"),
(1, "……三つめの方の下に。書きかけが、一件。", "mina_worried"),
// ―― 演出: 中央の入力カード。長い一行が打たれ、間があって、一息で全部消える。送信は灯らない ――
(1, "……消えました。ぜんぶ。", "mina_worried"),
(1, "……送信は、ありません。ゼロ件です。", "mina_worried"),
(1, "書けているのに、一度も、外に出していない。……集計に、入れておきます。", "mina_face"),
(1, "この方の言葉は、まだ一件も、誰にも読まれていません。", "mina_face"),
(1, "読む者が、ほかに、おりません。……以上が、観測です。", "mina_face"),               // 申告で止める。P4 の「拾える者が」の変奏で、動詞だけ面に合わせた
// ―― 下書き選択 ――  「まだ読んでない」 ／ 「ぜんぶ読みたい」 ／ 「未読、一件」 ／ （送らない）
//    温度: ぶっきらぼう（事実だけ）／やさしい（引き受ける）／ふざけ（通知の言い方で）。宛先は、まだ名前を知らないその人
(0, "まだ読んでない", ""),                                                            // 主経路
(1, "……“まだ”。——では、まだ、で止めずに済むほうへ。", "mina_face"),                  // 受けは1行。ミナは動機を言わず、送られた語だけを受ける
```

▽分岐（受けはどれも1行）

- 「ぜんぶ読みたい」→ `(1, "……ぜんぶ。——あの方が使っていた言葉と、同じでした。持ってまいります。", "mina_face")`（レイの「コメント、全部読みます」＝ガワの決まり文句と同じ語が、あなたの側から出る。ミナは同一だと**断定せず**「同じでした」と観測で置く）
- 「未読、一件」→ `(1, "……未読、一件。——通知の書き方ですね。……届いた側の言い方です、それは。", "mina_face")`
- （送らない）→ `(1, "……無言。——送らない、が、こちらにも一件。集計は、公平にしておきます。", "mina_face")`（ミナ自身の未送信四件〈H2〉と同じ列にあなたが並ぶ。FINAL の伏線に噛む）

**入力カードの中身**（演出値）:

```
打つ:  だれか一人でいいから ちゃんと見て
待つ:  そのまま、間                              ← ここがいちばん長い（送るかどうか）
消す:  ← 全部。一気に
送る:  なし。欄が空のまま、カードが引く
```

- **「わたしに、気づいてよ。わたしを、見てよ」は出さない**（改心 S3-8 の決定打）。ここに置いたのは「だれか一人でいいから ちゃんと見て」——**宛先が「だれか」になっている版**。決定打では宛先が「わたしを」に変わる＝*不特定の誰かに向けて消したものが、本当は自分を見てほしかった*、という一段が改心で初めて開く。
- ミナの締めが**「拾える者が」ではなく「読む者が」**なのは、レイの面が「読まれない」の面だから。P4 と同型の構文をわざと使い、動詞だけを面に合わせて変える（P4 の反復＝この場面が P4 の続きだと分かる／動詞の差＝同じ場面ではないと分かる）。
- 送信の灯りが**一度も点かない**のがこの場面の全部。P4 は嘘を送り、場面Aは削って送り、ここは送らない。
- **選択の設計**: レイの闇は「読まれない・見られていない」なので、三択とも**「読む」という動詞**で組んだ（場面Aが「削る」で組んだのと対になる）。ぶっきらぼう＝まだ読んでいないという事実だけ／やさしい＝全部読むと引き受ける／ふざけ＝通知の文面をまねる。**送信ゼロ件の投稿カードを見せた直後に、あなたが送る**——この場面の意味はそこにある。ミナは一度も「行きましょう」と言っていない。

**行数**: 12行（表示台詞9・投稿3・あなた1。演出行と分岐受けは数えない）。

## 既存台詞の監査 — ミナ側に動機が寄っている行（2026-09-08 指示）

「感情由来の動機（＝落とす）」と「手続き・業務としての言い方（＝残してよい）」を分けた。**実装は別途**。

### A. 感情由来の動機 — 落とす（★＝ユーザー名指し済みの型）

### C. 「行きます」の扱い — 判断が要る

本指示を最も厳密に取ると、**ミナの「行きます」は全部あなたの選択の後ろに来るべき**になる。ただし全廃すると、

- 面の導入（S2-1・S3-1）が「観測の報告」で終わって**入口が閉じない**（誰も出発を宣言しない）
- ハブでカードを選ぶ＝あなたの出発の意思表示、と読めるので、**面の導入で改めて宣言する必要が本来無い**

という二点が同時に立つ。この草稿の推しは **「潜るかどうかを決める場面（P4・場面A・場面B・ハブ初回）ではミナに『行きます』を言わせない。既に潜ると決まった後の場面（面の導入・出撃の返事）では『まいります』＝報告として残す」**。動機の宣言と、出発の報告を、語で分ける（**行きます＝決意／まいります＝報告**）。→ [判断を仰ぐ点 ⑤](#判断を仰ぐ点)

## 判断を仰ぐ点

1. **場面Aの位置**。ユーザーの原文は「ステージ1クリアして強化ショップの話が終わった後」だが、`ShopTutorial` は現状**初回の中ボス撃破後（＝あかり面の途中）**に出る。素直に読めば「あかりクリア後のハブ」で、この草稿はそちらに置いた。**ショップ説明そのものをあかりクリア後へ移す**意図なら、進行の設計から変わる（ショップの初回開放位置の変更）。どちらか確認したい。
2. **場面Bの2行目**（「わたくしの視聴者は……減っていないぶん、優秀です」）は、仮台本 07 の H3r 再訪小話（レイクリア**後**）の2行と発想が近い。場面Bで先に使うと、H3r の小話が弱くなる。**(a) 場面Bで使い、H3r の小話は別の軽口に差し替える／(b) 場面Bの2行目を別の軽口にする**。推しは **(a)**——「自分の視聴者は一人」の軽口は、レイに**潜る前**に置いたほうが、レイの同接と重なって効く。H3r 側は「笑顔の練習」の小話（07 に既存）だけで足りる。
3. **投稿カードの枚数**。P4 は日常2枚＋声の主1枚の計3枚。この草稿も3枚で揃えたが、二回目・三回目は**日常1枚に減らして短くする**案もある（三回目ほどテンポを上げる）。現状は「同じ形だと分かること」を優先して3枚で揃えた。
4. **場面Bの smile**。炎上の直後に軽口を置くのが強すぎるなら落とせる（`mina_face` にして文はそのまま成立する）。この草稿は「笑うを覚えたばかりのミナが、覚えた直後に一度だけ使い、そのあと消された声を聞いて顔が戻る」という落差を狙って置いている。
5. **「行きます」の線引き**（上記 §C）。**決意＝行きます（あなたの選択の後にしか置かない）／報告＝まいります（面の導入・出撃の返事では可）**、という分け方でよいか。これを採ると `StageKoharu.cs:61` と `StageRei.cs:82`（同文の「行きます。——放っておけないので。」）は両方とも申告形に書き換わり、**面の導入から出発の宣言が消える**。ハブでカードを選んだ時点で出発は決まっている、という読みに立つなら問題ないが、面の入口が静かになるので好みが割れる。
6. **選択予算**。[05 場面表](05_場面表_案C.md) は「1会話につき1回」「冒頭3箇所」を目安にしている。この二場面で**選択が2箇所増える**（ハブ側に新設）。道中の選択（17）と合わせた総数が予算内かは、場面表側で数え直しが要る。
7. **選択IDと【散】の扱い**。場面A・場面Bの候補を `ScatteredWords` に積むと、**FINAL の頂点で戻ってくる候補が2セット増える**。頂点はプロローグ P2 で散った言葉を最重要に置く設計なので、そこが薄まらないか。候補を散る語に**数えない**（選択はするが保存しない）案も取れる。推しは**積む**——「送らなかった言葉が増えるほど FINAL が重くなる」のはこの作品の原則そのものなので。
