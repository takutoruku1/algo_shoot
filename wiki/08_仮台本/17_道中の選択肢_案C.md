案C・**ユーザー承認済み（2026-09-06「この6か所でよい」）**・組み込み中。決定: ミナの受けで推定を言う箇所には「推定です」を添える。

> **この記事の範囲**: 検討中の草稿。ゲーム本体には入れていない（非正典）。プレイ所感「道中の会話に選択肢がないから、淡々とゲームが進む」を受けて、各面の道中に「あなたの下書き」の選択を **2か所ずつ、合計6か所** 足す下書き。既存の選択（P2・P3・P4・S1-4・S3-7・F4・E2・E6）には触れない。場面 ID と行数の枠は [05_場面表_案C](05_場面表_案C.md)、台詞の前後は [06_粗い台本_案C_1_冒頭とあかり](06_粗い台本_案C_1_冒頭とあかり.md)・[07_粗い台本_案C_2_こはるとレイ](07_粗い台本_案C_2_こはるとレイ.md) に接ぐ。人物は [12_キャラ設定シート v3](12_キャラ設定シートv2_社会人版.md) を正典とする。

## 書式と決まり

- 話者は「あなた」「ミナ」「投稿」「本人（あかり／こはる／レイ）」。会話は「」のみ。who・face は末尾の付録にまとめる。
- `// ―― 下書き選択 ――` の行に候補を書き、直後に選ばれた例を1行。分岐の受けは箇条書き（06 の命名の場面と同じ書き方）。
- 各3択＋（送らない）。三つの言葉は **ぶっきらぼう／やさしい／ふざけ** の三つの温度で組む（05「選択肢の温度」）。（送らない）がいちばん冷たい温度を担う。例外は S3-5c で、ふざけ枠の代わりに **ミナ自身の一件** を混ぜる（後述）。
- **言い回しの決まり**（05）: あなたが男か女か分からない言葉にする。命令形と語尾の「か／な／ぞ／よ／わ」を使わず、て形・言いかけ・体言止め・「そっか」「ありがとう」のような口語で組む。
- ミナの受けは一行。温度を評価しない（「やさしいですね」と言わない）。観測で返す。内心は説明しない。
- 選ばなかった下書きは散る（既存の仕組み。散った言葉は FINAL の頂点と E1 の件数に戻る）。（送らない）は言葉ではないので散る語に数えない＝表示候補3件が丸ごと散る。
- 効果は場面ごとに **軽く一つ**。三つの言葉のどれにも「正解」を作らない（温度が違うだけ。効果は「送った」ことに付き、どの言葉を送ったかは台詞の一語にしか効かない）。（送らない）は既存の作法どおり【濁】微増（+0.02）で、代わりに散る語が一つ多い＝頂点で戻る言葉が増える。
- 選択が出るきっかけは場面の中に置く（本人の投稿の直後、中ボスの捨て台詞の直後、入力欄のカーソルが残った直後）。提示中は戦闘が止まる。沈黙14秒で末尾が灯り、20秒で（送らない）に落ちる（実装値）。1か所は、きっかけ1〜2行＋選択＋受け1行＋締め1行＝20秒以内で読める分量。
- 各面の本人の闇（あかり＝返して／こはる＝送れない／レイ＝見て）に、その面の二つの選択が両方とも触れる。ミナ自身の言葉の寄与は S3-5c（ミナの一件を混ぜる）と S3-2（暗い光のミナが「見えていますか」と聞く）に置く。

## STAGE1 あかり

### S1-2　小話・雨（想定 きっかけ1行＋受け1行＋締め1行）

06 の S1-2 は「雨の音は、嫌いではありません。……うるさい、と思いながら、消していないので。」で終わる。その直後に足す。返事の声がひとつも混じっていないフロアで、ミナが一度だけ、返事を待つ。言いかけで止めるので、問いの形にはしない。

```
ミナ「……ご主人様は。——雨。」
// ―― 下書き選択 ――  べつに ／ きらいじゃない ／ 置き傘、三本目 ／（送らない）      // 【散】拾。（送らない）で【濁】+0.02
あなた「きらいじゃない」
ミナ「……きらいじゃない、と。——わたくしと、同じ集計です。……それだけ、記録しておきます。」
ミナ「——では、先へ。声を、祓いながら。」
```

- 「べつに」→ ミナ「……べつに。——二文字。……このフロアで、はじめて拾った、返事の形です。」のあと締めへ
- 「置き傘、三本目」→ ミナ「……三本目。——傘立てに、空きは、あります。……色だけ、あとで教えてください。二本とも、違う色ですので。」のあと締めへ
- （送らない）／沈黙20秒 → ミナ「……無言。——雨の音だけ、続いています。」のあと締めへ

効果: 送った言葉があれば、次のハブの再訪小話は「雨粒」（06 H1r）が優先で出て、末尾の「……いまの間、{n}秒。」の前に一行入る。ミナ「……あのフロアで、雨は、{送った言葉}、と、いただきましたので。——集計に、入れてあります。」。（送らない）なら小話は変わらない。

### S1-5　中ボス・ね?（想定 きっかけ2行＋受け1行＋締め1行）

06 の S1-5 の捨て台詞「ぜったい、また会いに来てよね。ぜったいだよ?」と、ミナ「……あの人、降りやまない雨の奥へ。逃げるみたいに、消えてしまいました。」の直後に足す。問いだけが残る。あなたが答えるのは、いなくなった相手の代わりではなく、たまたま来た側として。宛先はミナが決めない。

```
ミナ「……「ぜったいだよ?」。——問いだけが、残っています。宛先は、こちらでは、ありませんが。」
ミナ「ご主人様。下書きが、開いています。……宛先は、わたくしが、決めません。」
// ―― 下書き選択 ――  宛先、ちがう ／ ぜったい ／ 傘、忘れてる ／（送らない）      // 【散】拾。（送らない）で【濁】+0.02
あなた「ぜったい」
ミナ「……ぜったい、と。——同じ言葉が、雨の奥と、こちらに、ひとつずつ。」
ミナ「……雨の奥へ、一通。——届いたかは、観測できません。」
```

- 「宛先、ちがう」→ ミナ「……はい。宛先は、ちがいます。——それでも、一通。取り消されずに、雨の奥へ。」のあと締めへ（「取り消されずに」は S1-10 の「取り消されていない一通」への遠い仕込み。ここでは一度きり）
- 「傘、忘れてる」→ ミナ「……傘立てに、二本とも、残ったままです。——傘なしで、雨の奥へ。……観測だけ、しておきます。」のあと締めへ
- （送らない）／沈黙20秒 → ミナ「……無言。——「ね?」は、雨の奥へ。返事の、ないまま。」のあと締めへ

効果: 送った言葉があれば、ハブの返信（06 H1r）のミナ側に一行足す。「ミナ→@akari 想いは、罪ではありませんよ。たとえ既読が、もう付かなくても。——あのフロアで、{送った言葉}、と、一通。送られていましたので。」。あかりの返信「……なんでだろ。あなたの言い方、誰かに似てる。」は一字も変えない。（送らない）なら返信は現行のまま。

## STAGE2 こはる

### S2-2　中ボス・ペンライト（想定 きっかけ2行＋受け1行＋締め1行）

07 の S2-2 の捨て台詞「はい、これ。ペンライト。振ってみて。楽しいから。ぜったい、楽しいから。」の直後に足す。押しつけられたのは、消えたままのほう。送れない人が、言葉の代わりに物を渡していった。受け取りの返事だけ、あなたに回す。

```
ミナ「……押しつけられました。ペンライト。——消えたままの、ほうです。」
ミナ「ご主人様。……手は、わたくしにありません。受け取りは、そちらで。」
// ―― 下書き選択 ――  あとで ／ 振ってみる ／ 電池、切れてる ／（送らない）      // 【散】拾。送ったら やさしさ +0.02。（送らない）で【濁】+0.02
あなた「振ってみる」
ミナ「……振ってみる、と。——光は、点いていませんが。……振る、と、点く、は、別の動作だそうです。」
ミナ「——先へ。「むだだ」の声を、祓いながら。」
```

- 「あとで」→ ミナ「……あとで、と。——期限は、ありませんね。……持っておきます。消えたままで。」のあと締めへ
- 「電池、切れてる」→ ミナ「……切れています。——本人も、たぶん、知っています。振っていましたので。」のあと締めへ
- （送らない）／沈黙20秒 → ミナ「……無言。——ペンライト、こちらに、残りました。消えたままで。」のあと締めへ

効果: 送った言葉があれば、やさしさゲージ +0.02。三つのどれでも同じ値（受け取った、ということにしか付けない）。（送らない）は【濁】+0.02 で、ゲージは動かない。

### S2-4 の直後　カーソル（想定 きっかけ2行＋受け1行＋締め1行）

07 の S2-4 は「……画面の中の笑顔は、いまの一行を、読んだでしょうか。——観測できません。向こう側ですので。」で終わる。入力欄は閉じず、カーソルだけが点いたまま、あなたの下書きが開く。P4 で言った「消された言葉は、消えていない」が、ここでは、あなたの側に向く。宛先は決めない。

```
ミナ「……入力欄の、カーソル。——まだ、点いています。」
ミナ「ご主人様。下書きが、開いていますね。……打って消しても、わたくしには、聞こえます。そのつもりで、どうぞ。」
// ―― 下書き選択 ――  打ってた ／ 消えても、あった ／ 続き、気になる ／（送らない）      // 【散】拾（この場面の散った語は F4 の枠の先頭）。（送らない）で【濁】+0.02
あなた「消えても、あった」
ミナ「……消えても、あった。——はい。ありました。……拾った一行の、隣に、置いておきます。」
ミナ「——カーソルが、消えました。……先へ。」
```

- 「打ってた」→ ミナ「……打ってた、と。——はい。打って、消して。……両方、見ました。」のあと締めへ
- 「続き、気になる」→ ミナ「……続きは、拾ってあります。——中身は、本人の前で。……ご主人様にも、まだ、ですよ。」のあと締めへ
- （送らない）／沈黙20秒 → ミナ「……三件。——消えても、聞こえます。……あの一行と、同じところに、置いておきます。」のあと締めへ

効果: この場面で散った言葉（送れば2件、送らなければ3件）は、FINAL の頂点（08 F4）で漂う悲鳴に **必ず** 混ざる。悲鳴に混ざる散った言葉には枠の上限があるので、「送れない」の場面で送らなかった言葉を先頭に入れる。他の場面の散った言葉は現行どおり出た順。

## STAGE3 星逢レイ

### S3-2　小話・暗い画面（想定 きっかけ1行＋受け1行＋締め1行）

07 の S3-2 は「わたくしの光と、あの数字と、どちらが薄いか。……比べません。どちらも、集計はしますが。」で終わる。その直後に足す。炎上で光の薄いミナが、この面で初めて、自分のことで一度だけ聞く。「見て」の面で、見えているかを聞くのはミナの側。

```
ミナ「……ご主人様。この部屋、そちらから、見えていますか。——わたくしの光が、少し、暗いので。」
// ―― 下書き選択 ――  見えてる ／ ちゃんと見てる ／ 同接、9 ／（送らない）      // 【散】拾。（送らない）で【濁】+0.02
あなた「見えてる」
ミナ「……見えてる、と。——では、このままで。暗いのは、こちらの都合ですので。」
ミナ「——祓います。「見て」の声を。……見ているのは、こちらですが。」
```

- 「ちゃんと見てる」→ ミナ「……ちゃんと、と。——一語、多いですね。……多いぶんは、集計に、入れておきます。」のあと締めへ
- 「同接、9」→ ミナ「……九。——右上の数字は、動きません。こちらは、向こう側の数に、入りませんので。……こちらで、ひとつ、数えておきます。」のあと締めへ
- （送らない）／沈黙20秒 → ミナ「……無言。——見えているかは、観測できません。……暗いまま、続けます。」のあと締めへ

効果: 送った言葉があれば、次のハブの再訪小話は「同接」（07 H3r）が優先で出て、二行目「減っていませんので、優秀です。……増えてもいませんが。」の直後に一行入る。「同接、9」なら ミナ「……九、と、いただきましたが。——こちらの集計では、一です。」、それ以外なら ミナ「……あの部屋で、{送った言葉}、と、いただきましたので。暗いまま、続けました。」。（送らない）なら小話は変わらない。

### S3-5c　道中C・三つの席（想定 きっかけ1行＋受け1行。締めは 07 の残り2行）

07 の S3-5c の一行目「右上の数字。「3」。……残った三つの席の、ひとつは、あの一行です。」の直後に足し、受けのあとに 07 の残り「……光が、重い。」「画面が、部屋を、呑みこんでいきます。」を続ける。ここだけ、ふざけ枠の代わりに **ミナ自身の下書き** を三つめに混ぜる。ミナはどれが自分のかを言わない。表記（です・ます）で気づける。気づくかどうかも、この場面の遊び。だれも中に気づかない部屋で、混ざった一件に気づくか。

```
ミナ「……ご主人様。ご報告を。下書きに、ひとつ、わたくしのを、混ぜてあります。——どれかは、言いません。」
// ―― 下書き選択 ――  見てる ／ ここにいる ／ 見ています ／（送らない）      // 三つめがミナの一件。【散】拾。（送らない）で【濁】+0.02
あなた「見ています」
ミナ「……それ、わたくしのです。——気づいて、いただけましたか。それとも、偶然か。……どちらでも。送られました。」
ミナ「……光が、重い。……気のせいでは、なさそうです。」
ミナ「画面が、部屋を、呑みこんでいきます。……奥に、笑顔だけが。」
```

- 「見てる」→ ミナ「……見てる、と。——はい。……わたくしのは、散りました。自分のぶんは、自分で、拾っておきます。」のあと 07 の残り2行へ
- 「ここにいる」→ ミナ「……ここにいる、と。——席が、ひとつ、こちらに。……わたくしのは、散りました。自分で、拾っておきます。」のあと 07 の残り2行へ
- （送らない）／沈黙20秒 → ミナ「……三件、散りました。うち、一件は、わたくしのです。——同じ棚に、置いておきます。」のあと 07 の残り2行へ

「見ています」は S3-8 の決定打「見ていました。——だれも見ていない場所に、あなたが書いて、消した一行を。」の現在形。送られていれば、決定打はあなたが送った言葉の過去形になる。散っていれば、ミナは自分で拾って、決定打で自分で言う。S3-8 の台詞は変えない。

効果: E4 の開示（08）の「あの日から、ひとつも、消していません。わたくしが、覚えている係ですので。」の直後に一行入る。送られていれば ミナ「——あの部屋で、わたくしの一件を、送っていただいたのも。覚えています。」、散っていれば ミナ「——あの部屋で散った、わたくしの一件も。自分で、拾ってあります。」。散った場合は既存の仕組みで、F4 の悲鳴の中に「見ています」が混ざる（ミナが抱えた悲鳴の中に、ミナ自身の言葉が一つ）。

| S3-5c | `s3_5c` | 見てる／ここにいる／見ています／（送らない） | E4 に一行（`ChosenAt("s3_5c") == "見ています"` で分岐） | 汚染 +0.02 | `choice_s3_5c` | STAGE3 の step 9（MidEnd）の一行目の直後 |

- 既定カーソルは末尾＝（送らない）。沈黙20秒の自動決定もそこへ落ちる（S1-4・S3-7 と同じ）。
- 【散】は表示候補3件のうち選ばれなかったぶんを計上（送れば2件、送らなければ3件）。同じ id で呼び直せば前回ぶんが取り消される（既存）。
- 汚染の +0.02 は S1-4・S3-7 の `SkipContam` と同じ値。やさしさの +0.02 は やさしさゲージの充填率に足す（充填の加算経路は既存。会話中に足すための入口が要るかは未確認）。
- 「既読キー」は既読スキップ（Ctrl 押しっぱなし）で止まる場面の識別子の案。選択で必ず止まる決まり（05）なので、キーが無くても動作は同じ。

### 実装メモ（どの step に挟むか）

- **共通の型**: S1-4 の三フェーズ型（問いまで流す → 選択を重ねる → 受け＋締めを流す。`RunLinesInPlace` と `ChoiceOverlay.Show(Hud, 候補, defaultSel: 末尾)`）をそのまま使う。会話配列を「きっかけ」「受け（3本＋無言）」「締め」に割り、提示中は `HoldBubble` でバブルを保持して弾・敵を止めたままにする。自動プレイは提示中も Z をパルスするので既定カーソルで即決され、詰まらない。
- **S1-2 / S1-5（STAGE1）**: 現行は中ボス（step 3）の直後が Mid（step 4）で、Mid の先頭2行が S1-5 の受け、残りが S1-2。つまり **二つの選択が同じ会話に入る**。05 の「1会話につき1回」に反するので、(a) S1-5 の選択を step 3 と 4 の間の新 step に切り、S1-2 の選択は Mid の末尾に置く（間に戦闘が無く二連続になる）か、(b) S1-2 の選択を step 6（S1-7 道中B、向かいの席の会話）の末尾へずらして道中Aを挟む、のどちらか。本記事の台詞は (b) でもそのまま使える（雨の言いかけは S1-7 の「返事の声だけが、ここまで来ても、ひとつも、ありません。」の直後でも成り立つ）。
- **中ボス撃破の直後に挟む場面（S1-5・S2-2）**: 初回の中ボス撃破は `CheckpointFlow.OnMidBossCleared` でショップ説明へ離脱し、以降の進行が止まる。選択を離脱の後ろに置くと初回は飛ぶので、離脱の前（撃破を確認した直後）に置く。再入場（中ボスから）で中ボスを再走すると選択も再走するが、同じ id の上書きなので二重計上しない。「ボスから」の入場では通らず、前回値が残る（S1-4 と同じ扱い）。
- **S2-4 直後**: 入力欄（`CommentInput`）は現行だと行を流し切った時点で閉じる。「カーソルが、まだ、点いています」を見せるため、選択が決まるまで入力欄を残し、締めの「カーソルが、消えました」で閉じる。空欄でカーソルだけ明滅する表示が要る（入力欄側の対応は未確認）。
- **S3-2**: Mid（step 2）の末尾。三フェーズ型で足すだけ。
- **S3-5c**: MidEnd（step 9）の一行目の直後。受けのあと、現行の二行目・三行目へ戻す。この直後がボス戦で、戦闘中に S3-7 の割り込み（step 15〜17）が来る。S3-5c → ボス → S3-7 と、選択が短い間隔で二つ並ぶ。密度が高すぎるなら S3-5c の選択を S3-3（step 4 BossTalk）へ前倒しする案もあるが、「三つの席」「光が重い」の直後に置く意味が薄れる。
- **候補が4件**: 既存の ChoiceOverlay は 2〜4 択に対応しているので、3択＋（送らない）の4件は収まる。行間90pxで4件だと縦の占有が 270px 前後になり、吹き出しと重なるかは要確認。
- **ミナの一件（S3-5c）**: 候補配列に「見ています」を入れるだけで、選択の仕組みは他と同じ。散った場合は `ScatteredWords` に「見ています」が入り、F4 と E1 の件数に乗る。E1 の「あなたが選ばなかった下書き——{n}件」にミナの一件が一つ混ざることになる。E4 で白状する側に回るので矛盾はしないが、E1 の文言を「選ばなかった」のままにするかは判断待ち。
- **F4 の枠**: 現行の頂点は固定の悲鳴10語に散った言葉を足して合計30件まで（固定側が22件を占め、散った言葉は8件まで）。本記事で選択が6か所増えると散った言葉は最大で二十数件になるので、枠を広げるか、S2-4 の散った語を先頭に入れた上で残りを抽選にするかを決める。
- **ハブの返信・再訪小話への差し込み**: 返信（`ReplyDialog`）と再訪小話（`IdleDialogs`）は文字列の表なので、`ChosenAt(id)` を読んで一行足す分岐を入れる。あかり・こはる・レイの返信本文（「誰かに似てる」「知らない人」「誰よあんた」）は文言固定のまま触らない。
- **セーブ**: `RecordChoice` の台帳（散った語・迷い秒数・送った語）は既にセーブに載る。新しい id を足すだけで後方互換。
