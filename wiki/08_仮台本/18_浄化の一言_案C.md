# 浄化の一言 案C

案C・未承認・ユーザーの許可後に組み込む。

> **この記事の範囲**: 検討中の草稿。ゲーム本体には入れていない（非正典）。道中の敵を浄化した瞬間に頭上へ浮く一語を、全面共通の五語から、面ごとの語に差し替える下書き。語の意味づけは [05_場面表_案C](05_場面表_案C.md) の三人の闇（あかり＝返して／こはる＝送れない／レイ＝見て）と FINAL（ミナ自身）に合わせ、投稿の本文は [09_投稿文集](09_投稿文集_X風.md)、人物は [12_キャラ設定シート v3](12_キャラ設定シートv2_社会人版.md) を正典とする。後半に、あなたが道中で送った言葉を浄化の一語に混ぜる仕掛けの案を置く。

## 現状と狙い

いまは、どの面でも浄化のたびに「ありがとう」「だいじょうぶ」「きみは悪くないよ」「ごめんね」「また話そう」のどれかが浮く。慰めの語で、面の物語と繋がっていない。

この草稿では、浮く一語を **その投稿の下にあった声** にする。道中の敵は X の投稿の穢れ（言葉であって本人ではない）で、浄めた瞬間、その投稿を打った人が本当は置きたかった一語が、ひとつだけ浮いて消える。面ごとに「下にあった声」の出どころが違う。

| 面 | 敵（投稿の穢れ） | 下にあった声 |
|---|---|---|
| STAGE1 あかり | 送信取消の束、向かいの席の机、「すき」の吹き出し | 取り消した本文の側。返ってこないと分かっていて、それでも置きたかった一語 |
| STAGE2 こはる | 「むだだ」の声、教室の机と椅子、届かないペンライトの光 | 打って消した入力欄の側。「今日も来ました」の隣に、本当は足したかった一語 |
| STAGE3 レイ | 灰色の初期アイコン、空の吹き出し、顔のない引用 | 顔のないアイコンの下にいた人の側。見ていたのに、書かなかった一語 |
| FINAL | 悲鳴の言葉、三人の変質した投稿 | ミナ自身の、悲鳴の下の声。です・ます調のミナ語 |

決まり: 1語は 2〜7 文字。説教語（がんばれ／大丈夫／悪くない）は置かない。慰めではなく、その人の側の言葉にする。[05](05_場面表_案C.md) の「言い回しの決まり」に従い、命令形と語尾の「か／な／ぞ／よ／わ」は使わない（性別が出ない）。改心の決定打で使う語（「読みました」「八十七回」「見ていました」）と、道中の選択肢の候補（[17](17_道中の選択肢_案C.md)）は、固定の語には入れない。消した一行そのもの（「おめでとう」「レイちゃんが」「気づいてよ」）も入れない。浮くのは一歩手前の語まで。

## 仕掛けの案: 送った言葉が、相手の上に浮く

道中の選択（[17](17_道中の選択肢_案C.md)）であなたが送った言葉を、その面の残りの浄化で **3回に1回** 混ぜる。自分の言葉が、浄めた相手の上に一瞬だけ浮いて消える。ミナはそれを口にしない。色も大きさも固定の語と同じで、区別の印は付けない。気づく人だけが気づく。

- 起点は、その面で選択が決まった瞬間。それより前の浄化は固定の語だけ。
- 乱数ではなく数える。選択のあとの浄化を1体目から数え、3体目・6体目・9体目……に送った言葉が浮く。必ず一度は見える。
- 一つの面に選択が複数あるときは、直近に送った言葉。あかりは S1-2 → S1-4 → S1-5 の順で上書き、レイは S3-2 → S3-5c → S3-7。
- （送らない）を選んだ場合は混ぜない。散った言葉は FINAL の頂点（F4）の分で、ここでは浮かべない。
- 中ボスとボスの改心の一語は数えず、固定の語を引く（ボスに送った言葉を浮かべる案は、下の判断点）。
- FINAL は混ぜない。【初】が F4 で戻ってくる前に見せない。

S3-5c で「見ています」（ミナの一件）を送っていた場合、レイの面の残りでは「見ています」が浮く。あなたが送ったミナの言葉が、顔のないアイコンの上に浮く。ミナはそれも口にしない。

## 付録: 効果の値と条件

| 項目 | 値・条件 |
|---|---|
| 表示 | 敵の位置の 10px 上に一語。色は現行の浄化と同じ（Sig2）、大きさ 9、寿命 0.7 秒、上昇 26px/s。現行の値を変えない |
| 固定の語の引き方 | その面の表から、直前に浮いた語と違う語を引く（同じ語が二連続しない） |
| 混ぜる割合 | 3回に1回。選択後の浄化数 n を数え、n を 3 で割り切れるとき送った言葉 |
| 元になる語 | あなたが送った言葉の台帳。あかり `s1_2`／`s1_4`／`s1_5`、こはる `s2_2`／`s2_4`、レイ `s3_2`／`s3_5c`／`s3_7`。直近の空でないもの |
| （送らない） | 混ぜない。カウンタは回さない |
| 中ボス・ボス | 数えない。固定の語 |
| FINAL | 混ぜない。ミナ語 7 語のみ |
| 練習・面不明 | 共通の予備 4 語 |
| 再開・周回 | 台帳はセーブに載るので、「ボスから」入場でも前回に送った言葉が残る。「はじめから」で消える（既存の作法） |
| 【濁】・やさしさ | 動かさない。表示だけの仕掛け |

## 判断を仰ぎたい点

- **指揮官の決定（2026-09-06）**: 1「既読」は使わず「読んだ」に。2 ボスの改心は固定語。3 混ぜた語に印は付けない。4 FINAL はです・ます調のまま。5 S3-8 に「はじめまして」は足さない（沈黙を太く）。6 仕込みの変化（大きさだけの差）は受け入れる。7 中ボスのボスバー名はボスと同じ「星逢レイ @hoshiai_rei_live」。残りはユーザーの承認のみ。
- **「既読」を浮かべてよいか**（決定済み: 使わない）。05 では、ミナの決定打で「既読、です」を単独で使わないと決めている。浮く一語はミナの言葉ではなく投稿の下の声なので別扱いにしたが、画面上は同じ語が出る。
- **ボスの改心で送った言葉を浮かべるか**。こはるに「消えても、あった」、レイに「つづけて」が浮くのは効くが、あかりに「宛先、ちがう」が浮くと外れる。本案は固定の語にしている。
- **混ぜる印を付けるか**。本案は色も大きさも同じ。気づかない人には固定の語に見える。
- **FINAL の語をです・ます調で揃えるか**。悲鳴の中で丁寧語が浮くのは、ミナらしさでもあり、浮いて見えるかもしれない。

## 実装メモ

- 現行は `Enemy.cs` の `KindWords`（5語固定・乱数）を `PickKindWord()` で引き、`Redeem` の浄化演出で `FxLayer.DamageNumber(位置+(0,-10), 語, Sig2)` に渡している。中ボス（`CameoBoss`）とボスも同じ経路を通る。
- 差し替え先: 面ごとの配列 `PurifyWordsAkari`／`PurifyWordsKoharu`／`PurifyWordsRei`／`PurifyWordsMina`／`PurifyWordsCommon` と、面の識別子（`akari`／`koharu`／`rei`／`mina`／それ以外）で表を選ぶ関数。敵は面を知らないので、各面のステージが開始時に面の識別子を静的に立て、練習や面の外では空に戻す。FINAL のステージは `GameManager.Stages` に無いので、シーンのパスから引くのではなく明示で `mina` を立てる。
- 送った言葉: `GameManager.ChosenAt(id)` を上の id の順に読み、空でない直近を採る。`HasChoiceAt` が全て偽なら混ぜない。選択が決まった時点でカウンタを 0 に戻す（`RecordChoice` の直後、または面側の選択の受けで）。
- 中ボス・ボスの除外: `CameoBoss` とボスの `Redeem` はカウンタを回さず固定の語を引く（敵の種別で分ける）。
- 承認後に直す正典ページ: [02 世界観](../02_世界観.md)、[04 キャラクター / 06 その他](../04_キャラクター/06_その他.md)、[05 ゲーム仕様 / 06 ボス戦](../05_ゲーム仕様/06_ボス戦.md)、[05 ゲーム仕様 / 11 音楽と演出](../05_ゲーム仕様/11_音楽と演出.md) の「ありがとう／だいじょうぶ／きみは悪くないよ／ごめんね／また話そう」の記述。
