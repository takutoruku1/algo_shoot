# キャラ設定シート v2（社会人版）

> **この記事の範囲**: 検討中の設定案。非正典・未承認で、ゲーム本体のコード・データ・画像は一切変更していない。方針B「ヒロイン三人とも社会人にする」を、案C（少年なし・ご主人様＝あなた・ミナは観測できたことしか言わない・改心は「消された一行を返す→ミナ自身の言葉」の証人型）の上に置いたときの人物像を、三人ぶん並べる。対象は 20代後半から30代後半の、社会に組み込まれて現実に疲れている人。闇の芯と名前は現行のまま、状況だけを大人に移す。

## 共通方針

- 年齢は 27・30・34 に散らす。同じ疲れでも、まだ間に合うと思っている歳、追い抜かれ始める歳、もう言えないと決めた歳で顔が変わるので、三人で三つの歳を担う。作中で数字は出さない。「三十手前」「この歳で」までにとどめる。
- 仕事は名詞だけ借りる。役職・同期・有給・定時・面談・社員証・置き傘・1K。会社名、業界、年収の数字は出さない。
- 三人は現行どおり互いに他人で、面の中で交わらない。ハブの返信とFINALの援護で初めて同じ画面に並ぶ。
- 三人の芯は不変。レイ＝比べる指、あかり＝確かめに行く指、こはる＝止められない手。芯を撃つ細部は [02_共感ポイント](02_共感ポイント.md) の三本をそのまま持ち上げる。
- あなたは大人で、三人と同じ側にいる。だから道中の投稿は「昔の自分」ではなく「今日の自分」として流れる。ミナはそれを知らないし、言わない。
- 口調は現行を保つ。大人にしたからといって敬語にしない。レイの「〜なんだから」、あかりの「〜てね?」、こはるの「〜もん」は、家に帰ってスマホに向かうときの声として残す。

## レイ

- **一行の像**: 30歳。企画部門の会社員で、今年、同期でいちばん早く役職がついた。会社から二駅の1LDKに一人。表示名「レイ」、メイン @rei_____、技を宣言するときだけ @rei_compete、改心後の返信では @rei。
- **闇の芯と起点**: 芯は比較。役職がついた日から、同期の報告に「おめでとう」が押せなくなった指。起点は、辞令が出た日の昼。いつも一緒に社食でカレーを食べていた同期が、弁当を持って別のフロアへ行った。半年後、その同期は転職して、転職先の話をタイムラインに書くようになった。それだけ。
- **生活の細部**:
  - 弁当は作らない。社食のカレーを12分で食べる。ひとりだと早い。
  - 通知は全部切ってある。それでも午前二時に自分から開く。
  - 有給は、消化率の警告が人事から来るまで取らない。
  - 実家から届く荷物は米で、箱に「昇進祝い」と書いてある。
  - 洗濯は日曜にまとめて。ハンガーの数がちょうど一週間ぶん。
- **SNSでの姿**:

| 層 | 本文 |
|---|---|
| 1 | 辞令 出ました 以上 |
| 2 | 同期の転職報告 今月3件目 おめでとうは打った 打った |
| 3 | 2:14 同期の転職先 三秒だけ見て閉じた いいねは押してあげないんだから |
| 3 | 昼休み 12分で終わった ひとりだと早い |
| 3 | 役職ついてから 誰もわたしに愚痴を言わなくなった それの何がいけないの |
| 下書き | だれか追いついてよ |

- **面の舞台**: 「終わりのない査定会場」。会議室の長机が果てなく続き、正面の大画面に同期の順位表。「１位」だけ白飛びして読めない。無数の目は評価者の目で、監視カメラの敵はそのまま使える。ホワイトボードの隅の落書き「今日のカレーうまかった」も社食の話としてそのまま置ける。作り直すのは、一位の隣の空席を「長机の隣の席、弁当箱が置いたまま」にすること。表彰台のボス背景は社内表彰の壇としてそのまま生きる。
- **道中の共感の細部**:
  - 隣の席の弁当箱。蓋が閉まったまま、毎日同じ位置にある。
  - 「てっぺんは、こんなに寒いんですか」の会場に、面談の声「がんばってるね、で終わる」が混じる。
  - 投稿「三秒だけ見て閉じた」の直後、順位表の二位以下の行が全部同じ顔になる。
- **中ボスの姿**: 先出しの本人。ジャケットを脱いだブラウスに、首から社員証。社員証の役職欄だけ白飛びしている。片手にスマホ、画面は伏せてある。第一声「——だれ? あなた。わたしの査定に、勝手に入ってこないでくれる?」捨て台詞「逃げたら……承知しないんだから。」は現行維持。
- **改心の決定打**: 消された一行は「だれか追いついてよ」で現行案と同じ。式の語彙は使えないので、ミナは隣の席を見ていた証人として言う。

```csharp

(1, "——消された一行を、拾っておりました。「だれか、追いついてよ」。", ""),
(1, "わたくしが、追いつきました。——隣の席、ずっと空いていましたので。", "mina_face"),   // ここでBGM停止
(2, "…………。", "rei_face_cry"),
```

- **救済後の実在感**: 改心後の投稿「次は本気のあなたと 逃げたら承知しないから」。ハブの返信「は?誰よあんた」。スタッフロール「昼 隣の席の人と社食 カレー 12分じゃ足りなかった」。
- **失う資産**: 三年前の地区予選と二十二分・二十三分は案Cで既に消えている。加えて、式・証明・合格の語彙のうち「式の最後の一行」、模試を前提にしたロール投稿、パーカーと「2位」の名札、カットインの受験生らしい若さ。「合格。なんて言ってあげないんだから」は面談の採点者の言葉として残る。
- **流用できる資産**: 中ボスの全行、ボス戦の挑発二行、弾幕名『凡人の定理』『敵などいない』『孤高の王座』、カットインの一言、順位表の反転演出、監視カメラの敵、表彰台の背景、返信「は?誰よあんた」。『Q.E.D.』は判断が要る点に回す。
- **絵の発注メモ**: 立ち絵は白いブラウスに黒のタイトスカート、首に社員証、髪は現行の色と長さを保って後ろでまとめる。年齢感は三十手前、目の下にうっすら影。表情は平常、泣き顔、そして中ボス用に「画面を伏せる」半目の三種。敵形態は順位の帯がそのまま社員証のストラップに変わって体に絡む方向。中ボスは立ち絵の平常にスマホを持たせた差分で足りる。

## あかり

- **一行の像**: 34歳。総務の会社員。駅から徒歩十八分の1Kに一人。表示名「あかり」、メイン @akari.、技を宣言するときだけ @akari_ame、改心後の返信では @akari。末尾の「.」は、送信取消のあとに残った一文字。
- **闇の芯と起点**: 芯は承認。渡せなかった気持ちの行き場を、既読の付かない通知画面に代行させる指。起点は、同じ部署にいた同僚の送別会の夜。帰りの電車で「あたしも、」まで打って送り、三秒で取り消した。翌週、相手の転職先が決まって、それきり既読が付かない。相手の性別も名前も出さない。
- **生活の細部**:
  - 通知は全部オン。アイコンのバッジの数字が消せない。
  - 送信取消は三秒以内が癖になっている。三秒を過ぎると、消せないと思って寝る。
  - 会社の置き傘は二本。一本は自分のではない。
  - 実家からの電話は「元気」の一言で切る。切ったあとに、その一言も取り消したくなる。
  - 昼は、前にその同僚と行っていた店のサラダを一人で買う。
- **SNSでの姿**:

| 層 | 本文 |
|---|---|
| 1 | 雨 置き傘 会社に忘れた 駅まで走る |
| 2 | 向かいの席 空いたまま 3日目 |
| 3 | いいね1 増えてないの知ってるのに今日だけで四回も見にきちゃった |
| 3 | 0:40 通知 開いて閉じて開いた 既読 まだ |
| 3 | 送信取消 今日で12回目 全部同じ人宛 |
| 下書き | おめでとう ほんとだよ 元気でね |

- **面の舞台**: 「雨の降りやまない、退勤後のフロア」。誰もいないオフィスで、デスクとチェアが天井へ落ちていく。ホワイトボードと全部のモニタが「すき」で埋まる。ノートは、社内チャットの「メッセージの送信を取り消しました」が縦に積み上がった束に置き換える。窓ぎわの空いた机は「向かいの席、中途の人がまだ来ない席」に。ボス戦の「雨の帰り道」の通路はそのまま使える。教室の背景、机と椅子の敵、ノートと教科書の敵は作り直し。
- **道中の共感の細部**:
  - 送信取消の束。取り消しの行だけが並んで、本文はひとつも残っていない。
  - 向かいの席のモニタが暗いまま、キーボードの上に付箋が一枚。文字は読めない。
  - 投稿「四回も見にきちゃった」の直後、通知の吹き出しが「1」のまま四つ同じ形で降ってくる。
- **中ボスの姿**: 先出しの本人。退勤後のカーディガン、首から社員証、片手にスマホで画面の光が顔に当たっている。第一声「あ、来た来た。ねえ、あなた、あたしの、見てくれた? 見た? 見たよね? ね?」捨て台詞「ぜったい、また会いに来てよね。ぜったいだよ?」は現行維持。
- **改心の決定打**: 束の底に、取り消されていない本物が一通ある。宛名なし。ミナは取り消された言葉をぜんぶ弾として浴びた証人として言う。

```csharp

(1, "束の底に、一通だけ、取り消されていないものが。「おめでとう ほんとだよ 元気でね」。", ""),
(1, "取り消された言葉を、ぜんぶ浴びてきました。——汚れた“好き”は、ひとつも、ありませんでした。", "mina_face"),   // ここでBGM停止
(2, "……ぁ……", "akari_face_cry"),
```

- **救済後の実在感**: 改心後の投稿「ほんとバカなんだから あたしもだけど」。ハブの返信「あなたの言い方 誰かに似てる」。スタッフロール「向かいの席 中途の人来た 自分から話しかけた 既読とかない 顔見て言った」。
- **失う資産**: セーラー服、教室の背景、黒板、机と椅子の敵、ノートと教科書の敵、「教室で会ったら言えないから夜に打つ」の投稿、転校の設定、隣の子に話しかけたロール投稿。傘と交差点と「キミ」呼びは案Cで既に消えている。
- **流用できる資産**: 中ボスと捨て台詞の全行、「ひとりにしないで」「来ないで……っ」、弾幕名『ねえ、こっち見て』『すきって言って』『ずっと一緒』『離さない』、カットインの一言、「バカ」の三段、「既読も三秒でつけるし」は大人のほうがよく刺さる、雨、黒板の「あたしのせいだ」が「ありがとう」になる反転はホワイトボードに移して同じ演出、返信「誰かに似てる」とFINALでのレイの反転回収。
- **絵の発注メモ**: 立ち絵は淡い色のカーディガンにブラウス、社員証、髪は現行より少し短く。年齢感は三十代半ば、化粧は落としかけ。表情は平常、泣き顔、中ボス用の「画面の光を浴びた」顔の三種。敵形態は雨とチェーンの穢れを、通知のバッジと取り消し線の帯に置き換える方向。背景は雨の夜のオフィスで、窓ぎわではなく向かいの席を空けて描く。

## こはる

- **一行の像**: 27歳。受付と事務の仕事で、職場では明るい人で通っている。兄と二人で借りた2DKに一人。表示名「こはる」、メインも改心後の返信も @koharu、技を宣言するときだけ @koharu_kitchen。アカウントを演じ分けないのは現行のまま。
- **闇の芯と起点**: 芯はむだ。帰らない人のぶんの夕食を作り続ける手。期限の切れたプリンを、捨てない、食べない手。起点は、兄が「しばらく帰らない」とだけ言って荷物を減らして出た夜。テーブルに二人分の夕食が残った。こはるはそれを翌日も作った。兄はそのまま帰らず、年齢だけ上がっていく。連絡は年に数回のスタンプだけで、死は書かない。
- **生活の細部**:
  - 炊飯器は三合炊き。一人分の目盛りを見たことがない。
  - 冷蔵庫のプリン。扉を開けるたびに視界の隅で確かめて、閉める。
  - 玄関の電気はつけたまま寝る。
  - 給料日に職場へ配るお菓子を買う。明るいね、と言われる。
  - 実家からの荷物に「お兄ちゃんにも分けといて」とメモが入っている。

## ミナと「あなた」

ミナは変更なし。一人称、口調、観測しか言わない憲法、空の問い、汚染の抱え方、いずれも動かさない。あなたが大人になったことで変わるのは、観測芸の材料だけ。

- 起動時刻が本物の観測値になる。R1の起動日時と同じ仕組みで、冒頭②の受けに一度だけ「起動時刻、{hh:mm}。集計に入れておきます」を置ける。遅いとも早いとも言わない。
- 冒頭④の「たすけて」を三回消した投稿は、大人のタイムラインの中に沈んでいるほうが見つけにくく、見つけたときに重い。層1を厚くする。
- ハブ再訪の小話で、ミナの「本日の業務は以上です」「業務連絡です」の言い回しが、あなたの側の言葉と同じ温度になる。ここは足さず、既存行の意味が勝手に変わるのに任せる。
- 「外の世界は、今日はどんな天気ですか」に大人が答えないのは、答えを知らないからではなく、見ていないから。行は変えない。
- 三人の投稿が「昔の自分」ではなく「今日の自分」になるので、[09_投稿文集](09_投稿文集_X風.md) の「層3 と大人の読み手」節の変換の理屈は消える。代わりに層3の文面そのものを大人の細部で書き、層1・層2との段差を小さくする。段差が小さいほど、見つけたときの落差が大きい。

## 判断が要る点

1. **こはるの兄をどこまで生かすか。** 本記事は「疎遠、年に数回のスタンプ、死は書かない」を置いた。生存を一つも示さない現行案のままだと、大人の読み手は死を先に読む。スタンプ一つで生きていると分かるほうが、こはるの「むだ」は軽くならず、むしろ重くなる。ただし兄の年齢を上げる描写をどこに置くかは未決。
2. **あかりの相手の性別と名前。** 出さない案で書いた。「同僚」だけで通し、中ボスの「見てくれた?」も既読の話として成立する。出すなら、社会人の恋の話に一気に寄るので、承認の芯がぼやける。
3. **レイの空席の相手。** 同期が転職して「上へ行った」案で書いた。追いついた側が置いていかれる反転が芯に合う。同期がまだ社内にいて別フロアで昼を食べている案は、空席が生々しくなる代わりに、順位表の反転が弱くなる。
4. **弾幕名『Q.E.D.』と式の語彙。** レイの数学の匂いは、会社員になると浮く。『Q.E.D.』を『査定済』に替えるか、レイの趣味として残すか。他の三つは動かさなくてよい。
5. **口調の幼さをどこまで残すか。** あかりの「ね?」の連打とこはるの「もん」は、家でスマホに向かう声としては大人でも成立するが、中ボスで画面に出る顔と合わせたときに違和感が出るかは、絵が上がってからでないと判断できない。
