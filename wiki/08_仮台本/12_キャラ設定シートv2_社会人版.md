# キャラ設定シート v3

> **この記事の範囲**: 検討中の設定案。非正典・未承認で、ゲーム本体のコード・データ・画像は一切変更していない。v2（三人とも社会人）を差し替える第三版。面の順番は STAGE1 あかり、STAGE2 こはる、STAGE3 レイ。読者は20代後半から30代後半の、社会に組み込まれて疲れている人だが、キャラをその年齢に合わせることはせず、読者が「自分にもある」と思える闇を、三人がそれぞれ別の年齢と立場で持つ。案C（少年なし、ご主人様＝あなた、ミナは観測できたことしか言わない、改心は消した一行を返してからミナ自身の言葉で決定打を打つ証人型）は維持する。

## 共通方針

- 年齢と立場を散らす。会社員三十歳、高校生、二十四歳の配信者。読者は自分と同じ立場の人にではなく、自分と同じ手つき（返事を待つ指、打って消す手、数字を見比べる指）に刺される。v2 の「三人とも会社員」は、立場を揃えたぶん手つきまで似て見えたので戻す。
- 名前は据え置き。レイだけ、姓の付いた配信名「星逢（ほしあい）レイ」を名乗る。本名は作中に出さない。
- 三人は互いに他人で、面の中で交わらない。例外は、こはるの推しがレイであること。片方向で、こはるは知っていてレイは知らない。ミナはこの繋がりを口で説明しない。ハブの返信と FINAL の援護で初めて同じ画面に並ぶ。
- あなたは三人と同じ側にいるが、同じ立場ではない。道中の投稿は、あかりの面では「今日の自分」として、こはるとレイの面では「昔の自分」か「隣の誰か」として流れる。ミナはそれを知らないし、言わない。
- 動詞を分ける。あかりは「返して」（既読と返事）。レイは「気づいて」「見て」。こはるは動詞ではなく「送れない」（打って、消す手）。三人の SNS の位置は、あかり＝送ったのに返ってこない、こはる＝送れない、レイ＝返ってきたものに心がない。互いに重ねない。あかりの中ボスの「見てくれた?」は返事側へ寄せ、「見て」はレイに譲る。
- 口調は現行を保つ。あかりの「〜てね?」、こはるの「〜もん」、レイの「〜なんだから」は動かさない。
- 表記と文体は大人向け。見出しは漢字、説明は最小限。本人の投稿には年齢の分かる語を使わず、層1・層2 の社会人の投稿と同じ顔で沈める（[09_投稿文集](09_投稿文集_X風.md) の「見つける」を保つため）。

## あかり（STAGE1）

- **一行の像**: 30歳。総務の会社員。駅から徒歩十八分の1Kに一人。表示名「あかり」、メイン @akari.、技を宣言するときだけ @akari_ame、改心後の返信もメインのまま。末尾の「.」は、送信取消のあとに残った一文字。
- **闇の芯と起点**: 芯は承認、動詞は「返して」。返事がほしい。既読がついて、そのあとに返事がほしい。起点は同じ部署にいた同僚の送別会の夜。帰りの電車で「あたしも、」まで打って送り、三秒で取り消した。翌週その同僚の転職先が決まり、それきり既読が付かない。相手の性別も名前も出さず、向かいの空いた席で示す。
- **生活の細部**:
  - 通知は全部オン。バッジの数字が消せない。
  - 送信取消は三秒以内が癖。三秒を過ぎると、消せないと思って寝る。
  - 会社の置き傘は二本。一本は自分のではない。
  - 実家からの電話は「元気」の一言で切る。切ったあとに、その一言も取り消したくなる。
  - 昼は、前にその同僚と行っていた店のサラダを一人で買う。
- **SNSでの姿**:

| 層 | 本文 |
|---|---|
| 1 | 雨 置き傘 会社に忘れた 駅まで走る |
| 2 | 向かいの席 空いたまま 3日目 |
| 3 | 既読ついて 3日 返事まだ 忙しいよね 忙しいよね |
| 3 | 0:40 通知 開いて閉じて開いた 既読 まだ |
| 3 | 送信取消 今日で12回目 全部同じ人宛 |
| 下書き | おめでとう ほんとだよ 元気でね |

- **面の舞台**: 「雨の降りやまない、退勤後のフロア」。v2 から流用。誰もいないオフィスで机と椅子が天井へ落ち、ホワイトボードと全モニタが「すき」で埋まる。送信取消の束、向かいの席の暗いモニタと読めない付箋、ホワイトボードの「あたしのせいだ」。一面目に来るので、この世界の決まり（飛んでくるのは言葉であって本人ではない、奥の本人へ届けに行く）の提示はこの面の導入が担う。作り直しは v2 と同じく、教室の背景と机椅子・ノートの敵。
- **道中の共感の細部**:
  - 送信取消の束。取り消しの行だけが並んで、本文はひとつも残っていない。
  - 向かいの席のモニタが暗いまま、キーボードの上に付箋が一枚。文字は読めない。
  - 投稿「四回も見にきちゃった」の直後、通知の吹き出しが「1」のまま四つ同じ形で降ってくる。反応はない。
- **中ボスの姿と第一声**: 先出しの本人。退勤後のカーディガンに社員証、片手のスマホの光が顔に当たっている。第一声「あ、来た来た。ねえ、あなた、あたしの、読んだ? 返事、まだ? 見たよね? ね?」捨て台詞「ぜったい、また会いに来てよね。ぜったいだよ?」は現行維持。「見て」はこの一言の「見たよね」までにとどめ、繰り返さない。
- **改心の決定打**: 束の底に、取り消されていない本物が一通ある。宛名なし。ミナは取り消された十二通をぜんぶ弾として浴びた証人として、既読を言う。相手の返事は代弁しない。

```csharp
(2, "……返事なんて、来ない。分かってる。分かってるから、取り消すしか——", "akari_face"),
(1, "束の底に、一通だけ。取り消されていないものが。「おめでとう ほんとだよ 元気でね」。", ""),
(1, "十二通、読みました。——汚れた“好き”は、ひとつも、ありませんでした。", "mina_face"),   // 既読の観測と判決を一行に（指揮官決定）
(2, "……ぁ……", "akari_face_cry"),
```

- **救済後の実在感**: ホワイトボードの「あたしのせいだ」が「ありがとう」に。改心後の投稿「ほんとバカなんだから あたしもだけど」。クリア時「あったかい声が、した。……知らない声なのに」。ハブの返信「あなたの言い方、誰かに似てる。」は一面目の返信になり、三面あとの FINAL の邂逅でレイが回収する（→ ミナと「あなた」）。FINAL の援護一人目、返礼は「既読、つけに来た。……あなたのぶん。」スタッフロール「向かいの席 中途の人来た 自分から話しかけた 既読とかない 顔見て言った」。
- **失う資産**: セーラー服、教室、黒板、机と椅子の敵、ノートと教科書の敵、転校、隣の子のロール投稿、傘と交差点と「キミ」呼び。v2 の決定打「汚れた“好き”は、ひとつも、ありませんでした」は「既読、です」に席を譲る（→ 判断が要る点）。
- **流用資産**: 中ボスと捨て台詞の全行、「ひとりにしないで」「来ないで……っ」、弾幕名『ねえ、こっち見て』『すきって言って』『ずっと一緒』『離さない』、カットインの一言、「バカ」の三段、「既読も三秒でつけるし」、雨、ホワイトボードの反転、返信「誰かに似てる」。v2 の舞台・生活の細部・道中の細部はそのまま。
- **絵の発注メモ**: 立ち絵（a）は淡い生成りのカーディガンに白いブラウス、社員証、髪は琥珀で現行より少し短く。年齢感は三十、化粧は落としかけ。表情は平常、泣き顔、画面の光を浴びた顔の三種。戦闘用デフォルメ（b）は 2.5 頭身、小道具は光るスマホ、記号は社員証。穢れは雨青の通知バッジと取り消し線の帯が体に絡む形で、改心後はほどける。中ボスは（b）の待機にスマホを持たせた一枚。パレットは [13_絵の発注方針](13_絵の発注方針.md) の表のまま。

## こはる（STAGE2）

- **一行の像**: 高校生。進学校に入ってから友達ができない。親の期待（成績、塾、進路）と他人の目の中で、学校では明るい子で通している。推し活をしている間だけ、全部忘れられる。推しは星逢レイ。登録者二千のうちの一人で、毎回来ている視聴者。レイはこはるの存在を知らず、こはるはレイの裏を知らない。表示名「こはる」、メインも改心後の返信も @koharu のまま、技を宣言するときだけ @koharu_light。アカウントを演じ分けないのは現行のまま。
- **闇の芯と起点**: 芯はむだ。動詞ではなく「送れない」（打って、消す手）。配信を見ている間は親も学校も消えているのに、ふと現実を見ると「自分なにしてんだろ」と我に返る。その瞬間、推し活に使った時間とお金が全部むだに見え、親の期待と他人の目がそれを責める声になる。起点は、塾を一回さぼって配信を見た夜。終わって部屋の電気をつけたら、机の上に模試の結果と、机の下にグッズの箱があった。責める宛先は作らない。親は悪くないし、学校も悪くない。
- **生活の細部**:
  - 配信は部屋の電気を消して見る。親の足音がしたら画面を伏せる。
  - ペンライトは配信画面に向けて振る。誰にも見えない。振っている自分だけが見える。
  - 塾の帰りにグッズの通販の箱を受け取る。箱は机の下、親の目線より低い場所に積む。三つ目。
  - コメントは毎回打つ。送る前に消す。「今日も来ました」だけは送れる。
  - 学校では明るい。昼は誰かの輪の端で笑う。何の話だったかは覚えていない。
- **SNSでの姿**（本人の投稿に推しの名前は出さない。層1・層2 の推し活の投稿と同じ顔で沈む）:

| 層 | 本文 |
|---|---|
| 1 | 今日の配信も最高だった これで明日も学校行ける |
| 2 | 塾の帰り 配信間に合った 宿題は 大丈夫 |
| 2 | グッズの箱 3つ目 親には言ってない |
| 3 | 配信終わった 部屋の電気つけた 自分なにしてんだろ |
| 3 | 1:20 ペンライト振ってた 一人で 部屋で ふと鏡見た |
| 3 | 今日も明るいねって言われた 何の話してたか覚えてない |
| 下書き | レイちゃんがいたから、今日も学校行けた |

- **面の舞台**: 「推し活の部屋と、誰も見ていない教室」。二つの場所を交互に通る。部屋は電気を消した暗さの中に配信画面の光だけがあり、棚のグッズ、机の下の箱、握ったままのペンライト。教室は全部の席が自分を見ていないのに、視線だけがある。黒板に「期待」の二文字。道中の終わりで部屋に戻ると配信画面が消えていて、黒い画面に自分の顔が映る。ボス戦は、消えた画面の前の部屋で行う。現行の台所は全部捨て、あかりの面から外れた教室の背景と机椅子の敵をこはるの教室へ転用する。二面目になるので、炎上の「弱くなった面」はこの面ではなく次のレイの面へ移る（→ ミナと「あなた」）。
- **道中の共感の細部**:
  - 配信画面の光だけの部屋。ペンライトの光が画面に届かない。
  - 「むだだ」の声の合間に、学校の声「今日も明るいね」と、家の声「模試、どうだった」が同じ色で混じる。
  - 投稿「自分なにしてんだろ」の直後、配信画面が消えて、黒い画面に自分の顔が映る。ペンライトを持ったまま。
  - コメント入力欄に「レイちゃんが」まで打たれて、一文字ずつ消える。「今日も来ました」だけが残って、送られる。
- **中ボスの姿と第一声**: 先出しの本人。制服、片手に消えたペンライト、もう片手にスマホ。第一声「あ、来た来た。……あたし、なにしてんだろ、って顔してる? ……してないよ。してないってば。」すぐ明るく戻る。「見てって、これ。推しの配信。今日も来てるんだ、あたし。」の途中で顔が蒼白になり「……何時間、見てるんだろ。塾……」がこぼれて、また明るく戻る。捨て台詞「はい、これ。ペンライト。振ってみて。楽しいから。ぜったい、楽しいから。」
- **ボス**: 「我に返るわたし」（仮）。技の名は親と他人の目の語彙で仮置き『ちゃんとしなきゃ』『みんな見てる』『期待』『我に返る』。最終選考は『自分なにしてんだろ』（安全地帯は配信画面の光の中）。言葉弾の語彙は「模試」「塾」「進路」「何してるの」「明るいね」。
- **改心の決定打**: 消された一行は、レイの配信に打とうとして消したコメント「レイちゃんがいたから、今日も学校行けた」。ミナが観測できるのは、消したコメントと、配信に来ていた回数だけ。それを証人として言う。推しの側の話も、親の話もしない。

```csharp
(2, "……見てる間だけ、ぜんぶ忘れてられるの。でも、忘れてた時間、ぜんぶ、むだで——", "koharu_face_pale"),
(1, "消されたコメントを、拾っておりました。「レイちゃんがいたから、今日も学校行けた」。", ""),
(1, "来ていた回数を、数えました。八十七回。一度も、欠けていません。——むだな時間は、一秒も、ありませんでしたよ。", "mina_worried"),   // ここでBGM停止
(2, "……ほんとに? ……明日も、見に行って、いいのかな。", "koharu_face"),
```

- **救済後の実在感**: 消えていた配信画面が灯り、ペンライトの光が画面に届く。改心後の投稿「送れなかったコメント 送った 読まれたかは知らない 送った」。ハブの返信「ありがと、知らない人。」は不変で、二面目の返信になる。FINAL の援護二人目、返礼は「知らない人じゃ、なかったよ」（→ 判断が要る点）。スタッフロール「今日も来ました って打った あと一行 足した」。
- **失う資産**: 兄、台所、プリン、鍋、伏せた茶碗、弁当箱、祖母の荷物、おにぎり、エプロンとお玉、「たべに、きて」、「むだな鍋は、ひと鍋も」、弾幕名四つと『お残し禁止』、「ぜんぶ食べてくれた。えらいね」、「だれも、こない」、湯気が戻る反転、包丁と鍋の敵、兄の声で祈りが届いたと告げる決定打、「妹の様子でも見ててくれよ」の託し、中学生の設定、「あの人のせいだ」の他責二行。ミナの投稿「ちゃんと食べていますか」からエピローグの DM への線は、こはる由来ではなくなる（→ 判断が要る点）。
- **流用資産**: 「ちゃんと」の口癖（『ちゃんとしなきゃ』へ）、蒼白の顔が絶望を担う構成、明るさと蒼白を往復する中ボスの型、「やめないで……止まったら」（止まったら我に返る、へ意味が変わる）、改心の受け「……ほんとに?」の型、返信「ありがと 知らない人」と FINAL の「知らない人じゃ、なかったよ」、一人称「あたし」と「〜もん」「〜だよ?」の口調、あかりの面から外れた教室の背景と机椅子の敵。
- **絵の発注メモ**: 立ち絵（a）は学校の制服（白いシャツにリボン、紺の上着）、髪は焦げ茶で下ろす。小道具は消えたペンライト一つ。年齢感は高校生で、笑顔の作り方がうまい顔。表情は学校の明るい顔、蒼白、配信画面の光を浴びた顔の三種。戦闘用デフォルメ（b）は 2.5 頭身、小道具はペンライト、記号は制服のリボン。穢れは灰色の視線の線が数本、体に絡む形で、文字は乗せない。改心後は視線がほどけ、ペンライトが灯る。中ボスは（b）の待機にペンライト。背景は共通パーツ C1 を藍に色掛けした部屋（中景: 配信画面の光る面と棚のグッズ、近景: 机の下の箱）と、C1 を青灰に色掛けした教室（中景: 机の列、近景: 黒板の「期待」。文字はここ一箇所）。パレットは 13 の表を「髪 焦げ茶、主色 白（シャツ）、副色 紺（上着）、アクセント 菫（ペンライトの色）」に差し替える。菫はレイのガワと同じ色だが、ミナはそれを言わない。

## レイ（STAGE3）

- **一行の像**: 24歳。配信名「星逢（ほしあい）レイ」。VTuber を三年やって、登録者は二千で一年止まり、同接と再生は右肩下がりで、二桁の前半に一桁が混じりはじめている。ガワは伸びていた頃に貯金をつぎ込んで作った豪華なもので、減った今も同じガワで配信している。部屋は狭い。昼はシフトの仕事、夜は配信。実家の一室で、親に画面を見せても「ふーん」で終わる。表示名「星逢レイ」、メイン @rei_____（五つの空白は、届かない五桁目の席として読める）、技を宣言するときだけ @hoshiai_rei_live、改心後の返信もメインのまま。本名は出さない。
- **表と裏**: 表は配信中のガワ。いつも明るく、初見さんに手を振り、コメントを一つずつ読んで笑う。裏は配信を切った直後の部屋。通知を伏せて、コメントを全部読んで、消す一行を打つ。設定上は仮面だが、作中の語彙では「ガワ」で通し、仮面とは言わせない。絵で分かるようにする。
- **闇の芯と起点**: 芯は比較の先の「気づかれない自分」に、「減っていく数字」「作れなくなった自分」「理由の分からない攻撃」を重ねたもの。動詞は「気づいて」「見て」。起点は、顔のない、心のない引用やコメントが積もって、中のわたしが潰されそうになった夜。なぜ叩かれているのかは本人にも分からない（切り抜き、引用、界隈の空気。原因は作中で示さない）。数字の減少はその背景で、同じ日に始めた配信者の万を超えた告知を三秒だけ見て閉じた指、企画メモが下書きのまま増えて一本も出せない手、家の「ふーん」が、その夜の下に積んである。潰されないために、ガワの中に引っ込んだ。見られているのはガワで、中のわたしには誰も気づかない。
- **生活の細部**:
  - 配信前の三十分、リングライトの前で笑顔の練習をする。ガワには映らない。
  - 同接の数字は配信中は隠す設定にしてある。それでも終わってから開く。先週より少ない。
  - 企画メモは下書きに十四件。一年前に一度だけ伸びた企画を月に一度やる。来るのは同じ三人。
  - 通知を切れないまま、画面を伏せて寝る。伏せた画面が、夜中に一度光る。
  - 引き出しの手前にあるのは通帳ではなく、ガワの制作費の領収書。
- **SNSでの姿**（層1 は配信中の声、層2・層3 は配信を切った直後の同じアカウント。同じ人の二つの声が並ぶのがレイの層の特徴で、読者の TL では推し活の投稿の隣に沈む）:

| 層 | 本文 |
|---|---|
| 1 | 今日も20時から! 初見さん大歓迎 コメント全部読みます |
| 2 | 登録者2000人ありがとう 去年の今日も2000人 |
| 2 | 企画メモ 下書き14件 出せるの0件 |

- **面の舞台**: 「終わりのない配信枠」。v2 の査定会場と現行のコンテスト会場は捨てる。狭い部屋の壁一面が配信画面になっていて、コメント欄が流れ、右上の同接カウンターは「8」から「3」へ下がっていく。画面の中央にガワの星逢レイが等身大より大きく笑顔で立ち、部屋の隅の机とヘッドセットは小さい。コメント欄の中に「今日も来ました」が一つ、毎回同じ位置にある（こはるの結線。→ ミナと「あなた」）。道中の後半、レイの投稿に顔のない引用が一枚ずつ積もり、豪華なガワの上に心のない言葉が貼りついて、中の人が見えなくなる。これが [11_引用ポストの嵐](11_引用ポストの嵐.md) の移設先で、あかりの面には置かない。この面の核の場面として、ミナが一枚ずつ剥がし切った下に、消した一行「わたしに、気づいてよ。わたしを、見てよ」がある。ボス戦で壁の画面が部屋を呑み込み、ガワだけが残る。三面目なので炎上中で、ミナの光は薄い。監視カメラの敵は「視聴者のアイコン」（灰色の初期アイコンの群れ）に、順位表は「同接の推移」（右肩下がりのグラフ）に作り直す。
- **道中の共感の細部**:
  - 同接カウンター。「11」「8」「3」と、面が進むたびに減る。うち一つは、机の上でつけっぱなしの自分の端末。
  - 「気づいて」「見て」の声の合間に、家の声「ふーん」が同じ色で混じる。
  - 投稿「読まなきゃよかった」の直後、ガワの上に引用が貼られはじめる。一枚ずつは誰でも打てる軽さで、凄む文は一枚もない。剥がすと下に、まだ同じ笑顔のガワ。
  - 伏せたスマホが、机の上で一度だけ光る。誰も拾わない。
- **中ボスの姿と第一声**: 先出しの本人、中の人。ヘッドセットを首に掛けたパーカー、狭い机、リングライトの光が顔に当たっている。配信中の顔で出る。第一声「……だれ? あなた。……わたしの配信、見に来た人?」のあと、すぐ配信用の笑顔に切り替わる。「はじめまして! 星逢レイです。今日も来てくれて、ありがとう。」捨て台詞「逃げたら……承知しないんだから。」は笑顔のまま。中ボスはガワではなく中の人なので、ボスと姿も大きさも違うことがここで仕込まれる（中ボス 23px、ボス 52px の差が、そのまま中の人とガワの差になる）。
- **ボス＝ガワ**: ボス「星逢レイ」は本人が作ったキャラで、本人を閉じ込めて襲う。潰されないためにガワの中に引っ込んだ人を、ガワが外へ出さない。派手さは三面で最大で、怖さの源は笑顔のまま撃ってくること。技の名は配信の語彙で『初見さんいらっしゃい』『登録者２０００』『同接８』『切り抜かれない』。最終選考は『同接３』（安全地帯は残った三つの席）。言葉弾の語彙に「低評価」「切り抜き」「界隈」「初見です」「ふーん」を足す。無被弾の一言は「合格。なんて」を捨て、「……初見さん、じゃなかったのね」に置き換える。改心でガワが割れて、笑っていない中の人が出る。割れるのは「もう隠れなくていい」の意味で、ガワを壊す言葉は誰も言わない。この構図は FINAL の予告である。あなたが作ったミナがあなたに向かって襲ってくる四面目の前に、レイが作ったガワがレイを閉じ込めて襲う三面目を置く。説明はしない。絵の構図（作ったものが、作った人より大きい）だけを揃える。
- **改心の決定打**: 消された一行は「わたしに、気づいてよ。わたしを、見てよ」。ミナはだれも見ていない場所（下書き）を見ていた証人として言う。式の語彙も順位の語彙も使わず、叩いた側の話もしない。

## ミナと「あなた」

ミナは変更なし。一人称、口調、観測しか言わない憲法、空の問い、汚染の抱え方は動かさない。面の順番が変わって動くのは、返信の回収先と炎上の位置だけ。

- ハブの返信は、あかり「あなたの言い方、誰かに似てる。」（H1r）、こはる「ありがと、知らない人。」（H2r）、レイ「は? 誰よあんた。」（H3r）の順になる。FINAL の邂逅で、最後に「誰よあんた」と言ったレイが「あんたの言い方、この人に、そっくりよ」と言う。一面目のあかりの気づきを三面あとにレイが引き継いで言い切る形で、気づかれたかった人が、最初に気づく人になる。説明はしない。
- 炎上（ミナの投稿の伸びと、ミナへの引用）は二面目の後に来るので、「弱くなった面」は三面目のレイの面になる。ミナの投稿が十万を超えた直後に、同接が一桁に落ちかけている人の面へ潜る。ミナはその数字を言わない。ヒロインへの引用の嵐（11 の本命）はあかりの面からレイの面へ移り、ミナが自分に貼られた引用を剥がしきれないまま、レイに貼られた引用を剥がしに行く順になる。
- レイ戦と FINAL の相似は、絵と構図だけで揃える。三面目でガワが割れて中の人が出る。四面目で穢れたミナからミナが出る。どちらも「作った人より、作ったもののほうが大きい」構図で、ミナがそれを口にする行は置かない。
- こはるとレイの結線は、絵と一行だけで置く。レイの層1・層3 や道中のコメント欄に、こはるらしき視聴者のコメント（名前は出さない。「今日も来ました」程度）を一つ置ける。こはるのペンライトの菫がレイのガワの菫と同じ色でもよい。ミナはこの繋がりを口で説明せず、こはるの面で「レイちゃん」と読み上げた一行と、レイの面の「今日も来ました」を、あなたが自分で繋ぐ。
- 三人の投稿が「今日の自分」「昔の自分」「隣の誰か」に散るので、あなたの側の設定は空欄のまま増やさない。

## 判断が要る点

1. **あかりの決定打。** 決定済み: 「十二通、読みました。——汚れた“好き”は、ひとつも、ありませんでした。」（既読の観測と v2 の判決を一行に。「既読、です」単独は使わない）。
2. **ボス名。** レイは現行「孤高のわたし」が一位前提なので捨て、「星逢レイ」そのもの（配信名がボス名）にする案で書いた。「ガワのわたし」と迷う。こはるは「とまれないわたし」を「我に返るわたし」に仮置きした。技の名四つも仮置きで、親と他人の目の語彙の中から選び直してよい。
3. **レイが叩かれている原因を作中で示すか。** 示さないまま、を推奨する。原因を置いた瞬間に「叩かれる側にも理由があった」と読める席ができ、引用の一枚一枚の軽さ（誰でも打てる）が消える。本人も分からない、ミナも観測していないので言わない、で通す。配信の告知と深夜の投稿を同じ @rei_____ にしたのも、裏垢を作ると原因の在処が説明的になるため。
4. **FINAL でこはるの返礼をどこへ向けるか。** 本記事はミナへの「知らない人じゃ、なかったよ」のままにした。三人が並ぶ画面でこはるの一言がレイに向く（「今日も来ました、って打ったの、あたし」のような）案は、二人の結線を一度だけ本人の口で閉じられる代わりに、ミナへの返礼が一つ減り、ミナが説明しない原則の外側で繋がりが確定する。どちらにしても、ミナはこの繋がりを言わない。
5. **炎上の位置と、ミナの投稿の文面。** 炎上を二面目の後に置いたままだと、三面目のレイの面で「ミナの十万」と「レイの一桁」の対比が強すぎて、説明に見えるおそれがある。ミナが数字を言わなければ足りると考えているが、場面表の H2・S3-1 を書き直すときに確認する。あわせて、ミナの投稿「ちゃんと食べていますか」（現行はこはるの台所由来）とエピローグの DM の文面は、こはるが台所を失ったので、別の一行に差し替えるか判断が要る。
