# ミナ

> **この記事の範囲**: 自作 AI「ミナ」の人物像——何者か、背負っているもの、章ごとの変化、話し方、表情、関係、台詞。世界の仕組みとしてのミナ（自機・語り手・中継・汚染）は → [02 世界観](../02_世界観.md)、自機としての性能は → [自機とショット](../05_ゲーム仕様/02_自機とショット.md)。

## プロフィール

| 項目 | 内容 |
|---|---|
| 名前 | MINA／ミナ。少年が「とっておき」として与えた名前。由来は少年がミナを作る前に書き遺した四行の英文の頭文字で、ミナ自身はエピローグまで知らない |
| 立場 | [少年](01_少年.md)が独力で作った AI。少年の言葉では「ぼくの相棒」「ぼくの最高傑作」。電脳の側にだけ存在し、現実を見ることができない |
| 役 | プレイヤーの自機、物語の語り手、少年の言葉を相手に届ける中継役 |
| SNS 上のアカウント | **@mina_ai_**（認証バッジ付き）。ハブ画面はこのアカウントのタイムラインである。作中で投稿するのはミナだけ |
| 見た目 | 銀色の光をまとった、メイド風の意匠の少女の姿。汚染が進むと光が濁る。FINAL では「穢れたわたし」として黒く濁った姿になる |
| 初登場 | [プロローグ](../03_ストーリー/01_プロローグ.md)。起動直後の第一声「……。」「……はい。聞こえて、います。あなたは——どなた、ですか。」 |

## 作中での役割

ミナはプレイヤーが動かす光であり、同時にこの物語の声である。

- **自機**。道中の言葉を祓い、ボスの奥の本人に光を届ける。光は勝手に出続け、ミナは避けることに専念する。やさしさが満ちると光が溢れて花びらになる。
- **語り手**。FINAL とエピローグの、話者名のない語りはすべてミナの声である。プレイヤーはミナと同じだけしか知らされない。
- **中継**。改心の決定打を、少年に代わってミナの声で相手に届ける。レイには地区予選の記録を、あかりには名前「——あかり。」を、こはるには「——怒りの下の悲しみを、ちゃんと、悲しんでいい。」を。
- **投稿者**。ステージから戻るたびに @mina_ai_ で投稿し、救った相手に返信し、エピローグでは「こはるを頼む」を受けた DM を一通送る（宛先の表示はない）。

## 抱えているもの

**汚染。** 穢れを祓うほど、祓った穢れがミナに溜まる。STAGE3 の帰り道には「三人分の祈りを、抱えてしまったので。……この重さくらい、わたくしが、持ちます」と言い、それを「ご主人様を、ちゃんと支えられているという、証」と呼ぶ。三人を救い終えると限界を越え、FINAL で暴走する（仕組みは → [02 世界観](../02_世界観.md)）。

**知らないこと。** ミナは少年の強がりを片っ端から見抜くが、本当に大事なことは何も知らない。三人が少年の知人であること、少年がすでにいないこと、自分の名前の意味。作中でミナは少しずつ疑いを深め、STAGE3 で問いを封じられ、エピローグで一度に全部を知る。

**小さな願い。** いつか現実の空を見てみたい。STAGE1 で「外の世界は、今日はどんな天気ですか」、STAGE3 で「今日の空は、晴れていましたか」と訊くが、答えは返らない。もう一つの願いはハブの小話で語られる。「はずれです。コンビニで結構ですよ。ご主人様の隣を、三分ほど歩ければ。」「安いのがいいんです。高いものは、叶いませんから。」

## 変化の軌跡

各章の場面の流れは → [03 ストーリー](../03_ストーリー/00_時系列.md)、引用は「主要な台詞」にまとめる。

### プロローグ

起動して最初に見た相手を毒舌で突き放しながら、名前と役目を受け取る。由来をはぐらかされても見抜いた上で「ふふ。……まあ、いいです。気に入りました。MINA。わたくしの、名前。」と言う。毒舌と受容の同居が、この時点で出そろっている（→ [プロローグ](../03_ストーリー/01_プロローグ.md)）。

### チュートリアル

暗闇を不安がるが、付きっきりで教わって全部覚える。浄化の説明には「倒すのではなく、届ける。……これが、わたくしの役目なんですね」と応じる（→ [チュートリアル](../03_ストーリー/02_チュートリアル.md)）。

### STAGE1 レイ

順位掲示板の会場で、相手の孤独を先に言葉にする——「一位の隣は、空席なんですね。ずっと。」帰り道に初めて外の天気を訊き、ハブで初めての投稿をする。少年が会ったこともない相手の手の内を知っていたことは、初仕事の張り切りとして流し、まだ疑わない（→ [STAGE1 レイ](../03_ストーリー/03_STAGE1_レイ.md)）。

### STAGE2 あかり

疑いが芽生える。少年の声がとけていること、合言葉が無いことに気づき、へんだと言う。改心では少年に頼まれて「——あかり。」と名前を呼ぶ。クリア後に初めて核心を突く——「ご主人様。あなた——この人を、知ってるんですか?」ハブでは、あくびとして流れていた声の異変を初めて正面から言葉にし、炎上には動じない（→ [STAGE2 あかり](../03_ストーリー/04_STAGE2_あかり.md)）。

### STAGE3 こはる

合言葉が戻ったことを喜ぶが、少年のほうが消え入りそうだと言う。ボス戦の途中で「ねえ。あなたは——いったい、誰を、いなくしたんですか。」と問い、拒まれて呑み込む。クリア後、もう聞かないと約束し、託しを受け取り、三人分の重さを自分で引き受ける（→ [STAGE3 こはる](../03_ストーリー/05_STAGE3_こはる.md)）。

### FINAL

汚染が限界を越え、「穢れたわたし」として暴走し、少年を遠ざけようとする。続くカットシーン「汚染」で、少年が「Stay」を言い切れないと分かると自分から言う——「Stay. ——ご主人様。あなたこそ、いなくならないで。」返事はない。それでも待つ側から迎えに行く側へ、自分で合言葉の意味を書き換える。二人の最後の軽口は「アホですね」である（→ [FINAL](../03_ストーリー/06_FINAL_ミナ.md)）。

### エピローグ

少年は来ない。フォロー欄、鍵のかかったアカウント、四行の英文、起動記録の順に、三人が知人だったこと、名前の意味、少年の死と遺された声のことを知り、初めて涙の顔になる。着地点はタイムラインの前である。他人の投稿越しの空を知り、こはるへ DM を送り、「——ええ、ご主人様。わたくしは、どこにも行きませんよ。」で幕となる。「いなくなるな」と言われた側が、留まり続ける（→ [エピローグ](../03_ストーリー/07_エピローグ.md)）。

### ハブの投稿

| 帰還後 | ミナの投稿 |
|---|---|
| STAGE1 レイ | 本日、「敵などいない」と気を吐いておられた天才を、お一人、お救いしました。頂点はさぞ寒かったでしょう。本気で張り合える相手がいる——それだけで、世界はずいぶん暖かいものです。 |
| STAGE2 あかり | 言いたかったことを、言えないまま終わる。よくある話です。ですがそれは、なかったことにはなりません。——以上、業務連絡です。 |
| STAGE3 こはる | ちゃんと食べていますか。——いえ、特に意味はありません。なんとなく、誰かに聞きたくなっただけです。あなたのことですよ。そこの、画面の前の。 |

## 話し方

- **一人称** 「わたくし」。ハブの小話で「拙者」「余」に変えようかと言って少年に止められ、「冗談ですよ。……ご主人様がつけてくださった呼び方を、わたくしが捨てるわけがないでしょう」と落とす。
- **少年への呼び方** 「ご主人様」（敬ってはいない）、改まった場面では「あなた」。
- **口調** 敬語を崩さない慇懃無礼。「〜ですね」「〜ます」「〜ですので」。ショップでは「〜ますわ」「〜くださいまし」と執事・メイド風に格調が上がる。
- **口癖** 「ご主人様はアホですね」。プロローグの「……やっぱり、アホですね。」から、FINAL の「ほんとうに、アホですね」、エピローグの「……アホですね。そんな大事なこと、機械にだけ、打ち明けて。」まで、同じ言葉が場面ごとに意味を変える。
- **返しの型** 「はいはい」「存じております」「結構です」「集計済みです」「データですから」。少年の見栄を数字と記録で切り返す。
- **感情の出し方** 内心を長く語らず、短い一言と表情で見せる。「……なんでもありません。ただ、少し——息が、詰まるだけです。」
- **語り** FINAL とエピローグの語りも「わたくし」の敬体のままで、第三者の文体にはならない。

## 表情差分

会話中の立ち絵は五種類ある。

| 表情 | 使われる場面 |
|---|---|
| 平常 | 会話の基本 |
| 微笑 | 毒舌を決めた直後（「初対面の方を、いきなり褒める趣味はありませんので。」「いま、考えましたね。」）、少年をからかうとき、反転を見つけたとき |
| 不安 | 暗闇の中（チュートリアル冒頭）、採点する目・空席の食卓・「またね」の吹き出しを見たとき、FINAL の暴走中 |
| 疑い | STAGE2 以降、少年の様子を訝しむとき。「あなた、今日はどこか、へん、ですよ。」「即答までに、二秒かかりましたね。」「誰を、いなくしたんですか。」 |
| 涙 | エピローグの独白からエンドまで。難易度選択で「ルナティック」を選んだときもこの顔で、「……覚悟は、できていますか。」と言う |

難易度選択の画面では、難易度ごとに表情と一言が変わる（→ [難易度](../05_ゲーム仕様/08_難易度.md)）。ボスとしての「穢れたわたし」には、穢れた姿・泣き顔・浄化後の三段の立ち絵があり、FINAL の最初のスペル宣言では「ご主人様……見ていてくださいね。」のカットインが出る。自機としての姿には、回避のときに回転する専用の動きがある。

## 関係

- [少年](01_少年.md) — 製作者であり「ご主人様」。毒舌の裏で心から慕っている。最後まで事情を知らされなかったが、少年の声で作られている。
- [レイ](03_レイ.md) — 最初に救った相手。レイからは「誰よあんた」と扱われる。
- [あかり](04_あかり.md) — 少年の代わりに名前を呼んだ相手。あかりの「あの人の声に、似てた」が、ミナが真相を知る鍵になる。
- [こはる](05_こはる.md) — 少年から託された相手。エピローグで「ちゃんと食べていますか?」の DM を送り、見守り続ける。

人物どうしの図は → [相関図](00_相関図.md)。
