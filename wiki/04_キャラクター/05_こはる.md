# こはる

> **この記事の範囲**: STAGE2 の相手、こはるの人物像——立場、穢れ、章ごとの変化、話し方、表情、関係、台詞。ステージの流れは → [STAGE2 こはる](../03_ストーリー/04_STAGE2_あかり.md)（ファイル名は旧来のまま）、弾幕と技の仕様は → [ボス戦](../05_ゲーム仕様/06_ボス戦.md)。

## プロフィール

| 項目 | 内容 |
|---|---|
| 名前 | こはる（作中は常にひらがな） |
| 立場 | 高校生。進学校で、学校では明るい子で通っている。推しは星逢レイで、配信を見ている間だけぜんぶ忘れていられる |
| SNS 上のアカウント | メイン **@koharu**（ハブの投稿カード、中ボス、改心後の返信も同じ）／ボスの表示と技の宣言では **@koharu_light** |
| 心象世界 | 電気を消した部屋と、誰も見ていない教室。部屋には配信画面の光だけがあり、棚のグッズ、机の下の箱三つ、握ったままのペンライト。教室は席が全部埋まっているのに視線だけがあり、黒板に「期待」の二文字 |
| ボスとしての名 | 「我に返るわたし」（中ボスとして先に現れるときは「こはる」） |
| 初登場 | ハブの投稿カード。姿を見せるのは STAGE2 道中の中ボス戦 |

こはるだけはアカウントを演じ分けない。メインと改心後の返信が同じ @koharu なのは、SNS で人格を使い分けない高校生だからである。本人の投稿に推しの名前は出ない。

## 作中での役割

二面目の相手であり、二面目のあとに炎上が起きる。こはるの面には、あなたが下書きを送る場面がない。ミナは投稿の下の声を聞き、入力欄で消えた一行を拾い、その中身を本人の前まで言わない。

レイとの結線を担う。こはるが打って消したコメントは「レイちゃんが」で始まり、送れた一行「今日も来ました」は、次の面のレイの配信枠のコメント欄の同じ場所にある。片方向で、こはるはレイを知っていてレイはこはるを知らない。ミナはこの繋がりを口で説明せず、あなたが自分で繋ぐ。

## 抱えているもの

こはるの穢れは「むだ」である。動詞ではなく「送れない」——打って、消す手。投稿は「今日の配信も最高だった。これで、明日も学校、行ける。」と明るい。道中の声は「むだだ」と繰り返し、合間に学校の声「今日も明るいね」と家の声「模試、どうだった」が同じ色で混じる。ボスの弾幕は親と他人の目の語彙で『ちゃんとしなきゃ』『みんな見てる』『期待』『我に返る』と名付けられ、一度きりの技は『全部見なきゃ』『自分なにしてんだろ』である。

根にあるのは、塾を一回さぼって配信を見た夜である。終わって部屋の電気をつけたら、机の上に模試の結果と、机の下にグッズの箱があった。配信を見ている間は親も学校も消えているのに、ふと現実を見ると「自分なにしてんだろ」と我に返る。その瞬間、推し活に使った時間が全部むだに見え、親の期待と他人の目がそれを責める声になる。責める宛先はどこにもない。親は悪くないし、学校も悪くない。改心の直前に漏れる本音は「……忘れてた時間、ぜんぶ、むだで——」である。

コメントは毎回打って、送る前に消す。「今日も来ました」だけは送れる。消した一行は「レイちゃんがいたから、今日も学校行けた」——重いと思われそうで、やだった。

## 変化の軌跡

場面の流れは → [STAGE2 こはる](../03_ストーリー/04_STAGE2_あかり.md)、引用は「主要な台詞」にまとめる。

### 投稿から中ボスまで

ハブに「今日の配信も最高だった。」の投稿が並ぶ。部屋ではペンライトの光が画面に届かない。道中の途中でこはる本人が先に現れ、「なにしてんだろ、って顔してる? ……してないよ。してないってば。」と明るく言い、「何時間、見てるんだろ。塾……」で顔が蒼白になり、「なんでもない。ね、楽しいでしょ? 楽しいってば。」とすぐ戻る。去りぎわにペンライトを押しつける。

### 入力欄と、我に返る一拍

教室を抜けたあと、配信画面の下の入力欄に「レイちゃんが」まで打たれ、一文字ずつ消える。「今日も来ました」だけが送られる。道中の終わりで投稿「自分なにしてんだろ」の直後に配信画面が消え、黒い画面に自分の顔が映る。ペンライトを持ったまま。

### ボス戦

消えた画面の前の部屋で、「我に返るわたし」として現れる。板を剥がされた直後には「やめないで……止まったら——」と漏れ、「……なんでもない。楽しいってば。」と取り繕う。止まったら我に返る、という構造が、戦いそのものになっている。『全部見なきゃ』ではアーカイブを並べ、見切れば「ありがと。ありがと、ね。」と言い、見残せば「ぜんぶ、見てほしいのに。」と責める。

### 改心

「見てる間だけは、ぜんぶ、忘れてられるの。」から「あたし、なにしてんだろ。」へ落ちる。ミナが消されたコメントを返し、来ていた回数を数えた証人として「来ていた回数を、数えました。八十七回。一度も、欠けていません。」「——むだな時間は、一秒も、ありませんでしたよ。」と言い切る。推しの側の話も、親の話もしない。こはるは「……ほんとに? ……明日も、見に行って、いいのかな。」と訊く。

### クリア後・ハブ

消えていた配信画面が灯り、ペンライトの光が画面に届く。投稿は「送れなかったコメント、送った。読まれたかは、知らない。……送った。」に変わる。ハブでミナが返信すると、こはるは「ありがと、知らない人。……明日も、行ってみる。」と返す。

### FINAL・エピローグでの姿

FINAL では、ミナに溜まったこはるの穢れが投稿「なにしてんだろ、あたし……ぜんぶ、むだ。……画面、もう、つかない」と、『こはるの怒り』『こはるの扇』の弾幕になって戻る。援護の二人目として来て、「ありがと、知らない人——って。……知らない人じゃ、なかったよ。」「送れなかったやつ、送ったもん。——ペンライト、振るね。」と返礼を投げる。スタッフロールの投稿は「今日も来ました って打った あと一行 足した」。

## 話し方

- **一人称** 「あたし」。
- **口調** 中学生ではなく高校生の、笑顔の作り方がうまい明るさ。「〜でしょ」「〜だよ?」「〜ね?」「〜もん」「〜ってば」。取り繕うときは「なんでもない」「楽しいってば」。
- **口癖** 「ちゃんと」（『ちゃんとしなきゃ』「ちゃんとしなきゃ、だめだもん。」）と「なにしてんだろ」。
- **決まり文句** 「今日も来ました」——唯一送れる一行。改心後は「あと一行」が足される。

## 表情差分

| 表情 | 使われる場面 |
|---|---|
| 学校の明るい顔（平常） | 中ボスの第一声と捨て台詞、ボス戦の字幕、改心の最初と最後（「……ほんとに?」） |
| 配信画面の光を浴びた顔 | 中ボスで「見てって、これ。推しの配信。」と言うとき |
| 蒼白 | 中ボスで「何時間、見てるんだろ。塾……」がこぼれる行、改心で「あたし、なにしてんだろ。」から「やだったから……」まで |
| カットイン | 最初のスペル宣言 |

会話中の立ち絵に泣き顔はなく、蒼白の顔が絶望を担う。戦闘の姿は、待機・攻撃・泣き・改心後の段で切り替わる。中ボスは待機の姿にペンライトを持たせた小さな一枚である。
