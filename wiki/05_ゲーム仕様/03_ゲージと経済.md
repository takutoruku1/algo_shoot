# ゲージと経済

> **この記事の範囲**: 汚染、インプレッション（浄化した心）、フォロワー、コンボ、スコアの増え方と効き方。それらを得るための操作は → [操作](01_操作.md)、使い道は → [ショップと強化](07_ショップと強化.md)、汚染と浄化の物語上の意味は → [世界観](../02_世界観.md)。

## やさしさゲージ

**無効。** やさしさゲージと「やさしさ全開」は 2026-09-06 に機能ごと撤去された。ゲージも発動も画面に出ない。

## 汚染

物語が進むほど自然に上がる値（0〜1）。ステージごとに開始値と終了値が決まっていて、そのステージの進行度に応じて開始値から終了値へ上がっていく。ステージをやり直しても、ハブに戻っても、その時点の値が残る。セーブには入らず、「はじめから」で 0 に戻る。

| 場面 | 開始 → 終了 |
|---|---|
| ステージ0（れんしゅう）・トレーニング | 0（固定） |
| STAGE 1（あかり） | 0.00 → 0.18 |
| STAGE 2（こはる） | 0.18 → 0.45 |
| STAGE 3（レイ） | 0.45 → 0.80 |
| FINAL（ミナ）・Final | 1.0（固定） |

汚染が及ぼす影響は、**見た目と音だけ**である。ゲージの溜まりや威力といった数値には掛からない。

| 影響 | 内容 |
|---|---|
| 自機の色 | 白から藍鼠へ、汚染率ぶん濁る |
| 画面の濁り | 汚染 0.30 未満は無し。0.30 → 1.00 で画面の端が濁っていく（中央 60 px は抜ける）。FINAL でも出る |
| 音 | ステージ曲・ボス曲がこもる（→ [音楽と演出](11_音楽と演出.md)） |
| 表示 | 戦闘中の数値表示は無い（画面の濁りと自機の色だけで見せる）。ハブではヘッダの全幅の細いバーに出る |

**汚染の上がり方を緩める手段は無い。** かつての「澄んだ心」は一本道 13 段に入らなかったので、上昇は素のまま（×1.0）である（→ [ショップと強化](07_ショップと強化.md)）。ステージ内の上昇はそのステージの進行度に比例し、次のステージに入るとそのステージの開始値から始まる。

## インプレッション（浄化した心）

ショップの通貨。画面では「浄化した心」「♥ 心」「Imp」と表記される。獲得は「基礎値 × 倍率」で、倍率は次の積。

| 倍率 | 値 |
|---|---|
| 難易度 | やさしい ×0.7 ／ ふつう ×1.0 ／ むずかしい ×1.6 ／ ルナティック ×3.0 |
| フォロワー | ×(1 + min(0.5, フォロワー数 × 0.00008))。6,250 人で上限 +50% |
| 炎上中 | ×0.6 |
| 周回減衰 | ×0.8^（同じステージの連続回数）、下限 ×0.4（下記） |
| 固定 | ×2 |

**獲得倍率を買う段は無い。** かつての「浄化倍率」は一本道 13 段に入らず、恒久の上乗せは ×1.0 で固定されている。稼ぎの伸びは一律の ×2 とクリア報酬（下記）が担う。

獲得源の基礎値:

| 獲得源 | 基礎値 |
|---|---|
| 敵の浄化 | **撃破の瞬間には入らない。** 散った「心の欠片」を拾って初めて入る（下記） |
| 心の欠片（1 体ぶんの合計） | round((2 + そのときのコンボ数) × 1.25) |
| グレイズ | **入らない**（スコアだけ） |
| 回避グレイズ | 2（1 回の回避で 12 発まで） |
| **ステージクリア** | **400** |
| ハブでの帰還会話 | 40 |
| ハブの「返信」（クリア済みカードに 1 回） | 60 |

クリア報酬 400 に固定の ×2 が掛かるので、**1 ステージ通すごとに強化の 1〜2 段**ぶんが入る勘定になる（13 段の価格は 150〜4,000。→ [ショップと強化](07_ショップと強化.md)）。

- ボムで浄化した敵は、1 発につき 3 体までしか報酬が付かない。
- ステージ中に稼いだ分は、ゲームオーバーでステージから抜けても失わない。

### 心の欠片（2026-09-17）

**敵を浄化すると「心の欠片」が散る。通貨（インプレッション）はこれを拾って初めて入る。** 撃破の瞬間に見えないまま加算される方式は撤去され、その額をそのまま欠片が運ぶようになった——チュートリアルもショップも「浄化するたびに貯まる」と説明しており、プレイヤーは画面の欠片を通貨と読む。説明と手触りの食い違いを、説明のほうへ揃えたものである。

- 1 体ぶんの合計は **round((2 + コンボ数) × 1.25)**。係数 1.25 は取りこぼしの補正で、「普通に前へ出て拾う人は以前より少し得、画面端に張り付く人は以前並み」に着地する。拾いに行く＝攻めることに、初めて見返りが付いた。
- 欠片は **自機から半径 48 px** に入ると吸い寄せられ、**寿命は 5 秒**。放っておくと消える。合計額は粒の数で割って配られるので、拾った分だけが入る。
- **ボスと中ボスを倒した瞬間は強制回収**（2.6 秒／1.9 秒）が走る。距離に関係なく全部が吸い寄せられ、改心の会話が始まっていても回収は止まらない。**ステージクリア時も全部が自動で回収される**ので、道中の取りこぼしだけが実際の損になる。
- 欠片はスコアも同時に運ぶ。スコア側にだけ難易度倍率（やさしい ×0.8／ふつう ×1.0／むずかしい ×1.3／ルナティック ×1.6）が掛かり、通貨側には掛からない（通貨には上の表の難易度倍率が掛かるので、二重には適用しない）。

粒の数は敵の格と難易度、そして敵ごとの重みで決まる（見た目の量だけが変わり、金額は変わらない）。

| 格 | 粒の数（ふつう） |
|---|---|
| 道中の雑魚 | 10〜16（難易度倍率と敵ごとの重みが掛かる。上限 56 粒） |
| 中ボス | 52〜64 |
| ボス | 104〜128 |

敵ごとの重みは「倒すと楽になる度合い」に比例させてある（例: バズ壁 ×2.5 ／ 撃つ種 1.15〜1.25 ／ 撃たない種 0.85〜1.0 ／ 祈り運び ×0.45）。

> **2026-09-17 の不具合修正。** ボスと中ボスの欠片は、撃破直後に改心の会話が始まると処理が止まり、拾われないまま寿命切れで全損していた。強制回収を入れて、欠片が運ぶスコア（**中ボス +70／ボス +180**。難易度倍率が別に掛かる）と通貨が、実際に入るようになった。
- 周回減衰は、同じステージを同じか低い難易度で続けて遊ぶたびに深くなる（2 回目 ×0.8、3 回目 ×0.64、…、下限 ×0.4）。別のステージへ移るか難易度を上げるとリセットされる。減衰中はクリアバナーに「周回逓減 ×0.8（連続N回目・別ステージ/難度アップでリセット）」と出る。ステージクリア時のフォロワー獲得にも同じ減衰が掛かる。

## 炎上

STAGE 2（こはる）をクリアしてハブに戻ったとき、帰還の会話の終わりに一度だけ起きる（トースト「炎上中… 次のダイブはミナが弱体化します」）。次に入る 1 ステージだけ有効。

**炎上で減るのは収入だけである。** インプレッションの獲得が ×0.6 になり、それ以外には何も掛からない——発射間隔も移動速度も素のままである（かつての連射 ×1.3・移動 ×0.9 の弱体は、手触りそのものを鈍らせるうえに理由も画面から読めないため 2026-09-13 に撤回された）。戦闘中に炎上を示すバッジは出ない（炎上したこと自体はハブのトーストと会話で伝わる）。1 周につき一度で、周回では再発しない（「はじめから」で再び起きる）。

## フォロワー

ハブのヘッダとショップに表示される恒久的な人数。減ることはない。

| 増える場面 | 人数 |
|---|---|
| ステージクリア | round(40 × 周回減衰)。増やす強化は無い（「口コミ」は一本道 13 段に入らなかった） |
| ハブでの帰還会話 | +8 |
| ハブの「返信」 | +12 |

効果:

| 効果 | 内容 |
|---|---|
| 火力 | 自機弾の威力に ×(1 + min(0.5, フォロワー数 × 0.00025))。2,000 人で上限 +50% |
| インプレッション | 上記の倍率（6,250 人で上限 +50%） |
| ルナティックの解放 | 200 人以上（または強化「火力 2倍」の所持）で解放 |

かつて道中で自機に付いてきた「随伴フォロワー」は無効で、いまは出ない（→ [自機とショット](02_自機とショット.md)）。

## コンボ

| 項目 | 値 |
|---|---|
| 増え方 | 敵を浄化するたびに +1（上限 16） |
| 猶予 | 2.0 秒で固定（延ばす強化は無い）。猶予内に次の浄化が無いと 0 に戻る |
| 猶予の延長 | グレイズ・回避グレイズでも猶予が延びる（コンボが立っているときのみ） |
| 効果 | 浄化のスコアが 基礎点 × コンボ数、インプレッションの基礎値が 2 + コンボ数 |
| 表示 | 画面右上に「×n」と猶予の残りバー |

ボムでの浄化は 1 発 3 体までしかコンボに数えない。

## スコア

| 獲得源 | 点数 |
|---|---|
| 敵の浄化 | 敵ごとの基礎点 × コンボ数（雑魚の基礎点は → [敵](05_敵.md)、ボスは → [ボス戦](06_ボス戦.md)） |
| グレイズ | +30 |
| 回避グレイズ | +50 |
| 弾消し（ボム・祈りの帳・パネル剥がし） | 1 発 +5 |
| 祈り弾の受け止め | +15 |
| 中ボス撃破 | +900 |
| レイの「最終選考」完走・こはるの『全部見なきゃ』完走 | 残機が上限のときは +1000 |

スコアはステージ × 難易度ごとにベストが記録される（→ [セーブと周回](09_セーブと周回.md)）。
