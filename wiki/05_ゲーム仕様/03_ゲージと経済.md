# ゲージと経済

> **この記事の範囲**: やさしさゲージ、汚染、インプレッション（浄化した心）、フォロワー、コンボ、スコアの増え方と効き方。それらを得るための操作は → [操作](01_操作.md)、使い道は → [ショップと強化](07_ショップと強化.md)、汚染と浄化の物語上の意味は → [世界観](../02_世界観.md)。

## やさしさゲージ

画面左の紫のゲージ。満タンにしてから手動で「やさしさ全開」を発動する。自動では発動しない。

| 項目 | 値 |
|---|---|
| 溜まる量 | グレイズ +0.07 ／ 敵の浄化 +0.12 ／ 祈り弾の受け止め +0.02 ／ 祈りの帳の弾消し +0.01 ／ 中ボス撃破 +0.6（満タン = 1.0） |
| 汚染の補正 | すべての加算に「やさしさ倍率」（下記の汚染の節）が掛かる |
| 発動 | 満タンのとき Ctrl（R3）。ゲージの横に「満タン！Ctrl」が点滅する |
| 持続 | 5.0 秒。ゲージは金色になって残り時間を示し、終わると 0 に戻る |
| 効果 | 全モードの発射間隔が 0.07 秒になる／後方弾の間隔 ×0.6／随伴フォロワーが毎ショット同期して撃つ／発動の瞬間に自機の周囲 40 px の敵弾が花びらに変わる（1 発 +5 点）／自機が金色に光る |

ステージ0（れんしゅう）では一度だけ強制的に満タンになる。

## 汚染

物語が進むほど自然に上がる値（0〜1）。ステージごとに開始値と終了値が決まっていて、そのステージの進行度に応じて開始値から終了値へ上がっていく。ステージをやり直しても、ハブに戻っても、その時点の値が残る。セーブには入らず、「はじめから」で 0 に戻る。

| 場面 | 開始 → 終了 |
|---|---|
| ステージ0（れんしゅう）・トレーニング | 0（固定） |
| STAGE 1（あかり） | 0.00 → 0.18 |
| STAGE 2（こはる） | 0.18 → 0.45 |
| STAGE 3（レイ） | 0.45 → 0.80 |
| FINAL（ミナ）・Final | 1.0（固定） |

汚染が及ぼす影響は次のとおり。

| 影響 | 内容 |
|---|---|
| やさしさ倍率 | 無強化で 汚染 0 → ×1.00、0.16 → ×0.98、0.42 → ×0.89、0.72 → ×0.73、1.0 → ×0.55（下限 0.55） |
| 自機の色 | 白から藍鼠へ、汚染率ぶん濁る |
| 画面の濁り | 汚染 0.30 未満は無し。0.30 → 1.00 で画面の端が濁っていく（中央 60 px は抜ける）。FINAL でも出る |
| 音 | ステージ曲・ボス曲がこもる（→ [音楽と演出](11_音楽と演出.md)） |
| 表示 | 戦闘中は左の「救った人 ◯/3」パネル内の「汚染」バー、ハブではヘッダの全幅の細いバー |

「澄んだ心」の効果:

| ノード | 汚染の上がり方 | やさしさ倍率 |
|---|---|---|
| 澄んだ心 I | ×0.85 | 下限 +0.05、全体 ×1.06 |
| 澄んだ心 II | ×0.55 | 下限 +0.15、全体 ×1.18（上限 ×1.1） |

上がり方の補正はそのステージ内の上昇に掛かる。次のステージに入ると、そのステージの開始値から始まる。

## インプレッション（浄化した心）

ショップの通貨。画面では「浄化した心」「♥ 心」「Imp」と表記される。獲得は「基礎値 × 倍率」で、倍率は次の積。

| 倍率 | 値 |
|---|---|
| 難易度 | やさしい ×0.7 ／ ふつう ×1.0 ／ むずかしい ×1.6 ／ ルナティック ×3.0 |
| フォロワー | ×(1 + min(0.5, フォロワー数 × 0.00008))。6,250 人で上限 +50% |
| 浄化倍率 I〜IV | ×1.12 / ×1.24 / ×1.36 / ×1.48 |
| 炎上中 | ×0.6 |
| 周回減衰 | ×0.8^（同じステージの連続回数）、下限 ×0.4（下記） |
| 固定 | ×2 |

獲得源の基礎値:

| 獲得源 | 基礎値 |
|---|---|
| 敵の浄化 | 2 + そのときのコンボ数 |
| グレイズ | 1 |
| 回避グレイズ | 2（1 回の回避で 12 発まで） |
| ステージクリア | 120 |
| ハブでの帰還会話 | 40 |
| ハブの「返信」（クリア済みカードに 1 回） | 60 |

- ボムで浄化した敵は、1 発につき 3 体までしか報酬が付かない。
- ステージ中に稼いだ分は、ゲームオーバーでステージから抜けても失わない。
- 周回減衰は、同じステージを同じか低い難易度で続けて遊ぶたびに深くなる（2 回目 ×0.8、3 回目 ×0.64、…、下限 ×0.4）。別のステージへ移るか難易度を上げるとリセットされる。減衰中はクリアバナーに「周回逓減 ×0.8（連続N回目・別ステージ/難度アップでリセット）」と出る。ステージクリア時のフォロワー獲得にも同じ減衰が掛かる。

## 炎上

STAGE 2（こはる）をクリアしてハブに戻ったとき、帰還の会話の終わりに一度だけ起きる（トースト「炎上中… 次のダイブはミナが弱体化します」）。次に入る 1 ステージだけ有効で、その間は発射間隔 ×1.3、移動速度 ×0.9、インプレッションの獲得 ×0.6 になり、画面左上に「炎上中」バッジが出る。1 周につき一度で、周回では再発しない（「はじめから」で再び起きる）。

## フォロワー

ハブのヘッダとショップに表示される恒久的な人数。減ることはない。

| 増える場面 | 人数 |
|---|---|
| ステージクリア | round(40 × (1 + 0.15 × 口コミの段数) × 周回減衰) |
| ハブでの帰還会話 | +8 |
| ハブの「返信」 | +12 |

効果:

| 効果 | 内容 |
|---|---|
| 火力 | 自機弾・後方弾・返し光の威力に ×(1 + min(0.5, フォロワー数 × 0.00025))。2,000 人で上限 +50% |
| インプレッション | 上記の倍率（6,250 人で上限 +50%） |
| ルナティックの解放 | 200 人以上（または光の出力 IV）で解放 |

なお、道中で敵を 3 体浄化するごとに自機に付いてくる「随伴フォロワー」は別のもので、被弾で 1 体離れる。こちらの詳細は → [自機とショット](02_自機とショット.md)。

## コンボ

| 項目 | 値 |
|---|---|
| 増え方 | 敵を浄化するたびに +1（上限 16） |
| 猶予 | 2.0 秒（コンボ持続 I / II で 2.4 / 2.8 秒）。猶予内に次の浄化が無いと 0 に戻る |
| 猶予の延長 | グレイズ・回避グレイズでも猶予が延びる（コンボが立っているときのみ） |
| 効果 | 浄化のスコアが 基礎点 × コンボ数、インプレッションの基礎値が 2 + コンボ数 |
| 表示 | 画面右上に「×n」と猶予の残りバー |

ボムでの浄化は 1 発 3 体までしかコンボに数えない。

## スコア

| 獲得源 | 点数 |
|---|---|
| 敵の浄化 | 敵ごとの基礎点 × コンボ数（雑魚の基礎点は → [敵](05_敵.md)、ボスは → [ボス戦](06_ボス戦.md)） |
| グレイズ | +10 |
| 回避グレイズ | +50 |
| 弾消し（ボム・祈りの帳・やさしさ全開・パネル剥がし） | 1 発 +5 |
| 祈り弾の受け止め | +15 |
| 中ボス撃破 | +900 |
| レイの「最終選考」完走・こはるの『全部見なきゃ』完走 | 残機が上限のときは +1000 |

スコアはステージ × 難易度ごとにベストが記録される（→ [セーブと周回](09_セーブと周回.md)）。
