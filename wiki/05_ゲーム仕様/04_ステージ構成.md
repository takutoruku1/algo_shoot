# ステージ構成

> **この記事の範囲**: ステージの並びと解禁、面ごとの進行、道中の湧き、中ボス、チェックポイント、クリアの条件と記録、ステージ0（れんしゅう）の流れ。各面で語られる物語は → [ストーリー](../03_ストーリー/00_時系列.md)、ボス戦の中身は → [ボス戦](06_ボス戦.md)、雑魚の一覧は → [敵](05_敵.md)。

## ステージ一覧と解禁順

| ステージ | 入口 | 解禁 |
|---|---|---|
| ステージ0「れんしゅう」 | **無効。** 入口がなく、プロローグの後はハブへ直行する | — |
| STAGE 1（あかり） | ハブの投稿カード | 最初から |
| STAGE 2（こはる） | 同上 | STAGE 1 をクリア |
| STAGE 3（レイ） | 同上 | STAGE 2 をクリア |
| FINAL（ミナ） | ハブに現れる FINAL カード | STAGE 1〜3 をすべてクリア |

クリア済みのステージは何度でも入れる。未クリアのステージは物語順で「次の 1 つ」だけが入れる（カードに NEW、その先は LOCKED）。

## 共通の流れ

1. ハブでカードを選び、投稿詳細で潜り方（難易度）を決めてそのまま入る。開始は必ず道中の最初から。開始時にバナー「STAGE n START」が出る。
2. 会話の間は敵・弾・パネル・予兆がすべて止まり、会話が始まる瞬間に画面の弾は自機の光も含めてすべて消える（会話中は新しい弾も出ない）。
3. 道中では右端の外から雑魚が湧き、規定の数を浄化すると次の段階へ進む。画面中央上の「浄化」ゲージが進行度を示す。
4. ボス本人が一度だけ顔を見せる中ボス戦がある（FINAL を除く）。
5. 道中を終えるとボス戦。ボスを改心させるとクリア。
6. クリアバナー「STAGE n CLEAR」と TIME・SCORE（自己ベストなら NEW BEST!）→ 帰還の会話 → ハブへ戻る。

背景は面ごとの描き下ろしイラスト三層（遠景・中景・近景）で、別々の速さで横に流れる。色は進行度に応じて寒色から暖色へ変わり、進行度 25% / 55% / 82% で 4 段階に切り替わる。中ボス戦とボス戦では、それぞれ専用の一枚絵の舞台へクロスフェードする。

## 面ごとの構成

| 面 | 進行（浄化の目標数） | 浄化目標の合計 |
|---|---|---|
| STAGE 1（あかり） | 導入会話 → 肩慣らしの波（6）→ 中ボス → 会話 → 道中A（12）→ 会話 → 道中B（13）→ 束（下書き選択）→ 道中C（14）→ 会話 → ボス登場 → ボス前の会話 → ボス戦 → クリア | 46 |
| STAGE 2（こはる） | 導入会話 → 小話 → 道中A（15）→ 会話 → 中ボス → 道中B（14。部屋から教室へ）→ 教室の会話 → 入力欄 → 道中C（16。教室から部屋へ）→ 会話 → ボス登場 → ボス前の会話 → ボス戦 → クリア | 46 |
| STAGE 3（レイ） | 導入会話 → 小話 → 道中A（15）→ 会話 → 中ボス → 道中B（14）→ 会話 → 引用の嵐（十七枚）→ 会話 → 道中C（16）→ 会話 → ボス登場 → ボス戦（ボスの HP 20〜50% で一度、下書き選択が割り込む）→ クリア | 46 |
| FINAL（ミナ） | タイトルカード「FINAL」→ 導入会話 → 残響 3 体の浄化 → ボス戦 → Final（カットシーン） | 4 |

- STAGE 1（あかり）だけ中ボスが序盤（肩慣らしの波の直後）に出る。
- 道中の各段階は「規定数を浄化」で終わる。STAGE 3（レイ）は残った雑魚をすべて倒すまで待ち、STAGE 1・2 は残った雑魚が消えてすぐ進む。
- STAGE 3（レイ）の引用の嵐は、道中B のあとに約 50 秒入る。飛んでくる引用を撃ち落とす場面で、雑魚は湧かない（→ [STAGE3 レイ](../03_ストーリー/05_STAGE3_レイ.md)）。
- 浄化ゲージは**撃破率が本体**で、そこへ時間ぶんの「先行」を上乗せする（2026-09-17 に作り直した）。先行はまだ埋まっていない残り幅から借り、さらに**撃破が進んでいるぶんだけ**許される——**1 体も倒していなければゲージは 0% のまま動かない**。撃破率が 25% に届くと先行の窓が全開になり、残り幅の最大 85% まで先行できる。**倒し切るまで必ず 100% 未満**で、撃破率 100% でちょうど 100% になる。時間の積み上げ自体は自機が右に寄るほど速く（左端 ×0.55、中央 ×1.075、右端 ×1.60）、最大 0.35 まで。段階の切り替えは浄化数だけで判定する。

> **2026-09-17 の修正。** 旧式は「撃破率」と「撃破率 × 0.55 + 時間」の大きい方だったため、**敵を 1 体も倒さなくても時間だけでゲージが 35% まで自動で溜まり**、撃破 99% でも 100% に見えてしまっていた（ラベル「浄化」と中身が食い違っていた）。放置で汚染だけが進む現象も、汚染がこのゲージに連動していたことが原因で、同時に解消している。
- FINAL の「残響」は、ミナのテーマの人型 3 種（→ [敵](05_敵.md)）が 3 体だけ湧く短い戦い。3 体すべてを浄化すると、残った弾を片づけてからボスが現れる。

## 道中の湧き

| 項目 | 値 |
|---|---|
| 出現位置 | 画面右端の外。右 60% ／ 右上 20% ／ 右下 20% |
| 間隔 | 2.0 秒から始まり 28 秒かけて 0.8 秒まで詰まる。毎回 ±20% ばらつく |
| 自機の位置による補正 | 自機が右に寄るほど間隔が短くなる（左端 ÷0.60、中央 ÷1.05、右端 ÷1.50） |
| 同時出現の上限 | 10 体 |
| 波ごとの密度 | 道中B は詰まり具合 35%、道中C は 70% の状態から始まる |
| 種類の比率 | 各波の頭で、その面の人型 3 種がまず 1 体ずつ順に登場する（その間、下記の特殊種は湧かない）。以後は湧きの 60% が人型（3 種を順繰り）、残りが従来 2 種（速い方 75%・ゆっくり漂う方 25%）。進行が半分を過ぎると「引用リプ」が湧きの 15%、道中B・C では「バズ壁」が 10%、STAGE 2（こはる）では「祈り運び」が 10% 混ざる |
| 会話中 | 湧かない |

雑魚の性能は → [敵](05_敵.md)。

## 中ボス

その面のボス本人が道中に一度だけ現れる短い戦い。

| 項目 | 値 |
|---|---|
| HP | 2 本（難易度によらない） |
| パネル | 3 枚 × 耐久 2 |
| 撃破の点数 | 700 |
| 登場演出 | 0.85 秒 |
| 撃破報酬 | スコア +900、残機 +1、ボム +1（残機とボムは初期数が上限。回復した分だけ、**そのキャラの核マーク／ボム印に「+1」を添えたアイコン**のバナーが出る） |
| 撃破後 | ボスの捨て台詞が 2.4 秒ずつ流れ、道中の曲に戻る |

中ボスの弾幕は → [ボス戦](06_ボス戦.md)。中ボスを倒した記録はステージごとに永続するが、入口を選ぶ画面そのものが廃止されたので、いまは初回の強化ショップ導線の判定にだけ使われる。

全ゲームを通して初めて中ボスを倒した瞬間（通常は STAGE 1）、ステージから一時的に離れてショップの説明会話とショップへ移り、「つづける」で同じステージの中ボス直後の道中から再開する（→ [ショップと強化](07_ショップと強化.md)）。2 回目以降の中ボス撃破では離れない。

## チェックポイント

### やり直しと再開

| 状況 | 操作 | 再開位置 |
|---|---|---|
| ゲームオーバー | 選択肢「（ボスからやり直す）」／R | ボス戦から（道中で力尽きた場合も含む）。**既定のカーソル位置** |
| ゲームオーバー | 選択肢「（最初からやり直す）」／Shift + R | 最初から |
| ゲームオーバー | 選択肢「（ステージから抜ける）」／Q（× / B） | ステージから抜けてハブへ。稼いだインプレッションは保存される |
| 通常時 | R 長押し 0.45 秒／ポーズメニューの「リスタート」（はい／いいえの確認つき） | 最初から |
| FINAL | 上のどれでも | 最初から（残響の浄化を含めてやり直す） |

ゲームオーバーの選択肢は、会話中の 2 択と同じ縦積みの UI である（→ [操作](01_操作.md)）。ボスの改心が始まっていれば、残機 0 でもこの選択は出ない。

## クリアと記録

- クリア条件はボスの改心。ボスの HP を 0 にし、改心の会話を送り切ると確定する。
- クリアタイムはステージに入った瞬間からクリア確定までの秒数で、会話中も進み、ポーズ中は止まる。
- ステージ × 難易度ごとにベストタイムとベストスコアが残り、自己ベストなら「NEW BEST!」、そうでなければ「BEST …」が出る。ハブのカードにはそのステージの最速難易度のベストが出る（→ [セーブと周回](09_セーブと周回.md)）。
- クリア時と帰還の会話でインプレッションとフォロワーが増える（クリア報酬と帰還報酬 → [ゲージと経済](03_ゲージと経済.md)）。クリア時と帰還会話の終了時にオートセーブされる。
- STAGE 2 のクリア後に一度だけ炎上が起きる（→ [ゲージと経済](03_ゲージと経済.md)）。
- FINAL は改心の会話のあと記録とオートセーブをして Final（カットシーン）→ エピローグ（見上げる → 歩く → スタッフロール → END）→ タイトルへ進む。ハブには戻らない。

## ステージ0「れんしゅう」

**無効。** 現在この面へ入る導線はない。以下は中身の記録である。

残機とボムが減らない練習ステージ。汚染は 0。バナーは「れんしゅう」。教える相手はおらず、各ステップはボタンの絵と指示帯（n/N の進み具合つき）だけで実践に入り、達成すると次へ進む（実践には 60 秒、移動だけは 30 秒の上限があり、過ぎても次へ進む）。ミナが話すのは、浄化の前の一行と締めの一行だけである（→ [チュートリアル](../03_ストーリー/02_チュートリアル.md)）。

| 順 | 内容 |
|---|---|
| 1 | 移動: 上下左右をそれぞれ約 1 秒ずつ動かす |
| 2 | ショット: ダミー（練習の的）を 3 体倒す |
| 3 | 回避: 3 回成功させる（**回避を持っていなければ丸ごと飛ばす**） |
| 4 | ボム: 固まって出る 3 体をまとめて倒す |
| 5 | 浄化: ミナの一行のあと、パネルを剥がして 2 体を浄化する |
| 6 | 締めのミナの一行 → ハブへ |

かつて 3 番目にあった「低速移動」の段は、低速移動そのものが無くなったので素通りになった。
