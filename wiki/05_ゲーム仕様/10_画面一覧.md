# 画面一覧

> **この記事の範囲**: ゲームに出てくる画面と、それぞれで「何ができるか」「どこへ行けるか」。ボタンの割り当ては → [操作](01_操作.md)、ショップの中身は → [ショップと強化](07_ショップと強化.md)、セーブの仕組みは → [セーブと周回](09_セーブと周回.md)。

## 全体の流れ

| 画面 | できること | 行き先 |
|---|---|---|
| タイトル | はじめから／つづきから／あそびかた／チュートリアル／設定／クレジット／おわる | プロローグ、ハブ、ステージ0、設定、クレジット |
| プロローグ | 会話を読む | ステージ0、または（受講済みなら）ハブ |
| ステージ0「れんしゅう」 | 操作の練習 | ハブ |
| ハブ | ステージを選ぶ、返信する、強化・記録へ | 難易度選択、ショップ、記録 |
| 難易度選択 | 難易度と入口を選ぶ | ステージ、ハブ |
| ステージ本編 | 戦う | ハブ（クリア・離脱）、FINAL は Final へ |
| ショップ説明 | 初回のみ会話を読む | ショップ |
| ショップ | 強化を買う、装備する | ハブ、トレーニング、（初回のみ）中断したステージ |
| トレーニング | 試し打ち | ショップ |
| 記録 | ベストタイムとスコアを見る | ハブ |
| 設定 | 設定を変える | タイトル |
| クレジット | 出典を見る | タイトル |
| Final・エピローグ | 結末を読む | タイトル |
| あそびかた／ポーズメニュー／会話ログ | いまの画面の上に重なる | 閉じると元の画面 |

## タイトル

「A L G O : Refrain of Light — 心象シューティング」の表記、バージョン表記、上部のティッカー、画面下にミナのひとこと（起動時に 1 つ、10 秒放置するたびに 1 つ）。

| 項目 | 内容 |
|---|---|
| はじめから | 操作表示の 3 択（キーボード／コントローラ（PS）／コントローラ（Xbox））→ 持ち物を初期化 → プロローグ |
| つづきから | オートセーブ／スロット 1〜3 を選んで読み込み → ハブ。セーブが無ければ「セーブデータがありません」 |
| あそびかた | 3 ページの説明を重ねて表示 |
| チュートリアル | 難易度やさしい固定でステージ0 へ |
| 設定 | 設定画面へ |
| クレジット | クレジット画面へ |
| おわる | ゲームを終了 |

## プロローグ

コードの雨と起動のカットシーンのあと、少年とミナの会話を Z で読む。R（Start）長押しで最初からやり直せる。読み終えると、チュートリアル未受講ならステージ0、受講済みなら「チュートリアルを受ける?」（はい → ステージ0／いいえ → ハブ）。内容は → [プロローグ](../03_ストーリー/01_プロローグ.md)。

## ハブ（タイムライン）

SNS「X」のタイムラインを模した画面。

| 要素 | 内容 |
|---|---|
| ヘッダ | ミナのアカウント（@mina_ai_）、フォロワー数、浄化した心、全幅の細い汚染バー |
| タブ | 「おすすめ｜フォロー中」（飾り） |
| 投稿カード | ステージごとの投稿（本人のハンドルと一文）。右上のピルは NEW（入れる未クリア）／✓ CLEAR（クリア済み）／LOCKED（まだ入れない）／FINAL。エンゲージ数、クリア済みならミナの返信投稿とベストタイム（BEST）。LOCKED のカードを選ぶと「ロック中 — まだダイブできません」 |
| フッタ | ↑↓ えらぶ／Z ダイブ／C 返信（クリア済みで未返信のカードのとき）／X 強化／T 記録。マウスではクリック |
| 会話 | 入場時に、直前にクリアしたステージの帰還会話（STAGE 2 の後は炎上の会話が続く）。クリア済みが 1 つ以上あるときは約 50% で再訪の小話。返信を選ぶと返信の小話 |

- 帰還会話と返信で浄化した心とフォロワーが増える（→ [ゲージと経済](03_ゲージと経済.md)）。返信はクリア済みのカードごとに、そのプレイの間に 1 回できる。
- STAGE 1〜3 をすべてクリアすると FINAL カードが加わる。
- Esc（OPTIONS / MENU）でポーズメニューが開く。

## 難易度選択

上から やさしい／ふつう／むずかしい／ルナティック の 4 段。各段に弾密度メーター、説明文、報酬倍率が出て、右にミナの立ち絵と一言（→ [難易度](08_難易度.md)）。↑↓ で選び Z で決定、X でハブへ。中ボスのあるステージで解放済みの入口があると「どこから始めますか?」（最初から／中ボスから／ボスから）のダイアログが続く（→ [ステージ構成](04_ステージ構成.md)）。

## ステージ本編（HUD）

| 位置 | 表示 |
|---|---|
| 左上 | LIFE（残機）、BOMB（残数とボタン）、ショットモードのチップ「ショット 連射／拡散／ホーミング／加速球」と切替ボタン、やさしさゲージ（満タンで「満タン！Ctrl」、全開中は残り時間）、「救った人 ◯/3」と「汚染」バー、炎上中は「炎上中」バッジ。敵弾が重なると薄くなる |
| 中央上 | 「浄化」カプセル（進行度 %。前のめりに進んでいると縁が脈打つ） |
| 右上 | SCORE、「♥ 心」（このステージで稼いだ浄化した心）、コンボ「×n」と猶予バー／フォロワー人数、随伴フォロワーの進捗ドット、TIME |
| 中央 | ボスカード（名前・ハンドル・穢れバー・残り本数・n/総）、スペル宣言カード、袖のカットイン |
| 下部 | 「降ってくる言葉」のティッカー、会話バー、ボスの字幕、バナー（STAGE n START／CLEAR、れんしゅう、FINAL — いなくならないで、♥ +1 など） |
| 右下 | 操作ガイド（→ [操作](01_操作.md)）、「R 長押しでリトライ」のチップ |

## ゲームオーバー

残機 0 で自機が止まり、バナー「くじけちゃった… Rでもう一度」とプロンプト「R：ボスからやり直す　／　Shift+R：最初から　／　Q：ステージから抜ける（ハブへ戻る）」が出る。パッド表示時は「{OPTIONS/MENU}：メニュー→さいしょからやりなおす　／　{×/B}：ステージから抜ける（ハブへ戻る）」。抜けると稼いだ分をオートセーブしてハブへ戻る。

## ショップ説明

初回の中ボス撃破の直後だけ出る、見出し「SHOP TUTORIAL 強化ショップ」の会話画面。10 行を読むとショップへ進む（→ [ショップと強化](07_ショップと強化.md)）。

## ショップ

見出し「SHOT UPGRADE SYSTEM 弾・ショット強化システム」。ヘッダに浄化した心、モードチップ（連射／拡散／ホーミング）、「トレーニング」ボタン、ルナティック解放までの条件。中央に「ミナの核」から広がる強化ツリー（縦横スクロール）、右に「つぎの一手」の詳細パネル。ミナのひとことがトーストで出る。X でハブへ、初回のショップ説明から来たときは「つづける」で中断したステージへ。詳細は → [ショップと強化](07_ショップと強化.md)。

## トレーニング

見出し「トレーニング（試し打ち）」。的が 1 体、DPS と累計与ダメと装備モードの表示、Tab で開くスキル欄。Esc か「◀ ショップへもどる (Esc)」でショップへ（→ [ショップと強化](07_ショップと強化.md)）。

## 記録

見出し「RECORDS クリアタイム ステージ × 難易度のベストタイム／スコア」。ステージ 4 行 × 難易度 4 列の表（→ [セーブと周回](09_セーブと周回.md)）。「もどる」でハブへ。

## 設定

見出し「設定 SETTINGS」。左のカテゴリを Q E（L1 R1 / LB RB）で切り替え、↑↓ で項目、←→ で値を変える。X・Esc で保存してタイトルへ戻る。ゲームに反映される項目は次のとおり。

| カテゴリ | 項目 | 内容 |
|---|---|---|
| 表示 | 画面モード | ウィンドウ／フルスクリーン |
| サウンド | マスター音量／BGM／効果音 (SE)／ボイス／環境音 | 0〜100。既定 80／70／85／90／55 |
| ゲームプレイ | メッセージ速度 | 遅／中／速（28／48／80 字/秒） |
| ゲームプレイ | オート会話送り | ON で全文表示から 1.4 秒後に自動で次へ |
| ゲームプレイ | オートセーブ | クリア・帰還時などの自動保存の ON/OFF |
| 操作 | 操作表示 | キーボード／PlayStation／Xbox（パッド時の表記。キーボードとパッドの切り替えは自動） |

操作のカテゴリには現在の割り当て（移動／ショット オート／ボム X／低速移動 Shift／回避 Alt／ポーズ Esc）が一覧で出る。

## クレジット

見出し「CREDITS クレジット 音楽・素材・開発スタッフ」。音楽・効果音・開発・スペシャルサンクスの各セクションを ↑↓ 長押しかホイールでスクロールして読む。X・Esc でタイトルへ。表記の内容は → [音楽と演出](11_音楽と演出.md)。

## あそびかた

見出し「HOW TO PLAY あそびかた — 操作／画面の見かた／コア機能」の 3 ページ。1 ページ目は操作の一覧（マウス操作の注記付き）、2 ページ目は HUD の各表示の意味、3 ページ目はやさしさ全開・ボム・弾強化・後方弾・浄化と汚染の説明。←→（L1 R1 / LB RB）かホイールでページを送り、X・Esc（× / B）で閉じる。タイトルとポーズメニューから開ける。

## ポーズメニュー

見出し「MENU メニュー」。ステージ、ハブ、ショップ、難易度選択、記録、ステージ0、ショップ説明で Esc（OPTIONS / MENU）から開く。開いている間、ゲームは止まる。画面右下には常に「Esc メニュー」のヒントが出ている。

| 行 | 内容 |
|---|---|
| マスター音量／BGM／効果音 (SE) | ←→ で 5 ずつ調整、Z でミュートと復帰の切り替え |
| ボタン表記 | キーボード／PlayStation／Xbox／自動 |
| スロット1にセーブ／スロット2にセーブ／スロット3にセーブ | 手動セーブ（各行に「保存済み」「空き」。保存すると「スロットnにセーブしました」） |
| つづける | 閉じる |
| さいしょからやりなおす | ステージ中のみ。ステージを最初から |
| 会話ログ | 会話ログを開く |
| あそびかた | あそびかたを開く |
| ハブへもどる | ステージ中のみ。1 回目で「ほんとうに もどる？」、もう一度で確定。オートセーブしてハブへ |
| タイトルへ | オートセーブしてタイトルへ |

## 会話ログ

見出し「BACKLOG 会話ログ」。表示済みの会話を話者ごとに色分けして 200 行まで遡れる。無いときは「まだ会話の記録はありません。」。L / Tab（SHARE / VIEW）で開き、↑↓・左スティック・ホイールでスクロール、X・Esc・L・Tab や右クリックで閉じる。

## Final・エピローグ

FINAL のボスを改心させると Final（カットシーン）に移り、暴走の演出 3.2 秒のあと少年とミナの対話を Z で読む。読み終えると白い画面を 3 秒挟んでエピローグへ。エピローグでは鍵アカのパスワード入力（→ [セーブと周回](09_セーブと周回.md)）と 4 行の英文（4 秒後に Z で進む）、独白と DM、END、スタッフロール（自動で流れ、Z でも進む）を経てタイトルへ戻る。R（Start）長押しは、Final では Final の最初へ、エピローグではスタッフロール中ならタイトルへ、それより前ならプロローグへ。内容は → [FINAL ミナ](../03_ストーリー/06_FINAL_ミナ.md)、[エピローグ](../03_ストーリー/07_エピローグ.md)。
