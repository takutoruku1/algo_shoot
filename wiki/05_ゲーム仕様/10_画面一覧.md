# 画面一覧

> **この記事の範囲**: ゲームに出てくる画面と、それぞれで「何ができるか」「どこへ行けるか」。ボタンの割り当ては → [操作](01_操作.md)、ショップの中身は → [ショップと強化](07_ショップと強化.md)、セーブの仕組みは → [セーブと周回](09_セーブと周回.md)。

## 画面のレイアウト

内部解像度は 384 × 216 px、HUD の描画には 1280 × 720 の設計座標を使う。画面は**左のサイドパネルと右の盤面**の 2 つに割れている。

| 領域 | 内部座標 | 設計座標 | 中身 |
|---|---|---|---|
| サイドパネル | x 0〜112 | x 0〜373 | 不透明の板。LIFE / BOMB / 浄化 / SCORE / TIME などの数値表示 |
| 額縁の隙間 | x 112〜120 | x 373〜400 | 板を置かず、右端に縦罫を 1 本引く＝盤面の左辺が線として立つ |
| 盤面 | x 120〜384（幅 264） | x 400〜1280（幅 880） | 自機・敵・弾・背景。縦は 216 px 全部 |

この座標を持っているのは 1 か所だけで、自機の可動域・弾の画面外破棄・ボスの立ち位置・範囲攻撃の候補配置は全部そこを見る。**弾と数値表示が原理的に重ならない**のがこの割り方の目的である。背景とカットシーンとメニューは、割らずに画面全体を使う。

## 全体の流れ

| 画面 | できること | 行き先 |
|---|---|---|
| タイトル | はじめから／つづきから／あそびかた／チュートリアル／設定／クレジット／おわる。「はじめから」は確認も機器選択も挟まずそのままプロローグへ | プロローグ、ハブ、ステージ0、設定、クレジット |
| プロローグ | 会話を読む | ステージ0、または（受講済みなら）ハブ |
| ステージ0「れんしゅう」 | 操作の練習 | ハブ |
| ハブ | 声のする投稿を探す、返信する、ジョブを選ぶ、強化・記録へ（強化と記録は解禁後） | 投稿詳細、ショップ、記録 |
| 投稿詳細 | 投稿を読む、潜り方を選ぶ | ステージ、ハブ |
| ステージ本編 | 戦う | ハブ（クリア・離脱）、FINAL は Final へ |
| ショップ説明 | 初回のみ会話を読む | ショップ |
| ショップ | 一本道 13 段を上から順に買う | ハブ、トレーニング、（初回のみ）中断したステージ |
| トレーニング | 試し打ち | ショップ |
| 記録 | ベストタイムとスコアを見る | ハブ |
| 設定 | 設定を変える | タイトル |
| クレジット | 出典を見る | タイトル |
| Final・エピローグ・スタッフロール | 結末を読む | タイトル |
| あそびかた／ポーズメニュー／会話ログ | いまの画面の上に重なる | 閉じると元の画面 |

## タイトル

「A L G O : Refrain of Light — 心象シューティング」の表記、バージョン表記、上部のティッカー、画面下にミナのひとこと（起動時に 1 つ、10 秒放置するたびに 1 つ）。

| 項目 | 内容 |
|---|---|
| はじめから | 操作表示の 3 択（キーボード／コントローラ（PS）／コントローラ（Xbox））→ 持ち物を初期化 → プロローグ |
| つづきから | オートセーブ／スロット 1〜3 を選んで読み込み → ハブ。セーブが無ければ「セーブデータがありません」 |
| あそびかた | 3 ページの説明を重ねて表示 |
| チュートリアル | 難易度やさしい固定でステージ0 へ |
| 設定 | 設定画面へ |
| クレジット | クレジット画面へ |
| おわる | ゲームを終了 |

## プロローグ

コードの雨と起動のカットシーンのあと、ミナの会話を Z で読み、三度の下書き選択を ↑↓ と Z で送る。第一声（3 択）・命名（3 択）・タイムラインの受け（**2 択**「何をいってるの」「詳しく教えて」）である。R（Start）長押しで最初からやり直せる。読み終えると、チュートリアル未受講ならステージ0、受講済みなら「チュートリアルを受ける?」（はい → ステージ0／いいえ → ハブ）。内容は → [プロローグ](../03_ストーリー/01_プロローグ.md)。

## ハブ（タイムライン）

SNS「X」のタイムラインを模した画面。

| 要素 | 内容 |
|---|---|
| ヘッダ | ミナのアカウント（@mina_ai_）、フォロワー数、浄化した心 |
| 固定ポスト | 最上段。直近にクリアしたステージの帰還でミナが出した投稿（「固定」の印つき） |
| 投稿カード | ステージごとの投稿（本人のハンドルと一文）と、その間に混ざる他人の投稿 6〜10 本。右上のピルは 声（これから潜る）／届いた（クリア済み）／限界（FINAL）で、他人の投稿とまだ聞こえない投稿にはピルが付かない。エンゲージ数、クリア済みならミナの返信投稿とベストタイム（BEST）。潜れる投稿と病みサインを含む投稿の本文の下では、消された一行を示す伏字がうっすら明滅する |
| フッタ | Z 潜る／C 返信（クリア済みで未返信のカードのとき）／ジョブ／X 強化／T 記録。マウスではクリック。**ジョブは解禁の条件が無く初回訪問から出る**（ショップが開く前に一度も選べない、を避けるため）。**強化は最初の面のボスを倒すまで、記録はどれか一面をクリアするまで、ボタンごと出ない**（押せないものを見せない） |
| ジョブ選択 | フッタの「ジョブ」から、カードがその場で開く形の 4 択が出る。ここで選んだ型でそのランを通す（→ [ジョブ](12_ジョブ.md)） |
| 汚染の表れ | 汚染 0.25 以上で画面全体に灰〜紫の薄い膜がかかる（数値もバーも出さない） |
| 会話 | 入場時に、直前にクリアしたステージの帰還会話（STAGE 2 の後は炎上の会話が続く）。クリア済みが 1 つ以上あるときは約 50% で再訪の小話。返信を選ぶと返信の小話 |

- ↑↓ ですべての投稿を辿れるが、潜れるのは「声の聞こえる投稿」（解放済みのステージと FINAL）だけ。声のある投稿にカーソルが乗ると左のバーが 60bpm で脈打ち、カードの下にミナの一行が出る。他人の投稿では無言。まだ聞こえない投稿で Z を押すとミナが「……まだ、聞こえません。」と返す。
- 1 画面は 5 枚まで。カーソルに合わせて縦にスクロールする。カーソルの初期位置は次の声の投稿なので、Z 二押しで潜れる。
- 帰還会話と返信で浄化した心とフォロワーが増える（→ [ゲージと経済](03_ゲージと経済.md)）。返信はクリア済みのカードごとに、そのプレイの間に 1 回できる。
- STAGE 1〜3 をすべてクリアすると FINAL カードが加わる。
- 背景の夜景はごく低速で縦に漂う。Esc（OPTIONS / MENU）でポーズメニューが開く。

## 投稿詳細（潜り方を選ぶ）

ハブで声のある投稿を Z で開くと、そのカードがその場で開く。本文／消された一行の伏字／ミナの一言／潜り方が 1 枚に載る。潜り方は上から 浅く／いつも通り／深く／底まで の 4 段で、各段にミナの一言、♥（残機）とボムの数、ボスの板の枚数、♥ と報酬倍率が並ぶ（数値は → [難易度](08_難易度.md)）。既定の段は前回の難易度なので、そのまま Z で潜れる。↑↓ で段を選び、X で閉じる。FINAL は段を出さずそのまま潜る。

## ステージ本編（HUD）

数値の表示はすべて左のサイドパネルに集まっている。盤面の上には弾と敵と自機しか乗らない。

| 位置 | 表示 |
|---|---|
| サイドパネル（上から） | LIFE（残機のハート）→ BOMB（残数とボタンのバッジ）→「浄化」（進行度 % とバー）→ SCORE → TIME → COMBO「× n」（コンボ 2 以上のときだけ）→ ジョブ名と撃ち方のチップ（常設）→ 集中モードのチップ（覚えているときだけ） |
| 盤面の中央上 | ボスカード（名前・ハンドル・穢れバー・残り本数・n/総）、スペル宣言カード、袖のカットイン |
| 盤面の下部 | 「降ってくる言葉」のティッカー、会話バー、ボスの字幕、バナー（STAGE n START／CLEAR、れんしゅう、♥ +1 など） |
| 盤面の全体 | 被弾すると盤面の縁が赤く光る。フラッシュも盤面の中だけに出る |

- **常駐の操作ガイドは出ない**（→ [操作](01_操作.md)）。割り当ては「あそびかた」でいつでも開ける。
- **やさしさゲージ・「救った人 ◯/3」・汚染バー・「炎上中」バッジ・随伴フォロワーの進捗ドットは、いずれも撤去済みで表示されない。**
- 条件で出る行（コンボ・集中モード）は、出ていない間も場所を空けたままにする＝行が湧いて他がずれることがない。ジョブ名と撃ち方のチップは常に出ており、**切替キーのバッジは付かない**（切り替えられないため。→ [ジョブ](12_ジョブ.md)）。

## ゲームオーバー

残機 0 で自機が止まり、見出し「くじけちゃった…」の下に、会話中の 2 択と同じ縦積みの選択肢が盤面の中央に出る。

| 行 | 行き先 |
|---|---|
| （ボスからやり直す） | 直前のボス戦の頭から。**既定のカーソル位置** |
| （最初からやり直す） | そのステージの頭から |
| （ステージから抜ける） | ハブへ |

↑↓・左スティック・マウスのホバーで選び、Z / A / クリックで決定する。選択肢の下に既存キーの案内「R：ボスからやり直す　／　Shift+R：最初から　／　Q：抜ける」（パッド表示時は「B：抜ける」）が小さく添えられ、そのキーもそのまま効く。抜けると稼いだ分をオートセーブしてハブへ戻る。ボスの改心が始まっていれば、残機 0 でもこの選択は出ない。

## ショップ説明

初回の中ボス撃破の直後だけ出る、見出し「SHOP TUTORIAL 強化ショップ」の会話画面。8 行を読むとショップへ進む（→ [ショップと強化](07_ショップと強化.md)）。

## ショップ

見出し「SHOP つよくなる」。**1 画面に収まり、スクロールしない。** ヘッダに浄化した心と「T ためし撃ち」ボタン、左に 13 段の縦 1 列（買った段は水色に点灯して縦線でつながり、次の 1 段だけ金色で呼吸する。先の段も名前と価格が見えている）、右に詳細パネル（ジョブと撃ち方、「n / 13 段目」、段の名前、「いま → 買うと」の 2 行、買うボタン、進捗バー）。「溜め打ちを覚える」「集中モードを覚える」の 2 段だけ一回り大きく「NEW ABILITY」が付く。フッタは「もどる／えらぶ／買う／上から順に買えます」。ミナのひとことがトーストで出る。X でハブへ、初回のショップ説明から来たときは中断したステージへ。詳細は → [ショップと強化](07_ショップと強化.md)。

## トレーニング

見出し「トレーニング（試し打ち）」。的が 1 体、DPS と累計与ダメと撃ち方の表示、Tab で開くスキル欄。Esc か「◀ ショップへもどる (Esc)」でショップへ（→ [ショップと強化](07_ショップと強化.md)）。

## 記録

見出し「RECORDS クリアタイム ステージ × 難易度のベストタイム／スコア」。ステージ 4 行 × 難易度 4 列の表（→ [セーブと周回](09_セーブと周回.md)）。「もどる」でハブへ。

## 設定

見出し「設定 SETTINGS」。左のカテゴリを Q E（L1 R1 / LB RB）で切り替え、↑↓ で項目、←→ で値を変える。X・Esc で保存してタイトルへ戻る。ゲームに反映される項目は次のとおり。

| カテゴリ | 項目 | 内容 |
|---|---|---|
| 表示 | 画面モード | ウィンドウ／フルスクリーン |
| サウンド | マスター音量／BGM／効果音 (SE)／ボイス／環境音 | 0〜100。既定 80／70／85／90／55 |
| ゲームプレイ | メッセージ速度 | 遅／中／速（28／48／80 字/秒） |
| ゲームプレイ | オート会話送り | ON で全文表示から 1.4 秒後に自動で次へ |
| ゲームプレイ | オートセーブ | クリア・帰還時などの自動保存の ON/OFF |
| 操作 | 操作表示 | キーボード／コントローラー（起動直後の表記。触った機器へ自動で切り替わる） |

操作のカテゴリには現在の割り当てが 7 行で並ぶ（移動 ↑↓←→／ショット オート／ロックオン送り F／ボム X／回避 Alt／集中モード V／ポーズ Esc）。表示専用で、キーの変更はできない。溜め打ちはロックオン送りの行に添え書きとして出る（→ [操作](01_操作.md)）。

## クレジット

見出し「CREDITS クレジット 音楽・素材・開発スタッフ」。音楽・効果音・開発・スペシャルサンクスの各セクションを ↑↓ 長押しかホイールでスクロールして読む。X・Esc でタイトルへ。表記の内容は → [音楽と演出](11_音楽と演出.md)。

## あそびかた

見出し「HOW TO PLAY あそびかた」の **5 ページ**。先頭 3 ページは **キーボード／コントローラー／マウスの 3 タブ**で、その機器の割り当て一覧を 2 列で並べる（移動・撃つ・ロックオン送り・溜め打ち・回避・ボム・集中モード・会話送り・既読スキップ・メニュー・やりなおす）。**まだ手に入れていない操作（回避・溜め打ち・集中モード）は行ごと出ない。** 下に「※ 光は自動で出ます。撃つボタンはありません」と会話 2 択の案内が添えられる。4 ページ目は HUD の各表示の意味、5 ページ目は**ボム／弾強化／後方弾／浄化と汚染**の 4 枚のカード。←→（LB RB）かホイールで送り、X・Esc（B）で閉じる。タイトルとポーズメニューから開ける。

## ポーズメニュー

見出し「MENU メニュー」。ステージ、ハブ、ショップ、記録、ステージ0、ショップ説明で Esc（OPTIONS / MENU）から開く。開いている間、ゲームは止まる。

**二段構え**で、一段目は 3 行しかない。

| 一段目 | 二段目の中身 |
|---|---|
| つづける | （即閉じる） |
| このステージ ▸ | さいしょからやりなおす／会話ログ／ハブへもどる。ステージ中のみ有効で、上下 2 つは誤爆を防ぐため Z の二段階確認 |
| 設定とデータ ▸ | マスター音量／BGM／効果音 (SE) の 3 スライダー（←→ で 5 ずつ、Z でミュート切替）、ボタン表記、あそびかた、スロット 1〜3 へセーブ、タイトルへ |

二段目からは X / 右クリック / Esc で一段目へ戻る。Esc は一段目でだけメニューを閉じる。

## 会話ログ

見出し「BACKLOG 会話ログ」。表示済みの会話を話者ごとに色分けして 200 行まで遡れる。無いときは「まだ会話の記録はありません。」。L / Tab（SHARE / VIEW）で開き、↑↓・左スティック・ホイールでスクロール、X・Esc・L・Tab や右クリックで閉じる。

## Final・エピローグ

FINAL のボスを改心させると Final（カットシーン）に移り、暴走の演出 3.2 秒のあとミナの語りと台詞を Z で読み、最後の下書き選択を送る。読み終えると白い画面を 3 秒挟んでエピローグへ。エピローグは 4 つの場面を続けて流す——**夜空を見上げる 10 行 → 歩きながらの 8 行（行が進むほど空が明ける） → スタッフロール（自動で流れ、Z でも進む） → END の下書き選択**。END を送り切るとタイトルへ戻る。R（Start）長押しは、Final では Final の最初へ、エピローグではスタッフロール以降ならタイトルへ、それより前ならプロローグへ。内容は → [FINAL ミナ](../03_ストーリー/06_FINAL_ミナ.md)、[エピローグ](../03_ストーリー/07_エピローグ.md)。
