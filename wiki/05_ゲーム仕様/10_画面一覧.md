# 画面一覧

> **この記事の範囲**: ゲームに出てくる画面と、それぞれで「何ができるか」「どこへ行けるか」。ボタンの割り当ては → [操作](01_操作.md)、ショップの中身は → [ショップと強化](07_ショップと強化.md)、セーブの仕組みは → [セーブと周回](09_セーブと周回.md)。

## 画面のレイアウト

内部解像度は 384 × 216 px、HUD の描画には 1280 × 720 の設計座標を使う。画面は**左のサイドパネルと右の盤面**の 2 つに割れている。

| 領域 | 内部座標 | 設計座標 | 中身 |
|---|---|---|---|
| サイドパネル | x 0〜112 | x 0〜373 | 不透明の板。LIFE / BOMB / 浄化 / SCORE / TIME などの数値表示 |
| 額縁の隙間 | x 112〜120 | x 373〜400 | 板を置かず、右端に縦罫を 1 本引く＝盤面の左辺が線として立つ |
| 盤面 | x 120〜384（幅 264） | x 400〜1280（幅 880） | 自機・敵・弾・背景。縦は 216 px 全部 |

この座標を持っているのは 1 か所だけで、自機の可動域・弾の画面外破棄・ボスの立ち位置・範囲攻撃の候補配置は全部そこを見る。**弾と数値表示が原理的に重ならない**のがこの割り方の目的である。背景とカットシーンとメニューは、割らずに画面全体を使う。

## 全体の流れ

| 画面 | できること | 行き先 |
|---|---|---|
| タイトル | はじめから／つづきから／設定。「はじめから」は確認も機器選択も挟まずそのままプロローグへ。「チュートリアル」の項目は練習面と一緒に畳まれていて出ない | プロローグ、ハブ、設定 |
| プロローグ | 会話を読む → オープニングフィルム（約 41 秒・スキップ可） | ハブ（練習面が無効のため、受講確認は出ずに直行する） |
| ステージ0「れんしゅう」 | **無効。** 入る導線が無い（→ [ステージ構成](04_ステージ構成.md)） | — |
| ハブ（スマホ） | ホーム画面（最初の面のクリアで解禁）から SNS・強化ショップ・記録・写真・カスタマイズのアプリを開く。SNS のタイムラインで声のする投稿を探す、返信する、アカウント（ジョブ）を切り替える | 投稿詳細、ショップ、記録、写真、カスタマイズ |
| 投稿詳細 | 投稿を読む、潜り方を選ぶ | ステージ、ハブ |
| ステージ本編 | 戦う | ハブ（クリア・離脱）、FINAL は Final へ |
| ショップ説明 | 最初の面をクリアしてハブへ帰った回だけ会話を読む | ハブ（ホーム） |
| ショップ | 一本道 14 段を上から順に買う | ハブ、トレーニング |
| トレーニング | 試し打ち | ショップ |
| 記録 | ベストタイムとスコアを見る | ハブ |
| 写真・カスタマイズ | 背景写真を選ぶ／カーソルとコスチュームを買って着せる | ハブ |
| 設定 | 設定を変える | タイトル |
| クレジット | 出典を見る | タイトル |
| Final・エピローグ・スタッフロール | 結末を読む | タイトル |
| あそびかた／ポーズメニュー／会話ログ | いまの画面の上に重なる | 閉じると元の画面 |

## タイトル

画面いっぱいのミナの一枚絵の上に、「Refrain」のロゴと、ミナのひとこと（起動時に 1 つ、10 秒放置で 1 つ。操作するとまた出る）。左下にバージョン表記が小さく出る。項目は 4 つである。

| 項目 | 内容 |
|---|---|
| はじめから | 確認も機器選択も挟まず、持ち物を初期化してそのままプロローグへ |
| つづきから | オートセーブ／スロット 1〜3 を選んで読み込み → ハブ。セーブが無ければ「セーブデータがありません」 |
| 設定 | 設定画面へ |
| クレジット | クレジット画面へ（**2026-09-17 に追加**） |

「チュートリアル」の項目は練習面と一緒に畳まれていて出ない（切り替えを戻せば項目ごと復活する）。あそびかたはポーズメニューから開く。

> **クレジット項目が追加された理由。** それまでクレジット画面に到達する導線が 1 つも無く、**楽曲のライセンス表記義務（MusMus・PeriTune の CC BY 4.0）を果たせていなかった**。表記のための唯一の導線なので、チュートリアルのような出し分けはせず常に出す。

## プロローグ

コードの雨と起動のカットシーンのあと、ミナの会話を Z で読み、三度の下書き選択を ↑↓ と Z で送る。第一声（3 択）・命名（3 択）・タイムラインの受け（**2 択**「何をいってるの」「詳しく教えて」）である。R（Start）長押しで最初からやり直せる。読み終えると**オープニングフィルム**が流れる——約 41 秒・11 カット。三人の日常の一枚絵にそれぞれの本音の一行、まばたきするミナの一枚絵、四人の出撃カットイン、浄化の光、と続く。Z / X / Esc（B / Start）の長押し 0.65 秒か、右下の SKIP のクリックで飛ばせる。終わるとハブへ直行する（練習面が無効のため受講確認は出ない）。内容は → [プロローグ](../03_ストーリー/01_プロローグ.md)。

冒頭のスマホのカットでは「たすけて」が打たれては消える。**2026-09-17 に「消す」ほうへ溜めが足された**——打つのが 1 文字 0.55 秒なのに消すのが 0.20 秒で、いちばん見せたい「消す」手つきが一瞬で終わっていたため、消去を 0.60 秒/字、送る前の迷いの静止を 1.60 秒に伸ばした（そのぶんは前後の空白から借りていて、カット全体の尺は変わらない）。

## ハブ（少年のスマホ）

少年のスマホをかたどった画面。**最初の面をクリアするまではタイムラインだけ**が映り、クリアするとホーム画面が現れる。初回だけ、いままで見ていたタイムラインが縮んで SNS のアプリアイコンに収まり、強化ショップのアイコンが灯る一度きりの演出が入る——見ていた画面が「スマホの中のひとつのアプリ」だったと分かる瞬間である。

### ホーム画面

壁紙の夜景の上に「ホーム」の見出し、時計（実時刻）と日付、5 つのアプリ——**SNS／強化ショップ／記録／写真／カスタマイズ**——が並ぶ。←→↑↓（またはマウス）でアプリを選び、Z かクリックで開く。強化ショップは最初の面のボスを倒すまで、記録はどれか一面をクリアするまで鍵つきで、開こうとすると「準備中」のトーストが返る。画面の下には使用中のアカウント（キャラの顔・名前・ハンドル）と「救った心」・インプレッションが出る。

### SNS（タイムライン）

SNS「Y」のタイムライン（2026 年内に X から **Y** へ改名した。会話の話者ラベルも「Ｙ 投稿」「Ｙ システム」である）。X・Esc（B）でホーム画面へ戻る（ホームが現れる前は戻り先が無く、何も起きない）。

| 要素 | 内容 |
|---|---|
| ヘッダ | **使用中のアカウント**（顔・名前・認証バッジ・ハンドル）。押すとアカウント切り替えが開く。その下に「タイムライン」の見出しと、**「フォロワー」「インプレ」の語ラベル付き**の数（2026-09-17 に ♥ のアイコン表記から変更＝どちらの数字か読めるようにした） |
| 固定ポスト | 最上段。直近にクリアしたステージの帰還でミナが出した投稿（「固定」の印つき） |
| 投稿カード | ステージごとの投稿（本人のハンドルと一文）と、その間に混ざる他人の投稿 6〜10 本。右上のピルは 声（これから潜る）／届いた（クリア済み）／限界（FINAL）で、他人の投稿とまだ聞こえない投稿にはピルが付かない。エンゲージ数、クリア済みならミナの返信投稿とベストタイム（BEST）。潜れる投稿と病みサインを含む投稿の本文の下では、消された一行を示す伏字がうっすら明滅する |
| フッタ | **「ホーム」「アカウント」の 2 項目だけ**（2026-09-27 にキー表記 X／C／J を貼るのをやめた）。矢印で降りて Z、またはクリック。**アカウントは解禁の条件が無く初回訪問から開ける**。返信はカード下部の [返信] へ、強化と記録の入口はホーム画面のアプリへ移った |
| カード下部のボタン | 選んでいるカードの下に **[ダイブ] [返信]** が並び、**←→** で切り替えて Z。返信できないカード（声の無い投稿・未クリア・すでに返信済み）では [返信] が薄くなりカーソルが乗らない |
| アカウント切り替え | フッタの「アカウント」／ヘッダ（先頭のカードで ↑）／**スマホの左隣の「キャラ切り替え」ボタン（Tab・パッド Y・クリック）**のどれかで、カードがその場で開く形の 4 択が出る。行を選ぶと下に**性能パネル**（撃ち方・火力・溜め・♥・移動・回避距離・回避の戻り・強み・弱み）が開く。ここで選んだアカウント（＝ジョブ）でそのランを通す。**ミナ（@mina_ai_）以外は、その子の面をクリアするとつながる**（→ [ジョブ](12_ジョブ.md)） |
| キー案内 | 画面**右下のヒント帯 1 行**（[キャップ] ラベルの並び）。モードごとに中身が変わり、「メニュー」はクリックでも押せる（→ [操作](01_操作.md)） |
| 汚染の表れ | 汚染 0.25 以上で画面全体に灰〜紫の薄い膜がかかる（数値もバーも出さない） |
| 会話 | 入場時に、直前にクリアしたステージの帰還会話（STAGE 2 の後は炎上の会話が続く）。ミナ以外を使っていると、その子との掛け合いになる。クリア済みが 1 つ以上あるときは約 50% で再訪の小話（SNS を開いたときに始まる）。返信を選ぶと返信の小話 |

- ↑↓ ですべての投稿を辿れるが、潜れるのは「声の聞こえる投稿」（解放済みのステージと FINAL）だけ。声のある投稿にカーソルが乗ると左のバーが 60bpm で脈打ち、カードの下にミナの一行が出る。他人の投稿では無言。まだ聞こえない投稿で Z を押すとミナが「……まだ、聞こえません。」と返す。
- 最後のカードで ↓ を押すとフッタへ降り（着地は「アカウント」）、**先頭のカードで ↑ を押すとヘッダー（使用中のアカウント）**へ上がる。フッタ上では ←→ で項目を巡り、↑ でカードへ戻る。
- 1 画面は 5 枚まで。カーソルに合わせて縦にスクロールする。カーソルの初期位置は次の声の投稿なので、Z 二押しで潜れる。
- 帰還会話と返信で浄化した心とフォロワーが増える（→ [ゲージと経済](03_ゲージと経済.md)）。返信はクリア済みのカードごとに、そのプレイの間に 1 回できる。
- STAGE 1〜3 をすべてクリアすると FINAL カードが加わる。
- 背景の夜景はごく低速で縦に漂う。**M（Menu(≡)）でポーズメニューが開く**——スマホ系の画面では Esc は「もどる」のままである（→ [操作](01_操作.md)）。

## 投稿詳細（難易度を選んで潜る）

ハブで声のある投稿を Z で開くと、そのカードがその場で開く。本文／消された一行の伏字／ミナの一言／難易度の 4 段が 1 枚に載る。段は上から **EASY／NORMAL／HARD／LUNATIC**（2026-09-17 に「浅く／いつも通り／深く／底まで」から変更）で、各段に報酬（インプレッション）の倍率とボスの板の枚数が並ぶ（♥ とボムの初期数は全難易度共通なので出ない。数値は → [難易度](08_難易度.md)）。既定の段は前回の難易度。

- **段を選んだ時点でそのまま潜る。** ↑↓ で選んで Z、またはマウスなら**段を 1 回クリックするだけ**でダイブが始まる。「潜り方」の見出し・ミナの一言・「潜る」ボタンは 2026-09-17 に削除された。
- **1 クリックで入れるようになったのもこのときである。** それまでは詳細を開いた直後 0.15 秒のクリックが捨てられており、「ダブルクリックしないと入らない」状態だった。
- LUNATIC が未解放のときは、その段に「フォロワー{n}以上で解放（威力Lv4でも可）」と出る。
- X・Esc で閉じる。**FINAL も 2026-09-27 から同じ 4 段を出す。** 段が出ないのは「FINAL の初挑戦をミナで開いている」ときだけで、そこには段の代わりに穢れ色の一枚が出て「なぜ潜れないか」を先に示し、ボタンが「アカウントを選ぶ」に変わる（押すとアカウント切り替えが開く。→ [ジョブ](12_ジョブ.md)）。

## ステージ本編（HUD）

数値の表示はすべて左のサイドパネルに集まっている。盤面の上には弾と敵と自機しか乗らない。

| 位置 | 表示 |
|---|---|
| サイドパネル（上から） | 使用中のアカウント（顔・キャラクター名・ハンドル）→ 拾った強化アイテム → LIFE（そのキャラの核マークを並べる）→ BOMB（残数とボタンのキーキャップ）→「浄化」（進行度 % とバー）→ SCORE → TIME → **LOCK-ON**（下記）→ COMBO「× n」（コンボ 2 以上のときだけ）→ 集中モードの行（覚えているときだけ） |
| ボス本体の頭上 | **ボスの体力ゲージ**（いまの 1 本のバーと残り本数の点。無敵中は灰＋斜線、BREAK 中は金。→ [ボス戦](06_ボス戦.md)）。中ボスも同じ |
| 盤面の中央上 | スペル宣言カード、袖のカットイン。**画面上端のボスカードは 2026-09-27 に廃止された** |
| 盤面の中央 | 初見チュートリアル中だけ出る**操作カード**（下記） |
| 盤面の下部 | 「降ってくる言葉」のティッカー、会話バー、ボスの字幕、バナー（STAGE n START／CLEAR、れんしゅう など） |
| 盤面の全体 | 被弾すると盤面の縁が赤く光る。フラッシュも盤面の中だけに出る |

- **常駐の操作ガイドは出ない**（→ [操作](01_操作.md)）。割り当ては「あそびかた」でいつでも開ける。
- **やさしさゲージ・「救った人 ◯/3」・汚染バー・「炎上中」バッジ・随伴フォロワーの進捗ドットは、いずれも撤去済みで表示されない。**
- **与ダメージの数値は表示されない**（2026-09-17）。何点入ったかは数字で見せず、光・音・揺れ・HP バーで返す。「MAX」「BREAK!」のような状態を伝える語は数値ではないので残る。
- **ジョブ名と撃ち方のチップは廃止された**（2026-09-17）。代わりにサイドパネルの最上段が、いま潜っているキャラクターの顔・名前・アカウントになっている（→ [ジョブ](12_ジョブ.md)）。
- 条件で出る行（コンボ・集中モード）は、出ていない間も場所を空けたままにする＝行が湧いて他がずれることがない。
- **キーの表記はすべて「キーキャップ」**（押せる鍵の形。パッドは丸ボタン／ピル、マウスは小さなマウスの絵）に統一されている（→ [操作](01_操作.md)）。
- **戦闘画面の右下にあった「M メニュー」チップは 2026-09-27 に廃止された。** ヒント帯はスマホ系の画面にだけ出る。
- **会話で戦闘が止まっているあいだ、自機は吹き出しの奥へ回る。** 戦闘中の吹き出しは弾より奥に描かれるので、自機がそのまま前に居ると「動かせないのに読めない」が起きる。止まっている間だけ自機の描画順を吹き出しの下へ落とし、明けたら戻す（弾は触らないので、止まった弾の位置は吹き出し越しに見える）。
- **中ボスを倒したときの回復表示**は、「♥ +1　BOMB +1」のベタ文字をやめ、**そのキャラの核マークとボム印に「+1」を添えたアイコン表記**になった（♥ は 4 人共通の記号で「誰の何が増えたか」が伝わらないため）。

### LOCK-ON 行

TIME の下に、ロックオンの状態を出す行がある（2026-09-27）。左に「LOCK-ON」の見出しと発動キーのキーキャップ（押しているあいだキャップが沈む）、右に状態の語と点。

| 状態 | 見え方 |
|---|---|
| OFF | 灰色 |
| 待機（モードは立っているが盤面に敵が居ない） | 青緑でゆっくり明滅。**盤面に照準マーカーが出ないので、ここが唯一の手がかり** |
| 追尾中 | アカウント色 |

ロックオンは「掴んだ敵」ではなく**モード**で、対象が倒れても画面外でも敵ゼロでも解除されない（→ [操作](01_操作.md)）。

### ボスの体力の見せ方

**画面上端のボスカード（アイコン・名前・ハンドル・リプ数・穢れバー・残り本数・n/総）は 2026-09-27 に廃止され、ボス本体の頭上の簡略ゲージに置き換わった。** 撃破の見送り（穢れ色から浄化色へ抜けてから薄れる一拍）は頭上ゲージに引き継がれている。詳細は → [ボス戦](06_ボス戦.md)。

### 操作カード（初見チュートリアル）

初見チュートリアルの会話中だけ、盤面の中央に**キーボード／コントローラー／マウスの割り当てを 3 列で並べたカード**が出る。会話が進むにつれて 移動 → 撃つ → ロックオン → ロックオン解除 → ボム と話題が切り替わり、話題の無い行では畳まれる。**ミナのセリフからキー名の羅列が無くなった**のと対になっていて、セリフは「何ができるか・なぜするか」、カードは「どのボタンか」を受け持つ（→ [チュートリアル](../03_ストーリー/02_チュートリアル.md)）。入力は一切奪わないので、会話送りは止まらない。
- ミナ以外のアカウントで STAGE1〜3 に潜ると、会話がすべて**そのキャラ専用の物語**に置き換わる（ミナは登場せず、下書き選択も出ない。話者名は素の名前＋表情差分。→ [09 キャラ別ストーリー](../03_ストーリー/09_キャラ別ストーリー.md)）。

## ゲームオーバー

残機 0 で自機が止まり、見出し「くじけちゃった…」の下に、会話中の 2 択と同じ縦積みの選択肢が盤面の中央に出る。

| 行 | 行き先 |
|---|---|
| （ボスから・スコア半分消費） | 直前のボス戦の頭から。スコアは半分になる。**既定のカーソル位置**。そのランでボスが出ていなければこの行は出ない（2 択になる） |
| （最初からやり直す） | そのステージの頭から |
| （ステージから抜ける） | ハブへ |

## Final・エピローグ

FINAL のボスを改心させると Final（カットシーン）に移る。「待っている三人」の一枚絵の上に余韻を 3.2 秒置いたあと、ミナの語りと台詞を Z で読み、最後の下書き選択を送る（決着とともに「声が届いた」一枚絵へゆっくり重なる）。読み終えると屋上の一枚絵を 3 秒挟んでエピローグへ。エピローグは 4 つの場面を続けて流す——**屋上で空を見上げる会話 → エンディングフィルム（約 53 秒・その後の四人の一枚絵と一言。スキップ可） → スタッフロール（自動で流れ、Z でも進む） → END の下書き選択**。END を送り切るとタイトルへ戻る。R（Start）長押しは、Final では Final の最初へ、エピローグではスタッフロール以降ならタイトルへ、それより前ならプロローグへ。内容は → [FINAL ミナ](../03_ストーリー/06_FINAL_ミナ.md)、[エピローグ](../03_ストーリー/07_エピローグ.md)。
