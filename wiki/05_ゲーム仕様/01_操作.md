# 操作

> **この記事の範囲**: キーボード・ゲームパッド・マウスの割り当てと、画面に出るボタン表記の切り替え。各操作で何が起きるか（速度・無敵時間・効果量）は → [自機とショット](02_自機とショット.md)、各画面で何ができるかは → [画面一覧](10_画面一覧.md)。

## 入力機器と表記

キーボード、ゲームパッド、マウスのどれでも遊べ、遊んでいる途中で持ち替えられる。ゲームパッドのボタン配置は Xbox 系の物理配置で固定されており、画面上の表記だけを PlayStation 表記（〇 × □ △ / L1 R1 / L3 R3 / OPTIONS / SHARE）と Xbox 表記（A B X Y / LB RB / L3 R3 / MENU / VIEW）で切り替えられる。以下の表では「PS / Xbox」の順で併記する。

## 戦闘中の操作（ステージ・トレーニング）

| 操作 | キーボード | ゲームパッド（PS / Xbox） | マウス |
|---|---|---|---|
| 移動 | 矢印キー / WASD | 左スティック | カーソルの位置へ自機が追従する |
| 撃つ | 自動（ボタンなし） | 自動 | 自動 |
| 低速移動 | Shift（押している間） | L1 / LB | Shift を併用 |
| ロックオン（送り） | F | R1 / RB | 左クリック |
| ロック解除 | —（送りで一巡すると戻る） | —（同左） | 右クリック（回避と同時に出る） |
| 回避 | Alt | L3 / L3（左スティック押し込み） | 右クリック（カーソルの方向へ。カーソルが自機から 8 px 以内ならその場回避） |
| ボム | X | □ / X | 中クリック |
| ショットモード切替 | V | × / B | ホイール |
| ポーズメニューを開く | Esc | OPTIONS / MENU | —（右クリックで閉じる） |
| 会話ログを開く | L / Tab | SHARE / VIEW | —（右クリックで閉じる） |
| リトライ（最初からやり直す） | R 長押し 0.45 秒 | ポーズメニュー「さいしょからやりなおす」 | — |

- 撃つボタンは無く、光は常に自動で出る。会話中・回避中・ゲームオーバー後は止まる。
- マウス移動時も速度の上限は通常移動と同じで、Shift を押せば低速になる。
- 会話送りに使った左クリックは、離すまでロックオンの送りとして扱われない（会話明けの 1 クリックで意図せずロックが動くのを防ぐ）。

## ロックオン

**ロックオンは撃つ方向を敵へ向ける操作である。** 押していないあいだ、ミナの光は常に右へ飛ぶ。ロック中だけ、光がロック先の敵の方向へ飛ぶ。

- **対象** — 盤面の中にいる、まだ浄化していない敵すべて。雑魚も中ボスもボスも区別しない。
- **送り** — 左クリック / F / R1 を押すたび、自機から近い順に「今の対象の次」へ移る。一巡すると、いちばん近い敵へ戻る。何もロックしていない状態で押すと、いちばん近い敵から始まる。
- **解除** — 右クリック。回避と同じボタンなので、回避と解除が同時に出る。キーボードとパッドには解除専用のボタンを置いていない（送りで一巡すれば元へ戻れるため）。
- **自動で外れる場合** — ロック先が倒された・浄化された・盤面の外へ出たときは、ひとりでに外れる。次に送りを押すと、またいちばん近い敵からになる。
- **代償** — ロック中は移動速度が 0.8 倍になる。照準を任せているあいだは足が重い、という取引である。

対象には照準のマーカーが出る。効果量と撃ち方の詳細は → [自機とショット](02_自機とショット.md)。

## 会話中の操作

| 操作 | キーボード | ゲームパッド（PS / Xbox） | マウス |
|---|---|---|---|
| 送る（1 回目で全文表示、2 回目で次の行） | Z / Enter / Space | 〇 / A | 左クリック |
| 既読スキップ（既読の行だけ高速送り） | Ctrl 長押し | R1 / RB 長押し | — |
| 会話中の 2 択を選ぶ | ↑↓ で選び Z で決定 | 左スティック＋〇 / A | ホバーしてクリック |

- 「オート会話送り」が ON のときは、全文が表示されてから 1.4 秒で自動的に次へ進む。
- 既読スキップは、その行が表示された時点で既読だった行にだけ効く。未読の行では止まる。
- 会話中の 2 択は、放っておくと一定秒で末尾の選択肢へひとりでに決まる。詳細は → [ステージ構成](04_ステージ構成.md)。

## ゲームオーバー時の操作

くじけると、会話中の 2 択と同じ縦積みの選択肢が盤面の中央に出る。

| 行 | 何が起きるか |
|---|---|
| （ボスからやり直す） | 直前のボス戦の頭から。**既定のカーソル位置** |
| （最初からやり直す） | そのステージの頭から |
| （ステージから抜ける） | ハブへ戻る |

↑↓ か左スティックで選び Z / 〇 A で決定。マウスならホバーしてクリック。以前からのキーもそのまま効く——R でボスから、Shift + R で最初から、Q か × B で抜ける。選択肢の下に、そのキーの案内が小さく添えられる。再開位置の詳細は → [ステージ構成](04_ステージ構成.md)。

## ポーズメニュー

ポーズメニューは二段構えである。一段目は 3 行しかない。

| 一段目 | 中身 |
|---|---|
| つづける | 即閉じる |
| このステージ ▸ | さいしょからやりなおす／会話ログ／ハブへもどる |
| 設定とデータ ▸ | マスター音量・BGM・効果音（SE）の 3 スライダー、ボタン表記、あそびかた、スロット 1〜3 へセーブ、タイトルへ |

- ↑↓ で行、←→ で音量とボタン表記、Z で決定（音量の行では Z がミュート切替）。
- 二段目からは X / 右クリック / Esc で一段目へ戻る。Esc は一段目でだけメニューを閉じる。
- 「さいしょからやりなおす」と「ハブへもどる」は、誤爆を防ぐため Z の二段階確認になっている。

## メニュー画面の操作

| 画面 | 操作 |
|---|---|
| 共通 | 決定 = Z（Enter / Space でも可）／〇 A／左クリック。もどる = X または Esc／× B／右クリック。カーソル移動 = ↑↓←→／左スティック／マウスカーソル |
| タイトル | ↑↓ で項目、Z で決定。「はじめから」の直後は操作表示の 3 択（←→ と Z） |
| ハブ | ↑↓ えらぶ／Z 潜る／C（△ / Y）返信／X（□ / X）強化／T（L1 / LB）記録。投稿カードと下段のボタンはクリックでも押せる。強化と記録は解禁されるまでボタンごと出ない |
| ショップ | ↑↓←→ えらぶ／Z 購入／C（△ / Y）装備／T トレーニング（キーボード。ヘッダの「トレーニング」ボタンはクリック可）／X（× / B）もどる |
| トレーニング | Tab でスキル欄の開閉、行クリックで付け外し、ホイール・PageUp・PageDown でスクロール、`]` 全解放／`[` 全オフ、Esc または左下「ショップへもどる」でショップへ |
| 設定 | ↑↓ 項目／←→ 調整／Q E（L1 R1 / LB RB）でカテゴリ／X・Esc で保存してタイトルへ |
| 記録 | X・Esc・T（× / B）でハブへ |
| クレジット | ↑↓ 長押し・ホイールでスクロール、X・Esc でタイトルへ |
| あそびかた | ←→（L1 R1 / LB RB）またはホイールでページ送り、X・Esc（× / B）で閉じる |
| 会話ログ | ↑↓・左スティック・ホイールでスクロール、X・Esc・L・Tab（× B / SHARE VIEW）または右クリックで閉じる |
| カットシーン（プロローグ・FINAL・エピローグ） | Z で送る。R / Start 長押し 0.45 秒でやり直し（エピローグのスタッフロール以降はタイトルへ） |

## 操作表示の切り替え

- 「はじめから」を選ぶと必ず、操作表示を「キーボード／コントローラ（PS）／コントローラ（Xbox）」の 3 択から選ぶ。設定画面の「操作表示」とポーズメニューの「ボタン表記」でも変更できる。
- 画面に出るボタン名は、直近に触った機器に自動で追従する。キーボードを触ればキー表記に、パッドを触ればパッド表記（PS か Xbox かは上の選択に従う）になる。マウスを使っている間はキーボード表記になる。
- **戦闘中の常駐操作ガイドは出ない。** 割り当ての一覧は、ポーズメニューの「あそびかた」1 ページ目でいつでも開ける。
- 設定画面の「操作」カテゴリに並ぶ割り当ての一覧は、移動・ショット（オート）・ボム・低速移動・回避・ポーズの 6 行である。表示専用で、キーの変更はできない。
