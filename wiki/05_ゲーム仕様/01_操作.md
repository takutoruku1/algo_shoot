# 操作

> **この記事の範囲**: キーボード・ゲームパッド・マウスの割り当てと、画面に出るボタン表記の切り替え。各操作で何が起きるか（速度・無敵時間・効果量）は → [自機とショット](02_自機とショット.md)、各画面で何ができるかは → [画面一覧](10_画面一覧.md)、撃ち方を決めるのは誰と潜るか → [ジョブ](12_ジョブ.md)。

## 入力機器と表記

キーボード、ゲームパッド、マウスのどれでも遊べ、遊んでいる途中で持ち替えられる。**どの機器を使うかを最初に選ばせることはしない**——画面に出るボタン名は、直近に触った機器へ自動で追従する。ゲームパッドの表記は Xbox 基準（A B X Y / LB RB / L3 R3 / MENU / VIEW）に一本化されている。

## 戦闘中の操作（ステージ・トレーニング）

| 操作 | キーボード | ゲームパッド（Xbox 表記） | マウス |
|---|---|---|---|
| 移動 | 矢印キー | 左スティック | カーソルの位置へ自機が追従する |
| 撃つ | 自動（ボタンなし） | 自動 | 自動 |
| ロックオン（掴む） | Shift 長押し（いちばん近い敵。離すまで掴んだまま） | RB（押すたび次の敵へ） | 左クリック **短押し** |
| ロックの送り（前／次） | A＝前の敵 / S＝次の敵 | RB＝次の敵 | ロック中のホイール 上＝次 / 下＝前 |
| ロック解除 | Shift を離す | R3（右スティック押し込み） | ロック中にもう一度左クリック |
| 溜め打ち | Z 長押し | Y 長押し | 左クリック **長押し** |
| 回避 ※ | Space | L3（左スティック押し込み） | 右クリック（カーソルの方向へ。カーソルが自機から 8 px 以内ならその場回避） |
| ボム | X | X | 中クリック |
| 集中モード ※ | C | LB | ホイール回転 / サイドボタン |
| ポーズメニューを開く | M / Esc | MENU | —（右クリックで閉じる） |
| 会話ログを開く | L / Tab | VIEW | —（右クリックで閉じる） |
| リトライ（最初からやり直す） | R 長押し 0.45 秒 | ポーズメニュー「さいしょからやりなおす」 | — |

※ を付けた 2 つは、**手に入れるまで押しても何も起きず、操作の一覧にも出ない**（下記「まだ持っていない操作」）。溜め打ちは最初から使える。

- 撃つボタンは無く、光は常に自動で出る。会話中・回避中・ゲームオーバー後は止まる。
- **低速移動は無い。** 速度は 1 本だけである（かつての Shift / L1 の低速は 2026-09-13 に機能ごと無くなった。空いた LB は集中モードが、空いた Shift はロックオンが使う）。
- **撃ち方を切り替える操作も無い。** どの撃ち方になるかはジョブが決める（→ [ジョブ](12_ジョブ.md)）。かつての切替キー V は無くなった（集中モードは C）。
- 会話送りに使った左クリックは、離すまでロックオンの送りとして扱われない（会話明けの 1 クリックで意図せずロックが動くのを防ぐ）。

## ロックオン

**ロックオンは撃つ方向を敵へ向ける操作である。** 押していないあいだ、ミナの光は常に右へ飛ぶ。ロック中だけ、光がロック先の敵の方向へ飛ぶ。

- **対象** — 盤面の中にいる、まだ浄化していない敵すべて。雑魚も中ボスもボスも区別しない。
- **掴む／送る** — Shift を押した瞬間、いちばん近い敵を掴む。以後 **S / RB** を押すたび自機から近い順に「今の対象の次」へ、**A** で前へ移る。一巡すると、いちばん近い敵へ戻る。マウスは未ロックのときの左クリック短押しで掴み、ロック中はホイール 上＝次／下＝前で送る。
- **解除** — **Shift を離す（キーボード）／R3（パッドの右スティック押し込み）／ロック中の左クリック**。キーボードは「押しているあいだだけ掴む」長押し方式なので、離せば必ず外れる（会話中に離しても、会話が明けてから離しても外れる）。右クリックはロックに関わらない＝回避だけである。
- **自動で外れる場合** — ロック先が倒された・浄化された・盤面の外へ出たときは、ひとりでに外れる。次に送りを押すと、またいちばん近い敵からになる。
- **代償** — ロック中は移動速度が 0.8 倍になる。照準を任せているあいだは足が重い、という取引である。

対象には照準のマーカーが出る。効果量と撃ち方の詳細は → [自機とショット](02_自機とショット.md)。

**マウスの左クリックは短押しと長押しで役目が分かれる。** 0.25 秒より短く離せばロックの取得／解除、それを超えて押し続けていれば溜め打ちの充填に変わる。

## 溜め打ち

Z 長押し／パッド Y 長押し／左クリック長押しで充填する。**0.6 秒押し切ってから離すと、通常弾より重い大玉が飛ぶ。** 威力の倍率も本数もジョブごとに違う（→ [ジョブ](12_ジョブ.md)）。クールダウンは無く、充填に掛かる時間そのものが代償である。押しているあいだは通常のショットが止まる＝撃ちながら溜めることはできない。自機の頭上に充填の進み具合が出る。

**最初から使える**（2026-09-25 に習得ゲートを廃止）。ショップの 7 段目「溜め打ち 二段」を買うと、離さずさらに押し続けたときの 2 段目が開く（→ [ショップと強化](07_ショップと強化.md)）。

## 集中モード

C ／ パッド LB ／ マウスホイールの回転 ／ マウスのサイドボタンのどれかで発動する。**敵と敵弾の時間だけが 0.35 倍になり、1.5 秒続く。** 自機の操作感は等速のままで、向かってくるものだけが遅くなる。クールダウンは 20 秒。持っているあいだは、HUD に発動キーと充填状態のチップが出る。

ホイールは押しっぱなしにできないので 1 回転ぶんのパルスとして扱われ、会話中やゲームオーバー中の回転は溜め込まれずその場で捨てられる。

ショップの 11 段目「集中モード」を買うまでは使えない。

## まだ持っていない操作

回避と集中モードの 2 つは、手に入れるまで**そのボタンを押しても何も起きず、「あそびかた」の操作一覧にも行ごと出ない**。持っていない操作を見せない、という作りである（溜め打ちは 2026-09-25 にこの扱いから外れ、最初から使える）。

| 操作 | 手に入る条件 |
|---|---|
| 回避 | ショップの 2 段目「回避」を買う（2026-09-22 までは 1 面クリアの物語報酬だった） |
| 集中モード | ショップの 11 段目を買う |

回避を買ったあと最初にステージへ入ると、冒頭の会話で操作カード（キー・方向・無敵・クールダウン）つきの説明がひととおり入る（→ [ショップと強化](07_ショップと強化.md)）。

## 会話中の操作

| 操作 | キーボード | ゲームパッド（Xbox 表記） | マウス |
|---|---|---|---|
| 送る（1 回目で全文表示、2 回目で次の行） | Z / Enter / Space | A | 左クリック |
| 既読スキップ（既読の行だけ高速送り） | Ctrl 長押し | RB 長押し | — |
| 会話中の 2 択を選ぶ | ↑↓ で選び Z で決定 | 左スティック＋A | ホバーしてクリック |

- 「オート会話送り」が ON のときは、全文が表示されてから 1.4 秒で自動的に次へ進む。
- 既読スキップは、その行が表示された時点で既読だった行にだけ効く。未読の行では止まる。
- 会話中の 2 択は、放っておくと一定秒で末尾の選択肢へひとりでに決まる。詳細は → [ステージ構成](04_ステージ構成.md)。

## ゲームオーバー時の操作

くじけると、会話中の 2 択と同じ縦積みの選択肢が盤面の中央に出る。

| 行 | 何が起きるか |
|---|---|
| （ボスからやり直す） | 直前のボス戦の頭から。**既定のカーソル位置** |
| （最初からやり直す） | そのステージの頭から |
| （ステージから抜ける） | ハブへ戻る |

↑↓ か左スティックで選び Z / A で決定。マウスならホバーしてクリック。以前からのキーもそのまま効く——R でボスから、Shift + R で最初から、Q か B で抜ける。選択肢の下に、そのキーの案内が小さく添えられる。再開位置の詳細は → [ステージ構成](04_ステージ構成.md)。

## ポーズメニュー

**2026-09-17 に階層をやめた 1 枚のダイアログになった。** ステージ中は 6 行、ステージの外では 3 行（→ [画面一覧](10_画面一覧.md)）。

| 行 | 中身 |
|---|---|
| 離脱 ※ステージ中のみ | ハブへ戻る。「はい／いいえ」の確認つき（既定は「いいえ」） |
| リスタート ※ステージ中のみ | そのステージを最初から。同じく確認つき |
| ログ ※ステージ中のみ | 会話ログ |
| セーブ | スロット 1〜3 を選んで保存 |
| ロード | スロット 1〜3 を選んで読み込み |
| タイトルへ | タイトル画面へ |

- ↑↓ で行を選び Z で決定。行の下の「閉じる」と右上の「歯車」もカーソルで選べる（マウスならクリック）。
- 歯車＝設定ページ（音量 3 種・画面モード）。X／右クリック／Esc でトップへ戻る。
- Esc はトップでだけメニューを閉じる。
- 旧版の「つづける」行・「このステージ ▸」の階層・「ボタン表記」「あそびかた」は廃止された。

## メニュー画面の操作

| 画面 | 操作 |
|---|---|
| 共通 | 決定 = Z（Enter / Space でも可）／A／左クリック。もどる = X または Esc／B／右クリック。カーソル移動 = ↑↓←→／左スティック／マウスカーソル |
| タイトル | ↑↓ で項目、Z で決定。「はじめから」はそのままプロローグへ入る（機器を選ばせる画面は出ない） |
| ハブ | ホーム画面：←→↑↓ でアプリ（SNS／強化ショップ／記録）をえらび、Z かクリックで開く。タイムライン：↑↓ えらぶ／Z 潜る／C（Y）返信／J（RB）アカウント／X（B）ホーム／T（LB）記録。投稿カードと下段のボタンはクリックでも押せる。ホームは最初の面をクリアすると現れ、強化ショップと記録のアプリは解禁されるまで鍵つき |
| ショップ | ↑↓ えらぶ／Z 買う／T ためし撃ち（ヘッダのボタンはクリック可）／X（B）もどる。段はクリックで選び、もう一度クリックで確定 |
| トレーニング | Tab でスキル欄の開閉、行クリックで付け外し、ホイール・PageUp・PageDown でスクロール、`]` 全解放／`[` 全オフ、Esc または左下「ショップへもどる」でショップへ |
| 設定 | ↑↓ 項目／←→ 調整／Q E（LB RB）でカテゴリ／X・Esc で保存してタイトルへ |
| 記録 | X・Esc・T（B）でハブへ |
| クレジット | ↑↓ 長押し・ホイールでスクロール、X・Esc でタイトルへ |
| あそびかた | ←→（LB RB）またはホイールでタブ・ページ送り、X・Esc（B）で閉じる |
| 会話ログ | ↑↓・左スティック・ホイールでスクロール、X・Esc・L・Tab（B / VIEW）または右クリックで閉じる |
| ポーズメニュー | ↑↓ で行／Z で決定。「閉じる」「歯車」もカーソルとクリックの両方で押せる |
| カットシーン（プロローグ・FINAL・エピローグ） | Z で送る。R / MENU 長押し 0.45 秒でやり直し（エピローグのスタッフロール以降はタイトルへ）。オープニング／エンディングのフィルムとスタッフロールは**長押し**でスキップ |

**マウスで押せる場所は 2026-09-17 に広がった。** 「あそびかた」のデバイスタブとページのドット、「とじる」（あそびかた・会話ログ）、「もどる」（設定・難易度選択）、そして右下の「Esc メニュー」ヒントがクリックできる。ただし**メニューのヒントが押せるのは非戦闘画面だけ**である——戦闘中は自機がマウスカーソルを追うので、誤ってメニューが開くのを避けている。

## 操作表示の切り替え

- **起動して最初に機器を選ばせる画面は無い。**「はじめから」は確認を挟まずそのままプロローグへ入る。画面に出るボタン名は、直近に触った機器へ自動で追従する——キーボードを触ればキー表記、パッドを触ればパッド表記（Xbox 基準）になり、マウスを使っている間はキーボード表記になる。
- 何も触っていない起動直後にどちらで出すかだけは、設定画面の「操作表示」（キーボード／コントローラーの 2 択）で決められる。触った瞬間から自動追従に戻る（ポーズメニューの「ボタン表記」は 2026-09-17 の作り直しで無くなった）。
- **戦闘中の常駐操作ガイドは出ない。** 割り当ては、初回だけ盤面中央の操作カードで示される（→ [画面一覧](10_画面一覧.md)）。
- 「あそびかた」の画面自体は残っているが、**ポーズメニューの作り直しで開く導線が無くなった**（画面は先頭 3 ページがキーボード／コントローラー／マウスの 3 タブ、4 ページ目が「画面の見かた」、5 ページ目が「コア機能」。マウスではデバイスタブ・ページのドット・「とじる」がクリックできる）。
- 設定画面の「操作」カテゴリに並ぶのは、操作表示・移動・ショット / 溜め打ち・ロックオン・ボム・回避・集中モード・メニューの 8 行である。割り当ては表示専用で、キーの変更はできない。
