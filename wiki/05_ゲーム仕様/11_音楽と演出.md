### ボス戦の回想（StoryFilm）の曲

回想は **memory（戦闘中・過去の傷・モノクロ）** と **aftermath（撃破後・癒えた未来・カラー）** の対で、**音も同じ対で割ってある**。キャラ 4 人 × 2 状態の 8 枠のうち 7 枠に固有曲を当て、**ミナの aftermath だけ意図的に無音**（直後の Final が「無音 → 挿入曲」の一点投入を持つので、ここで曲を足すと落差が鈍る）。7 曲すべて甘茶の音楽工房。

| 回想 | memory（傷） | aftermath（癒え） |
|---|---|---|
| レイ | 街路灯の明かり | 放課後の夕空 |
| あかり | 霧雨の彼方（道中の「6月の雨傘」と同じ天気で包む＝地続きに聞こえる） | 春の予感（雨から季節が動く） |
| こはる | ないしょのお話（山を作らない平坦さ） | 陽だまり（冷えた温度が戻る＝候補中もっとも明るい） |
| ミナ | 虚しさと星空（ミナだけニューエイジ＝人間の楽器で鳴らさない） | **無音** |

- 中ボスを倒すと道中曲に戻る。同じ曲が続く場面では鳴り直さない（やり直しでも途切れない）。
- 音量の既定は マスター 80／BGM 70／効果音 85／ボイス 90／環境音 55。

### ボス曲は投稿の札を剥がすほど開く

ボス戦の曲は**最初からは全部聞こえない**。ボスが張る投稿の札を 1 枚割るごとに、曲の高音が戻り音量も上がる——5 枚めを割ったところで曲が本来の姿になる。表向きの投稿を剥がすほど本人の声が聞こえてくる、という戦いの構図が音でも起きている。

| ボス | 札 0 枚（戦いはじめ） | 札 5 枚（剥がし切った） |
|---|---|---|
| あかり | 1,800 Hz まで削られ、音量 −5 dB。合成の刻みが 2 層かぶさる | 16,500 Hz・0 dB。刻みも厚くなる |
| こはる／レイ／ミナ | 2,400 Hz まで削られ、音量 −4.5 dB | 18,000 Hz・0 dB |

**ルナティックは投稿の割り込みそのものを出さない**ので、札という単位が存在しない。そこでルナティックだけは**最初から開き切った状態**で鳴らす（2026-09-29 の修正。それまでは割る機会が無いまま深度 0 で固定され、4 ボスとも曲がこもったまま最後まで鳴っていた）。

## エピローグの音

エピローグの音の運びは、全編でここだけ「曲が止まる」を使う（→ [エピローグ](../03_ストーリー/07_エピローグ.md)）。

| タイミング | 音 |
|---|---|
| 見上げる場面の頭 | オルゴール「夕べの星」が 2 秒かけて入る。1 周で終わる再生で、ループしない |
| 見上げる「…………。」を送り切った直後 | 0.9 秒で**完全に停止**。以降の見上げの行は無音のまま読む |
| エンディングフィルムの頭 | メニュー曲（＝主題「巡る思い出」）が 2.5 秒かけて戻る |
| スタッフロール〜END | 主題のまま、終わりの余韻を一周する |

曲が未調達のときは最初から鳴らさず、停止処理も呼ばない（空の停止で事故らせない）。

## 汚染が音に与える変化

ステージ曲とボス曲が鳴っている間だけ、汚染の値から世界の暖かさ（進行度）の 0.3 倍を引いた「濁り」に応じて、曲の高音が削られ（ローパス 16,000 Hz → 800 Hz）、環境音の濁ったパッドが −60 dB から −12 dB まで持ち上がる。汚染が高いほど曲はこもり、ステージを浄化していくほど澄んでいく。メニュー曲、改心の音、Final の挿入曲、**FINAL の道中の曲**には掛からない。

FINAL の道中を外してあるのは、ここだけ汚染が 1.0 に固定されていて（ミナの内側＝穢れが頂点）、しかも道中の頭は浄化が 0 なので、**この濁しがゲーム中で唯一 800 Hz まで振り切ってしまう**ため。ミナ戦に入るころには浄化が進んでいて 6,900 Hz あたりに収まる。

効果音はすべてゲーム内で合成されている。

| 場面 | 音 |
|---|---|
| ショット | 発射音 |
| グレイズ | かすった瞬間の閃光音 |
| 被弾 | 最優先の警告音（マスター音量以外の影響を受けない） |
| 浄化 | 敵を救った音 |
| 心の欠片を拾う | 拾うたびに半音ずつ上がる連鎖音（1 オクターブで頭打ち。ボス撃破のラッシュ中は鳴る間隔が詰まる） |
| ボム | 溜め → 開放の二段の音 |
| 会話の開始 | 場が鎮まる音 |
| スペル宣言・HP バーが割れる | 警告音 |
| パネル剥がし | 削っている間は低く小さく、剥がれた瞬間に強く |
| ボス本体へのヒット | 威力 3 以上では重い音 |
| 会話の文字送り | 2 文字に 1 回。あなたの下書きの行は木質、ミナはガラス、相手（ボス）はくぐもった音、投稿の行はごく控えめ。話者名のない語りの行は無音 |

| メニュー | 移動・決定・キャンセル・購入・拒否 |
| 溜め打ち | 段が満ちた瞬間と撃った瞬間に、段ごとに別の音と閃光（2 段目は画面振動も一回り重い 2.6／0.18 秒） |

## ルナティックでは演出が畳まれる

ルナティック（LUNATIC）では、物語の演出（会話・選択・回想フィルム・撃破後のアフター・ボス投稿の割り込み・中ボスとボスの登場シーン・FINAL の段替わりのカットシーン・改心の会話）がすべて出ない（2026-09-26）。**回想の曲 7 本と Final の挿入曲、エピローグのオルゴール、スタッフロールの曲もそこでは鳴らない**（鳴る場面ごと無いため）。クリア後はリザルトを 3 秒置いて、本編 3 面はハブへ、FINAL はタイトルへ直行する。詳細は → [難易度](08_難易度.md)。

鳴る曲のほうは、演出を畳んだぶんの穴を埋めてある。

- **ボス曲は最初から開き切って鳴る**（上記「ボス曲は投稿の札を剥がすほど開く」）。
- **FINAL の道中（47 秒前後）にも曲が入る。** ルナティックは導入の会話が無いので、タイトルカードのあとすぐ道中の曲が立ち上がる。
- 改心の会話は出ないが、**改心の解決の音は鳴る**（本編 3 面。そのままクリアのリザルトまで続く）。
