## 汚染が音に与える変化

ステージ曲とボス曲が鳴っている間だけ、汚染の値から世界の暖かさ（進行度）の 0.3 倍を引いた「濁り」に応じて、曲の高音が削られ（ローパス 16,000 Hz → 800 Hz）、環境音の濁ったパッドが −60 dB から −12 dB まで持ち上がる。汚染が高いほど曲はこもり、ステージを浄化していくほど澄んでいく。メニュー曲、改心の音、Final の挿入曲には掛からない。

## 効果音

効果音はすべてゲーム内で合成されている。

| 場面 | 音 |
|---|---|
| ショット | 発射音。やさしさ全開中は高いピッチになる |
| グレイズ | かすった瞬間の閃光音 |
| 被弾 | 最優先の警告音（マスター音量以外の影響を受けない） |
| 浄化 | 敵を救った音 |
| ボム | 溜め → 開放の二段の音 |
| やさしさ全開 | 発動音 |
| 会話の開始 | 場が鎮まる音 |
| スペル宣言・HP バーが割れる | 警告音 |
| パネル剥がし | 削っている間は低く小さく、剥がれた瞬間に強く |
| ボス本体へのヒット | 威力 3 以上では重い音 |
| 記憶のフラッシュ（あかりの改心） | 専用音 |
| 会話の文字送り | 2 文字に 1 回。少年は木質、ミナはガラス、相手はくぐもった音。話者名のない語りの行は無音 |
| メニュー | 移動・決定・キャンセル・購入・拒否 |

## 画面演出

| 演出 | 内容 |
|---|---|
| HP バーが割れる | 白いフラッシュ、バーの発光、一拍の弾み |
| ヒットストップ | 被弾 0.09 秒、改心 0.08 秒、スペル宣言 0.05 秒、ボム 0.05 秒 |
| 画面の揺れ | 被弾（強さ 5.5、0.28 秒）、ボム（4.5、0.15 秒）、ボスの着地（2.5）、ボム直撃（1.6、0.10 秒） |
| 汚染の濁り | 汚染 0.30 以上で画面の端が濁り、1.0 で最も濃くなる（中央 60 px は抜ける） |
| 当たり芯のドット | すべての敵弾の中心に白い点。ここだけが当たり判定 |
| 敵弾の見た目 | 白いリングと暗い芯にスペルごとの色。形は玉・ひし形・星・リング・針・米粒。祈り弾は暖白のハロをまとう |
| 自機の色 | 汚染が進むほど白から藍鼠へ。やさしさ全開中は金色に脈打つ |
| グレイズ | 閃光と、自機のリングが一瞬光る |
| 浄化 | 波紋（半径 46 px）と、やさしい言葉のポップ、随伴フォロワーの飛来 |
| 弾消し | 消えた弾は花びらに変わる |
| 世界の色 | 進行度に応じて寒色から暖色へ。25% / 55% / 82% で背景が 4 段階に切り替わり、ボス戦でボス専用の背景になる。改心後は背景の投稿の文言が反転する |
| ダメージ数字 | 通常ヒットは「n」、密着クリティカルは金色の「n!」、ボム直撃と直接ダメージは大きな金色、窓の上限で「MAX」、言葉の残滓は「-4%」 |
| スペル宣言 | X 風のカードが 5.0 秒。初回だけ袖のカットイン |
| 会話中 | 敵・弾・予兆が止まり、開始時に敵弾が消える。操作ガイドは薄くなる |
| HUD の退避 | 左上の HUD に敵弾が重なると薄くなる |
| 改心 | 涙の立ち絵 → 改心後の立ち絵 → 左へ退場しながらフェード |
| ボスの登場 | 右端で顔見せ → 引く → 急加速 → ブレーキで揺れ → パネル展開 |
| FINAL の背景 | ミナの HP に合わせてレイ → あかり → こはる → ミナの背景へクロスフェード |
