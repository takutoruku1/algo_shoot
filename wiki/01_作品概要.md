# 作品概要

> **この記事の範囲**: 『ALGO: Refrain of Light』が何という作品で、どんな話を、どんな遊びで語るのかの全体像。世界の仕組みは → [02 世界観](02_世界観.md)、各章の詳細は → [03 ストーリー](03_ストーリー/00_時系列.md)、操作や数値は → [05 ゲーム仕様](05_ゲーム仕様/01_操作.md)。

## 基本情報

| 項目 | 内容 |
|---|---|
| タイトル | **ALGO: Refrain of Light** |
| 副題 | 心象シューティング |
| タグライン | — その痛みに、光を届けに。 |
| ジャンル | 横スクロールの弾幕シューティング（心象シューティング） |
| 構成 | 一本道。場面ごとに「あなた」が三つの下書きから一つを送るが、分岐やマルチエンディングはなく、変わるのはミナの受けの一行と、終盤に戻ってくる言葉である |
| 規模 | 1周のクリアまで約1〜2時間の短編。クリア後は難易度を上げて周回できる |
| 難易度 | やさしい／ふつう／むずかしい、条件を満たすとルナティックが解禁 |
| 対応入力 | キーボード、ゲームパッド、マウス |
| 表示 | 内部解像度 384×216 のドット絵をウィンドウに拡大表示 |

## 一言で言うと

SNS「X」の投稿の下から聞こえる「消された言葉」を入口に、あなたが起動した AI「ミナ」が三人の心の中へ潜り、その人を苦しめている言葉を祓って、本人が書いて消した一行を返しに行く物語である。撃つのは敵ではなく、その人を縛っている言葉。救うほどミナ自身は濁っていき、三人を救い終えたとき、ミナは自分の内側へ潜ることになる。そして最後に、あなたが最初に捨てた言葉が戻ってくる。

## 物語の骨格

物語はミナのひとり漫才——相方が返事をしないので、自分で振って自分で落とす——を基調に進み、重さは各面の改心の場面と終盤にだけ置かれている。三人の面はどれも「ミナが消された一行を返す → ミナ自身の言葉で決定打を打つ」の二段で組まれ、決定打の直前で音楽が止まる。

| 段 | 章 | 何が起きるか |
|---|---|---|
| 起 | [プロローグ](03_ストーリー/01_プロローグ.md) → [チュートリアル](03_ストーリー/02_チュートリアル.md) | あなたがミナを起動し、第一声を送る。ミナは「ご主人様」と呼ぶことに決め、名前を得て、投稿の下の『たすけて』を聞く。ひとりで動き方を覚える |
| 承 | [STAGE1 あかり](03_ストーリー/03_STAGE1_レイ.md) → [STAGE2 こはる](03_ストーリー/04_STAGE2_あかり.md) | 返事の来ない「すき」を取り消し続ける会社員、推しの配信の間だけ忘れていられる高校生。ミナが消された一行を返し、証人として言い切る。二面目のあと、ミナの投稿が炎上する |
| 転 | [STAGE3 レイ](03_ストーリー/05_STAGE3_こはる.md) → [FINAL](03_ストーリー/06_FINAL_ミナ.md) | 薄くなった光で、ガワの中に隠れた配信者へ。三人分の穢れを抱えたミナの内側へ、強化のない素の光で潜る。三人の返礼のあと、最初に散った言葉が戻ってくる |
| 結 | [エピローグ](03_ストーリー/07_エピローグ.md) | 次の日もタイムラインは流れている。あなたの下書きフォルダが、最後に送った言葉で開く。四行の頭文字と、ミナの最初の一件。送り出す側が入れ替わって幕になる |

出来事の順番は [00 時系列](03_ストーリー/00_時系列.md)、仕込みと回収の対応は [08 伏線と回収](03_ストーリー/08_伏線と回収.md) にまとめてある。

## 遊びの骨格

- **ショットは自動で出続ける。** プレイヤーは移動・低速・回避・ボム・向きの反転・モード切替に集中する（→ [01 操作](05_ゲーム仕様/01_操作.md)）。
- **敵の弾は「言葉」である。** 道中の敵はその面の投稿の穢れ、ボス戦で降ってくるのは X の投稿カードの形をした言葉で、日常・病みサイン・本人の三層でできている。弾に近づく（グレイズ）ほど得をする設計になっている（→ [02 自機とショット](05_ゲーム仕様/02_自機とショット.md)、[06 その他](04_キャラクター/06_その他.md)）。
- **ボスは「倒す」のではなく「届ける」。** パネルを剥がして無防備になった一瞬に光を当てる周期を繰り返し、体力を削り切ると改心の場面に入る（→ [06 ボス戦](05_ゲーム仕様/06_ボス戦.md)）。
- **二つのゲージ。** 弾をかすめ、敵を浄化して溜まる「やさしさ」は切り札になり、物語が進むほど濁る「汚染」は画面と音を変えていく（→ [03 ゲージと経済](05_ゲーム仕様/03_ゲージと経済.md)）。
- **あなたの下書き。** 場面ごとに三つの候補から一つを送る（送らないこともできる）。選ばなかった言葉は散り、FINAL とエピローグで戻ってくる（→ [02 世界観](02_世界観.md)）。
- **タイムラインがハブ。** ステージは SNS の投稿カードとして並び、稼いだ「浄化した心」でミナを恒久強化し、道中で浄化した相手はその場で味方（随伴フォロワー）になる（→ [07 ショップと強化](05_ゲーム仕様/07_ショップと強化.md)、[10 画面一覧](05_ゲーム仕様/10_画面一覧.md)）。
