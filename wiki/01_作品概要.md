# 作品概要

> **この記事の範囲**: 『ALGO: Refrain of Light』が何という作品で、どんな話を、どんな遊びで語るのかの全体像。世界の仕組みは → [02 世界観](02_世界観.md)、各章の詳細は → [03 ストーリー](03_ストーリー/00_時系列.md)、操作や数値は → [05 ゲーム仕様](05_ゲーム仕様/01_操作.md)。

## 基本情報

| 項目 | 内容 |
|---|---|
| タイトル | **ALGO: Refrain of Light** |
| 副題 | 心象シューティング |
| タグライン | — その痛みに、光を届けに。 |
| ジャンル | 横スクロールの弾幕シューティング（心象シューティング） |
| 構成 | 一本道。選択肢による分岐やマルチエンディングはなく、伏線の回収によって物語の意味が反転する |
| 規模 | 1周のクリアまで約1〜2時間の短編。クリア後は難易度を上げて周回できる |
| 難易度 | EASY / NORMAL / HARD、条件を満たすと LUNATIC が解禁 |
| 対応入力 | キーボード、ゲームパッド、マウス |
| 表示 | 内部解像度 384×216 のドット絵をウィンドウに拡大表示 |

## 一言で言うと

SNS「X」に流れる知人の「声にならない声」を入口に、自作AI「ミナ」を相棒として大切な人の心の中へ潜り、穢れを祓って本当の言葉を届けていく物語である。撃つのは敵ではなく、その人を縛っている言葉。救うほどミナ自身は濁っていき、三人を救い終えたとき、ミナは自分の名前に込められた想いと、あの声がもう応えないことを知る。

## 物語の骨格

物語は少年とミナの軽妙な主従漫才を基調に進み、暗さは各ボスの改心の場面と終盤にだけ置かれている。笑いと喪失の落差で刺す構成である。

| 段 | 章 | 何が起きるか |
|---|---|---|
| 起 | [プロローグ](03_ストーリー/01_プロローグ.md) → [チュートリアル](03_ストーリー/02_チュートリアル.md) → [STAGE1 レイ](03_ストーリー/03_STAGE1_レイ.md) 道中 | 少年がミナを起動し、操作と目的を教える。表向きの目標「濁った3つの心を浄化する」が示される |
| 承 | STAGE1 ボス戦 → [STAGE2 あかり](03_ストーリー/04_STAGE2_あかり.md) | 知人を一人ずつ救う。救うたびにミナの汚染が静かに進み、少年の様子に小さな違和感が積もる |
| 転 | STAGE2 末 → [STAGE3 こはる](03_ストーリー/05_STAGE3_こはる.md) → [FINAL](03_ストーリー/06_FINAL_ミナ.md) | 汚染が限界を越えてミナが暴走し、少年が初めて自分で光を握る。対話で帰還するが、少年からの返事は尽きる |
| 結 | [エピローグ](03_ストーリー/07_エピローグ.md) | 少年はもう来ない。鍵のかかったアカウントの中で、三人への旅が最初から「別れを届けるため」だったことが明かされる |

出来事の順番は [00 時系列](03_ストーリー/00_時系列.md)、仕込みと回収の対応は [08 伏線と回収](03_ストーリー/08_伏線と回収.md) にまとめてある。

## 遊びの骨格

- **ショットは自動で出続ける。** プレイヤーは移動・低速・回避・ボム・向きの反転・モード切替に集中する（→ [01 操作](05_ゲーム仕様/01_操作.md)）。
- **敵の弾は「言葉」である。** 道中の敵は暴言や自責の声、ボスはその人を縛っている言葉そのものを撃ってくる。弾に近づく（グレイズ）ほど得をする設計になっている（→ [02 自機とショット](05_ゲーム仕様/02_自機とショット.md)）。
- **ボスは「倒す」のではなく「届ける」。** パネルを剥がして無防備になった一瞬に光を当てる周期を繰り返し、体力を削り切ると改心の場面に入る（→ [06 ボス戦](05_ゲーム仕様/06_ボス戦.md)）。
- **二つのゲージ。** 弾をかすめ、敵を浄化して溜まる「やさしさ」は切り札になり、物語が進むほど濁る「汚染」は画面と音を変えていく（→ [03 ゲージと経済](05_ゲーム仕様/03_ゲージと経済.md)）。
- **タイムラインがハブ。** ステージは SNS の投稿カードとして並び、稼いだインプレッションでミナを恒久強化し、道中で浄化した相手はその場で味方（随伴フォロワー）になる（→ [07 ショップと強化](05_ゲーム仕様/07_ショップと強化.md)、[10 画面一覧](05_ゲーム仕様/10_画面一覧.md)）。
