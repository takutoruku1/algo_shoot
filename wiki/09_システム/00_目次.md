# システム編 目次

> **この記事の範囲**: このゲームの「仕組み」の側を、全体像・画面の遷移・機能の目録・機能の棚卸しの4本にまとめた入口。個々の数値と細かい仕様は → [05 ゲーム仕様](../05_ゲーム仕様/01_操作.md)。物語・台詞・人物は扱わない（→ [03 ストーリー](../03_ストーリー/00_時系列.md)、[04 キャラクター](../04_キャラクター/00_相関図.md)）。

## この編は何のためにあるか

作品の仕組みは、ひとつずつ足していくうちに全体の形が見えなくなる。この編は、遊びの部品を**上から一望する**ためにある。

- 起動から結末まで、一本の筋がどう繋がっているか（→ [01 全体の流れ](01_全体の流れ.md)）
- 画面がいくつあり、どのキーでどこへ行くか（→ [02 画面遷移](02_画面遷移.md)）
- 機能がいくつあり、それぞれ今どういう状態か（→ [03 機能一覧](03_機能一覧.md)）
- そのうち、どれを捨てられるか（→ [04 機能の棚卸し](04_機能の棚卸し.md)）

[05 ゲーム仕様](../05_ゲーム仕様/01_操作.md) との住み分けは単純で、**あちらは1つ1つの中身、こちらは全体の地図**である。同じ数値を二度書かず、細部は必ずあちらへリンクする。

## まず読む順

1. **[01 全体の流れ](01_全体の流れ.md)** — 起動から結末までを一本の筋で追う。どの段で何が記録され、何が変わるか。ここを読めば、以下の3本がどこに位置づくかが分かる。
2. **[02 画面遷移](02_画面遷移.md)** — 画面の地図。図で全画面と出入りのキーを見る。到達できない画面もここで印がつく。
3. **[03 機能一覧](03_機能一覧.md)** — 機能の目録。分類ごとの表で、機能の総数と「今も動いているか」を一望する。
4. **[04 機能の棚卸し](04_機能の棚卸し.md)** — 捨てる判断のための資料。使う頻度・壊れるもの・推しを並べ、末尾に決めるべきことを置く。

## 4本の見出し

| 記事 | 何が載っているか | こういうときに開く |
|---|---|---|
| [01 全体の流れ](01_全体の流れ.md) | 起動 → 冒頭 → ハブ → 面 → 帰還 → FINAL → 結末の一本の筋。各段で遊び手がすること、記録される値。二度目に潜ったときの違い | 「この作品はどういう順で進むんだったか」を思い出したいとき |
| [02 画面遷移](02_画面遷移.md) | 全画面の遷移図（図付き）。入口と出口のキー操作。図の外に置いた到達不能な画面 | 「この画面からどこへ行けるか」「この画面はどこから来るのか」を確かめたいとき |
| [03 機能一覧](03_機能一覧.md) | 分類7つ・機能の目録。各機能の役割／状態（稼働・無効・未到達）／関連する画面 | 「どんな機能があるんだったか」を数えたいとき |
| [04 機能の棚卸し](04_機能の棚卸し.md) | 捨てる判断の資料。頻度・稼働・依存・推し。次に決めること | 「不要な機能を落としたい」とき |

## 状態の語について

[03 機能一覧](03_機能一覧.md) と [04 機能の棚卸し](04_機能の棚卸し.md) では、機能の今を3つの語で言い分ける。

| 語 | 意味 |
|---|---|
| **稼働** | 普通に遊んでいれば画面に出る。今の作品の一部である |
| **無効** | 仕組みは残っているが、切り替えの一箇所で止めてある。戻す余地がある |
| **未到達** | 仕組みはあるが、今の導線からは辿り着けない。遊び手の目に触れない |
