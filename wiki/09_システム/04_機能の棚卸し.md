# 機能の棚卸し

> **この記事の範囲**: 機能を「捨てる／残す」で判断するための資料。使う頻度・今も動いているか・捨てたときに巻き込まれるもの・推しを並べる。**推しは案であって決定ではない。** 機能の全体像は → [03 機能一覧](03_機能一覧.md)、部品ごとの数値は → [05 ゲーム仕様](../05_ゲーム仕様/01_操作.md)。

## この表の使い方

「頻度」は、普通に一周遊んだときに遊び手がそれに触る回数のおおよそ。

| 語 | 目安 |
|---|---|
| **常時** | ほぼ毎秒。触らないと遊べない |
| **毎面** | 面ごとに何度も |
| **たまに** | 一周に数回 |
| **一度** | 一周に一度きり |
| **ゼロ** | 触れない。画面に出ない |

「推し」は4つに分ける。**残す**（今のまま）／**縮める**（あるが太らせない）／**捨てる候補**（落として構わないと見える）／**要判断**（作者が決めるべき）。

## 一度も画面に出ないもの

**遊び手がまったく触れない**ので、落としても遊びは1ミリも変わらない。ここが最初に見る場所である。

| 機能 | 頻度 | 今も動いているか | 捨てると壊れるもの | 推し |
|---|---|---|---|---|
| W0 の試作面 | ゼロ | 到達しない | 無し。正典のどの画面からも呼ばれない | **捨てる候補** |
| ヒカゲ系統の敵と専用の技 | ゼロ | 到達しない | 試作面だけが呼んでいる。試作面と一緒に落ちる | **捨てる候補** |
| 随伴フォロワーの実体 | ゼロ | 止めてある | 試作面が使う。正典側では切ってある | **要判断**（下の「直近で止めたもの」参照） |
| 排他フォーク（対を選ぶと片方が封印） | ゼロ | 対が一つも設定されていない | 無し。判定は常に「封印なし」を返すだけ | **捨てる候補** |
| 振り直し（返金） | ゼロ | 呼ばれない | 排他フォークと対。片方だけ残しても意味が無い | **捨てる候補** |
| ボスラッシュ（連戦） | ゼロ | 中身が無い | 無し。構想の記述があるだけ | **要判断**（作らないなら記述ごと畳む） |

**排他フォークと振り直しは特に注意して見てほしい。** 強化の木は「買い切りのノード」に作り替えたときに排他を全部やめており、対がひとつも残っていない。つまり封印は起きず、振り直しも呼ばれない。仕組みだけが宙に浮いている。

## 直近で止めたもの — 撤去してよいか / 戻す余地があるか

2026-09-06 の判断で止めた4つ。**止めただけで、仕組みはまだ残っている。** ここを決めないと、いつまでも両方の状態を抱えることになる。

| 機能 | 止め方 | 戻す余地 | 戻さないなら何が消えるか | 推し |
|---|---|---|---|---|
| 練習面「れんしゅう」 | 切り替え一箇所で非表示。面そのものも導線も無傷で残っている | **大きい。** 切り替えを戻すだけで元の導線がまるごと復活する | 面ひとつと、そこに専用の的・段の進行・タイトルの項目 | **要判断**（下記） |
| 随伴フォロワー | 切り替え一箇所で無効 | **ある。** 戻せば戦闘中にまた増える | 自機の脇の随伴と、それを増やす条件、HUD の進捗ドット | **捨てる候補** |
| 向きの反転 | 切り替え一箇所で入力を読まない。パッドの結線は残してある | **ある。** 戻せば回避の隣に案内が戻る | 左向きに撃つ選択肢 | **捨てる候補** |
| やさしさゲージ | **機能ごと撤去済み。** 加算の呼び出しはスコアや汚染へ置き換え済み | 小さい。置き換え先が既に馴染んでいる | もう無い | **残す**（＝撤去のままでよい） |

**練習面についての観点。** これは他の3つと性格が違う。止めた結果、**操作を教える場が冒頭の会話だけになっている**。今の作品は冒頭で「読む・選ぶ・送る」を教えるが、「避ける・撃つ・回避する・ボムを撃つ」は面に入ってから覚えることになる。あそびかたの画面はあるが、読むだけで手は動かない。

- 戻すなら、切り替えを戻すだけで済む（作業はほぼゼロ）。
- 捨てるなら、面ひとつぶんが丸ごと落ちる。そのぶん「初見の遊び手はどこで手を覚えるか」を別で決める必要がある。

**随伴フォロワーと向きの反転は、戻す理由が見当たらない。** 随伴は画面の情報を増やす割に遊び手の選択が生まれず、向きの反転はこの作品が右へ攻める構造（右へ寄るほど進む）と噛み合っていない。落とすと HUD の表示も一緒に減って、画面が静かになる。

## 名前はあるが中身が薄いもの

役割が小さい、または他のもので代わりが利く。

| 機能 | 頻度 | 今も動いているか | 捨てると壊れるもの | 推し |
|---|---|---|---|---|
| グレイズ | 毎面 | 動く。ただし**スコアが入るだけ** | 何も壊れない。かすっても得が薄いので、遊び手が狙う理由が弱い | **要判断**（下記） |
| 迷った秒数 | 一度 | 積んでいる | 終盤の対句が一つ。ほぼ見えない仕掛け | **縮める** |
| 命名の道すじ | 一度 | 記録している | 冒頭の名づけの分岐。下流で強く効いてはいない | **縮める** |
| 汚染 | 毎面 | 動く。縁が濁る | 画面の縁の濁りと、送らない選択の代償。数値としては見えない | **残す**（見えないままでよい） |
| 後方弾 | 毎面 | 動く。強化なしでも弱く撃つ | 背後の敵への自動対応。**遊び手は意識していない可能性が高い** | **要判断** |
| 報酬の各種上限 | 毎面 | 動く | 稼ぎの歯止め。無くすと1発ボムの稼ぎが青天井になる | **残す** |
| 端末の設定の保存 | 一度 | 動く | 音量などが毎回戻る | **残す** |

**グレイズについての観点。** 副次効果を全部剥がしてスコアだけにした結果、**危険を冒す理由が「点だけ」になっている**。この作品には既に「回避で弾をよけると高い報酬（点・お金・コンボの猶予）」があり、そちらが攻めの主役になっている。グレイズは役割がほぼ回避と重なっていて、**同じ役割の仕組みが2つある**状態に近い。

- 残すなら、回避よけと役割を分ける理由が要る（例：狙って寄る／踏み込んでよける、の違いを何かで示す）。
- 捨てるなら、判定の輪の表示だけは残すか決める必要がある（あれは「どこまで近づけるか」を示す視認の助けでもある）。

## 重複しているもの

同じ役割の仕組みが2つ以上ある。片方に寄せられる見込みがある。

| 重なっているもの | 何が重なるか | 推し |
|---|---|---|
| 難しさを選ぶ場所（投稿の詳細 と 入口の選択） | どちらでも潜り方の4段を選べる。ハブ側が吸収したあと、入口の選択は「入口を問う」ためだけに残ったが、**段の選択もそのまま残っている** | **縮める**（入口の選択からは段を落として入口だけにする） |
| かすってよける（グレイズ と 回避よけ） | どちらも「弾に近づくと得」。回避よけのほうが報酬が厚く、無敵もある | **要判断**（上記） |
| ショップの説明 と あそびかたの3ページ | どちらもルールを言葉で説明する場。前者は一度きり、後者はいつでも | **残す**（出る場面が違うので競合しない） |
| 面の骨格（4つの面が同じ段の並びを個別に持つ） | 導入 → 波 → 中ボス → 選択 → 波 → 溜め → 波 → ボス、が面ごとに書かれている | **残す**（面ごとの差が大きく、寄せると窮屈になる） |
| セーブの経路（手動スロット と オートセーブ） | どちらも同じ持ち物を残す | **残す**（役割が違う。自動は事故を防ぎ、手動は分岐を残す） |

## 稼働していて、迷いようがないもの

以下は「捨てる」の候補に入らない。遊びの骨格そのものなので、表としては短く畳む。

| 分類 | 中身 | 推し |
|---|---|---|
| 自機の基本 | 移動・低速・連射・回避・ボム・モードの切り替え | **残す** |
| 敵とボス | 道中の各種・中ボス・盾・無防備な窓・状態機械・スペル・範囲の予告 | **残す** |
| 進行 | 面の解禁・浄化の目標・前のめり進行・クリア判定・入口 | **残す** |
| 経済 | お金・フォロワー・強化の木・トレーニング・炎上・周回の逓減 | **残す** |
| 物語の仕掛け | 下書きの選択・散った言葉・合言葉・改心の二段・小話・返信 | **残す** |
| 画面 | HUD の各表示・ボスバー・宣言カード・カットイン・ティッカー・会話ログ・背景の層 | **残す** |
| 開発用 | 自動プレイ2種・画面の切り出し・起動時の差し込み | **残す**（遊び手には出ない。維持の手間も小さい） |

**撃ち方の4モードだけは注記が要る。** 4つとも動いていて、それぞれに強化の枝が伸びている。ただし遊び手が一周で全部を使う必然性は無く、**多くは1つか2つに落ち着く**と見える。捨てるなら1つ丸ごと（枝ごと）で、部分的に痩せさせると木の形が崩れる。今は **残す** 側に置くが、枝の総数が重いと感じるならここが次の候補になる。

## まとめ — 捨てる候補に並んだもの

| 機能 | 理由 |
|---|---|
| W0 の試作面 | 到達しない |
| ヒカゲ系統の敵と専用の技 | 到達しない。試作面と一緒に落ちる |
| 排他フォーク | 対がひとつも無く、常に「封印なし」を返すだけ |
| 振り直し（返金） | 排他フォークと対。単独では意味を持たない |
| 随伴フォロワー | 止めてある。戻す理由が見当たらず、HUD の表示も一緒に減る |
| 向きの反転 | 止めてある。右へ攻める構造と噛み合っていない |

この6つを落とすと、**遊び手が触れる画面はひとつも変わらない**。触れないものと、止めたまま戻す理由の薄いものだけが減る。

## 次に決めること

- **練習面を戻すか、捨てるか。** 捨てるなら、初見の遊び手が「避ける・撃つ・回避・ボム」をどこで覚えるかを別に決める（冒頭に手を動かす一拍を足す／あそびかたを開かせる／最初の面の頭を緩くする、など）。
- **グレイズを残すか、回避よけへ寄せるか。** 残すなら、回避よけと役割を分ける理由を作る。寄せるなら、判定の輪の表示をどう扱うか。
- **入口の選択から潜り方の段を落とすか。** 投稿の詳細が既に段を持っているので、ここは入口だけにできる。
- **ボスラッシュを作るか、構想ごと畳むか。** 作らないなら、記述を残しておく理由が無い。
- **後方弾を遊び手に見せるか、静かなままにするか。** 今は自動で撃っていて、意識されていない見込みがある。強化の枝が3本ぶら下がっている割に手応えが薄い。
- **撃ち方の4モードを4つのまま持つか。** 強化の木の重さと直結する。ここを減らすなら枝ごと。
- **止めた機能を「戻せる形で残す」か「消す」か、方針をひとつ決める。** 止めたまま残す状態が続くほど、全体像は見えにくくなる。
