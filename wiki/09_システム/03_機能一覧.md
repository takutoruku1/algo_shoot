## 遊びの中核

自機のできること。詳細は → [02 自機とショット](../05_ゲーム仕様/02_自機とショット.md)。

| 機能 | 何をするか | 今の状態 | 関わる画面 |
|---|---|---|---|
| 移動 | 八方向に動く。判定は中心の赤い一点だけ | 稼働 | 面、トレーニング |
| 低速移動 | 速度を落として精密によける。判定の輪が見える | 稼働 | 面、トレーニング |
| ショット・連射 | 初期から使える基本の撃ち方。前方へ真っ直ぐ | 稼働 | 面、トレーニング |
| ショット・拡散 | 扇に広げて撃つ。1発は軽いが面を取る。ショップで解放 | 稼働 | 面、トレーニング |
| ショット・ホーミング | 曲がって当たる。数体を同時に追う。ショップで解放 | 稼働 | 面、トレーニング |
| ショット・加速球 | 溜めて放つと加速して伸びる。ショップで解放 | 稼働 | 面、トレーニング |
| モードの切り替え | 解放済みの撃ち方を順に回す。未解放は飛ばす | 稼働 | 面、トレーニング |
| 後方弾 | 背後に敵がいると自動で軽い追尾弾が出る。強化なしでも弱く撃つ | 稼働 | 面 |
| 回避 | 短い無敵つきの踏み込み。回転しながら残像を引く | 稼働 | 面、トレーニング |
| ボム | 画面の弾を払い、周りを浄化する。残数を消費する | 稼働 | 面 |
| グレイズ | 敵弾をかすめる。**スコアだけが入る**（ほかの効果は付かない） | 稼働 | 面 |
| コンボ | 続けて浄化すると倍率が乗る。猶予が切れると戻る | 稼働 | 面 |
| やさしさゲージ | かつて溜めて放つ大技だった | 無効（機能ごと撤去済み） | — |
| 随伴フォロワー | 戦闘中に自機の脇へ増えて一緒に撃った | 無効（2026-09-06 の指示） | — |

## 進行と記録

面を開き、片づけ、残す仕組み。詳細は → [04 ステージ構成](../05_ゲーム仕様/04_ステージ構成.md)、[09 セーブと周回](../05_ゲーム仕様/09_セーブと周回.md)。

| 機能 | 何をするか | 今の状態 | 関わる画面 |
|---|---|---|---|
| 面の解禁 | 物語順で次の一つだけが開く。クリア済みには何度でも潜れる | 稼働 | ハブ |
| 浄化の目標 | 面ごとに浄化する数の目標があり、届くとクリア扱いになる | 稼働 | 面 |
| 前のめり進行 | 画面の右へ寄るほど進みが速く、敵も多い。時間だけではクリアできない | 稼働 | 面 |
| ボスの撃破判定 | 盾と窓を本数ぶん通し切ると改心が始まる | 稼働 | 面 |
| チェックポイント入口 | 「最初から／中ボスから／ボスから」。倒した実績で開く | 稼働 | 入口の選択 |
| クリアの記録 | 面 × 難しさごとのベストタイムとベストスコア | 稼働 | 記録、面 |
| セーブのスロット | 手動でスロット1〜3へ。読み込みはタイトルから | 稼働 | ポーズメニュー、タイトル |
| オートセーブ | クリア・帰還・離脱で自動で残す。設定で切れる | 稼働 | 面、ハブ |
| 端末の設定の保存 | 音量・表示・会話の速さなどを端末に残す | 稼働 | 設定 |
| 既読の記録 | 読んだ会話の行を端末に残す。スロットを替えても消えない | 稼働 | 会話の出る全画面 |
| 既読スキップ | 読んだ行だけを長押しで飛ばす。未読では止まる | 稼働 | 面、ハブ、結末、エピローグ |
| 周回の逓減 | 同じ面へ連続で潜ると稼ぎが細る。別の面か上の難しさで戻る | 稼働 | 面 |
| 難しさの4段 | 弾の数・速さ・間隔・湧きの量・盾の本数・報酬の倍率が変わる | 稼働 | 投稿の詳細、入口の選択 |
| 練習面 | 操作を覚えるための独立した面 | 無効（2026-09-06 の指示。戻す余地あり） | — |

| 機能 | 何をするか | 今の状態 | 関わる画面 |
|---|---|---|---|
| インプレッション（お金） | 浄化・回避よけ・投稿を届ける・返信で貯まる。強化に使うと減る | 稼働 | 面、ハブ、ショップ |
| フォロワー | 減らない第二の値。火力と稼ぎに常時わずかに乗り、いちばん深い段の解禁条件でもある | 稼働 | ハブ、ショップ |
| 強化の木 | 根から枝分かれする買い切りのノード群。買ったものは溶けない | 稼働 | ショップ |
| 強化の親条件 | 親を買っていないと子に入れない。順路の道しるべ | 稼働 | ショップ |
| 強化の前提条件 | 一部の枝には別系統の到達が要る。既に持っているものは没収されない | 稼働 | ショップ |
| 撃ち方の解放 | 拡散・ホーミング・加速球は、それぞれの入口を買うと使えるようになる | 稼働 | ショップ |
| 汚染 | 面をまたいで持ち越すミナの濁り。強化で上がりを緩められる | 稼働 | 面 |
| 炎上 | 二面目を片づけた直後に一度だけ起き、次の1面だけ弱くする | 稼働 | ハブ、面 |
| 報酬の上限 | ボム1発で報酬が付く数、窓1回で通る量、回避よけで稼げる数に上限がある | 稼働 | 面 |
| トレーニング | 本番の持ち物を一切変えずに、強化を自由に付け外して撃ち味を比べる場 | 稼働 | トレーニング |
| ショップの説明 | 初めて中ボスを倒したときだけ出る導入 | 稼働 | ショップの説明 |
| 排他フォーク | かつて「片方を選ぶともう片方が封印される」対があった | 未到達（対が一つも設定されていない） | — |
| 振り直し | その排他の対を戻して返金する仕組み | 未到達（対が無いので呼ばれない） | — |

## 物語の仕掛け

| 下書きの選択 | 会話の途中で3つの候補から1つ送る。送らない選択もある | 稼働 | 冒頭、面、結末、エピローグ |
| 散った言葉 | 選ばなかった候補が積まれ、終盤で戻ってくる | 稼働 | 面、結末 |

| 選択の台帳 | どの場面で何を送ったかを後から引ける。下流の場面が読む | 稼働 | 面、ハブ、結末、エピローグ |
| 合言葉 | エピローグで打ち込む。正解は自分が最後に送った言葉 | 稼働 | エピローグ |

| 小話 | ハブへ戻るたび、およそ半分の確率で雑談が1本挟まる。未読を優先し、読み切ると戻して回す | 稼働 | ハブ |
| 小話の固定 | 道中で特定の言葉を送っていると、次のハブの小話が1本に決まる | 稼働 | ハブ |
| 返信 | クリア済みの投稿に返信する。1つにつきそのプレイ中1回 | 稼働 | ハブ |
