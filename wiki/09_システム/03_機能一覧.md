自機のできること。詳細は → [02 自機とショット](../05_ゲーム仕様/02_自機とショット.md)。

| 機能 | 何をするか | 今の状態 | 関わる画面 |
|---|---|---|---|
| 移動 | 八方向に動く。判定は中心の赤い一点だけ | 稼働 | 面、トレーニング |
| ショット・連射 | 前方へ真っ直ぐ。結び手の撃ち方（初期のジョブ） | 稼働 | 面、トレーニング |
| ショット・拡散 | 扇に広げて撃つ。1発は軽いが面を取る。語り手の撃ち方 | 稼働 | 面、トレーニング |
| ショット・ホーミング | 曲がって当たる。数体を同時に追う。祈り手の撃ち方 | 稼働 | 面、トレーニング |
| ショット・加速球 | 溜めて放つと加速して伸びる。灯し手の撃ち方 | 稼働 | 面、トレーニング |
| ジョブ | 潜る前に4つの型から1つ選ぶ（画面上は「アカウント切り替え」）。撃ち方・体力・間合いの利が決まり、ラン中は変えられない。結び手以外は各キャラの面のクリアで開く | 稼働 | ハブ、面 |
| 溜め打ち | ボタンを0.6秒ためて離すと威力4倍の大玉。ショップで覚える | 稼働 | 面、トレーニング |
| 集中モード | 敵と敵弾の時間だけを1.5秒ゆるめる。ショップで覚える | 稼働 | 面、トレーニング |
| モードの切り替え | かつて解放済みの撃ち方を順に回した。撃ち方はジョブが決めるようになった | 無効 | — |
| 後方弾 | 背後の敵を自動で狙う軽い追尾弾だった。**2026-09-15 に廃止**（発射だけ止めてあり、コードは残る＝戻す余地はある） | 無効 | — |
| ロックオン | 押すたび、盤面の未浄化の敵を近い順に狙う。ロック中は光がその敵へ飛び、移動が少し遅くなる | 稼働 | 面、トレーニング |
| 回避 | 短い無敵つきの踏み込み。回転しながら残像を引く | 稼働 | 面、トレーニング |
| ボム | 画面の弾を払い、周りを浄化する。残数を消費する | 稼働 | 面 |
| グレイズ | 敵弾をかすめる。**スコアだけが入る**（ほかの効果は付かない） | 稼働 | 面 |
| コンボ | 続けて浄化すると倍率が乗る。猶予が切れると戻る | 稼働 | 面 |
| やさしさゲージ | かつて溜めて放つ大技だった | 無効 | — |
| 随伴フォロワー | 戦闘中に自機の脇へ増えて一緒に撃った | 無効 | — |
| 向きの反転 | 自機の撃つ向きを左右に切り替えた。役目はロックオンが引き継いだ | 無効 | — |

道中の敵からボスまで。詳細は → [05 敵](../05_ゲーム仕様/05_敵.md)、[06 ボス戦](../05_ゲーム仕様/06_ボス戦.md)。

| 撃つ種の敵 | 面ごとに姿と撃ち方が違う。速めに直進しながら弾を撒く | 稼働 | 面 |
| 撃たない種の敵 | ゆっくり上下にうねって横切る。無口 | 稼働 | 面 |
| 回り込みの敵 | 右から出て端を走り、自機の後ろに座って撃つ | 稼働 | 面 |
| 盾もちの敵 | 撃たない・遅い・硬い。火力を測る壁 | 稼働 | 面 |
| 祈り運びの敵 | 消せる弾をぶら下げて横切る。取りこぼしの練習台 | 稼働 | STAGE2 |
| 人型の敵（テーマの12種） | 面のテーマを人の姿で演じる。各波の頭に3種が順に登場し、以後も湧きに混ざる。FINAL の残響3体もこれ | 稼働 | 面 |
| 敵の湧きの制御 | 時間で密度を上げ、難しさと自機の位置で湧きの量が変わる | 稼働 | 面 |
| 中ボス | 本物のボスが先に一度だけ割り込む。盾と窓の縮小版 | 稼働 | STAGE1〜3 |

| 無防備な窓 | 盾を全部割ると本体に傷が通る。近いほど得が大きく、1回で通せる量に上限がある | 稼働 | 面 |
| ボスの状態機械 | 待つ・移動・構える・撃つ・余韻・のけぞる、を状態として持ち、立ち位置と向きを決める | 稼働 | 面 |
| スペル | 名前つきの技。宣言してから予告が出て、遅れて来る | 稼働 | 面 |
| ボスの第二形態 | 三人のボスが体力の中盤で姿を変える。繕っていたものが剥がれる。判定・体力・弾幕は変わらない | 稼働 | STAGE1〜3 |
| FINAL の段替わり | ミナが体力の節目で衣装・舞台・弾幕・大技をまとめて替える。節目ごとに救援の場面を挟む | 稼働 | FINAL |
| 範囲攻撃の予告 | 線や円で来る場所を先に見せ、着弾の一瞬だけ当たる | 稼働 | 面 |
| 投稿弾の三層 | 降る言葉が「日常」「病みサイン」「本人」の三層で混ざる。層2は撃って届ける対象 | 稼働 | 面 |
| 引用の嵐 | 貼りついた引用を剥がす場面。剥がし残しても咎めが無い | 稼働 | STAGE3 |
| ヒカゲ系統の敵 | 初期の試作の敵。専用の技も含む | 未到達（試作面の中にしかない） | — |

| 既読スキップ | 読んだ行だけを長押しで飛ばす。未読では止まる | 稼働 | 面、ハブ、結末、エピローグ |
| 周回の逓減 | 同じ面へ連続で潜ると稼ぎが細る。別の面か上の難しさで戻る | 稼働 | 面 |

## 経済と強化

貯めて、買って、強くなる。詳細は → [03 ゲージと経済](../05_ゲーム仕様/03_ゲージと経済.md)、[07 ショップと強化](../05_ゲーム仕様/07_ショップと強化.md)。

| 機能 | 何をするか | 今の状態 | 関わる画面 |
|---|---|---|---|
| インプレッション（お金） | 浄化・回避よけ・投稿を届ける・返信で貯まる。強化に使うと減る | 稼働 | 面、ハブ、ショップ |
| フォロワー | 減らない第二の値。火力と稼ぎに常時わずかに乗り、いちばん深い段の解禁条件でもある | 稼働 | ハブ、ショップ |
| 強化の一本道 | 分岐しない13段の列。買えるのはいつも上からひとつだけで、買ったものは溶けない | 稼働 | ショップ |
| 強化の順序条件 | ひとつ上の段を持っていないと買えない。これが一本道そのもの | 稼働 | ショップ |
| 旧セーブの引き継ぎ | 旧ノードに払った総額を計算し直し、新しい列を先頭から買えるだけ自動所持にする。没収しない | 稼働 | ショップ |
| 回避の解禁 | 最初の面をクリアすると回避が手に入る。ショップでは買えない | 稼働 | 面、ハブ |
| 汚染 | 面をまたいで持ち越すミナの濁り。緩める手段はもう無い | 稼働 | 面 |
| 炎上 | 二面目を片づけた直後に一度だけ起き、次の1面だけ収入を0.6倍にする（手触りは鈍らない） | 稼働 | ハブ、面 |
| 報酬の上限 | ボム1発で報酬が付く数、窓1回で通る量、回避よけで稼げる数に上限がある。窓の上限は火力の強化を積むほど伸びる | 稼働 | 面 |
| トレーニング | 本番の持ち物を一切変えずに、強化を自由に付け外して撃ち味を比べる場 | 稼働 | トレーニング |
| ショップの説明 | 初めて中ボスを倒したときだけ出る導入 | 稼働 | ショップの説明 |
| 装備の切り替え | かつてショップで撃ち方を選び直せた。ジョブがその役目を兼ねるので無くなった | 無効 | — |
| おすすめ表示 | かつて「次に買うといい段」を金色に脈打たせて示した。一本道では買える段が常に一つなので要らない | 無効 | — |
