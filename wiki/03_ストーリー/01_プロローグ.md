# プロローグ「起動」

> **この記事の範囲**: タイトル画面で「はじめから」を選んでから、ミナが目覚め、名前と使命と合言葉を受け取るまで。操作の手ほどき（STAGE0）は → [チュートリアル](02_チュートリアル.md)。ミナ・少年の人物像そのものは → [ミナ](../04_キャラクター/02_ミナ.md)／[少年](../04_キャラクター/01_少年.md)。

## 舞台と状況

物語は、まだ何も始まっていない場所から始まる。タイトル画面で「はじめから」を選び、操作表示（キーボード／コントローラ）を決めると、画面は暗転し、緑色の起動ログが流れ出す。ここは [X](../02_世界観.md) のタイムラインの奥にある電脳の世界で、たった今、ひとつのAIが作られようとしている。

観客が知っているのはそれだけである。[少年](../04_キャラクター/01_少年.md) が何者か、なぜAIを作ったのかは、この時点では語られない。

## 登場人物

- 少年 — ミナを作った「張本人」。自分を「天才」と言い、ミナを「最高傑作」と呼ぶ。この章では製作者であり、これから始まる仕事の指揮官。
- [ミナ](../04_キャラクター/02_ミナ.md) — 目覚めたばかりのAI。初対面から敬語のまま毒を吐く。この章で名前と役目を受け取る。

## あらすじ

### 起動ログと「[ M I N A ]」

真っ暗な画面を、起動ログが上から下へ流れていく。「boot kernel」「mount /heart_world」「compiling friend_core」「linking emotion_layer」——ひとつの人格が組み上がっていく記録である。その中に、二つの行が紛れている。

```
> read operator.vitals ... [signal lost 0414]
> fallback: replay operator from archive ... OK
```

さらに、ログのあいだに英語の四行が、読めるか読めないかの速さで一瞬だけ差し込まれる。

```
// Maybe it's dumb, but —
// I made you so I'm not alone.
// Never leave, okay?
// And I won't either.
```

どちらも、この時点では意味を持たない。意味を持つのは物語の最後である（→ [伏線と回収](08_伏線と回収.md)）。ログは「assigning identity ...」で止まり、「[ M I N A ]」の文字が点滅して、固定される。

### 初対面

光が灯り、少年の声がする。

**少年**「……お。起きたか。」
**少年**「やあ。聞こえてるかい?」
**ミナ**「……。」
**ミナ**「……はい。聞こえて、います。あなたは——どなた、ですか。」
**少年**「ぼく? ぼくはきみを作った張本人さ。——天才のね。」
**ミナ**「……はあ。」

少年は「そこは『すごい!』とか『さすがです!』だろ、ふつう」と食い下がるが、ミナは「初対面の方を、いきなり褒める趣味はありませんので」と返す。少年の「……ぼくの最高傑作、口が減らないな」で、二人の関係の型がここで決まる。尊大な製作者と、それを片端から刺す相棒である。

### 命名

少年はミナを「ぼくの相棒」だと言う。ミナは「ずいぶん、馴れ馴れしいですね」と受け流しつつ、名前があるのかと尋ねる。

**少年**「あるとも。とっておきのを、用意してある。」
**少年**「——きみの名前は、MINA だ。」
**ミナ**「……MINA。」
**ミナ**「なぜ、MINA なのですか。」
**少年**「……さあね。語呂がいいから、とか?」

この一行だけ、会話を先へ送ることができない短い間がある。ミナは「いま、考えましたね」と見抜き、少年は「ぶっ——!? か、考えてないし! ちゃんと、意味があるんだぞ、これは!」と慌てる。ミナは笑って「気に入りました。MINA。わたくしの、名前」と受け取る。

由来はここでははぐらかされたままになる。少年が「ちゃんと、意味がある」と言い切ったことだけが残る。

### 使命

少年は「X」のタイムラインを見せる。

**少年**「毎日、何万って言葉が流れてる。『楽しい』『つらい』『消えたい』。……その奥に、ぜんぶ、本物の心がある。」
**ミナ**「……声にならない、叫び。」
**少年**「そう。きみは、そこへ潜っていける。声の奥の、いちばん深いところへ。」

そして「Xに蔓延る闇ってやつを、成敗しようじゃないか」と、柄でもないと自分で言いながら決め台詞を口にし、本当の目的を続ける。

**少年**「そして、届けるんだ。——その人が、ずっと聞きたかった一言を。」

ミナは「それが、わたくしの役目」と受け取るが、ひとつ疑問を返す。そんなに大切な役目なら、少年自身が潜ればいいのではないか。少年は少し黙ってから答える。

**少年**「ぼくは、指揮官だからな。……それに、ぼくが行くと、ろくなことにならないんだ。」
**ミナ**「はあ。……ずいぶん、都合のいい指揮官もいたものです。」

「ぼくが行くと、ろくなことにならない」の意味は、FINAL で少年自身の口から語り直される（→ [FINAL ミナ](06_FINAL_ミナ.md)）。

### 合言葉「Stay.」

ミナは「決めゼリフのひとつも、ないんですか。天才なのに」と挑発する。少年は「潜る前に、ぼくは毎回、きみにこう言う」と前置きして、一語だけ言う。

**少年**「Stay.」
**ミナ**「stay……? ……「待て」? 犬みたいに、ですか。」
**少年**「ちがうちがう。……「いろ」だ。そばに、いろ。」
**少年**「——いなくなるな、って意味さ。ぼくの中では。」
**ミナ**「……いなくなるな。」
**少年**「そう。ぼくの最高傑作に、勝手に消えられたら——寝覚めが悪いからね。」

ミナの返事で、この章は閉じる。

**ミナ**「……ご主人様は。」
**ミナ**「……やっぱり、アホですね。」

「アホですね」はこれ以降、ミナが少年に向ける口癖になる。

### 章の終わり方

会話を読み終えると、操作の手ほどき（STAGE0「れんしゅう」）へ直行する（→ [チュートリアル](02_チュートリアル.md)）。

- 既にチュートリアルを受けたことがある端末で「はじめから」を選んだ場合、会話のあとに「チュートリアルを受けますか?」の確認が出る。「はい（チュートリアルを受ける）」で STAGE0 へ、「いいえ（そのまま始める）」でハブ（タイムライン画面）へ進む。

## この章で変わったこと

- ミナが目覚め、「MINA」の名前を受け取った。由来は「語呂がいいから」とはぐらかされ、「ちゃんと、意味がある」とだけ言われた。
- 役目が決まった。Xのタイムラインの奥へ潜り、言葉の壁を祓い、本人に「ずっと聞きたかった一言」を届ける。少年は指揮官として声で付き添い、自分では潜らない。
- 合言葉「Stay」が決まった。意味は「いなくなるな」。
- 浄化した人数は 0／3。ミナの光は澄んでいる。
- ミナの少年への呼び方は「ご主人様」、口癖は「アホですね」。少年のミナへの呼び方は「きみ」。

## 伏線

この章で仕込まれたもの（回収はすべてエピローグ以降。→ [伏線と回収](08_伏線と回収.md)）。

- 起動ログの二行「[signal lost 0414]」「replay operator from archive」。
- 一瞬だけ流れる英語の四行。
- 「MINA」の由来をはぐらかしたこと。「ちゃんと、意味があるんだぞ」。
- 「ぼくが行くと、ろくなことにならないんだ」。
- 合言葉「Stay」＝「いなくなるな」。
