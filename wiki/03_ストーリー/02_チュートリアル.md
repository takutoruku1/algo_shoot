# チュートリアル

> **この記事の範囲**: いま実際に遊べる**初見チュートリアル**（最初のステージの道中とボス戦に挟まる会話）と、面ごとの**アンチャー紹介**。そして無効化されている旧・練習面 STAGE0「れんしゅう」の記録。操作そのものの詳細は → [操作](../05_ゲーム仕様/01_操作.md)、プロローグは → [プロローグ](01_プロローグ.md)。

## 初見チュートリアル「フェイクレルム」（2026-09-16〜17）

**いま操作を教えているのはここである。** 練習用の面ではなく、最初に潜ったステージの中で、ミナが会話として説明する。

- **流れるのは一度だけ**（セーブ単位）。道中の会話は最初にどれかの面の道中へ入ったとき、ボスの会話は最初に本ボス戦が始まったときに、それぞれの会話の末尾へ続けて出る。
- **ミナで潜っているときだけ流れる。** ほかの 3 人で潜っている間は出ず、「一度見た」の記録も消費しないので、ミナの初回で必ず見られる（→ [ジョブ](../05_ゲーム仕様/12_ジョブ.md)）。
- ゲームオーバーになっても、初ボス到達までボスぶんの説明は温存される。

### 道中の 16 行 — 世界の名前を教える

ここでこの作品の語彙が出そろう。

| 語 | ミナの説明 |
|---|---|
| **フェイクレルム** | 「偽りの世界——「フェイクレルム」。ここは、本音を隠した世界です。」 |
| **アンチャー** | 「悪い者たち——通称「アンチャー」が、ここを汚染して、本音を隠しています。」＝道中の敵 |
| **アンフォールダー** | 「アンチャーの周りを、板が回っています。あれが「アンフォールダー（苦しめる者）」。砕けば、アンチャーごと浄化できます。」 |
| **コア** | 「アンチャーの攻撃や接触を、わたくしの中心の「コア」に受けると、LIFEが減ります。」 |
| **浄化ゲージ** | 「左のパネルの「浄化」。あれが100%になれば——この偽りの世界を作った方の、本音を、引き出せます。」 |
| **心の欠片** | 「浄化したアンチャーからは、「心の欠片」がこぼれます。拾っておいてください。のちほど、必ず、役に立ちます。」 |

操作は、移動 → 自動で出る光 → ロックオン（送り）→ ロックオン解除 → ボム の順に触れる。締めはプロローグの起動記録への接続である——**ミナ**「——起動記録には、operator と、ありました。」「では。オペレータのお仕事を、よろしくお願いいたします。……ご主人様。」

**キー名はセリフに入らない。** 「どのボタンか」は盤面中央に出る**操作カード**が担当し、ミナは「何ができるか・なぜするか」だけを話す（→ [画面一覧](../05_ゲーム仕様/10_画面一覧.md)）。

### ボス戦の 5 行 — 板は蘇る

本ボスの口上の直後に続く。「あの方が、このフェイクレルムを作った、主です。」——アンフォールダーを全部砕けば本人へ浄化が届くこと、**主のアンフォールダーは時間が経つと蘇る**こと、「よみがえるたび、砕いて。——届くまで、何度でも。」を伝える。

### アンチャー紹介 — 面ごとに一度

道中へ入る直前に、**その面の敵全体の性格**だけを 3〜4 行で掴ませる（個別の種は解説しない。画面に敵名が出ないので、名指ししても照合できないため）。面ごとに一度きりで、こちらもミナで潜っているときだけ流れる。

| 面 | ミナが言うこと |
|---|---|
| STAGE 1（あかり） | 「間合いを詰めてまいります。落ちてくるもの、途中から速くなるもの。」「立っていられる場所を、少しずつ削られます。……あの方が、そうされてきたように。」「同じ場所に留まらないでください。」 |
| STAGE 2（こはる） | 「一度に、たくさん寄越してきます。」「そのくせ、置いていくだけのものも混じっています。……速いものと、遅いものが、同じ部屋に。」「来る合図は必ず出ます。合図を見てから、一歩。」 |
| STAGE 3（レイ） | 「正面から来ません。上から、まわりから、背中から。」「見られている方向が、多すぎるのです。」「光る線が走ったら、そこは通れません。……ただ、線を引いた者を先に浄化すれば、線ごと消えます。」 |

## 旧・練習面 STAGE0「れんしゅう」

> **2026-09-06 から練習面は非表示（設定で戻せる）**。プロローグの後はハブへ直行し、タイトルの「チュートリアル」も出ない。面そのものは残してあるので、以下の記述は復活させたときの内容として読むこと。

## 舞台と状況

[ミナ](../04_キャラクター/02_ミナ.md) は目覚め、名前を得て、タイムラインの下の『たすけて』を聞いたばかりである（→ [プロローグ](01_プロローグ.md)）。「この身体で、なにが出来るのか。まだ、なにも、試していませんので」——最初のダイブの前に、ひとりで動き方を確かめに行く。

教える相手はいない。画面に出るのは、そのステップで使うボタンの絵と、短い指示帯だけである。ミナが口を開くのは、二度だけ——浄化の意味を知ったときと、最後に行く先の光を見つけたときである。

画面には「れんしゅう」の帯が出る。ここは練習の場で、ゲージも残機もボムも減らず、汚染も動かない。各ステップは「ボタンの絵と指示帯 → 実際にやってみる（指示帯に n/N の進み具合）→ できたら次へ」の順で進み、どのステップも時間切れで先へ進める。

- 初めてのプレイでは、プロローグの会話を読み終えると自動でここに入る。
- 既にチュートリアルを受けたことがある端末では、プロローグの後に「チュートリアルを受けますか?」と確認され、「いいえ」を選ぶとここを飛ばしてハブへ行く。
- タイトル画面の「チュートリアル」からも、いつでも受け直せる（難易度はやさしい固定）。

![れんしゅうの画面。自機の下にボタンの絵「移動 矢印 / WASD」と、指示帯「上下左右を それぞれ1秒くらい 押してみよう（0/4）」が出ている](../08_仮台本/図/v3/ingame_bg2_practice.png)

## 登場人物

- ミナ — 教わる側であり、教える側でもない。指示帯に従って自分の身体を試し、二行だけ言葉にする。
- あなた — ご主人様。この章では下書きの選択はなく、操作だけをする。

## あらすじ

### 起 — 暗い場所で、ひとつずつ

画面はうっすらと暗く沈み、そのステップで見るべき場所だけが照らされる。ミナは何も言わず、指示帯だけが更新されていく。

1. **移動** — 「上下左右を それぞれ1秒くらい 押してみよう（n/4）」。四方向をそれぞれ押し続けると次へ。
2. **光（ショット）** — 「ダミーに 光を あてて たおそう（n/3）」。光は勝手に出続ける。何も撃たない練習の的が一体ずつ湧き、三体倒すと次へ。
3. **回避** — 「いろんな方向に 回避してみよう（n/3）」。一瞬だけ無敵になって弾を抜ける。三度成功すると次へ。**回避をまだ持っていなければ、この段は丸ごと飛ばされる**（回避は最初の面をクリアして手に入るため、初回はここを通らない）。
4. **ボム** — サイドパネルの残機とボムの表示が照らされる。「ダミーを 3体まとめて X のボムで（n/3）」。固まって出る三体をひとつのボムで巻き込む。押すだけでは進まず、巻き込めなければ的が置き直される。

### 承 — 倒すのではなく、届ける

浄化のステップに入ると、サイドパネルの「浄化」の表示が照らされ、ミナがここで初めて口を開く。

**ミナ**「倒すのではなく、届ける。……これが、わたくしの役目なんですね。」

続けて「浄化した心」の表示が照らされる。「ダミーの敵を 浄化してみよう（n/2）」——言葉の板を回している的の板を全部剥がすと、奥の本体に光が届いて浄化になる。浄化するたびに「浄化した心」が貯まる。これが、以後の全ステージでミナが行うことの要約である（→ [世界観](../02_世界観.md)）。

### 結 — 行く先の光

すべてが終わると、画面がまた少し暗くなり、ミナが二行目を言う。

**ミナ**「……あ。暗闇に、ひとつ。行く先の光が、灯りました。」

読み終えると、ハブ（タイムライン画面）へ移る。この時点で、チュートリアルを受けたことが端末に記録される。

### ハブへ

ミナのアカウント「@mina_ai_」のタイムラインに、三枚の投稿カードが並ぶ。

- [あかり](../04_キャラクター/04_あかり.md) @akari. 「すき、すき、すき。……ひとつでいいから、本物になって。」 — **NEW**
- [こはる](../04_キャラクター/05_こはる.md) @koharu — LOCKED
- [レイ](../04_キャラクター/03_レイ.md) @rei_____ — LOCKED

![初めてのハブ。あかりの投稿だけが NEW で開き、こはるとレイは「ロック中 — まだダイブできません」](../08_仮台本/図/v3/ingame_hub_order.png)

初めてハブに入ったとき、あかりの投稿を前にミナが一度だけ口にする。

**ミナ**「……この投稿の下から、も。聞こえます。……何度も、同じ画面を開く音、みたいな。」
**ミナ**「行きます。——放っておけないので。」

選べるのはあかりの投稿だけである。ここから最初のダイブが始まる（→ [STAGE1 あかり](03_STAGE1_あかり.md)）。ハブの画面構成は → [画面一覧](../05_ゲーム仕様/10_画面一覧.md)。

## この章で変わったこと

- ミナが動き方・光の出し方・ボム・浄化を、ひとりで覚えた（回避はまだ持っていないので、この時点では習わない）。
- 「倒すのではなく、届ける」という、以後の全ステージの行動原理が、ミナ自身の言葉になった。
- 暗闇に「行く先の光」が灯り、ハブに着いた。
- 浄化した人数は 0／3 のまま。ミナの光は澄んでいる（練習のため汚染は動かない）。
- ハブに着き、あかりの投稿だけが「NEW」で開いている。

## 伏線

この章に新しい仕込みはない。プロローグの「あの声は——わたくしが、覚えておきます。」を抱えたまま、ミナは最初の投稿へ潜る（→ [伏線と回収](08_伏線と回収.md)）。

## 主要な台詞

**ミナ**「倒すのではなく、届ける。……これが、わたくしの役目なんですね。」
**ミナ**「……あ。暗闇に、ひとつ。行く先の光が、灯りました。」
**ミナ**「行きます。——放っておけないので。」（ハブ）
