## この wiki の約束

1. **ゲーム本体が正典。** 台詞・数値・画面の名称はすべてゲーム内の表記どおりに書く。設定資料は、ゲーム内に現れない背景（名前の由来や過去の出来事）を補うためにだけ使う。
2. **今の作品だけを書く。** 検討中の案・将来の予定・以前の設定は載せない。
3. **記事は1テーマ。** 他の記事の領分に触れるときはリンクで示し、同じ内容を二度書かない。
4. **物語は着地点まで書く。** 「始まる」で終わらせず、その章で何が決着し、何が変わったかまで記す。
5. **表記の統一。** 作品名は「ALGO: Refrain of Light」。人物は 少年 / ミナ / レイ / あかり / こはる。
